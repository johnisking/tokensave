"한도에 도달했습니다"는 한때 ChatGPT에서 가장 흔한 불만이었습니다. 2026년에는 규칙이 많이 바뀌었습니다. 일상적인 텍스트 대화는 이제 Free와 Go에서 한도가 없고 Plus는 한도가 늘었지만, 최신 모델, ChatGPT Work와 Codex, 파일 업로드, 이미지, 음성에는 여전히 한도가 있습니다. 요금제별로 무엇이 제한되는지, 한도가 어떻게 초기화되는지, 내 사용량은 어떻게 확인하는지 정리했습니다.

## 텍스트 대화: 2026년 8월부터 Free·Go는 한도 없음

2026년 8월 6일, OpenAI는 그다음 주부터 **Free와 Go** 요금제의 텍스트 대화를 무제한으로 바꾸고, 어려운 질문용 "Think" 버튼을 넣는다고 발표했습니다. Plus는 메시지와 업로드가 "확대"되지만 한도는 있습니다. 2026년 10월 7일부터 채팅 모델은 Plus, Pro, Business, Enterprise가 GPT-6 Sol, Free와 Go가 GPT-6 Luna입니다. 다만 무제한 대화에도 남용 방지 장치가 적용되어, 자동화된 사용이나 극단적인 사용은 속도가 제한될 수 있습니다.

그러니 Free나 Go에서 평범한 텍스트 메시지만 보낸다면 이제 메시지 한도를 볼 일은 없습니다.

## 아직 제한이 있는 것

![아직 제한이 있는 것: 기능, 제한 여부](/chatgpt-sayongnyang-hando-ko-2.jpg)

| 기능 | 제한 여부 |
|---|---|
| 일상 텍스트 대화 | Free·Go는 없음 (2026년 8월부터), Plus는 확대되었지만 한도 있음 |
| 파일 업로드, 이미지 생성, 음성 | 있음, 요금제별로 따로 |
| 높은 생각 수준과 Pro 모델 | 있음, 요금제에 따라 |
| ChatGPT Work와 Codex (GPT-6 Astra 포함) | 있음: 포함된 사용량, Plus·Business는 5시간 단위 한도 |

**요금제별 생각 수준.** Plus는 GPT-6 기반의 고급 추론 모델을 쓸 수 있습니다. Pro는 여기에 GPT-6 Astra로 돌아가는 Pro 추론 옵션과 Pro 전용인 GPT-5.6 Sol Pro가 추가됩니다.

## GPT-6 Astra 한도

![GPT-6 Astra 한도: 요금제, 5시간당 GPT-6 Astra 메시지](/chatgpt-sayongnyang-hando-gpt-6-astra-ko.jpg)

OpenAI의 플래그십 모델인 GPT-6 Astra는 ChatGPT Work와 Codex에서 씁니다. OpenAI 고객센터는 5시간 단위당 예상 로컬 메시지 수를 다음과 같이 안내합니다.

| 요금제 | 5시간당 GPT-6 Astra 메시지 |
|---|---|
| Plus | 약 5–45 |
| Standard Business | 약 5–45 |
| Pro 100 / 200 / 500 | 현재 5시간 단위 한도 없음 |

범위가 넓은 이유는 길고 여러 단계를 거치는 작업 하나가 짧은 작업보다 사용량을 훨씬 많이 쓰기 때문입니다. 주간 한도가 추가로 적용될 수 있습니다. Pro 요금제는 현재 Work와 Codex에 5시간 단위 한도가 없지만 포함된 사용량은 있고, 등급이 높을수록 더 많습니다. 신규 구독자 기준으로 Pro 200은 Plus의 10배, Pro 500은 Plus의 25배입니다(2026년 9월 22일~9월 29일 사이에 Pro 200 구독이 활성 상태였다면 10월 29일까지 예전 사용량이 유지됩니다). 배수는 OpenAI 공식 페이지가 아니라 OpenAI 티보 소티오(Thibault Sottiaux)의 X 글과 보도(WinBuzzer, Windows Report) 기준입니다. [ChatGPT Pro 100 vs 200 vs 500](/ko/blog/chatgpt-pro-yogeumje-bigyo)을 참고하세요.

## 한도가 초기화되는 방식

![한도가 초기화되는 방식: 5시간 단위; 주간 한도; 파일, 이미지, 음성](/chatgpt-sayongnyang-hando-ko-4.jpg)

- **5시간 단위:** 하루 중 정해진 시각이 아니라, 그 구간에서 첫 요청을 보낸 시점부터 계산되는 롤링 방식입니다. Plus와 Business에 적용되며, Pro 100, Pro 200, Pro 500은 현재 Work와 Codex에 5시간 단위 한도가 없습니다.
- **주간 한도:** OpenAI는 주간 한도가 추가로 적용될 수 있다고 안내합니다.
- **파일, 이미지, 음성:** 각각 별도의 사용량이 있습니다.

## 사용량 확인하는 법

OpenAI 고객센터는 **Settings → Usage**를 안내합니다. 여기서 Work와 Codex의 남은 사용량과 초기화 시각을 볼 수 있습니다. 한도에 걸리면 ChatGPT가 언제 다시 이어 쓸 수 있는지도 알려 줍니다.

## 한도에 걸렸을 때

1. **초기화를 기다립니다.** 5시간 단위 한도라면 보통 길어야 몇 시간입니다.
2. **리셋이나 크레딧을 씁니다.** 자격이 되는 Plus와 Pro 계정은 적립된 리셋을 쓰거나 즉시 리셋을 구매할 수 있고, 일부 요금제는 크레딧으로 계속 쓸 수 있습니다.
3. **모델을 바꿉니다.** 일상적인 작업에는 GPT-6 Astra가 필요한 경우가 드뭅니다. GPT-6 Sol이나 GPT-6 Luna는 사용량을 훨씬 적게 씁니다.
4. **업그레이드합니다.** Pro 100은 Plus의 5배, Pro 200은 10배, Pro 500은 25배입니다.
5. **API를 씁니다.** 특정 모델을 꾸준히 많이 쓴다면 토큰당 요금을 내는 편이 더 간단할 수 있습니다. GPT-6 Astra는 입력 100만 토큰당 $10, 출력 100만 토큰당 $50입니다. [GPT-6 API 가격](/ko/blog/gpt-6-api-gagyeok)을 참고하세요.

## 대화마다 "토큰 한도"가 있나요?

모든 모델에는 컨텍스트 윈도가 있습니다. 한 번에 고려할 수 있는 텍스트의 최대량입니다. 아주 긴 대화나 문서는 결국 여기에 닿고, 그 전에도 품질이 떨어집니다. 모델이 메시지마다 대화 전체를 다시 읽기 때문입니다. 짧은 요약과 함께 새 대화를 시작하면 생각보다 효과가 큽니다. [컨텍스트 윈도 설명](/blog/context-window-explained) (영어)을 참고하세요.
