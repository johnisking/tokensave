AIサイトはすでに数千を超えますが、その多くは同じいくつかのモデルに外見をかぶせただけのサービスです。この記事では **本当にブックマークしておく価値があるものだけ** を選びました。どれもひとつの仕事をしっかりこなし、**無料で始められる** サイトです。

無料プランや利用上限はよく変わります。以下の「無料」は「お金を払わずに試せる」という意味で、詳しい条件は各サイトで確認してください。

## AIチャット

**ChatGPT**（chatgpt.com）は今でも多くの人が最初に使う場所です。文章作成、質問、画像、ファイル、音声までひとつのアプリでこなせて、無料プランでもAIで何ができるかを十分に体験できます。

**Claude**（claude.ai）は文章が長いときに試してください。契約書、レポート、コード一式のような長い資料をうまく扱い、細かい指示に忠実で、わからないことはわからないと言う傾向があります。

**Gemini**（gemini.google.com）はGoogleのアプリをよく使う人に向いています。Gmail・Googleドキュメント・ドライブと連携でき、Androidにも入っています。

**Microsoft Copilot**（copilot.microsoft.com）は、WindowsやOfficeを中心に使う人向けの選択肢です。

全部使う必要はありません。毎日使うものをひとつ決め、行き詰まったとき用にもうひとつあれば十分です。有料プランを迷っているなら、[サブスク vs API 計算機](/ja/plans)で自分の使い方に月額プランが見合うか確認してみてください。

## 調べもの・勉強

**Perplexity**（perplexity.ai）は文章で答えてくれる検索エンジンで、すべての内容に出典リンクを付けてくれます。答えだけでなく事実確認が必要なときに使いましょう。

**NotebookLM**（notebooklm.google.com）は、自分がアップした資料（PDF、メモ、Webページ、YouTube動画）だけを見て答えます。資料の外の内容をでっち上げる可能性がずっと低く、資料の束を学習ノートや短い音声まとめに変えることもできます。試験勉強や会議資料の整理に特に便利です。

## 文章・翻訳

**DeepL**（deepl.com）は自然な翻訳で知られ、WordやPDFのファイルをレイアウトそのままで丸ごと翻訳できます。

**日本語でプロンプトを書く人へのヒント：** AIは同じ内容でも、日本語で書くと英語より **約1.79倍** のトークンを使います。[TokenSaveのトークンカウンター](/ja/)で **💸 トークン節約** ボタンを押すと、プロンプトを端末の中で英語に翻訳し、最後に "Reply in Japanese." を付けてくれます。回答は日本語のまま、トークンを約44％減らせます。測定の詳細は[日本語は英語よりトークンがどれだけ多いか](/ja/blog/nihongo-tokens-gpt)にあります。

## 画像・デザイン

**Canva**（canva.com）は、サムネイル、スライド、SNS画像をいちばん速く作れる方法です。デザインの中でAIを使って画像を作り、背景を消し、文章を書き直せます。

**remove.bg**（remove.bg）はひとつのことだけをします。写真をアップすると数秒で人や物だけをきれいに切り抜いてくれます。

AI画像をたくさん作るなら、モデルによって1枚あたりの価格は10倍以上違います。[AI画像コスト計算機](/ja/image)で Nano Banana、GPT Image、FLUX などをまとめて比べてみてください。

## 音声・音楽・動画

**ElevenLabs**（elevenlabs.io）は本物の人の声と区別しにくいAI音声を作ってくれます。日本語にも対応していて、ショート動画のナレーションや吹き替えによく使われます。

**Suno**（suno.com）は、曲の雰囲気とテーマを数行書くだけで、歌詞と歌まで入った曲を作ってくれます。

**CapCut**（capcut.com）は自動字幕、背景削除、テンプレートがそろった無料の動画編集アプリです。ショート・リール・TikTokを作る人に人気です。

AI動画生成はいちばん費用がかさみやすい分野です。クレジットを使う前に、[AI動画コスト計算機](/ja/video)で同じ動画が Veo、Kling、Runway などでそれぞれいくらかを確認しましょう。

## もう少し深く使いたい人へ

**LMArena**（lmarena.ai）では、ひとつの質問を名前を隠した2つのモデルに送り、良いほうに投票します。この投票でできたランキングは、AIモデルの順位として最もよく引用される資料のひとつです。

**Hugging Face**（huggingface.co）はオープンソースのAIモデルが集まる場所です。Spacesでは、インストールなしでブラウザから多くのモデルをすぐに試せます。

**Google AI Studio**（aistudio.google.com）は、開発者が Gemini モデルを自分のプロンプトで試し、APIキーを取得するいちばん速い方法です。

## AIの費用を知って使う：TokenSave

上のサイトの多くは、いずれは **使った分だけ** お金がかかります。**[TokenSave](/ja/)** は、その費用がいくらになるかを示す無料の計算機セットです。

- **[トークンカウンター](/ja/)：** 文章を貼り付けると、GPT・Claude・Gemini のモデルごとのトークン数と費用が出ます。日本語のプロンプトを英語にしてトークンを減らす機能もあります。
- **[サブスク vs API](/ja/plans)：** ChatGPT Plus、Claude Pro、Gemini のサブスクが従量課金より安いかを比べます。
- **[コーディングエージェント費用](/ja/agents)：** Claude Code、Codex、Gemini CLI を API で使うとタスクあたりいくらかを計算します。
- **[画像](/ja/image)・[動画](/ja/video)コスト計算機：** モデルごとの1枚あたり・1秒あたりの価格を比べます。

すべてブラウザの中で動き、登録は不要で、41言語に対応しています。

## 選び方

1. **AIチャットはひとつから始める。** ChatGPT、Claude、Gemini のどれかで大半は解決します。
2. **メインの作業に合うツールをひとつ足す。** 調べものは Perplexity、翻訳は DeepL、デザインは Canva、動画は CapCut。
3. **無料プランで足りなくなったときだけ払う。** そのときも、サブスクと API のどちらが安いかを先に確認しましょう。
