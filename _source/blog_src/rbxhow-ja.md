![Robloxゲームの作り方：インストールからAIで最初のゲームまで【2026】](/roblox-game-tsukurikata-ja.jpg)

Robloxゲームの作り方を調べると「プログラミングができなくても大丈夫」という話がよく出てきますが、実際にRoblox Studioを初めて開くとボタンが数十個並んでいて、どこから手をつければいいのか迷います。この記事では、Roblox Studioを初めてインストールした日に、ブロックを1つ置くところから、AIアシスタントで踏むと消える飛び石コースを作り、無料の車のアセットを入れて走らせるところまで、実際に進めた画面を順番にまとめました。途中でスクリプトを入れる場所を間違えてつまずいた部分とその原因もそのまま載せています。動作環境や公開条件など変わる可能性がある情報は、2026年10月13日にRobloxの公式ドキュメントで確認しました。

![Robloxクリエイターハブのトップ画面と「作成を始める」ボタン](/roblox-game-tsukurikata-hub-ja.jpg)

## Robloxゲームを作る前に必要なもの

Robloxのゲームは**Roblox Studio**という無料アプリで作ります。公式ドキュメントに書かれている動作環境は次のとおりです。

| 項目 | 最低 | 推奨 |
|---|---|---|
| OS | Windows 10、macOS 10.14 | Windows 11、macOS 14以降 |
| メモリ（RAM） | 3GB | 8GB |
| 画面解像度 | 1600×900以上 | 1600×900以上 |
| 料金 | 無料 | 無料 |

Robloxのアカウントも必要です。遊ぶときに使っているアカウントがあればそのまま使えて、なければインストールの途中で作れます。公式ドキュメントでは、Roblox Studioは**WindowsとMacのみ**対応です。スマホやiPadで作る方法は、後半の「スマホでRobloxゲームを作る：Build」で紹介します。

## ステップ1：Roblox Studioのインストールとログイン

1. クリエイターハブ（create.roblox.com）で**作成を始める**を押し、**Studioをダウンロード**を押します。
2. Windowsは`RobloxStudioInstaller.exe`、Macは`RobloxStudio.dmg`がダウンロードされます。Windowsでは実行前にセキュリティの確認が出るので、発行元がRoblox Corporationであることを確かめて実行します。
3. インストールが終わるとStudioが開き、ログイン画面が表示されます。

![Roblox Studioのログイン画面](/roblox-game-tsukurikata-login-ja.jpg)

**ログイン**を押すとブラウザが開きます。アカウントがなければ**アカウント作成**を押し、生年月日、ユーザー名、パスワードを入れて登録します。ユーザー名の欄には「本名を使わないで」という案内が出ます。

![Robloxのアカウント作成画面](/roblox-game-tsukurikata-signup-ja.jpg)

登録が終わると「Roblox Studioに進む」画面と利用規約の同意画面が続けて出て、同意するとStudioに戻ってスタート画面が開きます。最初にツアーをすすめる画面が出ますが、飛ばしてもかまいません。

## ステップ2：テンプレートを選ぶ

スタート画面の**新規**または**テンプレート**を押すと、あらかじめ作られたマップが並びます。私の画面に出たテンプレートは15種類でした。

![Roblox Studioのテンプレート一覧](/roblox-game-tsukurikata-templates-ja.jpg)

| 種類 | テンプレート |
|---|---|
| 空のマップ | Baseplate、Classic Baseplate、Flat Terrain |
| ゲームジャンル | Platformer、Laser Tag、FPS System、Racing、Classic Obby |
| 街・背景 | Village、Castle、Suburban、Pirate Island、Starting Place、Modern City |
| その他 | UGC Homestore |

初めてなら**Baseplate**がいちばんわかりやすいです。床とキャラクターが出てくるスポーン地点しかないので、自分が何を置いたのかがすぐにわかります。障害物レース（オビー）を作りたいならClassic Obby、レースゲームならRacingを開いて手を入れるほうが早く進みます。

## ステップ3：ブロックを置いて色を変える

![Baseplateでスポーン地点の色を変えた画面](/roblox-game-tsukurikata-editor-ja.jpg)

Studioの画面は大きく4つに分かれています。

- **中央の3D画面：** ゲームのマップです。マウスの右ボタンを押したままドラッグすると視点が回り、W・A・S・Dで移動します。
- **上のホームタブ：** パーツ（ブロック）の追加、移動、スケール、回転、カラー、アンカーのボタンがあります。
- **右のエクスプローラー：** マップに入っているものがツリーで表示されます。Workspaceの下にあるものが、実際にマップに置かれているものです。
- **右下のプロパティ：** 選んだものの色（Color）、素材（Material）、透明度（Transparency）などを変えます。

ホームタブの**パーツ**を押すと灰色のブロックが出てきます。プロパティのColorを押すと色の選択画面が開くので、試しにスポーン地点を黄緑色に変えてみました。ブロックが転がったり押されたりしないように、上の**アンカー**（いかりのアイコン）をオンにしておきます。上の青い▶を押すと、自分のキャラクターですぐにテストできます。

## ステップ4：スクリプトを入れる、そして最初につまずいたところ

ブロックに動きをつけるには**スクリプト**が必要です。RobloxではLuau（ルアウ）という言語を使います。踏むと半透明になり、1秒後に消えるブロックのコードは次のとおりです。

```lua
local part = script.Parent
local touched = false

part.Touched:Connect(function(hit)
	if touched then return end
	local humanoid = hit.Parent:FindFirstChildOfClass("Humanoid")
	if humanoid then
		touched = true
		part.Transparency = 0.5
		task.wait(1)
		part:Destroy()
	end
end)
```

入れ方は、エクスプローラーでブロック（Part）にマウスを乗せて**＋ → Script**を選び、開いた編集画面の`print("Hello world!")`を消してこのコードを貼り付けるだけです。

言葉にすると簡単ですが、私は実際にここでつまずきました。テストを押してもブロックが消えず、出力画面には赤い文字でこんなエラーが出ました。

![Touched is not a valid member of Workspace のエラーが出た出力画面](/roblox-game-tsukurikata-error-ja.jpg)

原因は3つ重なっていました。

| 症状 | 原因 | 直し方 |
|---|---|---|
| `Touched is not a valid member of Workspace` | スクリプトがブロックの中ではなく、Workspaceの直下に入っていた | エクスプローラーでScriptをドラッグしてPartの上に置く |
| 最後の行の1文字のミス | 貼り付けるときに`s`が1文字余計に入った | 消す（1文字でもスクリプト全体が止まる） |
| 直した内容が消える | テスト（▶）中に直していた | 赤い■でテストを止めてから直す |

エクスプローラーで何がどこの下に入っているかが、最初はいちばんわかりにくいところです。やり直したときも、今度はスクリプトが床（Baseplate）の下に、新しいブロックはTextureの下に入ってしまいました。そこで「もっと簡単な方法」に切り替えました。それが次のAIアシスタントです。

## ステップ5：RobloxのAIアシスタントでゲームを作る

Roblox Studioには**アシスタント（Assistant）**というAIが入っています。公式ドキュメントによると、質問に答えるだけでなく、オブジェクトやスクリプトの作成・修正、クリエイターストアのアセットの挿入、3Dモデルの生成までできます。画面のいちばん上の列の右にある**アシスタント**ボタンを押すと、右側にチャット画面が開きます。

![Roblox Studioでアシスタント画面を開いたところ](/roblox-game-tsukurikata-assistant-ja.jpg)

日本語でそのまま頼めます。私が送った依頼は4つでした。

1. 「赤いブロックを1つ作ってスポーン地点の前に置き、プレイヤーが踏んだら半透明になって1秒後に消えるようにして」
2. （修正）消えたブロックが元に戻るリスポーン機能を追加
3. 10個がつながるように飛び石の形で作成
4. （修正）10個すべてに1つ目のブロックと同じ機能と、リスポーン機能を入れるよう依頼

![アシスタントが作った赤いブロック](/roblox-game-tsukurikata-redblock-ja.jpg)

依頼1つあたり**15〜30秒**ほどでした。ステップ4で手作業ではうまくいかなかった「踏むと消えるブロック」が最初の依頼1回でできあがり、ブロックもスクリプトも正しい場所に入っていました。

3つ目の依頼のあと、アシスタントは作った内容をこうまとめてくれました。ブロックの大きさは3×1×3、ブロックの間は4スタッドでジャンプして渡れる間隔、スポーン地点の前から一列に10個です。新しいブロックはRedSteppingStonesというフォルダーにまとめたうえで、「この飛び石にも、踏むと消えて再生成される機能を入れますか？」と先に聞いてきました。

![アシスタントが作った赤い飛び石10個](/roblox-game-tsukurikata-stones-ja.jpg)

4つ目の依頼まで終えると、踏むと半透明になり、1秒後に消え、3秒後に同じ場所に戻ってくる飛び石コースが完成しました。

![飛び石を踏むとブロックが消えていく様子](/roblox-game-tsukurikata-stones-ja.gif)

![一人称視点で飛び石を渡るテスト画面](/roblox-game-tsukurikata-stones-play-ja.jpg)

スクリーンショットの時刻で見ると、アシスタントを最初に開いてから10個の飛び石を渡るテストまで約15分でした。自分でスクリプトを入れて迷っていた時間より短く済みました。

**依頼をうまく書くコツ。** Robloxの公式Buildガイドでも、ゲームの遊び方を具体的に書くようすすめています。最初の依頼のように、色・位置・動き・時間まで1文に入れておくと、あとから直す回数が減ります。

## ステップ6：保存する

作ったゲームは2通りの方法で保存できます。

- **ファイル → 名前を付けて保存：** 自分のパソコンに`.rbxl`ファイルとして保存します。私はこの方法でダウンロードフォルダーに保存しました。
- **ファイル → 公開（Publish）：** Robloxのクラウドに上げて自分のアカウントに結びつけます。別のパソコンからも続きを作れます。公開しても最初は自分と編集権限のある人しか入れません。

## 無料アセットで車を入れてみる

左の**ツールボックス**にあるクリエイターストアで、ほかの人が作ったモデルを検索して入れられます。無料のものが多く、有料のものもあります。試しに無料の「Drift Car mobile」を入れてみると、メーター付きの車がそのまま運転できました。

![クリエイターストアから無料の車のアセットを入れた画面](/roblox-game-tsukurikata-car-store-ja.jpg)

![無料の車のアセットを運転するテスト画面](/roblox-game-tsukurikata-car-drive-ja.jpg)

ただし、ほかの人が作ったモデルにはスクリプトが入っていることが多いです。入れたあとはエクスプローラーで、どんなスクリプトが一緒に入ってきたかを一度確認しておくと安心です。

## RobloxのAIは無料？使用量・APIキー・MCP

アシスタント画面右上の**…**メニューからアシスタント設定を開くと、使用量、APIキー、MCPサーバー、スキルの4つのタブがあります。

![アシスタント設定の使用量画面、無料使用量を6%使用](/roblox-game-tsukurikata-usage-ja.jpg)

**使用量。** 無料使用量のバーがあり、上の4つの依頼（ブロック、リスポーン、飛び石、飛び石の機能）を終えたあとで**6%使用済み**、**6日後にリセット**と表示されていました。無料分を使い切ったらRobuxで追加の使用量を買う設定をオンにでき、1日の支出上限も決められます（私の画面ではこの設定はオフで、上限の欄には500 Robuxと表示されていました）。公式ドキュメントには無料使用量が正確にどれくらいかは書かれていないので、この6%は「この程度の作業でこれくらい使う」という目安として見てください。

![アシスタント設定のAPIキー画面](/roblox-game-tsukurikata-apikey-ja.jpg)

**APIキー。** 標準のモデルは「Roblox デフォルト」で、1日の使用上限に従います。かわりに、Anthropic（Claude）、OpenAI、GoogleのAPIキーを自分で入れてほかのAIを使うこともできます。この場合の費用は各社のAPI料金で別にかかり、データがその会社に共有されるという注意も表示されます。APIで使うとどれくらいかかるかは[トークン計算機](/ja/)で事前に計算できます。

![アシスタント設定のMCPサーバー画面](/roblox-game-tsukurikata-mcp-ja.jpg)

**MCPサーバー。** 「StudioをMCPサーバーとして使用」をオンにすると、外部のAIコーディングツールが開いているStudioを直接操作できます。公式ドキュメントによると、スクリプトの読み書き、Luauコードの実行、プレイテストの開始・停止、キャラクターの移動やキー入力の再現、画面のキャプチャまでできます。クイック接続に対応しているのはAntigravity、Codex CLI、Claude Code、Claude Desktop、Cursor、Gemini CLI、Visual Studio Codeです（私の画面にはインストール済みの4つだけが出ていました）。Claude Codeが初めてなら[Claude Code の使い方](/ja/blog/claude-code-tsukaikata)、料金は[Claude Code の料金](/ja/blog/claude-code-ryoukin)と[Codex の料金](/ja/blog/codex-ryoukin)を参考にしてください。

## スマホでRobloxゲームを作る：Build

StudioはPC専用ですが、2026年7月にRobloxのスマホアプリに**Build**というAI制作機能が加わりました。公式ドキュメントによると、アプリのBuildタブに作りたいゲームを文章で書くと、AIが遊び方、キャラクター、背景、音まで作り、ボタン1つで公開できます。今はクリッカー、アーケード、横スクロールなど**2D・2.5Dのゲーム**が中心で、1日の無料の依頼回数が決まっていて、超えるとRobuxでクレジットを買います。

## ゲームの公開と収益：先に知っておきたい条件

今回は公開まではしていませんが、公式ドキュメントに書かれている条件をまとめておきます。

- **16歳以上に公開：** アカウント作成から2日以上たっていること、顔による年齢推定か身分証で年齢確認をすることが必要です。最初の質問（年齢制限のあるコンテンツかどうか）に答えると公開されます。
- **全年齢に公開：** 上の条件に加えて、本人確認、2段階認証、そしてRoblox Plus（またはPremium）を2か月続けて契約するか、返金される1,000 Robuxの公開手数料が必要です。手数料は、60日間アクティブなプレイヤー25人を保てば返ってきます。
- **収益：** パス、デベロッパー製品、サブスクリプション、有料プライベートサーバーなどでRobuxを稼ぎ、開発者換金プログラム（DevEx）で現金にします。標準レートは1 Robuxあたり$0.0038で、30,000 Robuxが$114です。13歳以上で、30,000 Robux以上を稼いでいることが申請の条件です。

## 実際に使ってみた感想

AIアシスタントのおかげで、初めての人でもインストールから1時間ちょっとで「踏むと消える飛び石」くらいは作れました。ただ、使ってみた正直な感想はこうです。

> ちゃんとしたゲームを作るには無料の上限が足りなさそうで、アシスタントの画面が思ったより狭く、ゲーム画面を隠しはしないものの、アシスタントだけを別ウィンドウに出せたらよかった。無料のアセットやテンプレート、それに有料のものも種類が多いので、作りやすそうだ。

飛び石ひとつで無料使用量の6%を使ったので、マップやショップ、セーブ機能までそろったゲームをアシスタントだけで作るには、無料分では足りなくなる可能性が高いです。大きな作業は、Robuxで追加の使用量を買うか、MCPでClaude CodeやCodexのようなツールをつなぐ方法もあわせて考えておく必要があります。

## 自分のゲームはどれくらいの期間と費用がかかる？

飛び石は入り口にすぎず、実際のゲームはジャンルと規模によって期間も費用も大きく変わります。[AIゲーム制作費計算機](/ja/ai-game-cost-calculator)でリリース先にRobloxを選び、ジャンルと規模を入れると、予想される期間、AIツールの費用、そのまま使える最初のプロンプトまで出てきます。

## よくある質問

**Robloxのゲーム作りは無料ですか？**
Roblox Studioのインストール、ゲーム制作、クラウドへの保存（Publish）は無料です。アシスタントのAIには無料の使用量があり、超えるとRobuxで追加購入します。全年齢への公開には、Plus・Premiumの契約か、返金される1,000 Robuxの手数料の条件があります。

**プログラミングができなくても作れますか？**
簡単なゲームなら作れます。今回の消える飛び石は、コードを1行も自分で書かずに、アシスタントに日本語で頼むだけで作れました。ただ、エラーが出たときにエクスプローラーの構造（何がどこの下にあるか）を読めると、迷う時間がかなり減ります。

**スマホやiPadで作れますか？**
Roblox StudioはWindowsとMac専用です。スマホでは、RobloxアプリのBuild機能で2D・2.5DのゲームをAIで作れます。

**作ったゲームを友だちに見せるには？**
公開前でも、ファイル → アーリーテスターを招待で、年齢の近い友だちを最大10人まで招待できます。
