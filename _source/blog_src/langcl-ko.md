![클로드 한국어 토큰, 영어보다 102% 더? 실측 비교](/claude-hangugeo-token-ko.jpg)

Claude에게 한국어로 물어보면 영어로 물을 때보다 토큰이 더 든다는 이야기는 많이 들어 보셨을 겁니다. 그런데 정작 "얼마나 더"인지는 글마다 숫자가 다릅니다. 40%라는 글도 있고, 100~200% 더 든다는 글도 있습니다. 대부분은 GPT 토크나이저로 잰 숫자를 그대로 가져온 것이라, Claude를 쓰는 사람에게 맞는 숫자인지도 알 수 없습니다.

그래서 Claude Code로 직접 쟀습니다. 같은 내용의 글과 질문을 한국어·영어·일본어로 준비하고, Claude Opus 5.5에 똑같이 보내서 입력 토큰, 출력 토큰, 실제 비용이 각각 얼마나 나오는지 비교했습니다. 측정은 2026년 10월 16일에 했고, 가격은 Anthropic 공식 가격표(10월 15일 확인)를 기준으로 했습니다.

이 글에 나오는 토큰 수와 비용은 모두 Claude Code가 응답과 함께 돌려준 사용량 기록(usage)과 비용 값을 그대로 옮긴 것입니다.

## 어떻게 쟀나

Claude Code는 원래 시작할 때마다 시스템 프롬프트와 도구 설명서를 약 5만 토큰 싣고 출발합니다. 이 부분은 영어로 고정돼 있어서, 그대로 재면 언어 차이가 그 밑에 묻혀 버립니다. 그래서 시스템 프롬프트를 "You are a helpful assistant." 한 줄로 바꾸고, 도구도 크기가 작은 Read 하나만 남겼습니다. 이렇게 하면 매번 붙는 고정 부분이 약 1천 토큰으로 줄어듭니다.

| 항목 | 설정 |
|---|---|
| 모델 | Claude Opus 5.5 |
| 생각 강도(effort) | low (생각 토큰이 끼어들지 않게) |
| 실행 도구 | Claude Code 2.1.295, 헤드리스 모드(-p) |
| 시스템 프롬프트 | 한 줄로 교체 |
| 측정 날짜 | 2026년 10월 16일, 실험마다 언어별 1회 |

비교에 쓴 재료는 두 가지입니다.

- **같은 내용의 글 한 편:** "작은 팀이 첫 모바일 게임을 기획하는 방법"이라는 글을 영어로 570단어 분량으로 쓰고, 같은 내용을 한국어와 일본어로 옮겼습니다. 한국어판은 공백을 빼고 1,263자, 일본어판은 1,553자, 영어판은 2,506자입니다.
- **같은 질문 5개:** 중고 노트북 고르는 법, 빨리 잠드는 법, 보통예금과 정기예금의 차이, 실내에서 바질 키우는 법, 새 언어를 매일 연습하는 법. 세 언어로 똑같이 묻고 "각각 한 문단 정도로" 답하게 했습니다.

이 재료로 세 가지 실험을 했습니다. 읽기(입력), 쓰기(출력), 그리고 실제로 쓰는 것처럼 질문하고 답을 받는 경우입니다.

## 실험 1: 같은 글을 읽힐 때 (입력 토큰)

같은 글을 언어별로 넣고 "OK라고만 답하라"고 했습니다. 답이 한 단어라 출력은 거의 0이고, 입력 토큰만 비교할 수 있습니다.

| 언어 | 입력 토큰 (고정 부분 제외) | 영어 대비 |
|---|---:|---:|
| 영어 | 1,539 | 기준 |
| 한국어 | 2,435 | **+58%** |
| 일본어 | 2,083 | **+35%** |

같은 내용을 읽히는데 한국어는 영어보다 토큰이 58% 더 들었습니다.

다만 이 숫자에는 언어와 상관없이 매번 붙는 부분이 일부 섞여 있습니다. Claude Code는 내가 보낸 글 앞뒤에 실행 환경 정보 같은 내용을 덧붙여 보냅니다. 이 부분을 실험 2의 영어 결과(영어는 약 3.4자에 1토큰)로 역산하면 약 600토큰으로 추정됩니다. 이를 빼고 글 자체만 비교하면 한국어는 영어보다 약 99%, 일본어는 약 60% 더 많습니다. 아래 실험 2의 결과와 거의 같은 숫자입니다.

## 실험 2: 같은 뜻을 쓰게 할 때 (출력 토큰)

![실험 2: 같은 뜻을 쓰게 할 때 (출력 토큰): 언어, 출력 토큰, 영어 대비, 비용, 걸린 시간](/claude-korean-token-translation-output-ko.jpg)

이번에는 반대로, 같은 뜻을 각 언어로 쓰게 했습니다. 영어 원문을 한국어와 일본어로 번역하게 하고, 영어 결과는 한국어판을 영어로 번역하게 해서 얻었습니다. 세 결과 모두 끝까지 빠짐없이 번역됐습니다.

| 언어 | 출력 토큰 | 영어 대비 | 비용 | 걸린 시간 |
|---|---:|---:|---:|---:|
| 영어 | 915 | 기준 | $0.038 (약 51원) | 10초 |
| 한국어 | 1,850 | **+102%** | $0.050 (약 67원) | 23초 |
| 일본어 | 1,510 | **+65%** | $0.043 (약 58원) | 19초 |

**같은 뜻을 한국어로 쓰게 하면 출력 토큰이 영어보다 102% 더 들었습니다.** 일본어는 65% 더 들었습니다.

출력 토큰이 중요한 이유는 가격 때문입니다. Opus 5.5는 입력이 100만 토큰당 $4, 출력이 $20입니다. 출력 단가가 입력보다 400% 비싸서 같은 1,000토큰이라도 출력 쪽이 훨씬 큰 돈이 됩니다. 한국어 답변을 받는다는 건, 가장 비싼 토큰을 영어보다 100% 가까이 더 쓴다는 뜻입니다.

걸린 시간도 같은 방향으로 늘었습니다. 모델은 토큰을 하나씩 만들어 내기 때문에, 토큰이 많으면 답이 끝나는 데도 오래 걸립니다. 한국어 번역은 영어(10초)보다 13초 더 걸린 23초였습니다.

비용 차이(+30%)가 토큰 차이(+102%)보다 작은 이유는 입력 쪽 때문입니다. 번역할 원문은 입력으로 들어가는데, 한국어·일본어 번역은 영어 원문을, 영어 번역은 한국어 원문을 읽었습니다. 영어 결과를 만들 때 오히려 더 비싼 한국어 원문을 읽어서 차이가 일부 줄었습니다.

## 실험 3: 같은 질문 5개를 물을 때

실제로 Claude를 쓰는 모습에 가장 가까운 실험입니다. 같은 질문 5개를 각 언어로 묻고, 그 언어로 답을 받았습니다.

| 언어 | 출력 토큰 | 영어 대비 | 비용 | 답변 글자 수(공백 제외) |
|---|---:|---:|---:|---:|
| 영어 | 1,371 | 기준 | $0.034 (약 45원) | 3,355자 |
| 한국어 | 1,921 | **+40%** | $0.045 (약 61원) | 1,394자 |
| 일본어 | 1,430 | +4% | $0.035 (약 47원) | 1,483자 |

한국어로 물었을 때 비용이 35% 더 들었습니다.

흥미로운 점은 글자 수입니다. 한국어 답변은 1,394자로, 영어 답변(3,355자)의 절반도 안 됩니다. 그런데 토큰은 40% 더 썼습니다. 한국어는 글자 하나가 담는 뜻이 많아서 글자 수는 짧지만, 토큰으로 바꾸면 오히려 많아집니다.

일본어가 +4%로 거의 차이가 없었던 건 일본어 답변이 다른 언어보다 짧게 나왔기 때문입니다. 실험 2에서 보듯 같은 뜻을 쓰면 일본어도 65% 더 듭니다. 실제 사용에서는 답변 길이가 그때그때 달라서, 언어 차이만큼 답변 길이도 비용을 좌우합니다.

## 글자 하나에 토큰 몇 개?

![글자 하나에 토큰 몇 개?: 언어, 1글자당 토큰 (출력 기준), 1만 자 출력 비용 (Opus 5.5)](/claude-korean-tokens-per-character-ko.jpg)

세 실험의 결과를 글자 수로 나누면, 언어별로 글자 하나에 토큰이 몇 개 드는지 알 수 있습니다.

| 언어 | 1글자당 토큰 (출력 기준) | 1만 자 출력 비용 (Opus 5.5) |
|---|---:|---:|
| 영어 | 약 0.3토큰 (3.4자에 1토큰) | 약 $0.06 |
| 한국어 | 약 1.05토큰 | 약 $0.21 |
| 일본어 | 약 0.9토큰 | 약 $0.18 |

한국어는 **글자 하나가 대략 1토큰**이라고 보면 됩니다. 답변 1만 자를 받으면 Opus 5.5 기준 출력 비용만 약 $0.21(약 280원)입니다. 다만 한국어 1만 자에 담기는 내용은 영어 1만 자보다 훨씬 많으니, 글자 수가 아니라 같은 내용끼리 비교한 실험 2의 +102%가 실제 차이에 가깝습니다.

글자 수를 넣으면 토큰과 비용을 바로 보여 주는 [토큰 계산기](/ko/)로 내 프롬프트를 직접 재 볼 수도 있습니다.

## 왜 한국어는 토큰을 더 쓸까

AI 모델은 글을 글자 단위로 읽지 않습니다. 토크나이저라는 도구가 글을 미리 정해 둔 조각(토큰)으로 자릅니다. 이 조각 목록은 학습 데이터에서 자주 나오는 글자 묶음을 모아 만듭니다.

학습 데이터에는 영어가 압도적으로 많습니다. 그래서 영어는 자주 쓰는 단어가 앞의 띄어쓰기까지 붙은 채로 통째로 하나의 토큰이 되는 경우가 많습니다. 영어가 3.4자에 1토큰꼴로 나온 이유입니다.

한국어는 사정이 다릅니다. 한글은 자음과 모음을 조합해 만들 수 있는 글자가 1만 1천 개가 넘고, 컴퓨터에서는 글자 하나가 3바이트로 저장됩니다. 자주 쓰는 글자나 짧은 단어는 하나의 토큰으로 묶이지만, 그렇지 않은 글자는 더 잘게 쪼개집니다. 이번 측정에서 한국어 글자 하나가 평균 약 1토큰이 된 건, 조각 목록에 한국어 묶음이 영어만큼 많지 않다는 뜻입니다.

일본어도 한자·히라가나·가타카나가 섞여 있어 비슷한 문제가 있습니다. 다만 이번 Claude 측정에서는 일본어가 한국어보다 덜 쪼개졌습니다. 어떤 언어를 얼마나 잘 묶는지는 회사와 모델마다 다르고, 같은 회사라도 모델이 바뀌면 달라질 수 있습니다.

## 직접 재 보는 방법

Claude Code가 설치돼 있다면 이번과 같은 방법으로 내 글을 직접 재 볼 수 있습니다. 재고 싶은 글을 파일로 저장한 뒤, 터미널에서 아래처럼 실행합니다. 시스템 프롬프트를 한 줄로 바꾸고 도구를 하나만 남겨서, 언어와 상관없는 고정 토큰을 최소로 줄이는 설정입니다.

```
cat 내글.txt | claude -p --system-prompt "You are a helpful assistant." --tools Read --output-format json
```

결과로 나오는 JSON에서 볼 곳은 세 군데입니다. usage 안의 output_tokens는 답변에 쓴 출력 토큰, cache_creation_input_tokens와 cache_read_input_tokens를 더한 값이 입력 토큰, total_cost_usd가 API 가격으로 환산한 비용입니다. 같은 글을 한국어판과 영어판으로 한 번씩 넣어 보면, 내 글에서 언어 차이가 얼마나 나는지 바로 알 수 있습니다.

Pro나 Max 요금제로 로그인한 상태라면 돈이 따로 나가지는 않지만, 요금제 사용량에서 그만큼 차감됩니다. 하루 몇 번 재 보는 정도는 한도에 거의 영향이 없습니다. 지난 대화들의 토큰을 날짜·모델별로 모아 보고 싶다면 [사용량 분석기](/ko/claude-code-usage)에 기록 폴더를 넣어 보세요.

## GPT 토크나이저와 비교하면

![GPT 토크나이저와 비교하면: 토크나이저, 한국어, 일본어](/claude-vs-gpt-korean-token-ko.jpg)

토큰세이브는 9월에 같은 짧은 프롬프트를 41개 언어로 옮겨 GPT 토크나이저(o200k_base)로 잰 적이 있습니다. 그때 결과는 한국어가 영어보다 44%, 일본어가 79% 더 많았습니다. 자세한 결과는 [한국어 프롬프트, 영어로 보내면 토큰 31% 절약](/ko/blog/korean-tokens-gpt)에 있습니다.

| 토크나이저 | 한국어 | 일본어 |
|---|---:|---:|
| GPT (o200k_base, 9월 측정) | +44% | +79% |
| Claude Opus 5.5 (이번 측정, 같은 뜻 출력) | **+102%** | +65% |

재료 글이 달라서 숫자를 그대로 맞대기는 어렵지만, 방향은 분명합니다. **GPT에서는 일본어가 한국어보다 불리했는데, Claude Opus 5.5에서는 한국어가 더 불리했습니다.** 토크나이저마다 어떤 언어의 글자를 묶어서 처리하는지가 달라서 생기는 차이입니다.

그래서 "한국어는 44% 더 든다"는 숫자를 Claude에 그대로 쓰면 비용을 절반 가까이 낮게 잡게 됩니다. Claude로 한국어 서비스를 만들거나 API 예산을 짠다면, 한국어 출력 토큰은 영어보다 100% 더 드는 것으로 계산하는 편이 안전합니다.

## 요금으로 바꾸면 얼마나 차이 날까

실험 3의 질문 5개짜리 대화를 하루 20번, 한 달(30일) 동안 API로 한다고 해 보겠습니다. 실제 측정 비용을 그대로 곱하면 이렇습니다.

| 언어 | 1회 비용 | 한 달(600회) |
|---|---:|---:|
| 영어 | $0.034 | 약 $20 (약 2만 7천 원) |
| 한국어 | $0.045 | 약 $27 (약 3만 6천 원) |
| 일본어 | $0.035 | 약 $21 (약 2만 8천 원) |

한 사람이 쓰는 정도라면 한 달 몇천 원 차이지만, 사용자가 많은 서비스라면 35%는 무시하기 어려운 차이입니다. 번역이나 긴 글 작성처럼 출력이 많은 작업일수록 차이는 실험 2의 +102% 쪽으로 커집니다.

Pro나 Max 같은 구독 요금제는 토큰 단위로 돈을 내지 않습니다. 하지만 Anthropic은 사용 한도가 대화의 길이와 복잡도에 따라 줄어든다고 안내합니다. 한국어 대화가 더 많은 토큰을 쓰는 만큼 한도도 더 빨리 줄어들 가능성이 큽니다. 요금제별 한도는 [클로드 요금제 정리](/ko/blog/claude-yogeumje)에 모아 두었습니다.

## 한국어 토큰을 줄이는 방법

결과를 보면 줄일 수 있는 곳이 분명합니다.

- **긴 지시문과 자료는 영어로 넣으세요.** 매번 반복해서 보내는 시스템 프롬프트나 참고 자료는 영어로 쓰면 입력 토큰이 크게 줄어듭니다. 답만 한국어로 받고 싶다면 끝에 "Reply in Korean."을 붙이면 됩니다. [토큰 계산기](/ko/)의 💸 토큰 절약 버튼을 누르면 내 기기 안에서 영어로 바꾸고 몇 % 줄었는지 보여 줍니다.
- **답이 필요 이상으로 길지 않게 하세요.** 가장 비싼 건 출력입니다. "세 줄로", "표로만"처럼 길이를 정해 주면 한국어 출력 토큰을 직접 줄일 수 있습니다.
- **영어로 읽어도 되는 결과는 영어로 받으세요.** 코드 설명, 로그 분석처럼 내가 읽고 넘어갈 내용이라면 영어 답변이 출력 토큰을 절반 가까이 아낍니다.
- **번역은 마지막에 한 번만.** 여러 단계를 거치는 작업이라면 중간 과정은 영어로 하고, 최종 결과만 한국어로 번역하게 하면 비싼 한국어 출력을 한 번만 씁니다.

## 자주 묻는 질문

**Claude는 한국어 토큰을 영어보다 얼마나 더 쓰나요?**
이번 Opus 5.5 측정에서 같은 뜻을 쓸 때 출력 토큰은 102% 더, 같은 글을 읽을 때 입력 토큰은 고정 부분을 포함해 58% 더 들었습니다. 고정 부분을 빼고 글 자체만 보면 입력도 약 99% 더 많습니다.

**한국어로 쓰면 비용이 그만큼 늘어나나요?**
출력 토큰은 100% 가까이 늘지만, 비용은 작업에 따라 다릅니다. 이번 일상 질문 실험에서는 35%, 번역 실험에서는 30% 더 들었습니다. 매번 붙는 고정 토큰과 원문 입력이 섞이기 때문입니다.

**GPT에서는 44%라던데 왜 다른가요?**
회사마다 토크나이저가 다르기 때문입니다. GPT의 o200k_base는 한국어를 비교적 잘 묶지만, 이번 측정에서 Claude Opus 5.5는 한국어 글자 하나를 대략 1토큰으로 처리했습니다.

**Claude Code로 코딩할 때도 이만큼 차이 나나요?**
코딩 에이전트는 시스템 프롬프트와 코드처럼 언어와 상관없는 부분이 비용의 대부분이라 차이가 훨씬 작습니다. 이번 글의 숫자는 글을 읽고 쓰는 작업 기준입니다. 같은 코딩 과제를 한국어·영어 등 5개 언어로 시켜 본 실측에서도 입력 토큰은 거의 같았습니다([실측 데이터](/data/ai-coding-prompt-language)).

**영어로 묻고 답만 한국어로 받으면 싸지나요?**
입력 쪽은 싸집니다. 질문과 자료를 영어로 바꾸면 그만큼의 입력 토큰이 크게 줄어듭니다. 하지만 답을 한국어로 받는 한 가장 비싼 출력 토큰은 그대로입니다. 짧은 질문이라면 효과가 작고, 긴 자료나 지시문을 영어로 바꿀 때 효과가 큽니다.

**프롬프트 캐시를 쓰면 차이가 없어지나요?**
없어지지 않습니다. 캐시에서 읽는 토큰은 일반 입력보다 95% 싸지만, 한국어 자료는 캐시 안에서도 영어보다 많은 토큰 수 그대로입니다. 단가가 내려가도 언어에 따른 비율 차이는 남습니다.

**내 프롬프트는 몇 토큰인가요?**
[토큰 계산기](/ko/)에 붙여 넣으면 모델별 토큰 수와 비용을 바로 볼 수 있습니다. 브라우저 안에서만 계산하고 아무것도 보내지 않습니다.

## 마무리

같은 내용을 Claude Opus 5.5에 한국어·영어·일본어로 보내 보니, 한국어는 같은 뜻을 쓸 때 출력 토큰이 영어보다 102% 더 들었습니다. 일본어는 65% 더였습니다. 글을 읽힐 때도 한국어 입력 토큰은 58%, 고정 부분을 빼면 약 99% 더 많았습니다. 일상 질문 5개를 묻는 실제 사용에서는 비용이 35% 더 나왔습니다.

GPT 토크나이저로 잰 "한국어 +44%"보다 Claude에서의 차이가 훨씬 컸고, GPT와 달리 Claude에서는 한국어가 일본어보다 불리했습니다. Claude로 한국어 작업을 많이 한다면 긴 지시문은 영어로, 답은 필요한 길이만큼만 받는 것이 가장 확실한 절약법입니다. 각 실험은 언어별 1회 측정이라, 답변 길이에 따라 결과는 조금씩 달라질 수 있습니다.
