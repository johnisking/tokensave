![Veo 3.1 料金と無料の使い方：Flow 毎日50クレジットで実測](/veo-3-1-ryoukin-ja.jpg)

Google の動画生成 AI「Veo 3.1」は使える場所が3つあるので、料金を調べると答えがばらばらです。開発者は Gemini API で秒単位の従量課金、一般のユーザーは Gemini アプリや動画制作ツール Google Flow でプランの上限やクレジットを使います。さらに10月に入って Google が新しい動画モデル Gemini Omni Flash を標準として打ち出したので、「Veo で作った」という動画が実際にどのモデルなのかも分かりにくくなりました。

そこで Google 公式の料金ページ（10月14日更新版）と、Flow・Gemini のヘルプを基に、Veo 3.1 の API 料金、プランごとに作れる量、無料で使える範囲をまとめました。さらに10月15日に、無料アカウントと Google AI Pro のアカウントで同じプロンプトを入れて、実際に動画を作ってみました。

円の金額は1ドル＝158円で計算したおおよその値で、消費税とカードの海外事務手数料は含みません。

## Veo 3.1 にはどんなモデルがある？

2026年10月15日時点で、Gemini API で使える Veo 3.1 は3種類です。

| 名前 | モデルID | 特徴 |
|---|---|---|
| Veo 3.1（Standard） | veo-3.1-generate-preview | いちばん画質が高い標準モデル。720p・1080p・4K、音声つき |
| Veo 3.1 Fast | veo-3.1-fast-generate-preview | 速くて安いモデル。720p・1080p・4K |
| Veo 3.1 Lite | veo-3.1-lite-generate-preview | いちばん安いモデル。720p・1080p のみで 4K は不可 |

3つとも映像と一緒に音（効果音・セリフ・環境音）を作り、料金も音声つきが基本です。Flow では同じモデルが「Veo 3.1 - Quality」「Veo 3.1 - Fast」「Veo 3.1 - Lite」という名前で出てきます。

1つ知っておきたい変化があります。Google の開発者向けドキュメントは、動画生成の標準モデルとして Gemini Omni Flash をすすめるようになり、Veo 3.1 はシーンの延長や最後のフレームの指定など、特定の機能が必要なときに使うよう案内しています。Omni Flash は出力トークンで計算され、Google が示している目安は 720p の動画1秒あたり約0.10ドル（約16円）です。

## Veo 3.1 の API 料金は1秒いくら？

Veo は画像のような1枚単位ではなく、できあがった動画の長さ（秒）で料金がかかります。生成に失敗した場合は課金されません。

| モデル | 720p | 1080p | 4K |
|---|---|---|---|
| Veo 3.1（Standard） | 約63円（$0.40） | 約63円（$0.40） | 約95円（$0.60） |
| Veo 3.1 Fast | 約16円（$0.10） | 約19円（$0.12） | 約47円（$0.30） |
| Veo 3.1 Lite | 約8円（$0.05） | 約13円（$0.08） | なし |

いちばんよく使う8秒の動画1本に直すと、こうなります。

- **Standard 1080p 8秒：** 約506円（3.20ドル）
- **Fast 720p 8秒：** 約126円（0.80ドル）
- **Lite 720p 8秒：** 約63円（0.40ドル）

Standard は 720p と 1080p が同じ料金なので、Standard を使うなら 1080p で受け取るほうが得です。また Standard は Fast 720p より300%高くなります。案をいくつも作って選ぶ段階なら、Fast や Lite で足りることが多いです。

## Veo 3.1 の API は無料で使える？

API では無料で使えません。Google の料金表では、Veo 3.1 の3モデルすべてで無料枠の欄が「利用不可」です。お支払い情報を登録した有料枠でだけ呼び出せ、そのかわり有料枠で送った内容は Google のサービス改善には使われません。

無料で Veo を試せるのは、実質的に Google Flow だけです。Gemini アプリは無料アカウントでは動画を作れません。どちらも下で実際に確かめました。

## Gemini アプリではプランごとに何本作れる？

![Gemini アプリではプランごとに何本作れる？: プラン, 月額（日本）, Gemini アプリの使用上限, 動画生成](/veo-3-1-ryoukin-gemini-ja.jpg)

Google のヘルプの表では、「動画生成」にチェックが付いているのは AI Plus・Pro・Ultra だけで、プランなしの無料アカウントには付いていません。

| プラン | 月額（日本） | Gemini アプリの使用上限 | 動画生成 |
|---|---|---|---|
| 無料 | 0円 | 標準の上限 | 不可 |
| AI Plus | 725円 | 標準の利用量の2倍 | 可 |
| AI Pro | 2,900円 | 標準の利用量の4倍 | 可 |
| AI Ultra | 14,500円 / 32,000円 | AI Pro の利用量の5倍または20倍 | 可 |

- Google はいま、1日何本という本数を公開していません。上限はメッセージ数ではなく使用量（計算量）で決まり、**5時間ごとに回復し、週の上限に達すると止まります。**
- 同じ表で動画生成は使用量の消費が「高」に分類され、「一般的に動画がもっとも多くの使用量を必要とする」と書かれています。会話だけのときより、ずっと早く上限に近づくということです。

ネットで見かける「Pro は1日3本」のような数字は、以前の基準です。いまの公式ドキュメントには本数がないので、使っていて上限の案内が出るかを見るのがいちばん確実です。

## Gemini の無料アカウントで試してみた

10月15日に、プランに加入していない無料の Google アカウントで、Gemini アプリに次のプロンプトを入れました。テストは韓国語のプロンプトで行ったので、ここでは日本語訳を載せます。

- **プロンプト（日本語訳）：** 動画を作って：雨の夜のソウルの路地にある小さな屋台、黄色い傘をさした人がトッポッキを買って食べる場面、温かい照明、雨の音、シネマティックなスタイル、8秒

返事は「お手伝いします。ただし、まずサブスクリプションをアップグレードする必要があります。」という1行だけで、動画は作られませんでした。ヘルプの表どおりの結果です。無料で Veo を使うなら Flow に行く必要があります。

## Google Flow の無料クレジットで作ってみた

Flow のヘルプによると、サブスクリプションの有無にかかわらず**毎日50 Flow クレジット**がもらえ、モデルごとに動画1本に必要なクレジットが違います。

| モデル（Flow での名前） | 動画1本あたりのクレジット | 無料の1日50クレジットで |
|---|---|---|
| Veo 3.1 - Lite | 10（Ultra 加入者は5） | 5本 |
| Veo 3.1 - Fast | 20（Ultra 加入者は10） | 2本 |
| Veo 3.1 - Quality | 100 | 作れない |
| Gemini Omni Flash 720p | 8秒12、10秒15 | 8秒なら4本 |

同じ無料アカウントで Flow に入り、上のプロンプトをそのまま入れました。やってみて分かったことは次のとおりです。

- **最初に同意画面が出ます。** マーケティングメールとユーザー調査への参加は任意で、プライバシーポリシーの案内は最後までスクロールしないと「続行」が押せません。
- **作る前にクレジットの確認があります。** 初期設定では Flow のエージェントが「20クレジットを使って動画1本の生成を始めますか？」と聞き、承認してから作ります。
- **モデルは言葉で指定するほうが確実でした。** 設定で Lite を選んでいたのに、エージェントがまた20クレジット（Fast）で提案してきたので、拒否して「Veo 3.1 - Lite モデルで」と書くと10クレジットに変わりました。
- **かかった時間：** Fast は承認から約1分20秒、Lite は約1分30秒でした。Lite は「優先度低」で処理される場合があり、Fast より遅くなることがあります。
- **クレジット：** Fast を1本作ると50から30に、Lite を1本作ると20に減りました。使わなかったクレジットは翌日に繰り越されません。

プロフィール画面には、クレジットが毎日同じ時刻に更新されると表示されました。ヘルプの説明どおり、その日の最初の生成時刻を基準に翌日また補充されます。同じ画面には「お住まいの地域では透かしの表示が必須です」という案内もあり、韓国のアカウントでは目に見える透かしをオフにできませんでした。日本のアカウントでどうなるかは確かめていません。

無料で使うときの注意がもう1つあります。サブスクリプションに加入していないユーザーは、**ピーク時間（UTC 14時〜17時、日本時間23時〜翌2時）**に動画を作れない場合があるとヘルプに書かれています。

## Gemini アプリの結果はなぜ違った？

![Gemini アプリ Pro アカウントの結果を、路地の全景・注文・トッポッキの鉄板・食べる場面に分けたもの](/veo-3-1-ryoukin-gemini-app-ja.jpg)

Gemini アプリで受け取った動画は 1280×720、**10秒**でした。8秒を頼んだのに10秒になり、1カットではなく、路地の全景 → 屋台のおばさんに注文 → トッポッキの鉄板のアップ → カップのトッポッキを食べる様子と、場面が次々に切り替わりました。短い広告のような、ストーリーのある構成です。瓦屋根やプラスチックのケース、オレンジ色のテントなど、実際のソウルの路地に近い雰囲気も4本の中でいちばんで、トッポッキを串ではなくカップで食べていたのもこの動画だけでした。そのかわり、トッポッキをすくう場面に正体の分からない大きなオレンジ色のかたまりが出てきて、不自然なところもありました。

アプリの画面には、どのモデルで作ったかは表示されませんでした。Veo 3.1 は動画の長さを4・6・8秒から選びますが、今回の動画は10秒で、Flow でも10秒を選べるのは Gemini Omni Flash です。そのため、Gemini アプリが Veo ではなく Omni Flash のような別のモデルで作った可能性があります。確実に Veo 3.1 で作りたいなら、Flow でモデルを直接指定するか API を使うほうが確実です。

## プランと API、どちらが安い？

![プランと API、どちらが安い？: 方法, 毎月もらえる Flow クレジット, Fast 8秒の動画, 1本の値段（クレジット換算）](/veo-3-1-ryoukin-ja-4.jpg)

Flow のクレジットだけで動画1本の値段を計算すると、次のとおりです。

| 方法 | 毎月もらえる Flow クレジット | Fast 8秒の動画 | 1本の値段（クレジット換算） |
|---|---|---|---|
| 無料 | 毎日50 | 毎日2本 | 0円 |
| AI Plus 725円 | 月200＋毎日50 | 月10本＋毎日2本 | 約73円 |
| AI Pro 2,900円 | 月1,000＋毎日50 | 月50本＋毎日2本 | 約58円 |
| API（Fast 720p） | なし | 使った分 | 約126円 |

プランの1本の値段は、月額を月のクレジットで作れる Fast の本数で割った値で、毎日の50クレジットは除いて計算しました。プランには Gemini アプリやストレージなど別の特典も含まれるので正確な比較ではありませんが、**動画を継続的に作るなら、プランのほうが API より安くつきます。** 反対に、アプリやサービスに動画生成を組み込んだり、一度に何百本も自動で作ったりするなら API が必要です。なお Flow のヘルプによると、AI クレジットの追加購入は日本では使えません。足りなくなったときはプランの変更で増やすことになります。

## Veo 3.1 の費用を抑えるコツ

- **案は Lite か Fast の 720p で：** 構図と動きを先に決め、気に入った場面だけ Standard（Quality）や 1080p で作り直します。
- **無料の50クレジットは毎日使う：** 繰り越せないので、Fast 2本や Lite 5本で案を作っておけば有料クレジットを節約できます。
- **ピーク時間を避ける：** 無料アカウントは日本時間23時〜翌2時に生成できない場合があります。
- **長さを短くする：** API は秒単位なので、8秒ではなく4〜6秒に分けて作れば、作り直しで捨てる費用が減ります。
- **モデル名を確かめる：** Gemini アプリや Flow のエージェントが選んだモデルが意図したものか、承認する前にクレジット数で確認します。

## どの方法を選べばいい？

- **まず試してみたい：** Google Flow の無料版。毎日50クレジットで Fast を2本作れます。
- **SNS 用の動画をときどき作る：** AI Plus か Pro。Gemini アプリで言葉で作り、Flow のクレジットでモデルを選んで作ります。
- **毎日何本も作る：** Ultra と API を比べます。Ultra 加入者は Flow の Lite（優先度低）を0クレジットで使えます。
- **サービスに組み込む：** Gemini API。Fast 720p で1秒約16円からで、これから始めるなら Google が標準としてすすめる Omni Flash（720p で1秒約0.10ドル）も一緒に比べてみてください。

## よくある質問

**Veo 3.1 は1秒いくら？** API で Standard の 720p・1080p が約63円（0.40ドル）、Fast 720p が約16円（0.10ドル）、Lite 720p が約8円（0.05ドル）です。8秒の動画なら Standard 約506円、Fast 約126円、Lite 約63円です。

**Veo 3.1 は無料で使える？** Google Flow で毎日50クレジットが無料でもらえ、Fast 2本か Lite 5本を作れます。Gemini アプリの無料アカウントと Gemini API の無料枠では動画を作れません。

**Gemini の Pro プランで動画は1日何本作れる？** Google は本数を公開していません。使用量ベースの上限が5時間ごとに回復し、週の上限があり、動画はもっとも多く使用量を消費します。別に Flow では、月1,000クレジットで Fast 50本、Quality 10本を作れます。

**Veo 3.1 の Quality と Fast は差が大きい？** 今回の比較では Quality が質感と光の表現で上でしたが、場面の組み立ては似ていました。クレジットは Quality が400%多くかかります。案は Fast で、最終版だけ Quality で作る方法をおすすめします。

**透かしは消せる？** すべての Veo の動画には目に見えない SynthID が入ります。目に見える透かしは Flow の設定にオン・オフの項目がありますが、韓国のアカウントでは「お住まいの地域では透かしの表示が必須」と出てオフにできませんでした。

## まとめ

Veo 3.1 をいちばん安く試す方法は、Google Flow の無料クレジットです。毎日50クレジットで Fast を2本作れ、今回のテストでは無料の Fast がプロンプトにもっとも素直でした。Gemini アプリは無料アカウントでは動画を作れず、有料アカウントでもどのモデルで作ったかは表示されませんでした。継続して作るならプランの Flow クレジットのほうが API より1本あたり安く、サービスへの組み込みや大量生成なら1秒約16円（Fast 720p）からの API が向いています。画質の差は思ったより小さいので、Quality は最後の1カットにだけ使うのがおすすめです。音は4本とも雨の音が機械音のようで、人の声が自然に入っていたのは Gemini アプリの動画だけでした。
