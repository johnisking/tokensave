OpenAI は2026年9月に GPT-6 モデルを3つ公開しました。最上位の **GPT-6 Astra** が9月4日、**GPT-6 Sol** と **GPT-6 Luna** が9月22日です。3つの API 料金は大きく違うので、割引よりもモデル選びのほうがはるかに重要です。料金、実際の使い方での費用、Claude・Gemini との比較をまとめました。

## GPT-6 の API 料金

100万トークンあたりの料金です。

| モデル | 入力 | キャッシュ入力 | 出力 |
|---|---|---|---|
| GPT-6 Astra | $10 | $1 | $50 |
| GPT-6 Sol | $2 | $0.20 | $10 |
| GPT-6 Luna | $0.10 | $0.01 | $0.50 |

Astra は Sol の5倍、Sol は Luna の20倍です。同じ GPT-6 でも、いちばん安いモデルといちばん高いモデルで100倍の差があります。

入力が272,000トークンを超えるリクエストには高い料金が適用されるので、非常に長いコンテキストは表より高くなります。

## GPT-5.6 と比べると

Sol と Luna は、置き換える前のモデルの半額で登場しました。GPT-5.6 Sol は入力$4・出力$20、GPT-5.6 Luna は$0.20・$1.20でした。まだ GPT-5.6 を使っているなら、モデル名を変えるだけで費用が半分になります。

## 実際にいくらかかるか

入力2,000トークン、出力500トークンの一般的なリクエストの場合です。

| モデル | 1リクエスト | 1万リクエスト |
|---|---|---|
| GPT-6 Luna | $0.00045 | $4.50 |
| Gemini 3.8 Flash | $0.0034 | $34 |
| GPT-6 Sol | $0.009 | $90 |
| Claude Sonnet 5.5 | $0.009 | $90 |
| Gemini 3.1 Pro | $0.010 | $100 |
| Claude Opus 5.5 | $0.018 | $180 |
| GPT-6 Astra | $0.045 | $450 |

ほかのモデルの料金は2026年10月1日に確認した公式 API 価格です。

GPT-6 Sol はトークン単価が Claude Sonnet 5.5 とまったく同じで、GPT-6 Astra は Claude Opus 5.5 の2.5倍です。

**日本語だとさらにかかります。** GPT のトークナイザーでは、同じプロンプトが日本語だと英語の約1.79倍のトークンになります。上の表の入力費用にその倍率がかかると考えてください。

## どの GPT-6 モデルを使うか

**GPT-6 Luna:** 分類、情報抽出、ルーティング、短い回答、短い文章の要約など、量が多くシンプルな作業に。入力100万トークンあたり$0.10なので、すべてのリクエストに使っても負担が小さいです。

**GPT-6 Sol:** ほとんどのアプリやコーディング作業の標準に。チャットボット、文章作成、分析、エージェントにちょうどいい中間の選択です。

**GPT-6 Astra:** 明らかに良い結果が出ると確認できるところだけに。長く多段階のエージェント作業、難しい推論、ミスのコストが高い作業。そうしたリクエストだけを Astra に送りましょう。

よくある構成は、普段は Sol か Luna で処理し、安いモデルが失敗したときや難しいタスクと判定されたときだけ Astra に回す方法です。

## 費用を抑える方法

1. **プロンプトキャッシュを使う。** 3モデルともキャッシュ入力は通常価格の10分の1です。固定の指示や文書はプロンプトの先頭に置きましょう。
2. **急がない作業は Batch API で。** 通常は半額です。
3. **出力を短く。** GPT-6 はどのモデルも出力が入力の5倍の価格です。
4. **推論を抑える。** 見えない推論トークンも出力として課金されます。足りる範囲でいちばん低い推論レベルを使いましょう。
5. **プロンプトを英語で。** 日本語よりトークンが約44%減ります。[トークンカウンター](/ja/)の 💸 トークン節約 ボタンなら、自分の端末の中ですぐに英語へ変換できます。

## ChatGPT のプランで GPT-6 を使う

API を使わなくても GPT-6 は使えます。GPT-6 Astra は ChatGPT の Pro、Business Premium、Enterprise で利用でき、Plus にも Work と Codex から順次展開されています。たくさん使うなら、Astra の API 料金よりプランのほうがずっと安くなることがあります。[サブスク vs API 計算機](/ja/plans)で比べてみましょう。
