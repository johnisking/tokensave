![Claude Code の料金【2026】月$20〜$200とAPI実費](/claude-code-ryoukin-ja.jpg)

**Claude Code の料金をひとことで言うと：** Claude Code（クロードコード）は Claude のすべての有料プランに含まれていて、**Pro は月$20**（年払いなら月$17）、**Max 5x は月$100**、**Max 20x は月$200** です。プランを使わずに API の従量課金でトークン単位で払うこともでき、私たちのテストでは小さなタスク1つが **Sonnet 5.5 で$0.10〜0.12、Opus 5.5 で$0.26〜0.35** でした（Claude Code 2.1.295、3回平均）。無料の Free プランには Claude Code は含まれません。価格は米ドル・税抜で、日本では2026年4月1日から消費税10%が加わるため、Pro の月払いは$22になります（私たちの計算）。以下の価格はすべて、2026年10月12日に Anthropic の料金ページで確認したものです。

「Claude Code の値段はいくらか」の答えは、使う量しだいで変わります。この記事では、各プランに含まれるもの、API で1タスクに実際いくらかかるか（実測）、4つの使い方での1か月の費用、そしてプランが API より安くなる境目をまとめました。

## Claude Code の料金早見表（2026年）

![Claude Code の料金早見表（2026年）: プラン, 料金, Claude Code, 5時間あたりの使用量](/claude-code-ryoukin-claude-code-2026-ja.jpg)

| プラン | 料金 | Claude Code | 5時間あたりの使用量 |
|---|---|:---:|---|
| Free | $0 | なし | – |
| Pro | 月$20（年払いなら月$17） | あり | Free の500%以上 |
| Max 5x | 月$100 | あり | Pro の500% |
| Max 20x | 月$200 | あり | Pro の2,000% |
| API（Claude Console） | トークン単位の従量課金 | あり | プランの上限なし、使ったトークンはすべて課金 |

- **価格は税抜**で、Max は月払いのみです。どちらの Max にも年払いの割引はありません。
- **使用量の枠はひとつです。** ターミナルや IDE（VS Code、Cursor、JetBrains）で使う Claude Code は、Web・デスクトップ・モバイルの Claude と同じ5時間の上限と週の上限を共有します。アプリで長いチャットをすると、コーディングに使える分がそのぶん減ります。
- **使用量あたりで割安になるのは Max 20x だけです。** Pro の1,000%の料金で Pro の2,000%の使用量が使えるので、使用量あたりの単価は50%安くなります。Max 5x の単価は Pro と同じです。
- **Max に付く月々の API クレジットは Claude Code には使えません。** 料金ページには、Claude Platform で開発するための API クレジットとして月$100（Max 5x）または月$200（Max 20x）が載っていますが、Anthropic のヘルプセンターによると、このクレジットは Claude Code や Claude アプリでは使えません。
- **Team と Enterprise。** Anthropic の料金ページの FAQ では、Claude Code はすべての有料プランに含まれるとされています。Team は Standard が1シート月$25（年払いなら$20）、Premium が月$125（年払いなら$100）で、2シートから契約できます。Enterprise は1シート$20に加えて、使用量を API 料金で払います。

### 日本での支払い：ドル建てに消費税10%

- **Anthropic は日本円の公式価格を公開していません。** 料金ページの表示は米ドルで、日本や日本円についての記載はありません。
- **2026年4月1日から、日本の顧客には消費税（JCT）10%が加算されています。** Claude ヘルプセンターのお知らせによると、すべてのプラン価格に10%の消費税が加わり、請求通貨は変わりません。
- **個人と法人で扱いが違います。** 課税事業者の法人は、Anthropic の適格請求書で仕入税額控除を受けられます。個人はこの控除を使えないため、消費税分はそのまま負担になります。

ドル建ての価格に10%を加えると、次のようになります（私たちの計算です）。

| プラン | 税抜 | 消費税10%込み |
|---|---:|---:|
| Pro（月払い） | $20 | $22 |
| Pro（年払い） | 月$17（年$200） | 月$18.70（年$220） |
| Max 5x | $100 | $110 |
| Max 20x | $200 | $220 |

円での引き落とし額は、カード会社の為替レートと手数料によって毎月変わります。ネットで見かける「Claude Code は約○○円」という数字は、記事ごとの為替換算で、公式の円価格ではありません。また Anthropic のヘルプセンターには、モバイルの価格はアプリのプラットフォームによって異なる場合があると書かれているので、iPhone や Android のアプリ内で契約する前に Web 版の価格と見比べましょう。日本での支払いの詳細は [Claude の料金プラン比較](/ja/blog/claude-ryoukin-plan)、ChatGPT・Gemini を含めた円での比較は[生成AIのサブスク料金比較](/ja/blog/ai-subscription-ryoukin-hikaku)にまとめています。

## Claude Code は無料で使える？

使えません。Claude の Free プランには Claude Code が含まれておらず、Claude Code の無料体験（トライアル）もありません。費用を抑えて始める方法は2つあります。

- **API で始める。** Claude Console のアカウントを作り、使ったトークンの分だけ払います。週に数回の小さなタスクなら、月$20を大きく下回ります（下の「1か月の費用」の表を参照）。
- **Pro を1か月だけ契約する。** $20で1か月使ってみて、上限に当たる頻度を見てから続けるかどうかを決めます。

本当に無料で使えるコーディングエージェントが欲しいなら、OpenAI の Codex は ChatGPT の無料プランで GPT-6 Luna を使って動きます。同じブロック崩しの依頼を無料プランの Codex で試した結果は [Codex の料金](/ja/blog/codex-ryoukin) にまとめました。Claude Code のインストールと最初の使い方は [Claude Code の使い方](/ja/blog/claude-code-tsukaikata) で、実際の画面を使って解説しています。

## API で使う場合の料金（100万トークンあたり）

Claude Code をプランではなく API クレジットで動かす場合は、Anthropic の通常の API 価格で払います。Claude API の料金ページによる、100万トークンあたりの価格です。

| モデル | 入力 | 出力 | キャッシュ書き込み（1時間） | キャッシュ読み込み |
|---|---:|---:|---:|---:|
| Fable 5.1 | $10 | $50 | $20 | $0.25 |
| Opus 5.5 | $4 | $20 | $8 | $0.20 |
| Sonnet 5.5 | $2 | $10 | $4 | $0.10 |
| Haiku 5.5（プロンプト10万トークン以下） | $0.10 | $0.50 | $0.20 | $0.01 |

- **Opus 5.5 のトークン単価は Sonnet 5.5 より100%高く**、Fable 5.1 は Opus 5.5 よりさらに150%高くなっています。
- **Claude Code を現実的な費用で使えるのは、キャッシュ読み込みのおかげです。** Opus 5.5 と Sonnet 5.5 ではキャッシュ読み込みが入力価格の5%、Fable 5.1 では2.5%です。Claude Code はコンテキストを自動でキャッシュします。

## 1タスクの実際の費用：4回の実測

2026年10月9日、Claude Code に同じ依頼を4回出しました。ブラウザで動くブロック崩しゲームを HTML ファイル1つで作り、2レベル、スコア、ライフ3つ、キーボードとマウスの操作に対応させるという内容です。トークン数は無料ツールの ccusage で測り、API 価格で金額に換算しました。

| モデル · effort | かかった時間 | ゲームのコード | API 価格での費用 |
|---|---:|---:|---:|
| Sonnet 5.5 · medium | 37秒 | 198行 | $0.25 |
| Sonnet 5.5 · high | 58秒 | 398行 | $0.30 |
| Opus 5.5 · medium | 52秒 | 358行 | $0.56 |
| Opus 5.5 · high | 1分50秒 | 523行 | $0.75 |

> **更新（2026年10月23日）：** Claude Code 2.1.295 で MCP サーバーなしに3回ずつ測り直すと、同じタスクは平均 $0.10（Sonnet 5.5 medium）、$0.12（Sonnet high）、$0.26（Opus 5.5 medium）、$0.35（Opus high）で、この表の10月9日の値より53〜61%安くなりました。[effort データセット](/data/claude-effort-cost)を参照。

- **4回とも、ちゃんと動くゲームができました。** effort を上げたり Opus を使ったりして増えたのは仕上がりの細かさで、動くか動かないかの差ではありませんでした。
- **費用の63〜81%はキャッシュ書き込みでした。** ゲームのコードそのもの（出力）は17〜33%です。キャッシュ読み込みはトークン数では最も多かったものの、費用では2〜4%にすぎませんでした。
- **合計の金額が合うのは、キャッシュ書き込みを1時間の料金（入力価格の200%）で計算したときだけでした。** これは ccusage の数字から私たちが読み取ったもので、今回の実行では Claude Code のキャッシュ書き込みが1時間の料金で課金されていたと考えています。
- **effort は料金を左右するレバーでもあります。** 思考（thinking）トークンは出力として課金され、high は medium より出力トークンを96〜97%多く使いました。

4つのゲームの画面と詳しいレビューは、[Claude Sonnet 5.5 vs Opus 5.5](/ja/blog/claude-sonnet-5-5-vs-opus-5-5) と [Claude Opus 5.5 の effort 比較](/ja/blog/claude-opus-5-5-effort) にまとめています。

## タスクの大きさ別の費用の目安

1ファイルのゲームは小さなタスクです。もっと大きな作業については、TokenSave の[コーディングエージェント費用計算機](/ja/agents)と同じ計算方法で見積もりました。エージェントはステップを重ねて作業し、ステップのたびに作業コンテキスト全体（指示、ツール定義、読んだファイル、それまでの経緯）をモデルに送り直します。書くコードが短くても、送るトークンは多くなるわけです。

表の低いほうの数字は計算機の値（新しいコンテキストを入力価格で計算）、高いほうは実測と同じく、新しいコンテキストを1時間のキャッシュ書き込み料金で計算した値です。

| タスク | ステップ | 送るトークン | Sonnet 5.5 | Opus 5.5 |
|---|---:|---:|---:|---:|
| 小さな修正 | 約8 | 約20万 | $0.14〜0.21 | $0.27〜0.43 |
| 新機能 | 約25 | 約160万 | $0.57〜0.81 | $1.14〜1.63 |
| 大規模リファクタ | 約60 | 約770万 | $1.91〜2.54 | $3.82〜5.07 |

- **Claude Code が送るトークンの大半は、読み直すコンテキストです。** 小さな修正では82%、大規模リファクタでは96%のトークンがキャッシュ読み込みです。160万トークンを送る新機能でも Sonnet なら$1を大きく下回るのは、このためです。
- **キャッシュがなければ、** Sonnet 5.5 での同じ新機能は$0.57ではなく約$3.38かかります。
- **実測したゲーム（Sonnet で$0.25〜0.30）は、小さな修正と新機能の間**に入ります。1ファイルのゲームとして妥当な位置です。

## Claude Code の1か月の費用（月額の目安）

月の稼働日を22日として、よくある4つの使い方を API 価格で計算しました。

| 使い方 | 月のタスク数 | API・Sonnet 5.5 | API・Opus 5.5 | たいてい合うプラン |
|---|---:|---:|---:|---|
| ライト：1日に小さな修正3件 | 66 | $9〜14 | $18〜28 | API または Pro |
| 普通：1日に新機能5件 | 110 | $63〜90 | $125〜179 | Pro または Max 5x |
| ヘビー：1日に新機能15件 | 330 | $188〜269 | $375〜537 | Max 5x または Max 20x |
| 一日中エージェント：大きなタスク1日8件 | 176 | $336〜446 | $672〜893 | Max 20x |

Anthropic 自身も参考になる数字を1つ公開しています。企業での導入全体の平均で、Claude Code の費用は**開発者1人あたり稼働日1日約$13、1か月$150〜250**で、利用者の90%は稼働日1日あたり$30未満に収まっているとのことです。これは私たちの表の「ヘビー・Sonnet」（1日$8.50〜12）と「ヘビー・Opus」（1日$17〜24）の間にあたります。

## プランが API より安くなる境目

Anthropic はプランの上限をトークン数や金額で公開していないので、境目は推定するしかありません。費用分析サイトの [FinOps LLM](https://finopsllm.com/research/claude-pro-max-tokens-limit) は、あるヘビーユーザーの Claude Code のセッションを、上限で止まるまで記録しました。

| プラン | 料金 | 5時間枠1回分を API 価格に換算 |
|---|---:|---|
| Pro | 月$20 | 約$7 *（私たちの推定）* |
| Max 5x | 月$100 | **約$37**（実測の中央値） |
| Max 20x | 月$200 | 約$150 *（私たちの推定）* |

Pro と Max 20x の数字は、実測された Max 5x の枠をもとに、Anthropic 自身が示しているプラン間の使用量の比率で換算したものです。桁の目安として見てください。Max 20x の1週間では約19億トークン、API 価格で約$1,800分の使用が記録されています。これに対してプランの料金は1か月で$200です。

上の1日あたりの費用と並べると、次のようになります。

- **ライトな使い方：** 稼働日1日あたりの費用が約$0.90未満なら、API のほうが Pro の月$20より安くなります。Sonnet で1日に小さな修正3件（$0.40〜0.60）なら十分に下回り、Opus（$0.80〜1.30）ならほぼ同じです。
- **Sonnet での普通の使い方（1日$2.80〜4.10）：** この推定では Pro の5時間枠1回に収まるので、Pro のほうが安くなります。Opus（1日$5.70〜8.10）では Pro の枠ぎりぎりです。ほぼ毎日上限に当たるなら Max 5x にしましょう。
- **ヘビーな使い方とエージェント：** Max です。同じ1か月を API で払うと$188〜893になります。

もう1つの制約が週の上限です。Max 5x で5時間枠には余裕があるのに週の上限に当たるなら、次の候補は Max 20x です。

## 私の使い方

私は Max 5x プランで毎日 Claude を使っています。Opus 5 の頃は上限を使い切っていましたが、Opus 5.5 になってからは上限に当たっていません。ただ、最近のある週は週の上限の93%まで使いました。Sonnet では細かいところを思いどおりに仕上げるまでに修正の回数が多く必要だったので、トークン単価が安くても、仕上がったタスク1つあたりの費用が安くなるとは限りませんでした。これは私の体験で、測定したものではありません。

## 思わぬ出費に注意

![思わぬ出費に注意: 環境変数に API キーが入っている。 ANTHROPIC_API_KEY が設定されていると、Claude Code は Pro や Max のログインではなくその API キーを使い、API 料金で課金されます。プラ](/claude-code-ryoukin-ja-4.jpg)

- **環境変数に API キーが入っている。** `ANTHROPIC_API_KEY` が設定されていると、Claude Code は Pro や Max のログインではなくその API キーを使い、API 料金で課金されます。プランの料金で使いたいなら、この環境変数を外してください。
- **上限を超えたあとの使用量クレジット。** 有料プランでは、上限に達したあとも使用量クレジット（usage credits）で作業を続けられますが、その分は通常の API 料金で課金されます。
- **高速モード（fast mode）。** Opus 5.5 の高速出力（リサーチプレビュー）は、API で100万トークンあたり入力$8・出力$40で、通常より100%高くなります。
- **長いセッション。** ステップのたびに会話全体が送り直されます。関係のないタスクの間は **/clear** で新しく始め、長いタスクでは **/compact** で要約しましょう。
- **日本語で指示を書く。** 同じ意味の文章でも、日本語は英語より約79%多いトークンが必要です（韓国語は約44%）。日本語の数字は GPT のトークナイザーで測ったもので、詳しくは[日本語プロンプトのトークン数の実測](/ja/blog/nihongo-tokens-gpt)にまとめています。自分のプロンプトは[トークンカウンター](/ja/)で数えられます。

自分の状況を確かめるには、**/usage**（セッションの費用を定価で表示。主に API 利用者向け）か **/status**（プランの使用枠の残りを表示）を実行します。さらに費用を抑える方法は [Claude Code のトークン節約術](/ja/blog/claude-code-token-setsuyaku) にまとめています。

## どれを選ぶか

1. **週に数回の小さなタスクなら：** API。月$20より安く済む可能性が高いです。
2. **Sonnet で毎日コーディングするなら：** Pro（月$20、年払いなら月$17）。
3. **ほぼ毎日 Pro の5時間上限に当たる、または一日中 Opus でコーディングするなら：** Max 5x（月$100）。
4. **何時間もエージェントを動かす、または Max 5x の週の上限に当たるなら：** Max 20x（月$200）。使用量あたりの単価が下がる唯一のプランです。
5. **CI パイプラインや自動化なら：** API。ジョブごとの費用をトークン単位で見積もれます。

どのプランでも、モデルはタスクごとに選びましょう。Sonnet 5.5 はトークン単価が Opus 5.5 の50%で、多くのコーディング作業をこなせます。私たちのテストでも、同じ effort で55〜60%安く済みました。プランの上限の仕組みは [Claude Code の使用量上限まとめ](/ja/blog/claude-code-shiyouryou-jougen) で、2つのプランの比較は [Claude Max vs Pro 比較](/ja/blog/claude-max-vs-pro) で解説しています。

## よくある質問

**Claude Code の料金は月いくらですか？**
Claude Pro なら月$20（年払いなら月$17）、Max 5x なら月$100、Max 20x なら月$200です。API の場合、普通の使い方（1日に新機能5件）で1か月あたり Sonnet 5.5 なら約$63〜90、Opus 5.5 なら約$125〜179です。

**日本では税込いくらになりますか？**
2026年4月1日から消費税10%が加わるため、Pro の月払いは$22、Max 5x は$110、Max 20x は$220です（私たちの計算）。Anthropic は円の公式価格を出しておらず、請求通貨も変わらないため、円での請求額はカード会社の為替レートで決まります。

**Claude Pro に Claude Code は含まれますか？**
はい。Claude Code は Pro、Max、Team、Enterprise に含まれ、Claude アプリと同じ使用量の上限を共有します。

**Claude Code は無料で使えますか？**
使えません。Free プランには含まれていません。たまに使うだけなら、トークン単位で払う API がいちばん安い方法です。

**Claude Code は API とプランのどちらが安いですか？**
週に数回の小さなタスクなら、API のほうが安くなります。ほぼ毎日使うなら Pro か Max のほうが安く、差がかなり大きくなることもよくあります。ヘビーに使った Max 20x の1週間は、API 価格で約$1,800分と記録されています。

**Max に付く月々の API クレジットを Claude Code に使えますか？**
使えません。Anthropic のヘルプセンターによると、Max に含まれる月々の API クレジットは Claude Code や Claude アプリでは使えません。

**Claude Code にいくらかかったかはどう確認しますか？**
/usage でセッションのトークン使用量と定価での費用を、/status でプランの使用枠があとどれだけ残っているかを確認できます。

## 自分の1か月を計算する

[コーディングエージェント費用計算機](/ja/agents)では、タスクの大きさ、1日のタスク数、稼働日数を入れると、Claude Code の API 費用を Claude と ChatGPT のすべてのプランと並べて比べられます。ほかのエージェントについては [Codex の料金](/ja/blog/codex-ryoukin) と [Cursor の料金プラン](/ja/blog/cursor-ryoukin) を、Pro そのものについては [Claude の料金プラン比較](/ja/blog/claude-ryoukin-plan) をご覧ください。

これまでに実際に使ったトークンと費用を知りたいときは、[Claude Code 使用量アナライザー](/ja/claude-code-usage)に記録フォルダを入れてみてください。日付・プロジェクト・モデル別のトークンと API 換算の費用を、ブラウザ内だけで計算して表示します。

*料金と上限は2026年10月12日に確認しました。Anthropic は上限をよく変更するので、決める前に [claude.com/pricing](https://claude.com/pricing) を確認してください。*
