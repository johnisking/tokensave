![클로드 API 가격 2026: 토큰당 비용·원화·결제 방법](/claude-api-gagyeok-ko.jpg)

클로드 API 가격은 100만 토큰당 입력/출력 기준으로 **소넷 5.5가 $2/$10, 오퍼스 5.5가 $4/$20, 하이쿠 5.5가 $0.10/$0.50, Fable 5.1이 $10/$50**입니다. 요금은 Claude Console에서 미리 사 둔 **선불 크레딧**에서 쓴 만큼 차감됩니다. Anthropic은 원화 가격표를 따로 내놓지 않았지만, 1달러=1,340원으로 가정한 우리 계산으로는 소넷 5.5가 100만 토큰당 입력 약 2,680원, 출력 약 13,400원입니다. 이 글에서는 모델별 클로드 API 비용과 원화 환산, 토큰 하나·메시지 하나의 가격, 클로드 코드로 실제 작업을 돌린 4회 실측, 그리고 크레딧을 사고 영수증을 받는 결제 방법까지 정리했습니다. API 가격은 2026년 10월 12일 Anthropic 공식 가격 페이지에서, 결제 방법은 2026년 10월 15일 Anthropic 고객센터와 공식 문서에서 확인했습니다.

## 클로드 API 가격표 (100만 토큰당, 2026)

![클로드 API 가격표 (100만 토큰당, 2026): 모델, 입력, 출력, 캐시 쓰기(5분), 캐시 쓰기(1시간), 캐시 읽기](/claude-api-gagyeok-api-100-2026-ko.jpg)

Anthropic 공식 가격 페이지에 나온 현재 클로드 모델의 API 정가입니다. 미국 달러 기준, 100만 토큰(MTok)당 가격입니다. 하이쿠 5.5는 프롬프트 길이에 따라 두 줄로 나뉩니다.

| 모델 | 입력 | 출력 | 캐시 쓰기(5분) | 캐시 쓰기(1시간) | 캐시 읽기 |
|---|---:|---:|---:|---:|---:|
| Fable 5.1 | $10 | $50 | $12.50 | $20 | $0.25 |
| 오퍼스 5.5 | $4 | $20 | $5 | $8 | $0.20 |
| 소넷 5.5 | $2 | $10 | $2.50 | $4 | $0.10 |
| 하이쿠 5.5 (프롬프트 10만 토큰 이하) | $0.10 | $0.50 | $0.125 | $0.20 | $0.01 |
| 하이쿠 5.5 (프롬프트 10만 토큰 초과) | $0.50 | $2.50 | $0.625 | $1 | $0.05 |

- **모든 현행 모델에서 출력은 입력보다 400% 비쌉니다.** 긴 답변이 비용을 키우는 이유입니다.
- **가격 차이가 가장 큰 곳은 모델 사이입니다.** 오퍼스 5.5는 소넷 5.5보다 100% 비싸고, 소넷 5.5는 하이쿠 5.5(10만 토큰 이하)보다 1,900% 비쌉니다.
- **캐시 읽기가 가장 싼 토큰입니다.** 오퍼스 5.5와 소넷 5.5에서는 입력 가격의 5%, Fable 5.1에서는 2.5%, 하이쿠 5.5에서는 10%입니다.
- **긴 프롬프트 가격이 따로 있는 모델은 하이쿠 5.5뿐입니다.** 프롬프트가 10만 토큰을 넘으면 그 요청의 모든 토큰이 아래 줄 가격으로 청구됩니다. 오퍼스 5.5, 소넷 5.5, Fable 5.1은 100만 토큰 맥락 창 전체를 표준 가격으로 받습니다.

이전 모델도 아직 예전 가격으로 팔립니다. 오퍼스 5는 입력 $5, 출력 $25로 오퍼스 5.5보다 25% 비싸고, 소넷 4.6은 $3와 $15로 소넷 5.5보다 50% 비쌉니다. 하이쿠 4.5는 $1와 $5입니다. 예전 모델 ID를 그대로 호출하고 있다면 5.5 버전으로 바꾸는 것만으로 토큰 단가가 내려갑니다. 무엇이 바뀌었는지는 [클로드 오퍼스 5 vs 5.5 차이](/ko/blog/claude-opus-5-vs-5-5)에 정리했습니다.

### 가격표에 없는 비용

Anthropic 공식 문서에 나오는, 토큰 단가를 바꾸는 항목들입니다.

| 항목 | 비용에 미치는 영향 |
|---|---|
| 생각(thinking) 토큰 | 출력 토큰으로 청구. effort가 높을수록 많아짐 |
| 배치 API | 기다려도 되는 작업은 입력·출력 50% 할인 |
| 프롬프트 캐시 쓰기 | 입력보다 25%(5분) 또는 100%(1시간) 비쌈 |
| 프롬프트 캐시 읽기 | 오퍼스 5.5·소넷 5.5에서 입력보다 95% 쌈 |
| 빠른 모드(오퍼스 5.5, 리서치 프리뷰) | 입력 $8, 출력 $40으로 표준보다 100% 비쌈 |
| 미국 내 추론(US-only) | 모든 토큰 종류에 10% 추가 |
| 도구 사용 | 5.5 모델은 요청마다 286토큰 시스템 프롬프트와 내 도구 정의가 붙음 |
| 웹 검색 | 검색 1,000회당 $10, 검색 결과는 입력 토큰으로 따로 청구 |
| 하이쿠 5.5 프롬프트 10만 토큰 초과 | 요청 전체가 400% 비싸짐 |

- **생각 토큰은 출력 가격으로 청구됩니다.** effort를 올리면 클로드가 답하기 전에 더 많이 생각하고, 그만큼 출력 요금이 붙습니다.
- **Anthropic에 따르면 배치 할인과 캐시 할인은 함께 받을 수 있습니다.**
- **도구 정의도 입력 토큰입니다.** 클로드가 그 도구를 부르든 안 부르든 요청마다 함께 전송됩니다.

## 토큰 하나·메시지 하나에 얼마

100만 토큰당 가격을 1,000,000으로 나누면 토큰 하나의 가격입니다. 1,000토큰 단위로 보면 읽기 쉽습니다.

| 모델 | 입력 토큰 1개 | 출력 토큰 1개 | 입력 1,000토큰 | 출력 1,000토큰 |
|---|---:|---:|---:|---:|
| Fable 5.1 | $0.00001 | $0.00005 | $0.01 | $0.05 |
| 오퍼스 5.5 | $0.000004 | $0.00002 | $0.004 | $0.02 |
| 소넷 5.5 | $0.000002 | $0.00001 | $0.002 | $0.01 |
| 하이쿠 5.5 | $0.0000001 | $0.0000005 | $0.0001 | $0.0005 |

소넷 5.5의 출력 토큰 하나는 1센트의 1,000분의 1입니다. 1달러면 소넷 5.5로 입력 50만 토큰 또는 출력 10만 토큰, 오퍼스 5.5로 입력 25만 또는 출력 5만 토큰, 하이쿠 5.5로 입력 1,000만 또는 출력 200만 토큰을 쓸 수 있습니다.

하지만 요청 하나가 토큰 하나로 끝나지는 않습니다. 아래는 흔한 요청 네 가지를 정가로 계산한 값입니다. Anthropic은 클로드의 단어당 토큰 비율을 공개하지 않아서, **영어 1단어를 클로드 토큰 약 1.6개**로 잡았습니다. 우리가 GPT 토크나이저로 잰 값에, 같은 영어 문장에서 현행 클로드 모델이 GPT보다 토큰을 약 38% 더 쓴 우리 측정값([데이터셋](/data/token-cost-by-language-claude-gemini))을 얹은 것이고, Anthropic 수치가 아닙니다. 측정값이 아니라 **영어 텍스트 기준 계산값**이며, 생각 토큰·도구·캐싱은 빼고 단순하게 계산했습니다.

| 요청 (영어 기준) | 입력 / 출력 토큰 | 하이쿠 5.5 | 소넷 5.5 | 오퍼스 5.5 |
|---|---|---:|---:|---:|
| 짧은 질문 + 300단어 답변 | 80 / 480 | $0.0002 | $0.005 | $0.010 |
| 5,000단어 보고서를 400단어로 요약 | 8,000 / 640 | $0.001 | $0.022 | $0.045 |
| 100쪽 문서(약 4만 단어) + 1,000단어 답변 | 64,000 / 1,600 | $0.007 | $0.144 | $0.29 |
| 대화 기록이 3만 토큰 쌓인 대화의 메시지 하나 | 30,000 / 640 | $0.003 | $0.066 | $0.133 |

- **짧은 답은 1센트도 안 됩니다.** 소넷 5.5와 오퍼스 5.5 모두 그렇습니다.
- **문서를 붙여 넣으면 입력 비용이 답변보다 더 컸습니다.** 출력 토큰 단가가 더 비싼데도 그렇습니다.
- **긴 대화일수록 메시지 하나가 비쌉니다.** 메시지마다 대화 전체를 입력으로 다시 보내기 때문입니다. 소넷 5.5에서 3만 토큰짜리 대화는 메시지당 $0.066으로, 짧은 질문의 0.5센트와 차이가 큽니다. 프롬프트 캐싱을 켜면 대화 기록을 입력 가격의 5%인 캐시 읽기로 가져오므로, 같은 메시지가 소넷 5.5로 약 $0.009, 오퍼스 5.5로 약 $0.019입니다.

## 한국어로 쓰면 비용이 더 드는 이유

![한국어로 쓰면 비용이 더 드는 이유: 같은 내용이라도 한국어는 영어보다 토큰이 약 44% 더 나왔습니다. 같은 프롬프트를 41개 언어로 옮겨 잰 우리 측정 결과입니다. 일본어는 약 79%, 스페인어는 약 18% 더 많았습니다. 다만 G](/claude-api-gagyeok-ko-4.jpg)

토큰은 모델이 읽고 쓰는 텍스트 조각입니다. 짧은 단어 하나일 때도 있고, 긴 단어의 일부나 띄어쓰기, 문장 부호일 때도 있습니다. 회사마다 텍스트를 나누는 토크나이저가 달라서 같은 문단이라도 클로드, GPT, 제미나이에서 토큰 수가 다르게 나옵니다. 클로드 API는 토큰 단위로 돈을 받으니, 같은 내용을 몇 토큰으로 쓰느냐가 곧 비용입니다.

- **같은 내용이라도 한국어는 영어보다 토큰이 약 44% 더 나왔습니다.** 같은 프롬프트를 41개 언어로 옮겨 잰 우리 측정 결과입니다. 일본어는 약 79%, 스페인어는 약 18% 더 많았습니다. 다만 GPT 토크나이저(o200k_base)로 잰 값입니다. 같은 프롬프트를 현행 클로드 모델로 다시 재 보니 한국어는 영어보다 약 89%, 일본어는 약 51%, 스페인어는 약 47% 더 나왔습니다([데이터셋](/data/token-cost-by-language-claude-gemini)). 위 메시지 표는 영어 기준이니, 한국어로 쓸 때는 토큰이 더 나올 수 있다고 보고 실제 텍스트로 세어 보는 게 안전합니다.
- **새 클로드 모델은 같은 텍스트에 토큰을 더 씁니다.** Anthropic에 따르면 클로드 4.7 이후 모델은 새 토크나이저를 써서, 같은 텍스트에 이전 모델보다 토큰이 약 30% 더 나옵니다. 위 가격표의 5.x 모델은 모두 이 토크나이저를 씁니다. 토크나이저는 4.7에서 바뀌었고, 토큰 단가가 내려간 건 그 뒤 5.5에서입니다.
- **웹 문서는 금방 쌓입니다.** Anthropic이 내놓은 기준으로 평균 10KB 웹 페이지는 약 2,500토큰, 100KB짜리 큰 문서 페이지는 약 25,000토큰, 500KB 논문 PDF는 약 125,000토큰입니다.

반대로, 같은 프롬프트를 영어로 보내면 한국어보다 토큰이 약 31% 줄었습니다(GPT 토크나이저 기준 우리 측정). 매 요청마다 함께 가는 긴 시스템 프롬프트나 지시문이라면 영어로 써 두는 것만으로 입력 비용을 줄일 수 있습니다. 41개 언어 결과와 측정 방법은 [한국어 프롬프트, 영어로 보내면 토큰 31% 절약](/ko/blog/korean-tokens-gpt)에 있고, 내 한국어 텍스트가 클로드 모델에서 몇 토큰, 얼마인지는 [클로드 토큰 계산기](/ko/claude-token-counter)로 어림해 볼 수 있습니다.

## 클로드 코드 실측 4회: 돈은 어디로 나갔나

위 계산은 단순한 채팅 기준입니다. 클로드 코드 같은 에이전트는 작업 맥락을 프롬프트 캐시에 크게 써 두고 단계마다 다시 읽기 때문에 비용 구조가 다릅니다. 우리 실측(2026년 10월 9일)에서 클로드 코드로 같은 작은 브라우저 게임(벽돌깨기)을 모델과 effort를 바꿔 네 번 만들었습니다. 토큰 수는 무료 도구 ccusage로 쟀고, 비용은 API 가격으로 환산한 값입니다. 게임 화면을 포함한 전체 테스트는 [클로드 소넷 5.5 vs 오퍼스 5.5 실측 비교](/ko/blog/claude-sonnet-5-5-vs-opus-5-5)에 있습니다.

| 실행 | 출력 토큰 | 캐시 쓰기 토큰 | 캐시 읽기 토큰 | 합계 | 비용 |
|---|---:|---:|---:|---:|---:|
| 소넷 5.5 · medium | 4,100 | 50,337 | 60,632 | 115,073 | $0.25 |
| 소넷 5.5 · high | 8,073 | 53,980 | 75,536 | 137,593 | $0.30 |
| 오퍼스 5.5 · medium | 6,299 | 53,002 | 74,123 | 133,428 | $0.56 |
| 오퍼스 5.5 · high | 12,376 | 59,146 | 151,326 | 222,854 | $0.75 |

새 입력은 실행마다 4~6토큰뿐이라 표에서 뺐습니다. 원화로는 작업 한 번에 약 335원(소넷 medium)에서 약 1,005원(오퍼스 high)입니다(1달러=1,340원 우리 계산). 각 실행 비용을 Anthropic 가격으로 토큰 종류별로 나눠 보면 이렇습니다.

| 실행 | 출력 비중 | 캐시 쓰기 비중 | 캐시 읽기 비중 | 100만 토큰당 평균 비용 |
|---|---:|---:|---:|---:|
| 소넷 5.5 · medium | 17% | 81% | 2% | $2.16 |
| 소넷 5.5 · high | 27% | 71% | 2% | $2.21 |
| 오퍼스 5.5 · medium | 22% | 75% | 3% | $4.23 |
| 오퍼스 5.5 · high | 33% | 63% | 4% | $3.37 |

- **비용의 63~81%가 캐시 쓰기였습니다.** 게임 코드 자체인 출력은 17~33%였습니다.
- **캐시 읽기는 토큰은 가장 많고 비용은 가장 적었습니다.** 오퍼스 high에서는 전체 토큰의 68%가 캐시 읽기였지만 비용으로는 4%였습니다.
- **합계는 1시간 캐시 쓰기 가격으로 계산해야 맞습니다.** 캐시 쓰기를 5분 가격으로 계산하면 소넷 medium이 $0.25가 아니라 $0.17, 오퍼스 high가 $0.75가 아니라 $0.57이 됩니다. ccusage 합계는 1시간 가격(100만 토큰당 소넷 5.5 $4, 오퍼스 5.5 $8), 즉 입력 가격의 200%와 맞아떨어집니다. 이번 실행에서 클로드 코드의 캐시 쓰기가 1시간 가격으로 청구됐다는 건 숫자를 보고 우리가 읽은 해석입니다.
- **평균 토큰 단가는 입력 가격 근처였습니다.** 실행 전체를 섞어 보면 100만 토큰당 소넷 5.5는 약 $2.2, 오퍼스 5.5는 $3.4~4.2로, 각 모델의 입력 가격과 비슷했습니다.

더 긴 실행은 모습이 달랐습니다. [클로드 오퍼스 5 vs 5.5 비교](/ko/blog/claude-opus-5-vs-5-5)에서 따로 돌린 오퍼스 5.5 실행은 674,452토큰 중 88%가 캐시 읽기였습니다. 같은 방식으로 계산하면 그 실행의 비용 $0.93 중 캐시 읽기가 13%, 캐시 쓰기가 55%, 출력이 33%이고, 평균은 100만 토큰당 약 $1.38입니다. 단계가 많을수록 싼 캐시 읽기의 비중이 커진 셈인데, 한 번의 실행이니 규칙이 아니라 예시로 보세요.

정리하면, 에이전트 작업에서 출력 토큰만 보고 예산을 잡으면 청구액 대부분을 놓칩니다. 캐시 쓰기까지 함께 계산해야 합니다. 클로드 코드를 한 달 쓰면 얼마인지는 [클로드 코드 요금](/ko/blog/claude-code-yogeum)에 정리했습니다.

## 클로드 API 결제 방법: 선불 크레딧 충전

클로드 API는 기본적으로 **크레딧을 먼저 사 두고 쓰는 선불 방식**입니다. Anthropic 고객센터 안내(2026년 10월 15일 확인)에 따르면 Claude API, Console의 플레이그라운드(playground), 그리고 Console 계정으로 쓰는 클로드 코드가 모두 이 선불 사용 크레딧으로 결제되고, 크레딧은 그 시점의 가격으로 차감됩니다. 매달 쓴 만큼 나중에 청구서로 받는 월별 인보이스는 Anthropic 영업팀(Sales)과 인보이스 계약을 맺은 조직만 쓸 수 있습니다.

**크레딧 사는 순서**

1. **Claude Console(platform.claude.com)에 로그인합니다.** 크레딧을 사려면 조직에서 관리자(Admin) 또는 결제(Billing) 역할이 있어야 합니다.
2. **Settings > Billing으로 갑니다.**
3. **Buy credits를 누릅니다.**
4. **충전할 금액을 입력하고 결제를 확인합니다.**
5. **산 크레딧은 바로 쓸 수 있습니다.** 남은 잔액과 사용량도 같은 Billing 페이지에서 확인합니다.

**알아 둘 규칙**

- **자동 충전(auto-reload):** 잔액이 내가 정한 기준 아래로 떨어지면 크레딧을 자동으로 삽니다. 기준 금액과 한 번에 충전할 금액은 직접 정합니다.
- **잔액이 0이 되면 멈춥니다.** 크레딧을 다 쓰면 다시 충전할 때까지 API를 호출할 수 없고 플레이그라운드도 쓸 수 없습니다. 서비스 중인 앱이라면 자동 충전을 켜 두거나 잔액을 자주 확인하세요.
- **성공한 호출만 청구됩니다.** 실패한 요청에는 요금이 붙지 않습니다. 다만 성공할 예정이던 요청을 내 쪽에서 연결을 끊거나 시간 초과로 놓친 경우에는 그 요청도 청구됩니다.
- **유효기간은 구매일로부터 1년입니다.** 만료일은 연장할 수 없습니다.
- **환불되지 않습니다.** 크레딧 구매는 모두 환불 불가입니다. 처음에는 필요한 만큼만 충전하는 편이 안전합니다.

**영수증 받기**

선불로 쓰는 조직은 크레딧을 살 때마다(자동 충전 포함) "Your receipt from Anthropic"이라는 제목의 영수증 이메일을 받습니다. Console의 Settings > Billing > Invoice history에서도 내려받거나(Download) Stripe 화면으로 볼(View) 수 있습니다.

## 세금과 결제 주소

- **세금은 청구 주소를 기준으로 계산됩니다.** Anthropic 고객센터에 따르면 API 셀프서브(사용량 티어) 계정은 청구 주소가 결제 수단인 카드에 묶여 있습니다.
- **청구 주소를 바꾸려면** Console의 Settings > Billing에서 카드 번호 옆 연필 아이콘을 누릅니다.
- **미국 밖 고객이 부가가치세(VAT) 처리를 위해 고정된 주소가 필요하다면,** VAT 등록 증명서를 첨부해 고객센터에 문의하라고 안내합니다.
- **한국에서 붙는 세율은 Anthropic이 따로 적어 두지 않았습니다.** 위 원화 계산에도 세금은 넣지 않았으니, 최종 결제 금액은 크레딧을 살 때 결제 화면에서 확인하세요.

## Max 요금제의 월 API 크레딧

Max 구독에는 API에 쓸 수 있는 월 크레딧이 들어 있습니다. Anthropic 공식 문서(2026년 10월 15일 확인) 기준입니다.

| 요금제 | 월 API 크레딧 |
|---|---:|
| Max 5x | $100 |
| Max 20x | $200 |
| Team | Standard 좌석당 $20, Premium 좌석당 $100 (조직 합산, 월 최대 $500) |
| 무료·프로·Enterprise | 대상 아님 |

- **쓸 수 있는 곳:** Claude API, Managed Agents, Agent SDK, 플레이그라운드.
- **쓸 수 없는 곳:** 클로드 코드, 그리고 클로드 앱에서 한도를 넘긴 뒤 쓰는 추가 사용량(extra usage). 클로드 코드는 구독 한도 안에서 쓰거나, Console에서 직접 산 크레딧으로 씁니다.
- **직접 산 크레딧보다 먼저 차감됩니다.**
- **이월되지 않습니다.** 결제 주기마다 새로 채워지고, 남은 크레딧은 그 주기가 끝나면 사라집니다.
- **새 구독자는 7일이 지나야 받을 수 있습니다.**
- **받는 방법:** claude.ai의 Settings > Billing에서 Console 조직을 연결해 받습니다.
- **프로 구독자는 받을 수 없습니다.** 무료와 Enterprise도 대상이 아닙니다.

## 구독(프로·Max)과 API 중 뭐가 싼가

클로드 프로(미국 기준 월 $20)와 Max(월 $100 또는 $200)는 토큰당 과금이 아닙니다. 5시간마다 초기화되는 사용량 한도와 주간 한도가 있고, 클로드 앱과 클로드 코드가 이 한도를 함께 씁니다. Anthropic은 이 한도를 토큰 수로 공개하지 않습니다. 1달러=1,340원 우리 계산으로는 프로가 약 2만 7천원, Max 5x가 약 13만 4천원, Max 20x가 약 26만 8천원입니다(세금 전).

많이 쓰는 사람에게는 요금제가 토큰당 훨씬 쌌습니다. [FinOps LLM](https://finopsllm.com/research/claude-pro-max-tokens-limit)이 한 사용자의 클로드 코드 세션을 기록한 결과, Max 5x의 5시간 한 번은 API 가격으로 약 $37어치였고, Max 20x의 한 주는 약 19억 토큰이었습니다. 이 한 주를 우리가 API 가격으로 계산하면 약 $1,800인데, Max 20x 한 달 요금은 $200입니다. 그 토큰의 96%는 캐시 읽기였습니다.

| 이런 경우 | 보통 더 싼 쪽 |
|---|---|
| 클로드를 매일 쓰고, 특히 클로드 코드를 많이 쓴다 | 프로 또는 Max |
| 내 앱·서비스에서 클로드를 호출한다 | API 종량제 |
| 일주일에 몇 번만 쓴다 | API 종량제 (한 달 $20보다 적게 들 수 있음) |
| 이미 Max를 쓰고 있고 API도 필요하다 | 포함된 월 API 크레딧부터 사용 |

내 사용량으로 직접 비교하려면 [구독 vs API 계산기](/ko/plans)를 쓰세요. 요금제별 기능과 한도, 원화 가격은 [클로드 요금제 총정리](/ko/blog/claude-yogeumje)에 있습니다.

## 클로드 API 비용 줄이는 법

1. **작업에 맞는 가장 작은 모델을 고릅니다.** Anthropic은 하이쿠 5.5를 분류, 정보 추출, 라우팅용으로 소개하고, 가격은 소넷 5.5보다 95% 쌉니다. 코딩은 대부분 소넷 5.5로 충분하고, 우리 실측에서도 같은 effort 기준 오퍼스 5.5보다 55~60% 쌌습니다.
2. **반복되는 내용에는 프롬프트 캐싱을 켭니다.** 긴 시스템 프롬프트, 여러 번 질문하는 문서, 길어지는 대화가 대상입니다. 5.5 모델에서 캐시 읽기는 새 입력보다 95% 쌉니다.
3. **기다려도 되는 작업은 배치 API로 보냅니다.** 밤새 돌리는 요약, 대량 태깅, 평가 작업은 50% 할인됩니다.
4. **출력을 짧게 요청합니다.** 필요한 길이를 정해 주세요. 출력이 가장 비싼 토큰입니다.
5. **단순한 작업은 effort를 낮춥니다.** 우리 실측에서 high는 medium보다 출력 토큰을 96~97% 더 썼습니다. 자세한 결과는 [클로드 오퍼스 5.5 effort 비교](/ko/blog/claude-opus-5-5-effort)에 있습니다.
6. **관련 없는 작업은 새 대화로 시작합니다.** 클로드 코드에서는 /clear로 예전 맥락이 계속 전송되지 않게 합니다. 더 많은 방법은 [클로드 코드 토큰 절약 방법 9가지](/ko/blog/claude-code-token-jeolyak)에 있습니다.
7. **자주 쓰는 긴 지시문은 영어로 씁니다.** 한국어 프롬프트를 영어로 보내면 토큰이 약 31% 줄었습니다(GPT 토크나이저 기준 우리 측정).

## 자주 묻는 질문

**클로드 API 가격은 토큰당 얼마인가요?**
소넷 5.5는 입력 토큰 하나가 $0.000002, 출력 토큰 하나가 $0.00001입니다(100만 토큰당 $2와 $10). 오퍼스 5.5는 100만 토큰당 $4와 $20, 하이쿠 5.5는 $0.10과 $0.50, Fable 5.1은 $10과 $50입니다. 1달러=1,340원 우리 계산으로 소넷 5.5는 100만 토큰당 입력 약 2,680원, 출력 약 13,400원입니다.

**클로드 API는 무엇으로 결제하나요?**
Claude Console의 Settings > Billing에서 선불 크레딧을 사서 씁니다. Anthropic 고객센터 안내에 나오는 결제 수단은 카드이고, 청구 주소도 그 카드에 묶여 있습니다. 매달 청구서로 받는 방식은 영업팀과 인보이스 계약을 맺은 조직만 쓸 수 있습니다.

**최소 충전 금액이 있나요?**
Anthropic 고객센터의 결제 안내 페이지에는 최소 충전 금액이 나와 있지 않습니다. Buy credits 화면에 금액을 직접 입력하는 방식이니, 입력할 수 있는 금액은 그 화면에서 확인하세요. 크레딧은 환불되지 않고 1년 뒤 만료되므로 처음에는 적게 충전해 보는 편이 좋습니다.

**남은 크레딧은 환불되나요?**
아닙니다. 크레딧 구매는 모두 환불되지 않고, 구매일로부터 1년이 지나면 만료되며 연장할 수도 없습니다. 실패한 API 요청은 처음부터 청구되지 않습니다.

**클로드 API는 챗GPT API보다 비싼가요?**
정가로는 아닙니다. 100만 토큰당 소넷 5.5와 GPT-6.1 Sol은 둘 다 입력 $2, 출력 $10이고, 하이쿠 5.5는 GPT-6 Luna와, Fable 5.1은 GPT-6 Astra와 가격이 같습니다. 구글 Gemini 3.1 Pro(프리뷰, 20만 토큰 이하)는 $2/$12입니다(각 회사 가격 페이지, 2026년 10월 11일 기준). 다만 모델마다 같은 텍스트를 다른 토큰 수로 세고 같은 작업에 쓰는 토큰 양도 달라서, 실제 청구액은 작업 단위로 비교해야 합니다. 22개 모델 비교는 [LLM API 가격 비교](/ko/blog/llm-api-gagyeok-bigyo)에 있습니다.

**Max 요금제의 API 크레딧으로 클로드 코드를 쓸 수 있나요?**
아닙니다. Max 5x의 월 $100, Max 20x의 월 $200 API 크레딧은 Claude API, Managed Agents, Agent SDK, 플레이그라운드에 쓸 수 있고, 클로드 코드와 클로드 앱의 추가 사용량에는 쓸 수 없습니다. 클로드 코드는 Max 구독 한도 안에서 쓰거나, Console에서 직접 산 크레딧으로 씁니다.
