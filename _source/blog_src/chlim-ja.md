![ChatGPT の回数制限・使用量上限まとめ2026：プラン別と5時間枠](/chatgpt-shiyouryou-jougen-ja.jpg)

「上限に達しました」は、かつて ChatGPT でいちばん多い不満でした。2026年の今もこの表示は出ますが、出る場所が変わっています。OpenAI は普段のテキストチャットの回数制限をなくしたあと、GPT-6 と GPT-6 Astra、ChatGPT Work と Codex が共有する使用枠、3段階の Pro プラン、そして独自のタイミングでリセットされる5時間枠を次々に加えました。そのため「ChatGPT はどれくらい使えるのか」という質問には、何をするかによって答えがいくつもあります。この記事では、ChatGPT の回数制限・使用量上限をプラン別、制限の種類別に分けて、それぞれがいつリセットされるのか、何が使用枠を早く減らすのか、上限に当たったときに何ができるのかを整理します。数値はすべて OpenAI のヘルプセンター、料金ページ、Codex のドキュメントを2026年10月13日に確認したものです。

## ChatGPT に使用制限はある？

あります。ただし、多くの人が思っている場所にはありません。今の ChatGPT の制限は3種類に分かれていて、互いに独立しています。

1. **チャット（Chat）の制限。** 普段のテキストチャットは、すべての個人向けプランで無制限です（不正利用防止の仕組みは適用）。チャットの中で上限があるのは、高い思考レベル（Thinking）、Pro モデル（GPT-6 Pro と GPT-5.6 Sol Pro）、そしてファイルのアップロード、画像生成、データ分析、ディープリサーチなどのツールです。
2. **Work と Codex の共有枠。** ChatGPT Work と Codex は、プランごとに1つの使用枠を共有します。Plus と Business Standard では5時間枠と週の枠が同時にかかります。GPT-6 Astra や GPT-6.1 Sol を使うのはここで、ヘビーユーザーがいちばんよく当たる上限もこれです。
3. **音声などその他の機能。** ChatGPT の音声（GPT-Live）にはプランごとに1日の利用時間があり、ほかにも個別の上限を持つ機能があります。

1つの上限に当たっても、ほかが使えなくなるわけではありません。Work の枠を使い切っても普通のチャットはたいてい続けられますし、GPT-6 Pro が週の上限に達すると、ChatGPT が別のモデルに切り替えることもあります。

## 普段のチャット：無制限、ただし不正利用対策あり

2026年8月6日、OpenAI はリリースノートで、Free と Go のユーザーに翌週から「無制限のテキストチャット」と、難しい質問向けの Think ボタンを提供すると発表しました。現在の料金ページは、すべての個人向けプランで普段のテキストチャットを無制限と表示しています。

「無制限」について知っておきたい点は3つです。

- **対象は普通のテキストの回答です。** Free と Go では GPT-5.6 Luna が答え、Think ボタンも GPT-5.6 Luna を使います。Plus 以上では、アカウントに GPT-6 が届くと Instant を GPT-6 Sol が担当します。
- **ツールには今も上限があります。** OpenAI は「ファイルのアップロード、画像生成、音声、データ分析、その他のツールには別の上限が引き続き適用される」と案内しています。料金ページも、Free と Go のアップロードを含むメッセージ、画像生成、ディープリサーチ、メモリー、Codex を「限定的」としています。
- **不正利用対策があります。** 自動化された利用、アカウントの共有、転売は一時的な利用制限につながることがあり、その場合は OpenAI が通知するとしています。

つまり、普通のテキストメッセージを送るだけなら、どのプランでもメッセージ数の上限を見ることはないはずです。それでも上限の表示が出るなら、思考レベル、Pro モデル、ツールのどれかを使っている可能性が高いと言えます。

## 回数制限の数字が記事ごとに違う理由

「ChatGPT の回数制限」で検索すると、「3時間あたり何回」といった固定の回数を載せた記事がまだ多く見つかります。これは以前のモデル時代の考え方で、今の OpenAI の公式説明とは合いません。

- **Work と Codex の枠は固定の回数ではありません。** OpenAI は「使用枠は決まったメッセージ数やタスク数に対応しない」と書いています。同じ1メッセージでも、作業の大きさ、モデル、推論レベルで消費量が大きく変わるからです。
- **公式の数字は「目安の幅」です。** 後で紹介する5時間あたりのメッセージ数も「推定であり、保証された回数ではない」とされています。
- **チャットの回数制限はなくなりました。** 普段のテキストチャットは無制限になったので、「無料版は○回まで」という数字は今のチャットには当てはまりません。上限があるのは思考レベル、Pro モデル、ツールです。

- **同じプランでも時期で枠が変わります。** たとえば Pro 200 は、新規の契約では以前より少ない枠になりました。2026年9月22日から9月29日（太平洋時間午前10時）までのあいだに Pro 200 を契約していた人は、10月29日まで以前の枠を使えて、その後は新しい枠に移ります。料金は月$200のままです。同じ「Pro 200」でも、契約した時期によって使える量が違うということです。
- **Fast や Ultrafast を使うかでも変わります。** 同じプラン・同じモデルでも、Fast は Standard の250%、Ultrafast は800%の速さで枠を使うので、体感の回数は大きく変わります。

記事によって数字が違うときは、いつ時点の情報か、チャットの話か Work・Codex の話か、どの速度モードの話かを確かめると混乱しにくくなります。

## 思考レベルと Pro モデル

チャットの思考（Thinking）スライダーがどのモデルで答えるかを決め、チャットの上限が実際にかかるのもここです。

| 思考レベル | モデル（GPT-6 選択時） | Plus | Pro | Business | Free・Go |
|---|---|:---:|:---:|:---:|:---:|
| Instant | GPT-6 Sol | ✓ | ✓ | ✓ | GPT-5.6 Luna |
| Medium・High | GPT-6 Sol | ✓ | ✓ | ✓ | – |
| Extra High | GPT-6 Sol | – | ✓ | ✓ | – |
| Pro | GPT-6 Pro（GPT-6 Astra ベース） | – | ✓ | ✓ | – |

- **思考レベルの上限はプランによって違います。** 上限に達すると「ChatGPT は別の利用可能なモデルで続けることがあり」、情報があればリセット時刻を表示します。
- **GPT-6 Pro はどのプランでも無制限ではありません。** OpenAI は「Pro のサブスクリプションには GPT-6 Pro モデルの無制限利用は含まれない」と明記しています。
- **Pro $100：** GPT-6 Pro と GPT-5.6 Sol Pro が1つの週の枠を共有します。モデルを切り替えてもメッセージは増えません。
- **Pro $200：** GPT-6 Pro の週の上限に達すると、GPT-5.6 Thinking の Medium に自動で切り替わります。GPT-5.6 Sol Pro は、1日の枠が残っている間は使えます。
- **Business：** Standard の席は月15回、Premium の席は週50回の Pro メッセージを、GPT-6 Pro と GPT-5.6 Sol Pro で共有します。
- **Plus はチャットで GPT-6 Pro を使えません。** 代わりに Work と Codex で、下の共有枠の範囲で GPT-6 Astra を使えます。

## Work と Codex：共有の使用枠

![Work と Codex：共有の使用枠: モデル, Plus, Business Standard](/chatgpt-shiyouryou-jougen-work-codex-ja.jpg)

「5時間制限」と言うとき、多くはこの枠のことです。ChatGPT Work と Codex は1つの使用枠を共有し、この枠は決まったメッセージ数ではありません。OpenAI は Plus と Business Standard について、5時間あたりのローカルメッセージ数を幅で示しています。

| モデル | Plus | Business Standard |
|---|---:|---:|
| GPT-6 Astra | 5〜45 | 5〜45 |
| GPT-6.1 Sol | 15〜160 | 15〜160 |
| GPT-6 Sol | 15〜150 | 15〜150 |
| GPT-6 Luna | 350〜3,000 | 350〜3,000 |
| GPT-5.6 Sol | 記載なし | 10〜100 |
| GPT-5.6 Terra | 記載なし | 25〜200 |
| GPT-5.6 Luna | 記載なし | 250〜2,000 |

GPT-6 系の数値は OpenAI の Codex 料金ページと Astra のヘルプ記事、GPT-5.6 系は Business のモデルと上限のヘルプ記事に基づきます。Business のヘルプでは、Standard 席の GPT-6.1 Sol と GPT-6 Sol をまとめて15〜150としています。

- **幅が大きいのには理由があります。** 1行の修正も、複数ステップの長い作業も同じ「1メッセージ」ですが、使う量は大きく違います。クラウドタスクはローカルのメッセージより多く使うことがあります。
- **Pro プランには現在、Work と Codex の5時間枠がありません。** ただし含まれる使用枠はあり、Settings → Usage（設定 → 使用量）に表示されます。
- **Business Premium** は Standard 席の500%にあたる Work と Codex の枠があり、5時間枠はありません。Standard 席は枠の中で Astra を「限定的に」使え、Premium は枠をすべて Astra に使えます。
- **Free と Go** は、Codex の料金ページによると、デスクトップアプリで GPT-6 Luna を使って Codex と ChatGPT Work を限定的に使えます。
- **モデルを切り替えても枠は戻りません。** OpenAI は、モデルを切り替えても「共有の使用枠は回復しない」としています。軽いモデルは、残りの枠を長持ちさせるだけです。

## 5時間枠のしくみ

Plus と Business Standard の Work と Codex には、2つの枠が同時にかかります。

- **5時間枠。** 前の枠が終わったあと、Work か Codex に最初のメッセージを送った時点から始まります。決まった時刻ではないので、同じプランの2人でもリセット時刻が違うことがあります。
- **週の枠。** 1週間に使える含まれる使用量の合計を決めます。

使い続けるには、両方の枠に余裕が必要です。そのため、週の枠がたっぷり残っていても1時間の重い作業で5時間枠に当たることがありますし、週末にまとめて使うと、5時間枠が新しく始まっても火曜日に止まることがあります。

Pro プランと Business Premium には5時間枠がありませんが、全体の使用枠とリセット時刻はあります。Free と Go にも5時間枠は見当たりません。後で紹介する無料プランの Codex テストでは、使用量メニューに月単位のバーが1本あるだけでした。

## 使用枠を早く減らすもの

プロンプトの長さだけでは見積もれません。OpenAI は、モデル、コンテキスト、推論、ツールの利用、検索、キャッシュを主な要因に挙げています。自分で調整できるのは次の点です。

- **モデル。** GPT-6 Astra はタスクあたりいちばん多く、GPT-6 Luna はいちばん少なく使います。上の Plus の幅で比べると、Astra の5〜45回に対して Luna は350〜3,000回です。
- **推論レベル。** 高いレベルほど多く使い、OpenAI も「必ずしも良い結果になるとは限らない」としています。Sol を High で使う前に、Astra を Low か Medium で試すことも勧めています。
- **速度モード。** Fast モードは含まれる使用枠を Standard の250%の速さで使います。Pro プランでは Pro 500 だけにある Ultrafast は、GPT-6 Astra と GPT-6.1 Sol で800%の速さで使います。
- **画像。** Work と Codex での画像生成は、画像なしの同じような作業より平均300〜500%の速さで枠を使います（品質とサイズによって変わります）。
- **コンテキスト。** 大きな指示ファイル、たくさん接続した MCP サーバー、長い資料は、どれもメッセージごとにトークンを増やします。OpenAI は AGENTS.md を小さくし、使っていない MCP サーバーは切るよう勧めています。

## 音声・画像・ファイル

これらの機能にはそれぞれ上限があり、Free と Go のユーザーが今も上限の表示を見るいちばんの理由です。

| 機能 | Free | Go | Plus | Pro |
|---|---|---|---|---|
| 音声（GPT-Live）、1日 | 限定的 | 最大3時間（GPT-Live-1 mini） | 最大3時間 | Pro 100：最大15時間、Pro 200：無制限 |
| 画像生成 | 限定的 | より高い上限 | 上限あり、より高品質 | 無制限* |
| ファイルのアップロード | 限定的 | より高い上限 | 拡大 | Plus 以上 |
| ディープリサーチ | 限定的 | 限定的 | 拡大 | 最大 |

音声の時間は OpenAI の2026年9月9日のリリースノート、そのほかは料金ページに基づいています。ほとんどの機能は正確な回数を公開していません。Plus と Pro は、音声の上限に達しても GPT-Live mini に切り替わらなくなりました。デスクトップの Codex アプリの音声はまた別で、Codex の使用枠から1分あたり$0.05を使います。画像をたくさん作るなら、同じ画像を API で作った場合の費用を [画像コスト計算機](/ja/image) で確認できます。

## コンテキストウィンドウ：チャットの中の「トークン上限」

![コンテキストウィンドウ：チャットの中の「トークン上限」: Free, Go, Plus, Pro](/chatgpt-shiyouryou-jougen-ja-4.jpg)

使用量の上限とは別に、どのチャットにもコンテキストウィンドウがあります。モデルが一度に扱えるテキストの最大量です。会話や文書がこれを超えると前の部分が見えなくなり、その手前から品質が落ちることもよくあります。

| | Free | Go | Plus | Pro |
|---|---:|---:|---:|---:|
| Instant の全体コンテキスト | 27K トークン | 54K トークン | 54K トークン | 128K トークン |
| Instant の最大入力（目安） | 約12ページ | 約40ページ | 約40ページ | 約250ページ |
| 推論の全体コンテキスト | プランによる | 256K トークン | 256K トークン | 400K トークン |

実際に入力できる量は全体より小さくなります。システムの指示、メモリー、モデル自身の推論が同じ領域を使うからです。長い会話で前の内容を忘れ始めたら、短い要約を添えて新しいチャットを始めるのがいちばん簡単な対処法です。日本語は同じ内容でも英語よりトークンを多く使うので、長い指示は [トークンカウンター](/ja/) で先に数えておくと安心です。1文字あたりのトークン数は [日本語のトークン数](/ja/blog/token-mojisuu) にまとめています。

## 枠を長持ちさせるコツ

OpenAI は Codex の料金ページで、使用枠を長持ちさせる方法をいくつか挙げています。チャットにもそのまま使える考え方です。

- **プロンプトを絞る。** 指示ははっきり書きつつ、関係のない背景説明は削ります。長い前置きは毎回トークンを使います。
- **資料を必要な分だけ渡す。** 関係するファイルだけを渡し、できれば範囲や期間を絞ります。フォルダごと読ませるより、対象のファイルを指定したほうが枠の減りは小さくなります。
- **出力の形を決める。** 読む人、形式、長さを先に伝え、必須の作業と「あればうれしい」改善を分けて頼みます。全部まとめて頼むと、出力も推論も長くなります。
- **AGENTS.md を小さくする。** 大きなプロジェクトでは、AGENTS.md をフォルダごとに分けて、必要な場所だけで読み込まれるようにします。
- **MCP サーバーを減らす。** つないだ MCP サーバーは、それぞれがメッセージにコンテキストを足します。使わないときは切っておきます。
- **まず軽い設定で試す。** 推論レベルは Low か Medium から始め、結果が足りないときだけ上げます。OpenAI も、高い推論レベルは足りない情報やアクセス権を補えないと書いています。

## 日本語で使うときの注意

日本語は、同じ内容でも英語より多くのトークンを使います。私たちの測定では、日本語の文章は英語より約79%多くのトークンになりました。チャットのテキスト自体は無制限なので回数には影響しませんが、次の2点には効いてきます。

- **コンテキストウィンドウが早く埋まる。** Free の Instant は全体で27K トークンなので、長い日本語の資料を貼ると英語より早く上限に近づきます。
- **Work と Codex の枠が早く減る。** 枠はトークンの量で減るので、長い日本語の指示や資料は英語より多くの枠を使います。

長い定型の指示は英語で書いておく、資料は必要な部分だけ貼る、といった工夫で差を小さくできます。自分の文章が何トークンになるかは [トークンカウンター](/ja/) で確認できます。

## 業務で使うなら Pro か Business か

一人で使うなら Pro、チームで使うなら Business が基本ですが、上限の面でも違いがあります。

- **Business Standard** は Plus に近い Work・Codex の枠で、5時間枠があります。チャットの Pro メッセージは月15回です。
- **Business Premium** は Standard の500%の Work・Codex 枠で、5時間枠がありません。Pro メッセージは週50回です。
- **追加の利用** は、Business ではワークスペースのクレジット、Pro では個人のクレジットで払います。Business では管理者がクレジットの使い方や支出の上限を設定できます。
- **Ultrafast** は、個人プランでは Pro 500 だけです。Business で必要な場合は、対象となる Enterprise・Edu のワークスペースかどうかを確認します。

Codex をほとんど使わない社員には Standard、毎日 Codex で開発する社員には Premium と、席の種類を分けて割り当てるのが無駄の少ない方法です。

## 使用量の確認方法

- **ChatGPT：** **Settings → Usage（設定 → 使用量）** を開きます。Work と Codex の残りの枠、今どの枠にいるか、それぞれのリセット時刻、保存されたリセットとクレジットの残高が表示されます。
- **Codex CLI：** セッション中に `/status` と入力すると、残りの上限が表示されます。
- **チャット：** モデルの枠を使い切ると、情報があればリセット時刻を表示します。

OpenAI は、1〜2週間に一度ダッシュボードを見て、自分の使うペースをつかむよう勧めています。

## どの上限に当たった？

それぞれの上限は別々に動くので、どれに当たったかがわかれば解決が早くなります。

| こんな症状なら | 当たった上限はおそらく | 確認する場所 |
|---|---|---|
| Work や Codex が止まったが、普通のチャットはできる | Work・Codex の5時間枠 | 設定 → 使用量、5時間枠のリセット時刻 |
| 5時間枠が新しく始まったのに Codex が止まったまま | Work・Codex の週の枠 | 設定 → 使用量、週のリセット日 |
| Pro の思考レベルが使えない、または Medium に変わる | GPT-6 Pro の枠（Pro は週、Business は月または週） | モデル選択メニューと表示されたリセット時刻 |
| High や Extra High の回答が別のモデルに切り替わる | プランの思考レベルの上限 | チャットに表示されるリセット時刻 |
| 画像・アップロード・ディープリサーチが断られる | そのツール自体の上限 | アップグレードするか待つ。テキストチャットは可能 |
| 音声が数時間で終わる | 1日の GPT-Live の時間 | 翌日にリセット |
| すべてが止まり、異常な利用についての通知が出る | 使用量の上限ではなく不正利用対策 | 誤りだと思ったらサポートに連絡 |

Business の席では、ワークスペースのクレジット設定も関係します。含まれる枠を使い切ったあとの追加の Astra 利用は、ワークスペースにクレジットがあり、支出の設定が許可している場合にだけ続けられます。

## 上限に当たったときの対処法

作業の途中で切られることはありません。Work や Codex の作業中に上限に達しても、公正な利用の範囲内で、その作業は最後まで終えられます。そのあとの選択肢はプランによって違います。

1. **リセットを待つ。** 5時間枠なら長くても数時間で、時刻は設定 → 使用量に出ます。
2. **保存されたリセットを使う。** OpenAI はときどきリセットを配布します。たとえば Astra の公開時、2026年9月3日と4日に配布しました。フルリセットは5時間枠と週の枠の両方を回復し、週のリセット日を動かします。
3. **即時リセットを購入する。** 一部の国の対象となる個人の Plus・Pro アカウントは購入できます。両方の枠をすぐに回復しますが、あとのために保存することはできません。
4. **クレジットを使う。** Plus と Pro はクレジットを買って、Codex、Work、Office 用の拡張機能で使い続けられます。クレジットは使用量を買うもので、モデルを開放するものではないため、Pro 100・200 でクレジットを買っても Ultrafast は使えません。
5. **ローカルの作業に API キーを使う。** この場合はプランではなく API 料金で計算されます。
6. **チャットでは別のモデルを使う。** 思考レベルや Pro の上限に達したら、別のモデルを選ぶか、ChatGPT の自動切り替えに任せます。

効かない方法も1つあります。サポートに頼むことです。OpenAI は、サポートは「ChatGPT や Codex の使用量の上限をリセットしない」としています。ただし、使用量の計算が間違っていそうなときは調査してくれます。

## 無料プランで実際に見たこと

私たちは [Codex の料金テスト](/ja/blog/codex-ryoukin) のために、ChatGPT の無料アカウントで Codex を動かしました。同じブロック崩しゲームのプロンプトを GPT-6 Luna で、1回は medium、1回は extra high の推論で実行し、どちらも39秒で終わりました。使用量メニューには5時間や週のバーはなく、月単位のバーが1本あるだけで、ゲームを2つ作ったあとも99%が残っていて、リセットは1か月後でした。小さなゲーム2つで1か月の無料枠の約1%を使った計算なので、軽い Codex の利用なら無料でも十分そうです。実際のコードベースでの大きな作業は、より多くのファイルを読み、より多くのステップを踏むので、もっと多く使います。

## Claude の上限とどう違う？

ChatGPT と並んでよく比べられる Claude も、2026年は似た形の上限を使っています。Anthropic のヘルプセンターによると、Claude の有料プランには5時間ごとにリセットされるセッションの上限と、全モデル共通の週の上限があり、Claude のアプリと Claude Code が同じ上限を共有します。

違いは「チャットが無制限かどうか」です。ChatGPT は普段のテキストチャットを無制限にし、上限を思考レベル、Pro モデル、Work・Codex、ツールに寄せました。Claude はチャットも含めて同じ上限から使う仕組みなので、長い会話を続けるとコーディングに使える分も減ります。どちらも「5時間」と「週」の2つの枠を同時に見る必要がある点は同じです。Claude 側の詳しいしくみは [Claude Code の使用量上限まとめ](/ja/blog/claude-code-shiyouryou-jougen) にまとめています。

## 当たる上限を避けるにはどのプラン？

- **チャットだけで、ときどきファイルを上げる：** Free か Go。テキストチャットは無制限で、Go はアップロード・画像・音声の上限が上がります。
- **思考レベルや画像生成の上限に当たる：** Plus。Medium と High の思考レベルと、より広いツールの上限が付きます。
- **Work や Codex の5時間枠にほぼ毎日当たる：** Pro 100。5時間枠がなくなり、使用枠も大きくなります。
- **GPT-6 Pro や Pro 100 の枠を毎週使い切る：** Pro 200。
- **一日中エージェントを動かす、または Ultrafast が必要：** Pro 500。Ultrafast がある唯一の Pro プランです。
- **チームを管理している：** 通常は Business Standard、Codex を一日中使う人は Premium。

## プランか API か

ほとんどがチャットなら、テキスト無制限のおかげでサブスクに勝つのは難しいでしょう。Codex や GPT-6 Astra をヘビーに使うなら、プランの料金と、同じ作業を API で行った場合の費用を比べてみてください。GPT-6 Astra の API は入力100万トークンあたり$10、出力100万トークンあたり$50です。[GPT-6 API 料金](/ja/blog/gpt-6-api-ryoukin) を参考に、自分の使い方を [サブスク vs API 計算機](/ja/plans) や、Codex・Claude Code 用の [コーディングエージェント費用計算機](/ja/agents) に入れてみてください。料金はドル建てなので、円での支払額は為替によって変わります。

## よくある質問

**ChatGPT の5時間制限とは？**
Plus と Business Standard の Work・Codex の使用枠にかかる2つの枠のうち、短いほうです。前の枠が終わったあと、Work か Codex の最初のメッセージから始まり、その枠で使える量を決めます。週の枠も同時にかかります。Pro プランと Business Premium には現在5時間枠がありません。

**ChatGPT の無料版に回数制限はある？**
普段のテキストチャットにはありません。2026年8月から、Free と Go のテキストチャットは無制限です（不正利用防止の仕組みは適用）。ファイルのアップロード、画像生成、音声、データ分析などのツールには、まだ上限があります。

**ChatGPT の上限は毎日リセットされる？**
上限の種類によって違います。Work と Codex は5時間枠と週の枠、音声は1日の時間、Pro プランの GPT-6 Pro は週の枠です。自分のアカウントの正確なリセット時刻は、設定 → 使用量で確認できます。

**モデルを切り替えれば上限を回避できる？**
Work と Codex ではできません。すべてのモデルが同じ共有枠を使い、切り替えても回復しません。軽いモデルは残りを長持ちさせるだけです。チャットでは、思考レベルや Pro の上限に達したときに別のモデルに切り替えて使い続けられます。

**上限のために ChatGPT Plus を契約する価値はある？**
テキストチャットだけなら、Free や Go でも無制限です。高い思考レベル、画像生成、頻繁なファイルのアップロード、GPT-6 Astra を使う Work・Codex が必要なら、Plus に意味があります。

**Plus の5時間枠でどれくらい使える？**
決まった回数はありません。OpenAI の目安では、ローカルのメッセージで GPT-6 Astra なら5〜45回、GPT-6.1 Sol なら15〜160回、GPT-6 Luna なら350〜3,000回です。作業の大きさや推論レベルで大きく変わるので、設定 → 使用量で残りを見ながら使うのが確実です。

**Go と Plus では上限がどう違う？**
普段のテキストチャットはどちらも無制限です。違いは、Plus には Medium・High の思考レベルと Work・Codex の本格的な枠（5時間枠と週の枠）があり、ツールの上限も拡大されている点です。Go はアップロード・画像・音声の上限が Free より高く、Codex と Work はデスクトップアプリで限定的に使えます。

**無料プランの Codex はどれくらい使える？**
OpenAI は具体的な量を公開していません。私たちのテストでは、小さなブロック崩しゲームを2回作って月単位の枠の約1%を使いました。軽い作業なら無料でも試せますが、大きなコードベースでの作業はずっと多く使います。

**サポートに上限をリセットしてもらえる？**
いいえ。使用量の計算が間違っている場合は調査しますが、上限のリセットはしません。リセットを待つ、保存されたリセットを使う、対象なら購入する、クレジットを使う、のいずれかになります。

*上限は頻繁に変わります。自分のアカウントは設定 → 使用量で、最新の数値は OpenAI のヘルプセンターで確認してください。*
