プログラミングが得意でなくても、いまはAIツールを組み合わせればスマホゲームを1人で作れます。この記事では、AIでゲームを作る手順と必要なツール、そして実際にかかる費用と期間をまとめます。

結論から言うと、**小規模なスマホゲームなら2〜3週間、費用は約$50〜180**です。費用の大半は画像ではなく、**コーディングAIのサブスク**にかかります。

数字はすべて[AIゲーム制作費計算機](/ja/ai-game-cost-calculator)で出したもので、料金は2026年10月5日時点です。計算機の規模の基準は、AIコーディングエージェントを使って実際に1人で作ったモバイルゲームです。

## AIでゲームを作る6つの手順

### 1. 何を作るか1行で決める

最初に「どんなゲームか」を1行で書きます。たとえば「猫の家具を合体させてカフェを飾るゲーム」のように、ジャンルと遊び方がわかれば十分です。初めてなら、ジャンルは小さくまとまるものを選びましょう。ハイパーカジュアル、マージ、ノベルゲームは素材も少なく、完成させやすいジャンルです。

### 2. ゲームエンジンを選ぶ

| エンジン | 向いている人 | 言語 |
|---|---|---|
| Unity | スマホゲームの定番。情報が多い | C# |
| Godot | 無料・軽量。2Dに強い | GDScript |
| Ren'Py | ノベルゲーム専用。文章中心ならいちばん早い | Python |
| Roblox Studio | Roblox上で遊ぶゲーム。公開も無料 | Luau |
| Phaser | ブラウザで遊ぶゲーム | TypeScript |

AIにコードを書かせる場合、Unity と Godot はAIの知識量が多く、指示どおりに動くコードが出やすい傾向があります。

### 3. コードはAIエージェントに書いてもらう

Claude Code、Cursor、Gemini CLI などの**コーディングエージェント**に「こういうゲームを作りたい」と伝えると、フォルダ構成から実装まで少しずつ進めてくれます。コツは次の3つです。

- 1回に1つの機能だけ頼む
- 各ステップのあとにスマホで動かして確認する
- 本番の絵ができるまでは四角や丸の仮素材で進める

計算機の「開発スタート」プロンプトは、この進め方をそのまま指示文にしたものです。コピーして貼り付ければ始められます。

### 4. キャラクター・背景・UIは画像AIで作る

Midjourney、Gemini（Nano Banana 2）、Leonardo などで作ります。ドット絵なら PixelLab がアニメーションまで作れるので便利です。

小規模なマージゲームで必要な画像は**約86枚**です。キャラクター、アニメーションのコマ、背景、アイテム、UIの合計です。3回生成して1枚使う前提でも、Midjourney の最安プラン（月$10）に収まります。

### 5. 音楽と効果音を用意する

BGMは Suno や AIVA、効果音は ElevenLabs で作れます。お金をかけたくない場合は、Pixabay、Kenney、Freesound の無料素材でも十分です。

### 6. ストアに出す

| 出し先 | 登録料 |
|---|---|
| Google Play | $25（1回だけ） |
| App Store | 年$99 |
| Steam | 1作品$100 |
| Web | 無料 |

Steam では、AIで作った素材を使っている場合に申告が必要です。ストアごとのAI生成物のルールは公開前に確認しておきましょう。

## ジャンル別の費用と期間（小規模）

| ジャンル | 期間 | 画像数 | コスパ重視 | 標準 |
|---|---|---|---|---|
| ハイパーカジュアル | 6〜10日 | 47枚 | $46〜65 | $128〜181 |
| ノベルゲーム | 12〜20日 | 87枚 | $53〜75 | $128〜181 |
| マージ | 14〜22日 | 86枚 | $53〜75 | $128〜181 |
| カードゲーム | 16〜26日 | 109枚 | $57〜80 | $128〜181 |

- **コスパ重視**：Gemini の画像生成 + Pixabay の無料音源 + Google AI Pro（Gemini CLI）でコーディング
- **標準**：Midjourney + Suno + ElevenLabs + Claude Max 5×

どちらも Google Play の登録料$25を含みます。コスパ重視は標準の約40%の費用で済みます。ただし無料素材は探す時間がかかり、コーディングAIの使い勝手にも差があります。

## お金はどこにかかるのか

小規模なマージゲームを標準の組み合わせで作った場合の内訳です。

| 項目 | 費用 | 割合 |
|---|---|---|
| コード（Claude Max 5×、1か月） | $100 | 約66% |
| ストア登録料（Google Play） | $25 | 約17% |
| 画像（Midjourney） | $10 | 約7% |
| 音楽（Suno） | $10 | 約7% |
| 効果音（ElevenLabs） | $6 | 約4% |

コーディングAIは一日中動かすので、使用量の上限に余裕のあるプランが必要になります。そのため、費用の3分の2がここに集中します。開発が1か月を超えるとサブスクがもう1か月分かかるので、**期間を短く区切ること**が一番の節約になります。

## 注意したいこと

- **最初から大きく作らない**：RPGやMMOは素材もコードも一気に増えます。まず小さく完成させてから広げましょう。
- **サーバー代**：オンライン対戦を入れると、Photon や Firebase などのサーバー代が別にかかります。
- **公開後の費用**：広告やアップデートの運営費は、ここでの計算に入っていません。
