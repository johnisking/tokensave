![클로드 코드 요금 2026: 월 $20·$100·$200, API 비교](/claude-code-yogeum-ko.jpg)

**클로드 코드 요금 한 줄 정리:** 클로드 코드(Claude Code)는 클로드 유료 요금제에 모두 포함되어 있습니다. **프로(Pro) 월 $20**(연간 결제 시 월 $17), **Max 5x 월 $100**, **Max 20x 월 $200**입니다. 요금제 없이 API 종량제로 쓴 토큰만큼 낼 수도 있는데, 우리 실측에서 작은 작업 하나가 **소넷 5.5로 $0.25, 오퍼스 5.5로 $0.56~0.75**였습니다. 무료 요금제에는 클로드 코드가 없습니다. 아래 가격은 모두 Anthropic 공식 가격 페이지 기준이며, 2026년 10월 12일에 확인했습니다.

Anthropic은 원화 가격표를 따로 내놓지 않았습니다. 1달러=1,340원으로 가정한 우리 계산으로는 프로 $20이 약 2만 7천원, Max 5x $100이 약 13만 4천원, Max 20x $200이 약 26만 8천원입니다. 세금 전 대략적인 금액이고, 실제 청구액은 카드사 환율과 해외 결제 수수료에 따라 달라집니다.

어느 방식이 가장 싼지는 얼마나 쓰느냐에 달려 있습니다. 이 글에서는 클로드 코드 요금제별로 무엇이 들어 있는지, API로 작업 하나에 실제로 얼마가 드는지(직접 측정), 사용량 네 단계별 한 달 비용, 그리고 구독이 토큰 종량제보다 싸지는 지점을 차례로 정리합니다.

## 클로드 코드 요금 한눈에 보기 (2026)

![클로드 코드 요금 한눈에 보기 (2026): 요금제, 가격, 클로드 코드, 5시간당 사용량](/claude-code-yogeum-ko-2.jpg)

| 요금제 | 가격 | 클로드 코드 | 5시간당 사용량 |
|---|---|:---:|---|
| 무료 (Free) | $0 | 없음 | – |
| 프로 (Pro) | 월 $20 (연간 결제 시 월 $17) | 포함 | 무료의 500% 이상 |
| Max 5x | 월 $100 | 포함 | 프로의 500% |
| Max 20x | 월 $200 | 포함 | 프로의 2,000% |
| API (Claude Console) | 토큰당 종량제 | 사용 가능 | 요금제 한도 없음, 쓴 토큰 전부 청구 |

- **가격은 세금 별도입니다.** 한국에서 붙는 세금은 Anthropic이 따로 적어 두지 않았으니, 최종 금액은 결제 화면에서 확인하세요. Max는 월간 결제만 되고, 두 Max 요금제 모두 연간 할인이 없습니다.
- **한도 하나를 같이 씁니다.** 터미널과 IDE(VS Code, Cursor, JetBrains)에서 쓰는 클로드 코드는 웹·데스크톱·모바일의 클로드와 같은 5시간 한도와 주간 한도를 나눠 씁니다. 앱에서 긴 대화를 하면 코딩에 쓸 양이 그만큼 줄어듭니다.
- **대량 할인은 Max 20x에만 있습니다.** 프로 가격의 1,000%를 내고 프로 사용량의 2,000%를 받으니, 같은 사용량당 가격이 50% 쌉니다. Max 5x는 사용량당 가격이 프로와 같습니다.
- **Max에 들어 있는 월 API 크레딧으로는 클로드 코드 비용을 낼 수 없습니다.** 가격 페이지에는 Claude Platform에서 개발용으로 쓰는 API 크레딧이 월 $100(Max 5x) 또는 $200(Max 20x) 들어 있다고 나옵니다. 하지만 Anthropic 고객센터는 이 크레딧을 클로드 코드나 클로드 앱에서는 쓸 수 없다고 안내합니다.
- **Team과 Enterprise.** Anthropic 가격 FAQ에 따르면 클로드 코드는 모든 유료 요금제에 포함됩니다. Team 좌석은 Standard가 월 $25(연간 결제 시 $20), Premium이 월 $125(연간 $100)이고, 최소 2석부터입니다. Enterprise는 좌석당 $20에 API 요금 기준 사용료가 더해집니다.
- **앱에서 결제하면 가격이 다를 수 있습니다.** 원화 기준 비교, 할인과 환불은 [클로드 요금제 총정리](/ko/blog/claude-yogeumje)에 정리했습니다.

## 클로드 코드 무료로 쓸 수 있나요?

아닙니다. 클로드 무료 요금제에는 클로드 코드가 없고, 클로드 코드 체험판도 없습니다. 적은 돈으로 시작하는 방법은 두 가지입니다.

- **API.** Claude Console 계정을 만들고 쓴 토큰만큼만 냅니다. 일주일에 작은 작업 몇 개 정도라면 한 달 $20보다 훨씬 적게 듭니다(아래 한 달 비용 표 참고).
- **프로 한 달.** $20를 내고 한 달 써 본 뒤, 한도에 얼마나 자주 걸리는지 보고 정합니다.

정말 무료인 코딩 에이전트를 찾는다면, OpenAI의 코덱스(Codex)는 챗GPT 무료 요금제에서 GPT-6 Luna로 돌아갑니다. 같은 벽돌깨기 게임 요청을 챗GPT 무료 계정의 코덱스로 돌려 본 결과는 [코덱스 요금 2026](/ko/blog/codex-yogeum)에 있습니다.

## 클로드 코드 API 가격 (100만 토큰당)

![클로드 코드 API 가격 (100만 토큰당): 모델, 입력, 출력, 캐시 쓰기(1시간), 캐시 읽기](/claude-code-yogeum-api-100-ko.jpg)

클로드 코드를 요금제 대신 API 크레딧으로 쓰면 Anthropic의 표준 API 가격을 그대로 냅니다. Claude API 가격 페이지 기준, 100만 토큰당 가격입니다.

| 모델 | 입력 | 출력 | 캐시 쓰기(1시간) | 캐시 읽기 |
|---|---:|---:|---:|---:|
| Fable 5.1 | $10 | $50 | $20 | $0.25 |
| 오퍼스 5.5 | $4 | $20 | $8 | $0.20 |
| 소넷 5.5 | $2 | $10 | $4 | $0.10 |
| 하이쿠 5.5 (프롬프트 10만 토큰 이하) | $0.10 | $0.50 | $0.20 | $0.01 |

- **오퍼스 5.5는 소넷 5.5보다 토큰당 100% 비쌉니다.** Fable 5.1은 오퍼스 5.5보다 150% 비쌉니다.
- **클로드 코드를 감당할 만한 가격으로 만드는 건 캐시 읽기입니다.** 오퍼스 5.5와 소넷 5.5에서 캐시 읽기는 입력 가격의 5%, Fable 5.1에서는 2.5%입니다. 클로드 코드는 작업 맥락을 자동으로 캐시합니다.
- **요금제에서 Fable을 쓰려면:** 프로는 유료 사용 크레딧으로만 Fable을 쓸 수 있고, Max에는 Fable용 주간 한도가 따로 있습니다.

## 작업 하나에 실제로 드는 비용: 4회 실측

2026년 10월 9일, 클로드 코드에 같은 요청을 네 번 줬습니다. 브라우저에서 돌아가는 벽돌깨기 게임을 파일 하나로, 레벨 2개, 점수, 목숨 3개, 키보드·마우스 조작으로 만들어 달라는 요청입니다. 토큰 수는 무료 도구 ccusage로 쟀고, API 가격으로 환산했습니다.

| 모델 · effort | 걸린 시간 | 게임 코드 | API 가격 환산 비용 |
|---|---:|---:|---:|
| 소넷 5.5 · medium | 37초 | 198줄 | $0.25 |
| 소넷 5.5 · high | 58초 | 398줄 | $0.30 |
| 오퍼스 5.5 · medium | 52초 | 358줄 | $0.56 |
| 오퍼스 5.5 · high | 1분 50초 | 523줄 | $0.75 |

- **네 번 모두 제대로 돌아가는 게임이 나왔습니다.** effort를 올리거나 오퍼스를 쓰면 완성도가 올라갔을 뿐, 되고 안 되고의 차이는 아니었습니다.
- **비용의 63~81%는 캐시 쓰기였습니다.** 게임 코드 자체(출력)는 17~33%였습니다. 캐시 읽기는 토큰 수로는 가장 많았지만 비용으로는 2~4%에 그쳤습니다.
- **합계는 1시간 캐시 쓰기 가격으로 계산해야 맞아떨어집니다.** 입력 가격의 200%인 가격입니다. ccusage 숫자를 우리가 읽은 결과로는, 이번 실측에서 클로드 코드의 캐시 쓰기는 1시간 가격으로 청구됐습니다.
- **effort도 가격을 움직입니다.** 생각(thinking) 토큰은 출력으로 청구되고, high는 medium보다 출력 토큰을 96~97% 더 썼습니다.

게임 화면을 포함한 전체 결과는 [클로드 소넷 5.5 vs 오퍼스 5.5 실측 비교](/ko/blog/claude-sonnet-5-5-vs-opus-5-5)와 [클로드 오퍼스 5.5 effort 비교](/ko/blog/claude-opus-5-5-effort)에 있습니다.

## 작업 크기별 예상 비용

파일 하나짜리 게임은 작은 작업입니다. 더 큰 작업은 토큰세이브 [코딩 에이전트 비용 계산기](/ko/agents)의 계산 방식으로 추정했습니다. 에이전트는 단계별로 일하고, 단계마다 작업 맥락 전체(지시문, 도구 정의, 읽은 파일, 그때까지의 모든 내용)를 모델에 다시 보냅니다. 낮은 값은 계산기 기준(새 맥락을 입력 가격으로 계산)이고, 높은 값은 실측처럼 새 맥락을 1시간 캐시 쓰기 가격으로 계산한 값입니다.

| 작업 | 단계 | 보내는 토큰 | 소넷 5.5 | 오퍼스 5.5 |
|---|---:|---:|---:|---:|
| 작은 수정 | 약 8 | 약 20만 | $0.14~0.21 | $0.27~0.43 |
| 새 기능 | 약 25 | 약 160만 | $0.57~0.81 | $1.14~1.63 |
| 대규모 리팩터링 | 약 60 | 약 770만 | $1.91~2.54 | $3.82~5.07 |

- **클로드 코드가 보내는 토큰 대부분은 다시 읽는 맥락입니다.** 작은 수정은 토큰의 82%, 대규모 리팩터링은 96%가 캐시 읽기입니다. 그래서 토큰 160만 개를 보내는 기능 작업도 소넷으로는 $1보다 한참 적게 듭니다.
- **캐싱이 없다면** 같은 기능 작업이 소넷 5.5로 $0.57가 아니라 약 $3.38입니다.
- **실측한 게임(소넷 $0.25~0.30)은 작은 수정과 새 기능 사이에 들어갑니다.** 파일 하나짜리 게임이 딱 그 정도 크기입니다.

## 클로드 코드 한 달 비용

작업일 22일 기준으로, API로 낼 때의 네 가지 사용 패턴입니다.

| 사용 방식 | 월 작업 수 | API, 소넷 5.5 | API, 오퍼스 5.5 | 보통 맞는 요금제 |
|---|---:|---:|---:|---|
| 가볍게: 하루 작은 수정 3개 | 66 | $9~14 | $18~28 | API 또는 프로 |
| 보통: 하루 기능 5개 | 110 | $63~90 | $125~179 | 프로 또는 Max 5x |
| 많이: 하루 기능 15개 | 330 | $188~269 | $375~537 | Max 5x 또는 Max 20x |
| 종일 에이전트: 하루 큰 작업 8개 | 176 | $336~446 | $672~893 | Max 20x |

Anthropic이 직접 내놓은 기준점도 하나 있습니다. Anthropic에 따르면 기업 도입 사례 전체에서 클로드 코드는 평균이 **개발자 1명당 활동일 하루 약 $13, 한 달 $150~250**이고, 사용자의 90%는 활동일 하루 $30 아래에 머뭅니다. 우리 표의 '많이·소넷'(하루 $8.50~12)과 '많이·오퍼스'(하루 $17~24) 사이에 해당합니다.

## 구독이 API보다 싸지는 지점

Anthropic은 요금제 한도를 토큰이나 달러로 공개하지 않습니다. 그래서 손익분기점은 추정할 수밖에 없습니다. [FinOps LLM](https://finopsllm.com/research/claude-pro-max-tokens-limit)은 헤비 유저 한 명의 클로드 코드 세션을 한도에 막힐 때까지 기록했습니다.

| 요금제 | 가격 | 5시간 한 번을 API 가격으로 환산 |
|---|---:|---|
| 프로 | 월 $20 | 약 $7 *(우리 추정)* |
| Max 5x | 월 $100 | **약 $37** (실측 중앙값) |
| Max 20x | 월 $200 | 약 $150 *(우리 추정)* |

프로와 Max 20x 값은 실측한 Max 5x 값을 Anthropic이 밝힌 요금제 간 사용량 비율로 환산한 것이니, 대략적인 크기로만 보세요. Max 20x의 한 주는 약 19억 토큰으로 측정됐는데, API 가격으로 약 $1,800입니다. 한 달 요금은 $200입니다.

위의 하루 비용과 나란히 놓으면 이렇습니다.

- **가볍게 쓸 때:** 작업일 하루 약 $0.90 아래로 쓰는 한 API가 프로의 월 $20보다 쌉니다. 소넷으로 하루 작은 수정 3개($0.40~0.60)는 넉넉히 아래이고, 오퍼스($0.80~1.30)면 거의 비슷합니다.
- **소넷으로 보통 쓸 때(하루 $2.80~4.10):** 이 추정으로는 프로의 5시간 한 번 안에 들어가므로 프로가 더 쌉니다. 오퍼스(하루 $5.70~8.10)라면 프로 5시간 한도의 경계 근처입니다. 거의 매일 한도에 걸린다면 Max 5x입니다.
- **많이 쓰거나 에이전트를 돌릴 때:** Max입니다. 같은 한 달을 API로 내면 $188~893입니다.

주간 한도도 따로 봐야 합니다. Max 5x에서 5시간 한도는 괜찮은데 주간 한도에 걸린다면, 다음 단계는 Max 20x입니다.

## 내 사용 경험

저는 Max 5x 요금제로 클로드를 매일 씁니다. 오퍼스 5를 쓸 때는 한도를 다 쓰곤 했는데, 오퍼스 5.5로 바뀐 뒤로는 한도에 걸린 적이 없습니다. 다만 최근 한 주는 주간 한도의 93%까지 쓴 적이 있습니다. 소넷은 디테일을 맞추려면 수정을 더 여러 번 거쳐야 해서, 토큰이 싸다고 완성된 작업까지 꼭 싸게 끝나지는 않았습니다. 측정값이 아니라 제 경험입니다.

## 예상 밖으로 비용이 나가는 곳

![예상 밖으로 비용이 나가는 곳: 환경 변수에 API 키가 있을 때. ANTHROPIC_API_KEY가 설정되어 있으면 클로드 코드는 프로·Max 로그인 대신 이 키를 쓰고, API 요금으로 청구됩니다. 요금제로 결제하고 싶다면 이](/claude-code-yogeum-ko-4.jpg)

- **환경 변수에 API 키가 있을 때.** `ANTHROPIC_API_KEY`가 설정되어 있으면 클로드 코드는 프로·Max 로그인 대신 이 키를 쓰고, API 요금으로 청구됩니다. 요금제로 결제하고 싶다면 이 변수를 지우세요.
- **한도를 넘긴 뒤의 유료 사용 크레딧.** 유료 요금제는 한도에 걸린 뒤에도 유료 사용 크레딧(usage credits)으로 계속 쓸 수 있고, 이 크레딧은 표준 API 가격으로 청구됩니다.
- **빠른 모드(fast mode).** 오퍼스 5.5의 빠른 출력(리서치 프리뷰)은 API에서 100만 토큰당 입력 $8, 출력 $40으로, 표준 가격보다 100% 비쌉니다.
- **긴 세션.** 단계마다 대화 전체를 다시 보냅니다. 관련 없는 작업 사이에는 **/clear**, 긴 작업에는 **/compact**를 쓰세요.
- **한국어로 지시할 때.** 같은 내용이면 한국어는 영어보다 토큰이 약 44%, 일본어는 약 79% 더 듭니다(GPT 토크나이저 기준 우리 측정). CLAUDE.md처럼 단계마다 함께 전송되는 긴 지시문은 영어로 쓰면 그만큼 줄일 수 있습니다. 측정 결과는 [한국어 프롬프트, 영어로 보내면 토큰 31% 절약](/ko/blog/korean-tokens-gpt)에 있습니다.

지금 얼마나 썼는지 보려면 클로드 코드 안에서 **/usage**를 입력하세요. 요금제 사용자는 5시간·주간 한도를 몇 % 썼는지와 초기화 시각이, API 사용자는 세션의 정가 기준 비용이 나옵니다. **/status**는 계정·요금제·모델 정보를 보여 줄 뿐 사용량은 나오지 않습니다. 명령어 입력 방법은 [클로드 코드 사용법](/ko/blog/claude-code-sayongbeop)에, 비용을 더 줄이는 방법은 [클로드 코드 토큰 절약 방법 9가지](/ko/blog/claude-code-token-jeolyak)에 있습니다.

## 무엇을 고를까

1. **일주일에 작은 작업 몇 개:** API. 한 달 $20보다 적게 들 가능성이 큽니다.
2. **소넷으로 매일 코딩:** 프로 월 $20, 연간 결제 시 월 $17.
3. **프로의 5시간 한도에 거의 매일 걸리거나, 하루 종일 오퍼스로 코딩:** Max 5x 월 $100.
4. **에이전트를 몇 시간씩 돌리거나 Max 5x의 주간 한도에 걸릴 때:** Max 20x 월 $200. 사용량당 가격이 싸지는 유일한 요금제입니다.
5. **CI 파이프라인과 자동화:** API. 작업마다 토큰당 비용을 예측할 수 있습니다.

어떤 요금제든 작업마다 모델을 고르세요. 소넷 5.5는 토큰 단가가 오퍼스 5.5의 50%이면서 대부분의 코딩 작업을 처리하고, 우리 실측에서도 같은 effort 기준으로 55~60% 쌌습니다. 요금제 한도는 [클로드 코드 사용량 한도 정리](/ko/blog/claude-code-sayongnyang-hando)에, 요금제끼리의 비교는 [Claude Max vs Pro 비교](/ko/blog/claude-max-vs-pro)에 정리했습니다.

## 자주 묻는 질문

**클로드 코드 요금은 한 달에 얼마인가요?**
클로드 프로는 월 $20(연간 결제 시 월 $17), Max 5x는 $100, Max 20x는 $200입니다. API로 쓰면 보통 수준(하루 기능 5개)의 한 달이 소넷 5.5로 약 $63~90, 오퍼스 5.5로 약 $125~179입니다.

**클로드 코드 가격은 한국 돈으로 얼마인가요?**
Anthropic은 원화 가격을 따로 내놓지 않았습니다. 1달러=1,340원으로 가정한 우리 계산으로는 프로 약 2만 7천원, Max 5x 약 13만 4천원, Max 20x 약 26만 8천원입니다. 세금 전 금액이고, 실제 청구액은 카드사 환율과 수수료에 따라 달라집니다.

**클로드 프로에 클로드 코드가 포함되나요?**
네. 클로드 코드는 프로, Max, Team, Enterprise에 포함되고, 클로드 앱과 같은 사용량 한도를 함께 씁니다.

**클로드 코드는 무료인가요?**
아닙니다. 무료 요금제에는 포함되지 않습니다. 가끔 쓴다면 토큰당 내는 API가 가장 싼 방법입니다.

**클로드 코드는 API와 구독 중 어느 쪽이 싼가요?**
일주일에 작은 작업 몇 개라면 API가 쌉니다. 거의 매일 코딩한다면 프로나 Max가 싸고, 차이도 큰 편입니다. 많이 쓴 Max 20x의 한 주를 API 가격으로 환산하면 약 $1,800였습니다.

**Max에 들어 있는 월 API 크레딧을 클로드 코드에 쓸 수 있나요?**
아닙니다. Anthropic 고객센터는 Max에 포함된 월 API 크레딧을 클로드 코드나 클로드 앱에서는 쓸 수 없다고 안내합니다.

**클로드 코드에 쓴 비용은 어떻게 확인하나요?**
/usage를 입력하면 요금제 한도(5시간·주간)를 몇 % 썼는지와 초기화 시각, 세션의 토큰 사용량이 나옵니다. /status는 계정과 요금제, 모델 정보를 보여 줍니다.
