클로드 코드(Claude Code)는 Claude Pro·Max 구독에 포함되어 있고, 사용한 만큼 내는 API로도 쓸 수 있습니다. 그럼 한 달에 실제로 얼마가 들까요? 쓰는 양에 따라 다르고, 같은 작업이라도 어떻게 결제하느냐에 따라 10배 넘게 차이가 납니다. 실제 숫자로 정리했습니다.

## 결제 방법은 두 가지

![결제 방법은 두 가지: 요금제, 월 가격, 사용량](/claude-code-yogeum-ko-2.jpg)

**1. 구독 요금제.** 클로드 코드가 포함된 요금제입니다(미국 가격, 2026년 10월 확인).

| 요금제 | 월 가격 | 사용량 |
|---|---|---|
| Pro | $20 (연간 결제 시 월 $17) | 기본 |
| Max 5× | $100 | Pro의 5배 |
| Max 20× | $200 | Pro의 20배 |

정액으로 내고 사용량 한도가 있습니다. 클로드 코드와 Claude 앱(웹·데스크톱·모바일)이 **같은 한도를 나눠 씁니다.**

**2. API.** 토큰 단위로 Anthropic API 가격을 냅니다.

| 모델 | 입력 100만 토큰 | 출력 100만 토큰 |
|---|---|---|
| Claude Haiku 4.5 | $1 | $5 |
| Claude Sonnet 5.5 | $2 | $10 |
| Claude Opus 5.5 | $4 | $20 |

프롬프트 캐시에서 읽는 입력은 보통 입력 가격의 약 10분의 1입니다. 요금제 한도는 없지만 쓰는 토큰은 전부 청구됩니다.

## 클로드 코드는 왜 토큰을 많이 쓸까

클로드 코드는 단계별로 일합니다. 파일을 읽고, 고치고, 테스트를 돌리고, 결과를 보고, 다시 시도합니다. 그리고 **단계마다 작업 맥락 전체**(지시문, 도구 정의, 읽은 파일, 이전 단계)를 모델에 다시 보냅니다. 그래서 기능 하나 추가하는 작업에도 입력 토큰이 **160만 개** 정도 쉽게 들어갑니다. 작성하는 코드가 짧아도 그렇습니다.

이 비용을 감당할 만하게 만드는 게 **프롬프트 캐싱**입니다. 반복되는 맥락은 입력 가격의 약 10%로 계산되고, 클로드 코드는 이걸 자동으로 씁니다.

## API로 작업 하나에 드는 비용

토큰세이브 [코딩 에이전트 비용 계산기](/ko/agents) 기준, 캐싱을 켠 경우입니다.

| 작업 | 단계 | Haiku 4.5 | Sonnet 5.5 | Opus 5.5 |
|---|---|---|---|---|
| 작은 수정 | ~8 | $0.08 | $0.15 | $0.31 |
| 새 기능 | ~25 | $0.36 | $0.72 | $1.43 |
| 대규모 리팩터링 | ~60 | $1.33 | $2.65 | $5.30 |

캐싱이 없으면 Sonnet으로 새 기능 작업 하나가 $0.72가 아니라 약 $3.38입니다.

## 한 달 비용

한 달 작업일 22일 기준입니다.

| 사용 방식 | 월 작업 수 | API (Sonnet) | API (Opus) | 보통 맞는 가장 싼 요금제 |
|---|---|---|---|---|
| 가볍게: 하루 작은 수정 3개 | 66 | 약 $10 | 약 $20 | API 또는 Pro($20) |
| 보통: 하루 기능 5개 | 110 | 약 $79 | 약 $158 | Pro 또는 Max 5× |
| 많이: 하루 기능 15개 | 330 | 약 $236 | 약 $473 | Max 5× 또는 Max 20× |
| 종일 에이전트: 하루 큰 작업 8개 | 176 | 약 $466 | 약 $932 | Max 20× |

정리하면 이렇습니다.

- **가끔 쓰면** API가 어떤 요금제보다 쌀 수 있습니다. Pro가 $20인 달에 API로는 $10 정도입니다.
- **매일 쓰면** 구독이 금방 훨씬 싸집니다. Opus로 보통 수준을 쓰면 API로 약 $158, Max 5×는 $100입니다.
- **많이 쓰면** 한도가 충분한 한 Max가 API보다 훨씬 쌉니다.

요금제의 함정은 한도입니다. Anthropic은 요금제별 정확한 토큰 수를 공개하지 않고, 많이 쓰는 사람은 주간 한도에 걸립니다. [클로드 코드 사용량 한도 정리](/ko/blog/claude-code-sayongnyang-hando)를 참고하세요.

## 토큰을 돈으로 바꾸면

Claude Sonnet 5.5 기준 간단한 계산법입니다.

- 입력 100만 토큰 = $2 (캐시에서 읽으면 약 $0.20)
- 출력 100만 토큰 = $10

클로드 코드가 보내는 것의 대부분은 캐시된 맥락이라, 에이전트 작업의 실제 평균 단가는 Sonnet 기준 처리 토큰 100만 개당 $1보다 한참 아래인 경우가 많습니다. Opus는 그 두 배로 보면 됩니다.
