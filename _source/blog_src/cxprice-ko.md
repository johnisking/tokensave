![코덱스 요금 2026: 무료로 직접 써 본 결과와 가격](/codex-yogeum-ko.jpg)

오픈AI 코덱스(Codex)를 쓰려고 요금을 찾아보면 "코덱스 Pro" 같은 별도 상품이 보이지 않아 헷갈립니다. 코덱스는 어떤 요금제에서 쓸 수 있는지, 요금제마다 무엇이 달라지는지, 한도에 걸리면 비용이 얼마나 드는지 궁금한 분이 많을 겁니다. 2026년 10월 11일 OpenAI 가격 페이지와 고객센터를 확인하고, 같은 날 챗GPT 무료 계정으로 코덱스에 벽돌깨기 게임을 두 번 만들게 해 봤습니다. 이 글에서는 요금제별 가격, 무료 계정으로 해 본 테스트 결과, 크레딧과 API 가격, 요금제 고르는 법을 차례로 정리합니다.

- **코덱스는 별도 구독이 아닙니다.** OpenAI 가격 페이지는 ChatGPT Work와 코덱스가 무료, Go, Plus, Pro, Business, Edu, Enterprise 요금제에 포함된다고 안내합니다. 코덱스만 따로 사는 상품은 없습니다.

- **API 키로 쓰면 클라우드 기능이 없습니다.** 코덱스 CLI, SDK, IDE 확장에 API 키로 로그인하면 표준 API 가격으로 결제되지만, GitHub 리뷰나 Slack 같은 클라우드 연동은 쓸 수 없습니다.

## 요금제별로 코덱스에서 달라지는 것

![요금제별로 코덱스에서 달라지는 것: 무료 (0원); Go (13,000원); Plus (29,000원)](/codex-yogeum-ko-3.jpg)

OpenAI 가격 페이지와 고객센터 기준입니다.

- **무료 (0원):** 데스크톱 앱에서 GPT-6 Luna를 표준 속도로 씁니다(순차 제공). OpenAI는 "빠른 코딩 작업으로 코덱스를 살펴보는 용도"라고 설명합니다. 클라우드 작업과 이미지 생성은 없습니다(API로 이미지를 만들 때 비용은 [이미지 비용 계산기](/ko/image)에서 확인할 수 있습니다). 무료 사용량 한도는 공개하지 않고 "요금제마다 다르다"고만 합니다. 크레딧 구매는 일부 무료 사용자에게만 열려 있습니다.
- **Go (13,000원):** 코덱스 쪽은 무료와 같은 GPT-6 Luna이고, 가벼운 코딩 작업용으로 안내됩니다. 일반 챗GPT 사용량은 늘어나지만 코덱스 접근 자체는 무료와 같습니다.
- **Plus (29,000원):** 웹, CLI, IDE 확장, iOS에서 코덱스를 쓰고 클라우드 연동까지 됩니다. 어려운 문제용 GPT-6 Astra부터 간단한 수정용 GPT-6 Luna까지 GPT-6 모델을 모두 쓰며, 5시간 단위 롤링 한도가 있습니다. 한도에 걸리면 크레딧을 추가로 살 수 있습니다.
- **Pro (159,000원부터):** Plus 기능에 사용량이 더 많고, 현재 5시간 한도가 없습니다. 사용량은 주 단위입니다. Pro 500에는 GPT-6 Astra와 GPT-6.1 Sol의 Ultrafast 모드가 추가됩니다.
- **Business (1인 $20~25):** Standard 좌석의 코덱스 한도는 Plus와 비슷하고, 워크스페이스 단위로 코덱스 크레딧을 살 수 있습니다. 2명부터 가입합니다.
- **Enterprise·Edu:** 계약 가격입니다. 유연 요금(flexible pricing)이면 고정 한도 없이 크레딧으로 청구되고, 아니면 좌석당 한도가 Plus와 비슷합니다.

**한 가지 주의할 점:** 어느 요금제든 코덱스는 ChatGPT Work, 엑셀용 ChatGPT, Workspace Agents와 사용량을 함께 씁니다. 코덱스를 오래 돌리면 다른 에이전트 기능에 남는 양이 줄고, 반대도 마찬가지입니다. 챗GPT 무료와 유료의 다른 차이는 [챗GPT 무료 vs 유료 차이](/ko/blog/chatgpt-muryo-yuryo-chai)에 정리했습니다.

## 챗GPT 무료 계정으로 코덱스를 직접 써 봤습니다

![코덱스 무료, 직접 써 봤습니다: medium, extra high](/codex-yogeum-ko-4.jpg)

공개된 한도만으로는 감이 안 와서 2026년 10월 11일에 직접 테스트했습니다.

![코덱스 무료로 만든 게임 두 개: medium과 extra high 화면 비교](/codex-yogeum-test-ko.jpg)

- **요금제:** 챗GPT 무료
- **모델:** GPT-6 Luna (무료 요금제의 코덱스 모델)
- **요청:** [클로드 오퍼스 5.5 effort 비교](/ko/blog/claude-opus-5-5-effort)에서 쓴 것과 같은 벽돌깨기 요청입니다. 브라우저 게임을 index.html 파일 하나로, 레벨 2개, 점수 표시, 목숨 3개, 키보드·마우스 조작으로 만들어 달라는 내용입니다.
- **실행:** 추론 수준(effort) medium과 extra high로 한 번씩, 각각 따로 파일을 만들게 했습니다.

| | medium | extra high |
|---|---|---|
| 걸린 시간 | 39초 | 39초 |
| 게임 코드 | 398줄 | 273줄 |
| 코덱스가 붙인 제목 | Brick Breaker | Neon Breakout |
| 레벨 | 2개 (벽돌 5×10, 다음 7×12) | 2개 (5×10, 다음 모양을 낸 6×11) |
| 효과 | 없음 | 벽돌이 깨질 때 파티클, 네온 빛 |
| 토큰 (코덱스 자체 추정) | 약 4,000~5,000개 | 4,000개대 |
| 무료 사용량 | 두 번 합쳐 월 단위 미터의 1% | |

두 게임 모두 요청한 조건(레벨 2개, 점수, 목숨 3개, 키보드·마우스 조작)을 다 지켰고, 시작 화면, 일시정지, 클리어·게임 오버 화면도 있었습니다.

**무료 계정의 사용량 화면**도 확인했습니다. 코덱스 앱에는 남은 사용량을 보여 주는 미터가 하나뿐이었고, 기간은 '1개월', 초기화 날짜는 한 달 뒤였습니다. 5시간 한도나 주간 한도 미터는 없었습니다. 두 번 돌린 뒤 이 미터는 1%가 줄어 99%가 남았습니다.

### 직접 해 본 소감

테스트한 사람이 두 게임을 직접 해 보고 남긴 소감입니다.

- **medium:** "부드러운 느낌이 드는데 게임 효과는 없어서 타격감은 아쉬운 느낌"
- **extra high:** "파티클이 화려하진 않지만 없는 것보단 나았고, 그 외 다른 기능은 잘 모르겠다"

### 결과에서 알 수 있는 것 (우리 해석)

- **effort를 올리니 시간은 같고 완성도만 달라졌습니다.** 두 번 다 39초였습니다. extra high는 코드가 31% 짧았지만 파티클, 네온 스타일, 그리고 빠른 공이 벽돌을 뚫고 지나가지 않도록 한 프레임을 잘게 나눠 충돌을 검사하는 처리를 넣었습니다. 마지막 것은 플레이할 때 눈에 보이지 않아서, "그 외 다른 기능은 잘 모르겠다"는 소감과 맞아떨어집니다.
- **토큰 수는 측정값이 아니라 코덱스의 자체 추정입니다.** 물어보니 정확한 수는 알 수 없다면서 한 번에 약 4,000~5,000개, extra high는 4,000개대라고 했습니다. 작성한 코드 크기와 비슷해서 출력만 센 것으로 보입니다. 지시문, 추론, 단계마다 다시 보내는 맥락은 빠져 있을 가능성이 큽니다.
- **무료로도 이 정도 작업은 넉넉했습니다.** 게임 두 개에 월 미터의 1%였으니, 그대로 계산하면 이 크기 게임을 한 달에 약 200개 만들 수 있는 양입니다(우리 계산). 다만 두 번만 측정했고 미터는 1% 단위로 반올림됩니다. 실제 프로젝트에서 파일을 많이 읽고 단계가 길어지면 사용량을 더 많이 쓸 것으로 보입니다.
- **API 가격으로 쳐도 Luna는 쌉니다.** 코덱스가 전체 토큰 수를 알려 주지 않아서 가정을 하나 두면, 같은 요청에서 클로드 소넷 5.5가 쓴 115,073토큰(거의 다 입력)만큼 썼다고 할 때 GPT-6 Luna API 가격으로는 캐시 없이도 1센트를 조금 넘습니다. 가정에 따른 추정이지 측정한 비용이 아닙니다.

| 도구 · 요금제 | 모델 | 걸린 시간 | 비용·사용량 |
|---|---|---:|---|
| 코덱스 · 챗GPT 무료 | GPT-6 Luna medium | 39초 | 두 번 합쳐 월 미터의 1% |
| 커서 · 무료(Hobby) | 자동 선택 (Grok 4.6) | 1분 31초 | 한 번에 월 한도의 15% |
| 클로드 코드 · API 가격 환산 | 소넷 5.5 medium | 37초 | $0.25 |
| 클로드 코드 · API 가격 환산 | 오퍼스 5.5 high | 1분 50초 | $0.75 |

> **업데이트 (2026년 10월 23일):** Claude Code 2.1.295에서 MCP 서버 없이 3번씩 다시 재 보니 같은 작업이 평균 $0.10(소넷 5.5 medium), $0.12(소넷 high), $0.26(오퍼스 5.5 medium), $0.35(오퍼스 high)로, 이 표의 10월 9일 값보다 53~61% 쌌습니다. [effort 데이터셋](/data/claude-effort-cost) 참고.

- **무료로 코딩 에이전트를 써 보기엔 코덱스가 가장 여유 있었습니다.** 다만 코덱스와 커서의 미터는 서로 다른 기준이라 퍼센트를 그대로 비교할 수는 없습니다.
- **클로드는 무료 요금제에 클로드 코드가 없습니다.** 클로드 쪽 수치는 ccusage로 잰 API 가격 환산 비용이고, 코덱스 토큰은 자체 추정이라 대략적인 비교로만 보세요.

## 모델별 한도: 모델 선택이 요금제보다 중요합니다

OpenAI는 Plus와 Business Standard 좌석 기준으로 5시간당 예상 로컬 메시지 수를 범위로 안내합니다.

| 모델 | 5시간당 로컬 메시지 (Plus·Business Standard) |
|---|---:|
| GPT-6 Astra | 5–45 |
| GPT-6.1 Sol | 15–160 |
| GPT-6 Sol | 15–150 |
| GPT-6 Luna | 350–3,000 |

- **모델이 가장 큰 변수입니다.** 범위 아래쪽 기준으로 GPT-6 Luna는 GPT-6 Astra의 7,000%만큼 메시지를 보낼 수 있습니다(350 대 5).
- **범위가 넓은 건 작업 크기가 제각각이라서입니다.** 파일 몇 개만 읽는 요청과 저장소 절반을 읽고 계획·작성·테스트까지 하는 요청은 비용이 크게 다릅니다. 클라우드 작업은 로컬보다 사용량을 더 많이 쓸 수 있습니다.
- **주간 한도가 추가로 걸릴 수 있습니다.** Pro는 현재 5시간 한도가 없어서 주간 사용량에 닿을 때까지 길게 작업할 수 있습니다.
- **빠른 모드는 사용량을 더 씁니다.** 포함 사용량 기준으로 Fast 모드는 표준의 250%, Ultrafast는 800% 속도로 줄어듭니다.

5시간·주간 한도와 초기화 방식은 [코덱스 사용량 한도 정리](/ko/blog/codex-sayongnyang-hando)에 자세히 있습니다.

## 코덱스 크레딧: 한도를 넘었을 때

크레딧은 포함 사용량을 다 쓴 뒤 계속 쓰는 방법입니다. 요금제 사용량을 먼저 쓰고, 그다음 크레딧 잔액에서 차감됩니다. OpenAI 요율표의 100만 토큰당 크레딧(표준 속도)입니다.

| 모델 | 입력 | 캐시된 입력 | 출력 |
|---|---:|---:|---:|
| GPT-6 Astra | 250 | 25 | 1,250 |
| GPT-6.1 Sol | 50 | 2.5 | 250 |
| GPT-6 Sol | 50 | 5 | 250 |
| GPT-6 Luna | 2.5 | 0.25 | 12.5 |

- **누가 살 수 있나:** Plus와 Pro는 한도에 걸렸을 때나 챗GPT의 설정 > 사용량, 코덱스 앱의 사용량·결제 화면에서 살 수 있습니다. 무료와 Go는 일부 테스트 그룹만 가능합니다.
- **유효 기간은 12개월**입니다.
- **크레딧으로 낼 때 Fast는 표준의 200%, Ultrafast는 600%**로 청구됩니다.
- **크레딧 1개의 가격은 공개되어 있지 않습니다.** 개인 요금제의 구매 금액은 계정, 지역, 요금제에 따라 다르고 구매 화면에 표시됩니다. 다만 확인한 세 모델 모두 API 정가 $1당 25크레딧으로 맞춰져 있어서, 크레딧 1개는 약 $0.04어치 API 사용량으로 설계된 것으로 보입니다(우리 계산, OpenAI 공식 가격 아님).

## 코덱스 API 가격

토큰 단위로 내고 싶다면 코덱스 CLI나 IDE 확장에 API 키로 로그인하면 됩니다. 요금제 한도 없이 표준 API 가격으로 청구됩니다.

| 모델 | 입력 (100만 토큰) | 캐시된 입력 | 출력 |
|---|---:|---:|---:|
| GPT-6 Luna | $0.10 | $0.01 | $0.50 |
| GPT-6.1 Sol | $2 | $0.10 | $10 |
| GPT-6 Astra | $10 | $1 | $50 |

- **코딩 에이전트는 쓰는 것보다 읽는 게 훨씬 많습니다.** 단계마다 지시문, 도구 정의, 파일, 이전 단계를 모델에 다시 보내서 입력 토큰이 청구서 대부분을 차지합니다.
- **큰 작업은 이렇게 늘어납니다.** 25단계짜리 일반적인 기능 구현 작업은 입력이 약 160만 토큰이고, API 가격으로 Sol급 모델은 약 $0.72, GPT-6 Astra는 약 $3.60입니다(우리 추정).
- **Luna로 되는 작업이면 훨씬 쌉니다.** GPT-6 Luna의 입력 가격은 GPT-6.1 Sol보다 95% 쌉니다.
- **한국어는 토큰을 더 씁니다.** GPT 토크나이저에서 같은 내용이면 한국어가 영어보다 토큰이 약 44% 더 듭니다(우리 측정).

## 자주 묻는 질문

**코덱스는 무료인가요?**
제한된 형태로 무료입니다. 챗GPT 무료 요금제에서 데스크톱 앱으로 GPT-6 Luna를 쓸 수 있습니다. OpenAI는 무료 한도를 공개하지 않았고, 우리 계정에는 5시간·주간 한도 대신 '1개월' 미터 하나만 있었습니다. 클라우드 작업은 Plus부터입니다.

**코덱스 요금은 얼마인가요?**
코덱스만의 가격은 없고 챗GPT 요금제에 포함됩니다. 한국에서 접속했을 때 OpenAI 가격 페이지에 표시된 금액(2026년 10월 확인, 결제 화면에서 최종 금액 확인 필요)으로 무료 0원, Go 13,000원, Plus 29,000원, Pro 159,000원부터이고, Business는 1인 $20(연간)입니다. API 키로 쓰면 표준 API 가격으로 청구됩니다.

**오픈AI 코덱스를 쓰려면 Plus가 꼭 필요한가요?**
아닙니다. 무료와 Go에서도 데스크톱 앱으로 GPT-6 Luna를 쓸 수 있습니다. Plus에서는 GPT-6 Astra·Sol 같은 더 강한 GPT-6 모델, 클라우드 작업, GitHub 코드 리뷰가 추가됩니다. 또 요금제와 상관없이 누구나 CLI나 IDE 확장에 API 키로 로그인해 API 가격으로 쓸 수 있습니다.

**코덱스 무료 한도는 얼마나 되나요?**
공식 수치는 없습니다. 2026년 10월 11일 테스트에서는 작은 벽돌깨기 게임 두 개에 월 미터의 1%를 썼습니다. 그대로 계산하면 이 크기 작업을 한 달에 약 200번 할 수 있는 양이지만, 큰 프로젝트는 사용량을 더 많이 쓸 것으로 보입니다.

**코덱스 크레딧 1개는 얼마인가요?**
개인 요금제의 크레딧 가격은 공개되어 있지 않고 구매 화면에 표시됩니다. 크레딧 요율이 API 정가 $1당 25크레딧이라, 크레딧 1개는 약 $0.04어치 API 사용량에 해당합니다(우리 계산).

**코덱스 한도에 걸리면 어떻게 하나요?**
진행 중인 작업은 마칠 수 있습니다. 그다음에는 요금제에 따라 크레딧을 추가하거나, 쓸 수 있는 리셋을 적용하거나, 업그레이드하거나, 5시간·주간 한도가 초기화될 때까지 기다립니다.
