![클로드 코드 vs 코덱스: 같은 프롬프트 실측·요금 비교](/claude-code-vs-codex-ko.jpg)

**클로드 코드 vs 코덱스 한 줄 정리:** 둘 다 월 $20 요금제로 시작합니다. 클로드 코드는 5시간·주간 한도로 사용량을 세고, 코덱스 무료 요금제는 직접 써 보니 한 달 단위 한도였습니다. 같은 프롬프트로 직접 돌려 보니 작은 작업에서는 속도가 비슷했고(37초 대 39초), 코덱스는 무료 요금제로도 돌아갔습니다. 독립 벤치마크에서는 클로드 코드가 점수가 높고(68 대 63), 코덱스는 작업당 비용이 93% 낮았습니다. 이 글에서는 요금제, 사용량 계산 방식, 직접 테스트 결과, 벤치마크, 용도별 선택 기준까지 한 번에 비교합니다.

클로드 코드(Claude Code)는 Anthropic이, 코덱스(Codex)는 OpenAI가 만든 AI 코딩 에이전트입니다. 요금표만 보면 $20, $100, $200 요금제가 나란히 있어서 비슷해 보입니다. 하지만 무료로 쓸 수 있는지, 한도를 어떻게 세는지, 작업 하나에 토큰을 얼마나 쓰는지가 꽤 다릅니다. 요금은 2026년 10월 11~14일 각 회사 공식 페이지 기준입니다.

## 클로드 코드 vs 코덱스 한눈에 보기

![클로드 코드 vs 코덱스 한눈에 보기: 클로드 코드, 코덱스](/claude-code-vs-codex-ko-2.jpg)

| | 클로드 코드 | 코덱스 |
|---|---|---|
| 만든 곳 | Anthropic | OpenAI |
| 쓰는 곳 | 터미널, IDE, Claude 앱 | 챗GPT 앱, CLI, IDE, 웹 |
| 모델 | Claude만 (소넷, 오퍼스 등) | OpenAI만 (GPT-6 Luna, 6.1 Sol 등) |
| 무료로 쓰기 | 불가 (Claude 무료 요금제에 없음) | 가능 (챗GPT 무료, GPT-6 Luna) |
| 첫 유료 요금제 | Claude Pro $20 | 챗GPT Plus $20 |
| 사용량 세는 방식 | 5시간 한도 + 주간 한도 | 무료: 한 달 단위 (직접 확인) · 유료: OpenAI 안내상 5시간·주간 |
| 한도를 같이 쓰는 곳 | Claude 앱 (웹·데스크톱·모바일) | 챗GPT의 다른 에이전트 기능 |

가장 큰 차이는 일하는 방식입니다. 클로드 코드는 터미널에서 진행 상황을 보면서 방향을 잡아 주는 데 강하고, 코덱스는 일을 맡겨 두면 알아서 끝내는 쪽에 가깝습니다. 커뮤니티 후기에서도 "클로드는 내가 원하는 방향으로 맞춰 간다", "코덱스는 알아서 방향을 잡는다"는 평가가 함께 나옵니다. 어느 쪽이 편한지는 사람마다 갈립니다.

## 요금제 비교 (2026)

![요금제 비교 (2026): 가격, 클로드 코드 (Anthropic), 코덱스 (OpenAI)](/claude-code-vs-codex-ko-3.jpg)

미국 달러 기준 월 가격입니다.

| 가격 | 클로드 코드 (Anthropic) | 코덱스 (OpenAI) |
|---|---|---|
| 무료 | 없음 | 챗GPT 무료 (GPT-6 Luna) |
| $8 | 없음 | 챗GPT Go (GPT-6 Luna) |
| $20 | Claude Pro (연간 결제 시 월 약 $17) | 챗GPT Plus |
| $100 | Max 5x | Pro 100 |
| $200 | Max 20x | Pro 200 |
| $500 | 없음 | Pro 500 |

- **Claude Max는 이름이 곧 사용량입니다.** Anthropic 안내 기준으로 Max 5x는 Pro 사용량의 500%, Max 20x는 2,000%입니다.
- **챗GPT Pro의 사용량 비율은 공식 수치가 아닙니다.** OpenAI는 "윗 단계일수록 더 많이 쓴다"고만 안내합니다. 보도와 OpenAI 직원의 X 글 기준으로 Pro 100·200·500이 Plus의 약 500%·1,000%·2,500%입니다.
- **무료로 진짜 에이전트를 돌릴 수 있는 건 코덱스뿐입니다.** Claude 무료 요금제에는 클로드 코드가 없습니다.
- **연간 할인은 클로드 Pro에만 있습니다.** Claude Pro는 연간 $200 선결제가 가능하고, Max와 챗GPT 요금제는 월 결제만 있습니다.

요금제별 자세한 내용은 [클로드 코드 요금 정리](/ko/blog/claude-code-yogeum)와 [코덱스 요금 정리](/ko/blog/codex-yogeum)에 있습니다.

## 사용량은 어떻게 세나

### 클로드 코드: 5시간 한도와 주간 한도

5시간 단위 한도와 그 위의 주간 한도가 있고, 둘 다 Claude 앱과 같이 씁니다. 앱에서 긴 대화를 하면 코딩에 쓸 한도가 그만큼 줄어듭니다. Max 요금제는 Fable 모델용 주간 한도가 따로 있습니다. 남은 양은 클로드 코드 안에서 **/usage**로 확인합니다. Anthropic은 한도를 토큰 수로 공개하지 않습니다. 자세한 내용은 [클로드 코드 사용량 한도 정리](/ko/blog/claude-code-sayongnyang-hando)를 보세요.

### 코덱스: 무료는 한 달 단위, 유료는 5시간·주간

**무료 요금제 (직접 확인):** 우리 무료 계정에는 5시간이나 주간 미터가 없었습니다. '1개월'짜리 사용량 막대 하나만 있고, 초기화도 한 달 뒤였습니다. 위 테스트의 "월 사용량 1%"가 이 막대 기준입니다.

**유료 요금제 (OpenAI 안내 기준):** 저는 Plus나 Pro를 써 보지 않아서, 아래는 OpenAI 안내를 옮긴 것입니다. Plus와 Business는 5시간 단위 한도가 있고 주간 한도가 추가로 걸릴 수 있습니다. Pro 요금제는 5시간 한도 없이 주간 한도만 있다고 안내합니다. 내 컴퓨터에서 돌리는 로컬 작업과 클라우드 작업은 같은 사용량을 나눠 쓰고, 클라우드 작업은 Plus부터 됩니다. 자세한 내용은 [코덱스 사용량 한도 정리](/ko/blog/codex-sayongnyang-hando)를 보세요.

- **둘 다 작업당 가격을 숨깁니다.** 화면에는 달러가 아니라 한도의 몇 %를 썼는지만 나옵니다.
- **한도가 차면 기다리거나 추가 사용량을 삽니다.** 클로드 코드는 사용 크레딧을 켜거나 API로 넘어갈 수 있습니다.

## 같은 프롬프트로 직접 돌려 봤다

![같은 프롬프트로 직접 돌려 봤다: 도구 · 모델 · effort, 요금제, 걸린 시간, 게임 코드, 사용량·비용](/claude-code-vs-codex-ko-4.jpg)

요금표와 벤치마크만으로는 감이 안 와서, 2026년 10월 9~11일에 같은 일을 시켜 봤습니다. 프롬프트는 이렇습니다.

> "현재 폴더에 index.html 한 파일로 브라우저에서 돌아가는 벽돌깨기 게임을 만들어 줘. 레벨 2개, 점수 표시, 목숨 3개가 있어야 하고, 키보드와 마우스로 할 수 있어야 해. 파일을 쓰고 끝내."

| 도구 · 모델 · effort | 요금제 | 걸린 시간 | 게임 코드 | 사용량·비용 |
|---|---|---|---|---|
| 클로드 코드 · 소넷 5.5 · medium | Max 5x | 37초 | 198줄 | API 가격 환산 $0.25 |
| 클로드 코드 · 소넷 5.5 · high | Max 5x | 58초 | 398줄 | API 가격 환산 $0.30 |
| 클로드 코드 · 오퍼스 5.5 · medium | Max 5x | 52초 | 358줄 | API 가격 환산 $0.56 |
| 클로드 코드 · 오퍼스 5.5 · high | Max 5x | 1분 50초 | 523줄 | API 가격 환산 $0.75 |
| 코덱스 · GPT-6 Luna · medium | 무료 | 39초 | 398줄 | 코덱스 2회 합쳐 무료 월 사용량의 1% |
| 코덱스 · GPT-6 Luna · extra high | 무료 | 39초 | 273줄 | (위에 포함) |

모든 실행이 요청한 기능(레벨 2개, 점수, 목숨 3개, 키보드·마우스 조작)을 갖춘 게임을 만들었습니다. 클로드 코드 비용은 ccusage로 재서 API 가격으로 환산했고, 코덱스는 앱의 사용량 미터에 나온 값입니다. 코덱스 쪽은 [코덱스 요금 글](/ko/blog/codex-yogeum)의 무료 요금제 테스트와 같은 실행입니다.

### 직접 해 본 소감

테스트한 게임을 모두 직접 플레이해 봤습니다.

- **소넷 5.5 medium:** 굉장히 심플하고 각종 게임 효과도 없고 하트도 없어서 밋밋하지만, 기능적으로는 정상 작동하는 느낌입니다.
- **소넷 5.5 high:** 오퍼스 5.5 high 수준의 작업물입니다. 파티클을 잘 만들었습니다.
- **코덱스 GPT-6 Luna medium:** "부드러운 느낌이 드는데 게임 효과는 없어서 타격감은 아쉬운 느낌"
- **코덱스 GPT-6 Luna extra high:** "파티클이 화려하진 않지만 없는 것보단 나았고, 그 외 다른 기능은 잘 모르겠다"

소넷과 오퍼스 결과는 [클로드 소넷 5.5 vs 오퍼스 5.5](/ko/blog/claude-sonnet-5-5-vs-opus-5-5)와 [오퍼스 5.5 effort 비교](/ko/blog/claude-opus-5-5-effort)에 화면과 함께 자세히 정리해 두었습니다.

### 숫자를 어떻게 읽을까 (우리 해석)

- **작은 작업에서는 속도가 비슷했습니다.** medium 기준으로 클로드 코드 소넷 37초, 코덱스 GPT-6 Luna 39초였습니다.
- **코덱스는 effort를 올려도 시간이 같았습니다.** extra high도 39초였고, 대신 파티클 같은 마무리가 추가됐습니다. 클로드 코드는 effort를 올리면 시간과 비용이 같이 늘었습니다.
- **코덱스 무료 요금제는 여유가 컸습니다.** 두 번 돌리고 월 사용량의 1%였으니, 단순 계산으로 이런 게임을 한 달에 약 200번 만들 수 있는 양입니다. 미터가 1% 단위라 정확한 값은 아닙니다.
- **품질 순위로 보면 안 됩니다.** GPT-6 Luna는 OpenAI의 가벼운 모델이고, 소넷과 오퍼스는 Anthropic의 중간·최상위 모델입니다. 이 테스트는 각 도구를 기본 설정에 가깝게 썼을 때 작은 일을 어떻게 처리하는지를 보여 줄 뿐입니다.

## 독립 벤치마크는 뭐라고 하나

![독립 벤치마크는 뭐라고 하나: 항목, 클로드 코드 (소넷 5.5, max), 코덱스 (GPT-6.1 Sol, xhigh)](/claude-code-vs-codex-ko-5.jpg)

큰 작업에서는 독립 평가 기관 Artificial Analysis의 Coding Agent Index를 참고할 수 있습니다. 코딩 에이전트 벤치마크 3개를 합친 지수이고, 각 도구를 최상위 설정(클로드 코드는 소넷 5.5 max, 코덱스는 GPT-6.1 Sol xhigh)으로 돌린 결과입니다.

| 항목 | 클로드 코드 (소넷 5.5, max) | 코덱스 (GPT-6.1 Sol, xhigh) |
|---|---:|---:|
| Coding Agent Index | 68 | 63 |
| DeepSWE v1.1 | 72% | 73% |
| Terminal-Bench 4.0 | 66% | 55% |
| SWE-Atlas-QnA | 67% | 61% |
| 작업당 비용 | $14.19 | $1.04 |
| 작업당 시간 | 1.5시간 | 15.5분 |
| 작업당 토큰 | 2,770만 | 320만 |

- **점수는 클로드 코드가 높았습니다.** 세 벤치마크 중 두 개에서 앞섰습니다.
- **비용과 시간은 코덱스가 훨씬 적었습니다.** 작업당 비용은 93% 낮았고, 시간은 약 6분의 1, 토큰은 88% 적었습니다.
- **effort를 낮추면 비용 차이가 줄어듭니다.** 같은 지수에서 클로드 코드 소넷 5.5 high는 55점에 작업당 $1.24, 코덱스 GPT-6.1 Sol medium은 61점에 $0.70입니다.

각 회사가 직접 발표한 수치도 있습니다. Anthropic 발표 기준으로 Terminal-Bench 4.0에서 소넷 5.5는 70.6%, 오퍼스 5.5는 66.4%이고, 같은 표에 OpenAI 보고치로 실린 GPT-6 Astra는 57.9%입니다. GPT-6.1 Sol의 이 벤치마크 수치는 발표되지 않았고 측정 조건도 회사마다 달라서, 회사 발표 수치로 순위를 매기지는 않는 편이 안전합니다.

우리 작은 테스트와 같은 흐름입니다. 코덱스는 토큰을 아껴 쓰고, 클로드 코드는 높은 effort에서 작업당 더 많은 일을 하는 대신 토큰을 많이 씁니다. 구독에서는 달러가 보이지 않지만, 늘어난 토큰은 그대로 한도에서 빠집니다.

## 커서는 어디에 맞나

커서(Cursor)는 둘과 결이 다른 도구입니다. 자체 코드 에디터 안에서 Claude, GPT, Gemini, Grok 모델을 골라 쓰고, 모델 사용료를 API 가격 그대로 월 사용량에서 차감합니다.

| | 클로드 코드 | 코덱스 | 커서 |
|---|---|---|---|
| 모델 선택 | Claude만 | OpenAI만 | 여러 회사 모델 |
| 과금 방식 | 5시간·주간 한도 | 무료는 월 단위, 유료는 5시간·주간 | 월 사용량을 API 가격으로 차감 |
| 같은 테스트 | 37초~1분 50초 | 39초 | 1분 31초 (무료, Grok 4.6, 월 무료 사용량의 15%) |

모델을 바꿔 가며 쓰고 작업당 비용을 보고 싶다면 커서가 맞습니다. 자세한 요금은 [커서 요금제 정리](/ko/blog/cursor-pricing)에 있습니다.

## 둘을 같이 쓰는 방법

클로드 코드와 코덱스를 함께 쓰는 사람도 많습니다. 흔한 방식은 이렇습니다.

- **설계와 어려운 디버깅은 클로드 코드, 반복 작업은 코덱스.** 코덱스는 토큰을 적게 쓰니, 단순한 수정이나 테스트 작성을 맡기면 클로드 한도를 아낄 수 있습니다.
- **한도가 찼을 때 갈아타기.** 클로드 코드의 5시간 한도가 차면 기다리는 동안 코덱스로 이어서 작업합니다.
- **서로 리뷰시키기.** 한쪽이 짠 코드를 다른 쪽에 검토시키면 놓친 버그를 찾는 데 도움이 됩니다.

두 구독을 동시에 쓰기 전에, 한쪽 요금제를 한 단계 올리는 것과 비용을 먼저 비교해 보세요. 클로드 코드 토큰을 아끼는 방법은 [클로드 코드 토큰 절약 방법 9가지](/ko/blog/claude-code-token-jeolyak)에 정리해 두었습니다.

## 제 설정

저는 Claude Max 5x 요금제로 매일 씁니다. 오퍼스 5를 쓸 때는 한도가 자주 찼는데, 오퍼스 5.5부터는 한 번도 안 찼습니다. 최근 한 주는 93%까지 갔습니다. OpenAI 쪽은 무료 요금제이고, 위 코덱스 테스트도 무료 요금제로 했습니다.

## 결론

- **둘 다 $20로 시작하지만 무료로 쓸 수 있는 건 코덱스뿐입니다.** 우리 테스트에서 무료 요금제로도 충분히 돌아갔습니다.
- **클로드 코드는 높은 effort에서 작업당 더 많은 일을 합니다.** 독립 벤치마크 점수가 가장 높고, 그만큼 토큰을 많이 씁니다.
- **코덱스는 가볍고 경제적입니다.** 작업당 비용과 시간이 적고, 무료 요금제의 한 달 한도로도 작은 작업은 넉넉했습니다.
- **매일 많이 쓴다면 $100·$200 정액 요금제가 API보다 보통 쌉니다.**

## 자주 묻는 질문

**클로드 코드와 코덱스 중 뭐가 더 나은가요?**
독립 평가(Artificial Analysis)에서는 클로드 코드(소넷 5.5 max)가 68점, 코덱스(GPT-6.1 Sol xhigh)가 63점입니다. 대신 작업당 비용은 $14.19 대 $1.04입니다. 높은 점수와 낮은 비용 중 무엇이 중요한지에 따라 답이 달라집니다.

**클로드 코드와 코덱스의 차이는 뭔가요?**
클로드 코드는 Claude 모델, 코덱스는 OpenAI 모델로 일합니다. 커뮤니티 후기로는 클로드 코드가 진행 상황을 보며 같이 조종하기 좋고, 코덱스는 일을 맡겨 두는 방식에 강하다는 평이 많습니다. 요금은 둘 다 $20부터지만, 무료로 쓸 수 있는 건 코덱스뿐입니다.

**코덱스가 클로드 코드보다 싼가요?**
시작 가격은 둘 다 월 $20입니다. 코덱스는 무료 요금제가 있고 작업당 토큰을 훨씬 적게 써서, 같은 한도로 더 많은 일을 하는 경우가 많습니다.

**클로드 코드는 무료로 쓸 수 있나요?**
아니요. 클로드 코드는 유료 Claude 요금제(Pro, Max, Team, Enterprise)나 API 키가 있어야 씁니다.

**코덱스는 무료인가요?**
제한된 형태로 무료입니다. 챗GPT 무료 요금제에서 데스크톱 앱으로 GPT-6 Luna를 쓸 수 있고, 클라우드 작업은 Plus부터입니다.

**클로드 코드와 코덱스를 같이 써도 되나요?**
네. 어려운 작업은 클로드 코드, 반복 작업은 코덱스에 맡기면 클로드 한도를 아낄 수 있습니다.

**채팅 앱과 한도를 같이 쓰나요?**
네. 클로드 코드는 Claude 앱과, 코덱스는 챗GPT의 다른 에이전트 기능과 한도를 같이 씁니다.
