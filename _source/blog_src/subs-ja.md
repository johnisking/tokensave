ChatGPT、Claude、Gemini、Grok は、それぞれ有料プランを3〜5つ用意しています。名前もバラバラで、支払い通貨も違う（ChatGPT・Google は円、Claude・Grok はドル）ので、ひと目では比べにくくなっています。日本で実際に払う金額で一つの表にまとめ、どのプランが誰に向いているかまで整理しました。

## 日本の料金 早見表

![日本の料金 早見表: 価格帯, ChatGPT, Claude, Google（Gemini）](/ai-subscription-ryoukin-hikaku-ja-2.jpg)

2026年10月6日確認。円の料金は各社の日本向け表示価格、ドル払いは税込の金額を1ドル＝158円で換算しています。

| 価格帯 | ChatGPT | Claude | Google（Gemini） |
|---|---|---|---|
| 1,000円前後 | Go 1,400円 | – | AI Plus 725円 |
| 3,000円前後 | Plus 3,000円 | Pro $22（約3,480円） | AI Pro 2,900円 |
| 1万円台 | Pro 16,800円〜 | Max 5x $110（約17,380円） | Ultra 5x 14,500円 |
| 3万円台 | – | Max 20x $220（約34,760円） | Ultra 20x 32,000円 |

- **ChatGPT:** 円建て・税込です。Pro は使用量に応じて複数のティアがあり、上位ティアは新規受付を止めている時期があります。
- **Claude:** 日本ではドル建てで、消費税10%込みの価格が表示されます。年払いなら Pro は月約2,900円相当です。カード会社によっては海外決済の手数料がかかります。
- **Google:** 円建てです。18歳以上の大学生は AI Plus を1年間無料で使える特典があります。
- **Grok:** ドル建てです。米国価格で SuperGrok Lite $10、SuperGrok $30、SuperGrok Plus $100、SuperGrok Heavy $300 です。

## 同じ3,000円でも中身は違う

![同じ3,000円でも中身は違う: ChatGPT Plus; Claude Pro; Google AI Pro](/ai-subscription-ryoukin-hikaku-ja-3.jpg)

3,000円前後の基本プランは、3社ともほぼ同じ値段です。ほとんどの人はこのクラスで十分です。違いは値段よりも**何に使うか**で出ます。

- **ChatGPT Plus:** 画像生成、音声、ディープリサーチ、カスタム GPT まで、機能の幅が一番広いです。Codex と ChatGPT Work も含まれます。
- **Claude Pro:** 長文やコーディングに強く、Claude Code が含まれます。ただし5時間と週の上限があり、たくさん使うとすぐ止まります。
- **Google AI Pro:** 5TB のストレージ、Gmail・ドキュメント・スプレッドシートの中の Gemini がセットです。Google のサービスをよく使うなら一番お得です。

## 1,000円前後のプランは要注意

- **ChatGPT Go（1,400円）:** 会話のモデルは小さい GPT-5.6 Luna で、広告が表示されることがあります。普段の会話は無料でも無制限なので、Go で増えるのはアップロード・画像・メモリの上限です。詳しくは[ChatGPT Go と Plus の違い](/ja/blog/chatgpt-go-vs-plus)へ。
- **Google AI Plus（725円）:** まもなく Pro モデルが使えなくなります。400GB のストレージが必要な人には今も悪くありません。[Gemini 無料版の変更まとめ](/ja/blog/gemini-muryou-flash-lite)を参照してください。

## 1万円以上のプランは「単価」を見る

![1万円以上のプランは「単価」を見る: プラン, 基本プランに対する使用量, 単価](/ai-subscription-ryoukin-hikaku-ja-4.jpg)

| プラン | 基本プランに対する使用量 | 単価 |
|---|---|---|
| Claude Max 5x | 5倍 | Pro と同じ |
| **Claude Max 20x** | **20倍** | **Pro の半分** |
| Google Ultra 5x | AI Pro の5倍 | AI Pro と同じ |
| Google Ultra 20x | AI Pro の20倍 | AI Pro より約45%安い |

Claude Max 20x と Google Ultra 20x は、上のプランほど使用量あたりの値段が下がります。Claude Code を一日中使うなら Claude Max 20x が一番効率的です。ChatGPT Pro はティアを上げても単価はほぼ変わりません。Claude のプランの違いは[Claude Max vs Pro 比較](/ja/blog/claude-max-vs-pro)にまとめています。

## サブスクは本当に必要？

4社とも、使った分だけ払う API も売っています。軽い使い方なら API のほうがずっと安く済みます。ただし**日本語は同じ内容でも英語よりトークンが約79%多く出る**ので、日本語でたくさん使う人ほど、定額のサブスクが相対的に有利になります（[日本語は英語よりトークンが多い？](/ja/blog/nihongo-tokens-gpt)）。画像生成、音声、ディープリサーチなど API にない機能を使うなら、サブスクが向いています。

自分の使い方で月の API 料金と各プランを並べて見るなら、[サブスク vs API 計算機](/ja/plans)を使ってみてください。Claude Code や Codex などのコーディングエージェントは[エージェント費用計算機](/ja/agents)で計算できます。
