![클로드 사용량 한도 2026: 5시간·주간 초기화 정리](/claude-sayongnyang-hando-ko.jpg)

클로드를 한창 쓰다 보면 "사용량 한도에 도달했습니다"라는 안내가 뜨고 입력창이 막힐 때가 있습니다. 언제 다시 쓸 수 있는지, 왜 이렇게 빨리 찼는지, 돈을 더 내면 바로 풀리는지 궁금해지는 순간입니다. 검색해 보면 "첫 메시지부터 5시간", "7일마다 초기화"처럼 글마다 설명이 조금씩 다르고, 그사이에 화면도 바뀌어서 지금 내 계정에 맞는 답을 찾기가 쉽지 않습니다.

그래서 Anthropic 고객센터의 사용량 관련 문서를 2026년 10월 16일에 다시 읽고, 실제로 Max 5x를 쓰고 있는 계정의 사용량 화면과 하나씩 맞춰 봤습니다. 이 글은 클로드의 세션 한도와 주간 한도가 어떻게 돌아가는지, 초기화 시간은 어디서 보는지, 새로 생긴 "무료로 초기화" 버튼은 무엇인지, 한국어 사용자가 한도를 더 빨리 쓰는 이유와 줄이는 방법까지 차례로 정리했습니다.

## 클로드 사용량 한도는 두 가지가 동시에 걸립니다

클로드에는 성격이 다른 한도가 두 종류 있습니다.

1. **사용량 한도.** 일정 시간 동안 얼마나 쓸 수 있는지 정하는 한도입니다. 유료 요금제(Pro, Max, Team 등)에는 **5시간마다 초기화되는 세션 한도**와 **일주일마다 초기화되는 주간 한도**가 함께 걸립니다.
2. **길이 한도.** 대화 하나가 얼마나 길어질 수 있는지 정하는 한도로, 모델의 맥락 창(context window) 크기에서 나옵니다. 유료 요금제의 최신 모델은 최대 100만 토큰까지 지원하고, 다른 모델은 50만 또는 20만 토큰입니다.

이 글에서 다루는 것은 첫 번째, 사용량 한도입니다. 세션 한도가 남아 있어도 주간 한도를 다 쓰면 막히고, 주간 한도가 넉넉해도 5시간 안에 몰아 쓰면 세션 한도에 걸립니다. 그리고 **claude.ai 웹, 데스크톱 앱, 모바일 앱, 클로드 코드(Claude Code)가 모두 같은 한도를 나눠 씁니다.** 클로드 코드로 코딩을 오래 하면 채팅에 남는 양도 줄어드는 구조입니다.

## 요금제별 클로드 사용량 한도

![요금제별 클로드 사용량 한도: 요금제, 월 요금(웹), 세션 한도(5시간), 주간 한도, 한도 초과 시](/claude-sayongnyang-hando-ko-2.jpg)

| 요금제 | 월 요금(웹) | 세션 한도(5시간) | 주간 한도 | 한도 초과 시 |
|---|---:|---|---|---|
| 무료 | $0 | 있음, 수요에 따라 달라짐 | 공식 안내 없음 | 초기화 대기 |
| Pro | $20 | 기준(무료보다 많음) | 있음, 모든 모델 합산 | 사용량 크레딧, 업그레이드 |
| Max 5x | $100 | Pro의 500% | 있음 + Fable 전용 주간 한도 | 사용량 크레딧, 업그레이드 |
| Max 20x | $200 | Pro의 2,000% | 있음 + Fable 전용 주간 한도 | 사용량 크레딧 |
| Team | 좌석별 | 있음 | 있음 | 사용량 크레딧 |

몇 가지 짚어 둘 점이 있습니다.

- **정해진 메시지 수는 없습니다.** Anthropic은 "5시간에 몇 개"라는 숫자를 내놓지 않습니다. 메시지 길이, 첨부 파일 크기, 지금까지의 대화 길이, 고른 모델과 effort(생각 수준), 웹 검색·리서치 같은 도구 사용에 따라 같은 한도로 보낼 수 있는 양이 달라지기 때문입니다.
- **Max의 배율은 세션 기준입니다.** 고객센터는 Max 5x가 Pro의 세션당 사용량의 500%, Max 20x가 2,000%라고 설명합니다. 주간 한도 크기는 숫자로 공개하지 않습니다.
- **Max에는 Fable 전용 주간 한도가 따로 있습니다.** 사용량 화면에 "이번 주 Fable"이라는 별도 막대가 보이고, 일반 주간 한도와 같은 시각에 초기화됩니다.
- **가격은 웹 결제 기준입니다.** 모바일 앱에서 결제하면 앱 마켓 정책 때문에 가격이 다를 수 있습니다. 요금제별 기능과 한국에서 실제로 내는 금액은 [클로드 요금제 총정리](/ko/blog/claude-yogeumje)에 정리해 두었습니다.

## 클로드 사용량 초기화 시간은 언제인가요?

두 한도는 초기화되는 방식이 다릅니다. 여기서 많이 헷갈립니다.

| 한도 | 초기화 방식 | 확인하는 곳 |
|---|---|---|
| 세션 한도 | 5시간마다. 화면에 "오후 5:40에 재설정"처럼 시각이 표시됨 | 설정 > 사용량의 "현재 세션" |
| 주간 한도 | 계정마다 정해진 요일·시각에 매주 초기화 | 설정 > 사용량의 "이번 주" |
| Fable 주간 한도 (Max) | 주간 한도와 같은 요일·시각 | 설정 > 사용량의 "이번 주 Fable" |

**세션 한도**는 하루 중 정해진 시각(예: 자정)에 풀리는 방식이 아닙니다. 사용을 시작하면 5시간짜리 세션이 열리고, 그 세션이 끝나는 시각이 사용량 화면에 표시됩니다. 오전 10시쯤 쓰기 시작했다면 대략 오후 3시쯤 다시 채워진다고 생각하면 됩니다.

**주간 한도**는 흔히 "첫 사용부터 7일"이라고 알려져 있지만, 2026년 10월 현재 고객센터 설명은 다릅니다. Pro와 Max 모두 **계정마다 고정된 주간 초기화 요일과 시각이 있고, 언제 처음 썼는지나 언제 구독을 시작했는지와 관계없이 그대로 유지된다**고 안내합니다. 실제로 확인한 계정은 "재설정: (목요일) 오후 7:00"으로 고정되어 있었습니다. 내 계정의 요일과 시각은 사용량 화면에서 바로 확인할 수 있습니다.

## 남은 사용량 확인하는 방법

![클로드 사용량 화면: 현재 세션 7%, 이번 주 9%, 이번 주 Fable 0%, 제한 초기화](/claude-usage-settings-screen-ko.jpg)

웹이나 데스크톱 앱에서 **설정 > 사용량**으로 들어가면 됩니다(주소창에 claude.ai/settings/usage를 입력해도 됩니다). 위 화면이 Max 5x 계정의 실제 사용량 화면입니다. 맨 위에 "주간 한도의 9%를 사용했습니다"처럼 한 줄 요약이 나오고, 그 아래에 세 개의 막대가 있습니다.

- **현재 세션:** 이번 5시간 동안 쓴 비율과 다음 재설정 시각
- **이번 주:** 주간 한도를 쓴 비율과 다음 재설정 요일·시각
- **이번 주 Fable:** Max에만 있는 Fable 전용 주간 한도

화면을 더 내리면 **이번 주 제품별 사용량**이 나옵니다. 주간 사용량을 클로드 코드, 채팅, Cowork, 기타로 나눠 보여 주기 때문에, 어디서 한도를 많이 썼는지 바로 알 수 있습니다.

![이번 주 제품별 사용량: Claude Code 3%, 채팅 1%, Cowork 93%, 기타 3%](/claude-usage-by-product-ko.jpg)

이 계정은 이번 주 사용량의 93%가 Cowork(파일과 도구를 쓰며 여러 단계로 일하는 에이전트 작업)에서 나왔고, 일반 채팅은 1%뿐이었습니다. 여러 단계를 스스로 돌리는 작업은 한 번 시켜도 내부에서 많은 요청이 오가기 때문에, 채팅 몇 번과는 한도를 쓰는 속도가 다릅니다.

클로드 코드를 쓴다면 터미널에서 `/usage`를 입력해 같은 정보를 볼 수 있습니다. 한도 비율이 아니라 지금까지 쓴 토큰을 API 요금으로 바꾸면 얼마인지, 날짜·프로젝트별로 어디에 많이 썼는지 보고 싶다면 [클로드 코드 사용량 분석기](/ko/claude-code-usage)에 기록 폴더를 넣어 보세요. 브라우저 안에서만 계산합니다.

## 새로 생긴 "무료로 초기화"(제한 초기화)

사용량 화면에 **제한 초기화**라는 칸이 생겼습니다. 고객센터 설명에 따르면 Anthropic이 대상 요금제에 가끔 제공하는 혜택으로, 쓰면 한도가 다시 꽉 찹니다.

- **종류가 두 가지입니다.** 5시간 세션 한도를 채워 주는 "5시간 초기화"와, 주간 한도를 채워 주는 "전체 초기화"가 있습니다. 확인한 계정에는 **전체 초기화 1회(만료일 10월 23일)**가 들어와 있었고, 5시간 초기화는 "지금은 없습니다"로 표시됐습니다.
- **한도에 닿기 전에도 쓸 수 있습니다.** 다만 한 번 쓰면 되돌릴 수 없고, 정해진 주간 초기화 일정은 그대로 유지됩니다.
- **웹이나 데스크톱 앱에서만 누를 수 있습니다.** 모바일 앱과 클로드 코드에는 버튼이 없습니다. 한도는 계정 전체가 나눠 쓰기 때문에, 웹에서 초기화하면 모바일과 클로드 코드도 함께 풀립니다.
- **만료일이 지나면 사라집니다.** 요금제를 낮추거나 해지해도 쓰지 않은 초기화는 없어집니다. 이미 결제된 추가 사용량을 돌려주지는 않습니다.

사용법은 설정 > 사용량의 제한 초기화 칸에서 **무료로 초기화**를 누르고, 확인 창에서 한 번 더 누르면 됩니다. 한도에 걸렸을 때 뜨는 안내 메시지에도 같은 버튼이 나옵니다. 주간 한도 초기화를 받았다면, 주 후반에 한도가 거의 찼을 때 쓰는 편이 가장 효율적입니다.

## 한도에 걸렸을 때 할 수 있는 것

| 방법 | 비용 | 언제 맞나 |
|---|---|---|
| 초기화 기다리기 | 없음 | 세션 한도에 걸렸고 몇 시간 기다릴 수 있을 때 |
| 무료로 초기화 | 없음 (받은 경우만) | 주간 한도가 거의 찼고 초기화 혜택이 있을 때 |
| 사용량 크레딧 켜기 | API 요금 기준으로 쓴 만큼 | 가끔 한도를 넘기고 바로 이어서 일해야 할 때 |
| 요금제 올리기 | 월 $80~$180 추가 | 거의 매주 한도에 걸릴 때 |

**사용량 크레딧**은 설정 > 사용량에서 켤 수 있습니다. 켜 두면 세션·주간 한도(Max는 Fable 주간 한도 포함)를 다 쓴 뒤에도 작업이 멈추지 않고 크레딧으로 넘어가서, 안내 문구가 "Now using credits"로 바뀝니다. 요금은 API 표준 요금 기준이고 구독료와 따로 청구됩니다. 켜기 전에 **월 지출 한도**를 꼭 정해 두세요. 무제한으로 두면 에이전트 작업 하나가 생각보다 큰 금액을 쓸 수 있습니다. 크레딧을 켜도 세션·주간 한도의 초기화 시각은 바뀌지 않습니다.

**요금제를 올리면** 새 한도가 바로 적용되고, 남은 기간은 일할 계산됩니다. 다만 한도에 가끔만 걸린다면 크레딧을 조금 쓰는 편이 매달 $80를 더 내는 것보다 쌉니다. 프로와 Max 중 무엇이 맞는지는 [클로드 Max vs Pro 비교](/ko/blog/claude-max-vs-pro)에서 사용 패턴별로 나눠 봤습니다.

## 한국어로 쓰면 한도를 더 빨리 씁니다

고객센터가 꼽는 사용량 요인 가운데 첫 번째가 메시지 길이와 대화 길이입니다. 그런데 같은 내용이라도 한국어는 영어보다 토큰이 더 많이 나옵니다. 오늘(10월 16일) Claude Opus 5.5로 같은 글과 질문을 한국어·영어로 보내 잰 결과는 이랬습니다.

- 같은 뜻의 글을 쓰게 하면 **한국어 출력 토큰이 영어보다 102% 많았습니다.**
- 같은 일상 질문 5개를 물었을 때 **한국어가 영어보다 비용이 35% 더 들었습니다.**

Anthropic이 한도를 토큰 수로 공개하지는 않기 때문에 이 차이가 그대로 한도 차이라고 단정할 수는 없습니다. 하지만 사용량이 메시지와 답변의 길이에 따라 정해지는 구조라면, 한국어 사용자는 같은 일을 해도 한도를 더 빨리 쓴다고 보는 게 자연스럽습니다. 측정 방법과 숫자는 [클로드 한국어 토큰 실측 비교](/ko/blog/claude-hangugeo-token)에 자세히 있습니다.

긴 지시문이나 매번 붙여 넣는 배경 설명을 영어로 바꾸면 이 차이를 줄일 수 있습니다. [토큰 계산기](/ko/)에 프롬프트를 붙여 넣고 💸 토큰 절약을 누르면 영어로 바꿨을 때 토큰이 얼마나 줄어드는지 바로 볼 수 있습니다. 답변은 "한국어로 답해 줘"라고 한 줄 붙이면 됩니다.

## 클로드 한도를 오래 쓰는 방법

- **질문은 모아서 한 번에.** 관련된 질문 세 개를 따로 보내면 매번 앞의 대화가 다시 처리됩니다. 배경 설명과 질문을 한 메시지에 담는 편이 쌉니다.
- **긴 대화는 새로 시작.** 대화가 길어질수록 메시지 하나가 쓰는 양이 커집니다. 주제가 바뀌면 새 대화를 여세요. 맥락이 필요하면 지금까지의 요점을 정리해 달라고 한 뒤 새 대화에 붙이면 됩니다.
- **자주 쓰는 자료는 프로젝트에.** 고객센터에 따르면 프로젝트에 올린 자료는 캐시되어 다시 쓸 때 한도를 덜 씁니다. 다만 오래 쉬었다가 다시 쓰면 첫 메시지에서 다시 전부 계산됩니다.
- **필요할 때만 확장 사고와 높은 effort.** 단순한 정리나 번역은 낮은 effort로 충분합니다. effort별 차이는 [오퍼스 5.5 effort 비교](/ko/blog/claude-opus-5-5-effort)에서 시간과 비용으로 재 봤습니다.
- **안 쓰는 커넥터와 웹 검색은 끄기.** 연결된 앱과 도구는 요청마다 설명이 함께 들어가고, 웹 검색은 결과를 읽느라 사용량을 씁니다.
- **에이전트 작업은 범위를 좁게.** Cowork나 클로드 코드처럼 여러 단계를 스스로 도는 작업은 "어떤 파일의 무엇을 바꿔라"처럼 범위를 정해 줄수록 단계가 줄어듭니다. 클로드 코드 쪽 방법은 [클로드 코드 토큰 절약 방법 9가지](/ko/blog/claude-code-token-jeolyak)에 모아 두었습니다.

## 직접 써 보니

저는 무료에서 Pro로, 다시 Max 5x로 올라와 지금은 Max 5x를 쓰고 있습니다. 코딩과 외부 도구를 연결한 작업이 많아서 토큰을 많이 쓰는 편이라 Max가 맞았고, 그런 작업이 아니라면 Pro로도 충분하다고 느꼈습니다. 오퍼스 5를 쓸 때는 한도를 다 쓴 적이 있지만, 오퍼스 5.5로 바뀐 뒤로는 아직 한도에 걸린 적이 없습니다.

숫자로 보면 이렇습니다. 클로드 코드 기록을 사용량 분석기로 돌려 보니 17일 동안 쓴 양을 API 요금으로 바꾸면 $145.90이었습니다. 같은 기간 Max 5x 구독료의 257%에 해당하는 양을 정액으로 쓴 셈입니다. 이번 주는 목요일에 주간 한도가 초기화된 뒤 9%를 썼고, 그중 93%가 Cowork 작업이었습니다. 화면으로 보면 한도를 빨리 쓰는 것은 대화 횟수보다 **에이전트에게 맡기는 긴 작업**입니다.

## 정리

클로드 사용량 한도는 5시간마다 초기화되는 세션 한도와, 계정마다 정해진 요일·시각에 초기화되는 주간 한도가 함께 걸리는 구조입니다. 웹·앱·클로드 코드가 한도를 나눠 쓰고, 정해진 메시지 수는 없으며, 메시지 길이와 대화 길이, 모델과 도구에 따라 쓰는 양이 달라집니다.

한도에 걸렸다면 먼저 설정 > 사용량에서 재설정 시각과 "무료로 초기화" 혜택이 있는지 확인하세요. 바로 이어서 일해야 하면 월 지출 한도를 정한 뒤 사용량 크레딧을 켜고, 거의 매주 막힌다면 그때 요금제를 올리는 순서가 가장 돈이 덜 듭니다. 한국어로 긴 지시문을 자주 쓴다면 그 부분만 영어로 바꾸는 것도 한도를 늘리는 쉬운 방법입니다.

## 자주 묻는 질문

**클로드 프로로 5시간에 메시지를 몇 개 보낼 수 있나요?**
정해진 숫자는 없습니다. Anthropic은 메시지 길이, 첨부 파일, 대화 길이, 모델과 기능에 따라 달라진다고만 안내합니다. 짧은 질문 위주라면 많이, 긴 문서나 에이전트 작업이면 훨씬 적게 보낼 수 있습니다.

**주간 한도는 첫 메시지부터 7일 뒤에 초기화되나요?**
2026년 10월 현재 고객센터 설명은 그렇지 않습니다. 계정마다 정해진 요일·시각에 초기화되고, 처음 쓴 시점이나 구독 시작일과 관계없이 유지됩니다. 설정 > 사용량의 "이번 주" 아래에 표시된 요일과 시각을 보면 됩니다.

**클로드 코드와 채팅은 한도가 따로인가요?**
아닙니다. claude.ai, 데스크톱 앱, 모바일 앱, 클로드 코드가 같은 한도를 씁니다. 사용량 화면의 "이번 주 제품별 사용량"에서 어느 쪽이 얼마나 썼는지 나눠 볼 수 있습니다.

**사용량 크레딧은 비싼가요?**
API 표준 요금 기준으로 쓴 만큼 냅니다. 가벼운 채팅은 부담이 적지만 오퍼스 모델로 긴 에이전트 작업을 돌리면 금방 커질 수 있으니, 켜기 전에 월 지출 한도를 정해 두세요.

**"무료로 초기화"는 누구나 받나요?**
고객센터는 "대상 요금제에 가끔 제공된다"고만 설명하고, 누가 몇 번 받는지는 밝히지 않습니다. 받았다면 설정 > 사용량의 제한 초기화 칸에 만료일과 함께 표시됩니다.

## 내 사용량으로 계산해 보기

한도 안에서 쓰는 게 나은지, API로 쓴 만큼 내는 게 나은지는 사용량에 따라 달라집니다. [구독 vs API 계산기](/ko/plans)에 메시지 수와 길이, 언어를 넣으면 어느 쪽이 싼지 바로 계산됩니다. 클로드 코드의 한도 구조는 [클로드 코드 사용량 한도 정리](/ko/blog/claude-code-sayongnyang-hando)에 따로 정리해 두었습니다.
