![Codex の料金は？無料・Plus・Pro・API をまとめて解説](/codex-ryoukin-ja.jpg)

OpenAI のコーディングエージェント「Codex」の料金は、調べるほど分かりにくく感じるかもしれません。プランの名前は ChatGPT と同じなのに、使えるモデルや上限はプランごとに違い、2026年に入ってからは料金の仕組みそのものが何度も変わりました。この記事では、Codex とは何かから、各プランで使える範囲、クレジットと API の料金、そして ChatGPT の無料プランで実際に小さなゲームを2回作ってみた結果までを順番に整理します。

## Codex とは

Codex は、OpenAI が提供する AI コーディングエージェントです。指示を出すと、ファイルを読み、コードを書き、コマンドを実行し、結果を見て直すところまで自分で進めます。ChatGPT のデスクトップアプリ、Web、CLI（ターミナル）、IDE 拡張機能、iOS など、いくつかの入口から使えます。

料金の面で最初に押さえておきたいのは、**Codex は単体で契約するサービスではない**という点です。OpenAI の料金ページでは、ChatGPT Work と Codex は Free・Go・Plus・Pro・Business・Edu・Enterprise の各プランに含まれると説明されています。「Codex Pro」のような Codex だけのサブスクリプションはありません。ChatGPT のプランを契約すれば、そのプランの範囲で Codex が使える、という仕組みです。

もうひとつの使い方が **API キー**です。Codex CLI、SDK、IDE 拡張機能には API キーでサインインでき、その場合は使ったトークンの分だけ API 料金を払います。

| Go | $8 | GPT-6 Luna（デスクトップアプリ） | 非公開 | – |

- **料金は米ドルで案内されています。** OpenAI のヘルプセンターでは、Plus の$20のように価格が米ドルで記載されています。日本から契約する場合は、決済画面に円の金額が表示されることがあるので、実際の支払額は契約時の決済画面で確認してください。

- **API キーではクラウド機能は使えません。** CLI・SDK・IDE 拡張機能で使えますが、GitHub レビューや Slack などのクラウド連携は対象外です。

## プランごとに Codex でできること

![プランごとに Codex でできること: Free（$0）： デスクトップアプリで GPT-6 Luna を標準速度で使えます（段階的に提供）。クラウドタスクと画像生成はありません（画像を API で作る場合の費用は画像コスト計算機で確認できます）。OpenAI](/codex-ryoukin-ja-3.jpg)

上限の大きさだけでなく、できることそのものがプランで変わります。OpenAI の料金ページとヘルプセンターをもとにまとめます。

- **Free（$0）：** デスクトップアプリで GPT-6 Luna を標準速度で使えます（段階的に提供）。クラウドタスクと画像生成はありません（画像を API で作る場合の費用は[画像コスト計算機](/ja/image)で確認できます）。OpenAI は Free の使用量の上限を公開しておらず、「プランによって異なる」とだけ説明しています。私たちの無料アカウントでは、Codex アプリに残りの使用量を示すメーターが1本だけあり、期間は1か月、リセット日は1か月後でした。5時間や週単位のメーターは表示されませんでした。クレジットの購入は、一部の Free ユーザーに限って試験的に開かれています。
- **Go（$8）：** Codex については Free と同じ GPT-6 Luna の利用で、軽いコーディング向けと位置づけられています。ChatGPT 全体の利用量は増えますが、公開されている Codex の内容は Free と同じです。
- **Plus（$20）：** Web、CLI、IDE 拡張機能、iOS で Codex を使え、クラウド連携も付きます。難しい問題向けの GPT-6 Astra から、手早い編集向けの GPT-6 Luna まで GPT-6 の全ラインを、ローリング方式の5時間枠の範囲で使えます。上限に当たったときはクレジットを追加購入できます。
- **Pro（$100・$200・$500）：** Plus のすべてに加えて使用枠が大きく、現時点では5時間枠がありません。使用枠は週単位です。Pro 500 では GPT-6 Astra と GPT-6.1 Sol の Ultrafast モードが使えます。
- **Business（1ユーザー $20 または $25）：** Standard シートの Codex の上限は Plus とほぼ同じで、ワークスペースとして Codex のクレジットプランを購入できます。2ユーザー以上が必要です。
- **Enterprise・Edu：** 契約による価格です。フレキシブル料金なら固定のレート制限はなくクレジットで課金され、そうでなければシートごとの上限は Plus とほぼ同じです。

どのプランでも、Codex は ChatGPT Work、ChatGPT for Excel、Workspace Agents と**同じ使用枠を共有**します。Codex で長い作業をすると、ほかのエージェント機能に使える分が減り、その逆も同じです。

## モデル別の使用量の目安

![モデル別の使用量の目安: モデル, 5時間あたりのローカルメッセージ数（Plus・Business Standard）](/codex-ryoukin-ja-4.jpg)

OpenAI は Plus と Business（Standard）について、5時間枠あたりのローカルメッセージ数の目安を公開しています。固定の上限ではなく、幅のある目安です。

| モデル | 5時間あたりのローカルメッセージ数（Plus・Business Standard） |
|---|---:|
| GPT-6 Astra | 5〜45 |
| GPT-6.1 Sol | 15〜160 |
| GPT-6 Sol | 15〜150 |
| GPT-6 Luna | 350〜3,000 |

- **いちばん効くのはモデル選びです。** 範囲の下限どうしで比べると、GPT-6 Luna のメッセージ数は GPT-6 Astra の7,000%（350対5）です。簡単な編集は Luna、難しいバグだけ Astra と使い分けるほうが、プランを上げるよりずっと枠が長持ちします。
- **幅が広いのはタスクの大きさがまちまちだからです。** 数ファイルを読むだけのメッセージと、リポジトリの半分を読んで計画し、書いてテストまで回すメッセージでは消費がまったく違います。クラウドタスクはローカルより多く消費することがあります。
- 5時間枠に加えて、**週の上限**がかかる場合もあります。
- **Pro には現在5時間枠がありません。** 週の使用枠に達するまで、ひとつの長いセッションで作業を続けられます。
- **高速モードは消費が速くなります。** プランに含まれる使用量では、Fast モードは標準の250%、Ultrafast は800%のペースで枠を消費します。
- 画像生成も枠を速く使います。OpenAI によると、品質やサイズによって平均で通常の約300%〜500%です。

5時間枠と週の上限、リセットの詳しい仕組みは [Codex の使用量上限まとめ](/ja/blog/codex-shiyouryou-jougen)で解説しています。

## Codex のクレジットの仕組み

クレジットは、プランに含まれる使用量を使い切ったあとも作業を続けるためのものです。まずプランの使用量が消費され、それがなくなるとクレジット残高から引かれます。

OpenAI のレートカードでは、標準速度でのモデル別のクレジット消費が100万トークンあたりで示されています。

| モデル | 入力 | キャッシュ入力 | 出力 |
|---|---:|---:|---:|
| GPT-6 Astra | 250 | 25 | 1,250 |
| GPT-6.1 Sol | 50 | 2.5 | 250 |
| GPT-6 Sol | 50 | 5 | 250 |
| GPT-6 Luna | 2.5 | 0.25 | 12.5 |
| GPT-5.6 Sol | 100 | 10 | 500 |
| GPT-5.6 Luna | 5 | 0.5 | 30 |

- **購入できる人：** Plus と Pro は、Codex の上限に当たったときに表示される案内から、または ChatGPT の Settings > Usage、Codex アプリの Usage & Billing から購入できます。フレキシブル料金の Business・Edu・Enterprise はワークスペース単位で購入します。Free と Go はテストグループに限られます。
- **有効期限は12か月**で、それを過ぎた分は繰り越されません。
- **キャッシュ書き込みは課金されません。** 対象は入力、キャッシュ入力、出力の3つだけです。
- **Fast と Ultrafast は割高です。** クレジット払いでは、Fast は標準の200%、Ultrafast は600%で計算されます。
- **一般的なタスクは数クレジットです。** OpenAI によると、GPT-5.6 Sol の典型的なタスクで2〜15クレジットほどです。

### 1クレジットはいくら？

個人向けプランのクレジットについて、OpenAI は固定のドル価格を公開していません。ヘルプセンターでは、購入できる量と価格はアカウント、地域、プランによって異なり、購入画面に表示されると説明されています。日本から買う場合も、購入画面の表示が正式な価格です。

ただ、クレジットのレートと API 価格を並べると、はっきりした関係が見えます。確認した3モデルでは、どれも API 定価1ドルあたりちょうど25クレジットでした。

| モデル | API 価格（100万トークンあたり 入力 / 出力） | クレジット（100万トークンあたり 入力 / 出力） | API 価格1ドルあたりのクレジット |
|---|---|---|---:|
| GPT-6 Luna | $0.10 / $0.50 | 2.5 / 12.5 | 25 |
| GPT-6.1 Sol | $2 / $10 | 50 / 250 | 25 |
| GPT-6 Astra | $10 / $50 | 250 / 1,250 | 25 |

私たちの解釈では、1クレジットは API 利用で約$0.04分に相当するよう設計されています。購入画面でクレジットがこの水準の価格なら、クレジットを買っても API キーで使っても費用はほぼ同じです。これは私たちの計算で、OpenAI が示した価格ではないため、購入前に実際の金額を確認してください。

## Codex の API 料金

トークン単位で払いたい場合は、Codex CLI や IDE 拡張機能に API キーでサインインします。その場合は通常の API 料金がかかり、プランの上限はありません。

| モデル | 入力（100万トークン） | キャッシュ入力（100万トークン） | 出力（100万トークン） |
|---|---:|---:|---:|
| GPT-6 Luna | $0.10 | $0.01 | $0.50 |
| GPT-6.1 Sol | $2 | $0.10 | $10 |
| GPT-6 Astra | $10 | $1 | $50 |

- **クラウド機能は使えません。** API キーで使えるのは CLI・SDK・IDE 拡張機能だけです。
- **プランと併用できます。** API キーを設定しておけば、プランの上限に達したあともローカルのチャットを API 料金で続けられます。
- **コーディングエージェントは書くより読むほうがはるかに多い**のが特徴です。ステップのたびに指示、ツール定義、ファイル、それまでの経緯をモデルに送り直すため、請求の大半は入力トークンになりがちです。これらのモデルではキャッシュ入力が通常の入力より90%〜95%安いので、長いセッションでも1ステップあたりの費用は思ったほど膨らみません。

1か月の API 利用とプランを比べたいときは、[コーディングエージェント費用計算機](/ja/agents)にタスクの大きさと1日のタスク数を入れてみてください。

## ChatGPT の無料プランで Codex を試してみた

公開されている上限だけでは分からないこともあるので、2026年10月11日に小さなテストをしました。

![無料プランの Codex で作った2つのゲーム：medium と extra high を並べた画面](/codex-ryoukin-test-ja.jpg)

- **プラン：** ChatGPT Free
- **モデル：** GPT-6 Luna（無料プランの Codex で使えるモデル）
- **プロンプト：** [Claude Opus 5.5 の effort テスト](/ja/blog/claude-opus-5-5-effort)と同じブロック崩しのプロンプト。index.html ひとつで動くブラウザゲームで、2ステージ、スコア表示、ライフ3つ、キーボードとマウスの両方で操作できるもの
- **実行：** 推論レベル medium と extra high で1回ずつ。それぞれ別のファイルを作成

| | Medium | Extra high |
|---|---|---|
| 完成までの時間 | 39秒 | 39秒 |
| ゲームのコード | 398行 | 273行 |
| Codex が付けたタイトル | Brick Breaker | Neon Breakout |
| ステージ | 2（5×10ブロック、次に7×12） | 2（5×10、次に形のある6×11） |
| 演出 | なし | ブロックが壊れるときのパーティクル、ネオン風の光 |
| トークン（Codex 自身の推定） | 約4,000〜5,000 | 約4,000台 |
| 無料プランの消費 | 2回合わせて月間メーターの1% | |

どちらのゲームもプロンプトの条件（2ステージ、スコア、ライフ3つ、キーボードとマウス操作）をすべて満たしていました。タイトル画面、一時停止、クリア画面とゲームオーバー画面も両方にありました。

### 遊んでみた感想

テストをした本人が両方のゲームを遊びました。感想は韓国語から翻訳したものです。

- **Medium：**「なめらかな感じはするけど、ゲームの演出がないので、当たったときの手応えが少し弱い。」
- **Extra high：**「パーティクルは派手じゃないけど、ないよりはいい。ほかの機能の違いはあまり分からなかった。」

### 数字から読み取れること（私たちの解釈）

- **effort を上げて変わったのは時間ではなく仕上がりでした。** どちらも39秒です。extra high は行数が31%少ない一方で、パーティクル、光るビジュアル、そして速いボールがブロックをすり抜けないよう1フレームを細かく分けて当たり判定をする処理を加えていました。最後の処理は遊んでいても目に見えないので、「ほかの違いは分からなかった」という感想とも合います。
- **トークン数は測定値ではなく Codex 自身の推定です。** 尋ねると、Codex は正確な数は分からないとしたうえで、1回あたり約4,000〜5,000トークン、extra high は4,000台だと答えました。書いたコードの量に近いので、おそらく出力だけを数えた数字です。各ステップで送られる指示、推論、コンテキストは含まれていないと考えられます。
- **無料プランでも余裕がありました。** 完成したゲーム2本で月間メーターの1%を使い、その後は次のリセットまで残り99%と表示されました。単純に割ると月200本ほど作れる計算ですが、測ったのは2回だけで、メーターは1%単位で丸められています。この程度の小さく完結したタスクは、OpenAI の言う「手早いコーディングタスク」に十分収まっています。実際のコードベースでの大きなタスクは、読むファイルもステップも増えるので、もっと消費すると考えてください。
- **API 価格なら、このタスクは Luna でとても安く済みます。** Codex は全体のトークン数を出さなかったので、ここからは仮定です。同じプロンプトで Claude Sonnet 5.5 が使った総トークン数（115,073、ほぼすべて入力）と同じだけ使ったとすると、GPT-6 Luna の API 価格では、キャッシュなしでも1セント強になります。測定した費用ではなく、この仮定に基づく推定です。

比較として、同じプロンプトを Claude Code で実行すると、Sonnet 5.5（medium）で37秒・$0.25、Opus 5.5（high）で1分50秒・$0.75でした（ccusage で測定）。詳しくは [Claude Sonnet 5.5 vs Opus 5.5](/ja/blog/claude-sonnet-5-5-vs-opus-5-5) にまとめています。Claude 側は測定値、Codex 側のトークン数は自己申告なので、大まかな比較として見てください。

## 大きめのタスクではいくらかかるか

テストはあえて小さくしました。実際の作業はステップが多く、ステップのたびに膨らんだコンテキストが送り直されます。

- **よくある機能追加タスクはずっと大きくなります。** [Codex の使用量上限まとめ](/ja/blog/codex-shiyouryou-jougen)では、25ステップの機能追加タスクで入力トークンが約160万になると試算しました。API 価格では Sol クラスのモデルで約$0.72、GPT-6 Astra で約$3.60です。
- **同じタスクを Luna でこなせれば、費用はずっと下がります。** GPT-6 Luna の入力価格は GPT-6.1 Sol より95%安い（100万トークンあたり$0.10対$2）からです。
- **effort を上げると推論トークンが増えます。** 今回のテストでは extra high でも時間は変わりませんでしたが、難しいタスクでは差が大きくなるのが普通です。

つまり、費用を左右するのはプランよりもモデル選びです。日常的な作業を Luna に任せる Plus ユーザーのほうが、何でも Astra に投げる Pro ユーザーより長く使える、ということも十分ありえます。

## 2026年の Codex 料金の変更

Codex の料金は今年何度も変わっており、古い解説記事どうしで内容が食い違うのはそのためです。OpenAI のリリースノートとヘルプセンターから、重要な変更をまとめます。

| 日付 | 変更内容 |
|---|---|
| 2026年4月2日 | Plus・Pro・Business・新規 Enterprise で、メッセージ単位の料金から API のトークン使用量に基づくクレジットへ移行 |
| 2026年4月23日 | 同じトークンベースのレートカードを、既存の Enterprise・Edu・Health・Gov・ChatGPT for Teachers にも適用 |
| 2026年7月下旬 | GPT-5.6 Terra が20%、GPT-5.6 Luna が80%値下げ |
| 2026年9月29日 | Pro が Pro 100・Pro 200・Pro 500 に分割。新規の Pro 200 は以前より使用枠が小さく、Ultrafast は Pro 500 のみ |
| 2026年10月14日 | GPT-5.5 が全プランの ChatGPT・ChatGPT Work・Codex から提供終了（API には影響なし） |

- **4月より前に書かれた記事は、トークンではなくメッセージ数で説明しています。** モデルを指定せずに「プランごとに何メッセージ」と書いているページは、おそらく情報が古いものです。「無料プランでは Codex は使えない」という説明も、現在の公式ページの内容とは異なります。
- **Codex でまだ GPT-5.5 を使っているなら、10月14日までに切り替えましょう。** クレジットのレートカードでは、GPT-5.5 は入力100万トークンあたり125クレジット、GPT-6.1 Sol は50クレジットです。

## どのプランを選ぶか

| こんな人 | おすすめ | 理由 |
|---|---|---|
| 小さなタスクで Codex を試したい | Free | デスクトップアプリで GPT-6 Luna を無料で使える |
| 週に何度かコードを書き、クラウドタスクも使いたい | Plus（$20） | GPT-6 の全ライン、クラウドタスク、GitHub レビュー |
| 週に何度も5時間枠に当たる | Pro 100 | 5時間枠がなく、週の使用枠が大きい |
| 一日の大半を Codex で作業する | Pro 200 または Pro 500 | さらに大きな週の枠、Pro 500 は Ultrafast も |
| たまに自分のツールから使う | API キー | 使った分だけ。クラウド機能はなし |
| チームで使う | Business | シートごとに Plus 程度の上限、ワークスペースのクレジット |

- **迷ったらまず無料プランで。** 費用はかからず、上のテストのとおり小さなプロジェクトなら完成させられます。
- **Go は Codex のアップグレードにはなりません。** $8で ChatGPT 全体の利用量は増えますが、公開されている Codex の内容は Free と同じ GPT-6 Luna です。
- **使い方が変わるのは Plus からです。** 強いモデル、クラウドタスク、コードレビューが加わります。
- **Pro は「モデル」ではなく「時間」のために。** モデルは Plus と同じで、Pro で得られるのは5時間枠の待ち時間がなくなることです。

ChatGPT と Claude の上位プランの違いは [ChatGPT Pro vs Claude Max](/ja/blog/chatgpt-pro-vs-claude-max) で比較しています。

## Codex・Claude Code・Copilot の入口価格

| ツール | 無料で使えるか | 最初の有料プラン | その次 |
|---|---|---|---|
| Codex（ChatGPT） | 使える（GPT-6 Luna） | Plus $20 | Pro 100 $100 |
| Claude Code | 使えない（Claude の Free には含まれない） | Claude Pro $20 | Max 5x $100 |
| GitHub Copilot | 使える（補完2,000回と限られたチャット） | Pro $10 | Pro+ $39 |

- **エージェントとして使える無料枠がいちばん実用的なのは Codex です。** Claude の無料プランには Claude Code が含まれず、Copilot Free は主に補完と少しのチャットです。
- **$20では Codex と Claude Code は同じ価格**で、どちらもドル残高ではなく、時間でリセットされる使用枠の方式です。Claude Code の料金は [Claude Code の料金は月いくら？](/ja/blog/claude-code-ryoukin)で詳しく解説しています。
- **有料の入口がいちばん安いのは Copilot の$10**ですが、クレジットは API 価格に連動しています。

## Codex の使用量を長持ちさせるコツ

1. **タスクに合ったモデルを選ぶ。** 小さな編集、説明、定型コードは GPT-6 Luna、普通の機能開発は GPT-6.1 Sol、ほかで行き詰まったときだけ GPT-6 Astra にしましょう。
2. **タスクは小さく具体的に。** 「プロジェクトを見て改善して」より、ひとつのファイルについての明確な依頼のほうが、読む量が減るぶん安く済みます。
3. **必要なとき以外は Fast モードを使わない。** プランの使用量を標準の250%のペースで消費します。
4. **残りの使用量を確認する。** Codex CLI では /status で現在のセッションのトークン使用量、/usage で日・週・全期間のトークン利用状況が分かり、使えるリセットがあれば適用もできます。ChatGPT デスクトップアプリでは Settings > Usage でリセット時刻を確認できます。長い作業の前にチェックしましょう。
5. **リセットとクレジットを計画的に使う。** 上限に当たったときは、クレジット追加、リセットの適用、アップグレード、待つ、という選択肢があります。たまにしか当たらないなら、上位プランよりクレジットか待つほうが安上がりです。

## まとめ

- **Codex はすべての ChatGPT プランに含まれています。** Free も含め、別料金はかかりません。
- **料金は米ドルで案内されています。** 日本から契約すると決済画面に円の金額が表示されることがあるので、支払額は決済画面で確認してください。
- **無料プランでも、小さな実作業なら十分試せます。** 私たちのテストでは、2ステージのゲームを39秒で2回完成させ、消費は月の使用量の1%でした。
- **毎日の道具になるのは Plus（$20）から**で、GPT-6 の全ライン、クラウドタスク、GitHub のコードレビューが使えます。
- **Pro は5時間枠の待ち時間をなくすためのプラン**で、モデルが良くなるわけではありません。
- **費用を最も動かすのはプランよりモデル選びです。** GPT-6 Luna のメッセージ数の目安は、下限で GPT-6 Astra の7,000%あり、API 価格は Astra のごく一部です。

## よくある質問

**Codex は無料で使えますか？**
制限付きで使えます。ChatGPT の Free プランに Codex が含まれており、デスクトップアプリで GPT-6 Luna を標準速度で使えます。無料プランの上限は公開されていません。私たちのアカウントでは、5時間や週ではなく月単位のメーターが1本表示されていました。クラウドタスクには Plus 以上が必要です。

**Codex の料金はいくらですか？**
Codex 単体の料金はありません。ChatGPT のプランに含まれ、Free $0、Go $8、Plus $20、Pro $100・$200・$500、Business は年払いで1ユーザー$20です。API キーを使って通常の API 料金で使うこともできます。

**ChatGPT Plus に Codex は含まれますか？**
含まれます。Plus では Web、CLI、IDE 拡張機能、iOS で Codex が使え、クラウドタスクと GPT-6 の各モデルもローリング方式の5時間枠の範囲で利用できます。

**日本円ではいくらになりますか？**
OpenAI のヘルプセンターでは、Plus の$20のように価格が米ドルで記載されています。日本から契約する場合は決済画面に円の金額が表示されることがあるので、実際に請求される金額は契約時の決済画面で確認してください。クレジットの価格も、地域やプランによって異なり、購入画面に表示されます。

**Codex の1クレジットはいくらですか？**
個人向けプランでは固定価格が公開されておらず、購入画面に表示されます。クレジットのレートは API 定価1ドルあたり25クレジットにそろっているため、API 換算で1クレジット約$0.04になります（私たちの計算です）。

**Codex の上限に当たったらどうなりますか？**
進行中のターンは最後まで終えられます。そのあとはプランに応じて、クレジットの追加、使えるリセットの適用、アップグレード、または5時間枠や週の枠のリセットを待つことになります。
