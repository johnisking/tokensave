![Cursor の料金プラン2026｜無料版を試した月額の目安](/cursor-ryoukin-ja.jpg)

AI コードエディタの **Cursor（カーソル）** の料金は、2026年10月中旬にがらりと変わりました。今は Grok・Cursor・X をまとめた1つのサブスク **「The X Subscription」** の一部として売られていて、プランは月$8から$200までです。もっと大きな変化は、プランに含まれる中身です。含まれる使用量は Cursor 独自のモデル（Grok と Composer）だけが対象で、**Claude・GPT・Gemini はどのプランにも含まれなくなりました**。Premium 以上のプランでは、これらを API 定価で別に支払います。

2026年10月23日に Cursor の公式料金ページと「Models & Pricing」ドキュメントを確認し直しました。それより前の10月11日には、Windows PC に Cursor をインストールして、Claude Code で Claude Opus 5.5 と Sonnet 5.5 を実測したときと同じブロック崩しのプロンプトを無料プランで試しています。新しい料金プラン、今の課金の仕組み、無料プランでどこまでできたか、モデル別の月額の目安を順にまとめます。

## Cursor の料金プラン一覧（2026年）

Cursor 公式料金ページとドキュメントの内容です（2026年10月23日確認）。表示価格は税抜きです。

| プラン | 月額 | 含まれる使用量 | Claude・GPT・Gemini |
|---|---:|---|---|
| Free | $0 | 制限あり | 使えない |
| Plus | $8 | 基本量（Grok と Composer のみ） | 使えない |
| Premium | $30 | Plus の400% | API 定価、前払いクレジットから |
| Super | $100 | Plus の1,500% | API 定価、前払いクレジットから |
| Ultra | $200 | Plus の5,000% | API 定価、前払いクレジットから |
| Teams | 1席 $30・$100・$200 | 対応する個人プランと同じ | API 定価に100万トークンあたり$0.25を上乗せ |
| Enterprise | 要問い合わせ | 全社で共有 | API 定価に100万トークンあたり$0.25を上乗せ |

**円での料金について:** Cursor の料金ページとドキュメントには円建ての価格はなく、すべてドル表示です。表示価格は税抜きです。円での実際の支払額は、その時点の為替レートとカード会社の海外利用手数料によって変わります。

- **年払いもあります。** 年額は Plus が$80、Premium が$300、Super が$1,000、Ultra が$2,000です。
- **Grok・X と共通のプランです。** 同じサブスクで、Grok アプリ、Grok の API、X Premium の機能（認証バッジ、広告の削減など）も使えます。
- **旧プランはそのまま使えます。** Hobby、Start、Pro（$20）、Pro+（$60）、Ultra、Teams Standard（1人$40）、Teams Premium（1人$120）は「レガシープラン」になりました。既存の契約者はそのまま継続でき、月ごとの2つの使用量プールとオンデマンド利用も残ります。インド限定だった Start プランも、このレガシープランの1つです。

## 各プランでできること

Cursor のドキュメントに書かれている内容を整理しました（2026年10月23日時点）。

- **Free:** エージェントとチャットを、制限付きの使用量で使えます。
- **Plus（$8）:** エージェントで使えるのは Cursor 独自のモデル（Grok 4.7・4.6・4.5、Composer 2.5）だけで、設定は固定（effort は medium、Fast はオフ）です。Auto、クラウドエージェント、コードレビューの「Bugbot」、他社モデル、自分の API キーは使えません。
- **Premium（$30）:** Plus の400%の使用量に加えて、クラウドエージェントと自動化、Origin でのコードホスティング、Bugbot、API 定価での他社モデル、Grok Bot が使えます。Cursor はエージェントを使い始める人に勧めています。
- **Super（$100）:** Plus の1,500%の使用量と、混雑時のモデルへの優先アクセス。Cursor はエージェントを毎日使う人に勧めています。
- **Ultra（$200）:** Plus の5,000%の使用量と、新しいモデルへの最速アクセス。複数のエージェントや自動化を動かすパワーユーザー向けです。
- **Teams:** メンバーごとに Premium・Super・Ultra の席を個人プランと同じ価格で選べて、種類を混ぜることもできます。一括請求と管理機能、ルール・スキル・プラグインを共有するチーム用マーケットプレイス、利用状況の分析、チーム全体のプライバシーモード、SAML/OIDC によるシングルサインオンが加わります。Plus はチームでは選べません。
- **Enterprise:** Grok と Cursor をまたいだ使用量の共有、請求書払い、SCIM、細かい支出管理、監査ログ。

### Auto（自動選択）のしくみ

個人プランの Auto はモードが1つだけで、Cost（従来の Auto）です。実際にどのモデルが使われても、Cursor モデルのリクエストとして扱われ、週ごとのプールから差し引かれます。Teams と Enterprise では、Balance と Intelligence のモードがリクエストを Claude や GPT に回すことがあり、その場合は他社モデルの利用として請求されます。

## Cursor の課金の仕組み

- **Cursor モデル用の週ごとのプールが1つ。** 有料プランには Grok 4.7・4.6・4.5、Composer 2.5 の使用量が含まれます。このプールはエディタ、CLI、クラウドエージェント、Grok Bot、Grok アプリで共通で、毎週リセットされます。
- **他社モデルは常に別料金。** Claude・GPT・Gemini はプールに含まれません。Premium 以上では最初のリクエストからモデルの API 定価で請求され、前払いクレジットから支払います。Plus と Free では使えません。
- **前払いクレジットと上限。** クレジットをチャージする（または自動チャージの Auto Top-up をオンにする）しくみで、月の上限額で追加利用の金額を抑えられます。週のプールを使い切ったあとの Cursor モデルの利用も、このクレジットから支払います。
- **Teams と Enterprise:** 他社モデルのリクエストには、100万トークンあたり$0.25の「Cursor Token Rate」が加わります。Claude Haiku 5.5 や GPT-5.6 Luna など一部の小さなモデルは対象外です。個人プランにはかかりません。
- **公開されていないこと:** 各プランの週のプールがドル換算でいくらなのかは書かれていません。残りの使用量と次のリセット日時は、エディタの設定と Grok のダッシュボードに表示されます。

## 「リクエスト回数制」「Max モード」は昔の仕組み

日本語の解説記事には、今も「Pro は毎月決まった回数の高速リクエスト、使い切ると低速に」「Max モードは別料金」と書かれているものがありますが、これは旧料金体系の説明です。

- **リクエスト単位の料金はレガシープランだけのものです。** 新しく契約するプランには関係ありません。
- **Max モードも、そのレガシープランにだけあります。** API 価格に20%上乗せして請求されます。

## 無料プランを実際に試した結果

![Cursor 無料プランでブロック崩しを作らせた結果：Auto が Grok 4.6 を選択、1分31秒、398行、月の無料使用量の15%](/cursor-ryoukin-ja-5.jpg)

試したのは2026年10月11日で、無料プランがまだ「Hobby」という名前だったころです。Windows PC に Cursor をインストールして登録し、Claude Code の実測で使ったのとまったく同じプロンプトを入力しました。内容は、ブラウザで遊べるブロック崩しゲームを `index.html` 1ファイルで作るもので、レベル2つ、スコア、ライフ3つ、キーボードとマウス操作という条件です。

| 項目 | 結果 |
|---|---|
| モデル | Auto（実際には Grok 4.6・medium が選ばれた） |
| かかった時間 | 1分31秒（Cursor の画面表示） |
| ゲームのコード | 398行、エラーなく動作 |
| 使った無料枠 | 月の上限の15% |

- **無料プランではモデルを選べませんでした。** Claude Sonnet 5.5 を選ぼうとすると、アップグレードを求められました。新しいプランでは、Free と Plus では Claude をまったく使えません。
- **1回で15%なので、この規模のゲームなら月に6回ほどで無料枠を使い切る計算でした。** 新しいプランは使用量を週単位で数えるので、今の無料枠では結果が変わる可能性があります。
- **ゲームはきれいでしたが、シンプルでした。** 角の丸いブロック、グラデーションの背景、レベル2ではパドルが狭くなってボールが速くなり、上の段ほど点数が高くなる作りでした。パーティクル、効果音、ハイスコアの保存はありませんでした。

同じプロンプトを Claude Code で実行したときは、Sonnet 5.5 の medium で37秒、high で58秒でした。詳しい結果は [Claude Sonnet 5.5 と Opus 5.5 の比較](/ja/blog/claude-sonnet-5-5-vs-opus-5-5)にまとめています。

無料プランは**試してみるには十分ですが、毎日の開発に使い続けるには足りません**。

## モデル別の月額の目安（試算）

今の Cursor は Claude を全額 API 価格で請求するので、Claude Code での実測コストがそのまま目安になります。同じゲームのプロンプトのコストは次のとおりでした（Claude Code、API 価格で換算）。

| モデル・effort | 1回あたり |
|---|---:|
| Sonnet 5.5・medium | $0.25 |
| Sonnet 5.5・high | $0.30 |
| Opus 5.5・medium | $0.56 |
| Opus 5.5・high | $0.75 |

effort（推論の深さ）の違いについては [Claude Opus 5.5 の effort 設定](/ja/blog/claude-opus-5-5-effort)で解説しています。

この規模の作業を1日10回、月22日（合計220回）行うとして単純に計算すると、次のようになります（当サイトの試算）。

- **Cursor で Sonnet 5.5・high:** 前払いクレジットが約$66、これに Premium の$30以上が加わるので、**月 約$96**
- **Cursor で Opus 5.5・high:** クレジットが約$165、これに$30が加わるので、**月 約$195**
- **Grok や Composer:** 週のプールを使い切るまではプランに含まれるので、プランの月額だけで済む可能性があります

おおよその目安としてご覧ください。Cursor のエージェントは独自の指示とコンテキストを付けて送るので、Claude Code とまったく同じトークン数にはなりません。実際の作業の大きさもまちまちです。

## Cursor と Claude Code の費用比較

## まとめ：Grok なら Plus、Claude なら Claude Code

- **Grok と Composer を使うなら、Cursor は安くなりました。** Plus の$8で使え、エージェントを毎日使うなら Cursor は Super（$100）を勧めています。

- **プランよりモデル選びのほうが料金に効きます。** 私の実測では Opus 5.5・high の1回あたりのコストは Sonnet 5.5・high より150%高く（$0.75と$0.30）、Grok と Composer はプランに含まれるプールから差し引かれます。
- **料金はドル建て・税抜き表示です。** 円での支払額は為替とカードの手数料で変わります。

## よくある質問

**Cursor は無料で使えますか？**
はい。Free プランは無料ですが、使用量に制限があり、使えるのは Cursor 独自のモデルだけです。10月11日の私の試用（旧 Hobby プラン）では、小さなゲーム1つで月の上限の15%を使いました。

**Cursor Pro はいくらですか？円だといくら？**
Pro（$20）と Pro+（$60）は、既存の契約者向けのレガシープランになりました。新しく契約する場合は Plus（$8）、Premium（$30）、Super（$100）、Ultra（$200）から選びます。Cursor は円建ての価格を出していないので、円での支払額は決済時の為替レートとカードの手数料で決まります。

**Cursor で Claude を使えますか？**
Premium 以上なら使えます。Anthropic の API 定価で、前払いクレジットから支払います。100万トークンあたり Sonnet 5.5 が$2/$10、Opus 5.5 が$4/$20です。Plus と Free では Claude を使えません。Teams と Enterprise では100万トークンあたり$0.25が加わります。

**チームで使うといくらですか？**
1席あたり月$30・$100・$200で、それぞれ Premium・Super・Ultra に対応します。1つのチームで席の種類を混ぜられます。

**「月○回」の制限や Max モードは今もありますか？**
いずれも旧料金体系のものです。リクエスト単位の料金と Max モードは、レガシープランだけに残っています。

**使用量を使い切ったらどうなりますか？**
週のリセットを待つか、前払いクレジットで同じモデル別の価格のまま使い続けるか、上位プランにアップグレードします。Cursor は、リクエストの品質や速度を落とすことはないとしています。

## 自分で計算してみる

[コーディングエージェント費用計算機](/ja/agents)で作業の大きさと1日の作業数を入れると、Claude Opus 5.5、Sonnet 5.5 などのモデル別に月の費用を比べられます。プロンプト1つの費用は[トークン計算機](/ja/)で、各サービスのプランは[AI サブスク vs API 計算機](/ja/plans)で確認できます。

*料金は2026年10月23日に確認しました（初回公開は10月12日）。無料プランの試用は旧 Hobby プランでの1回だけの結果で、Auto が選ぶモデルや作業の大きさによって変わります。*
