![Cursor の料金プラン2026｜無料版を試した月額の目安](/cursor-ryoukin-ja.jpg)

AI コードエディタの **Cursor（カーソル）** を使ってみたいとき、気になるのはプランごとの月額や、無料プランでどこまで使えるか、エージェントを使うと費用がどう変わるかではないでしょうか。2026年10月11日に Cursor の公式料金ページと「Models & Pricing」ドキュメントを確認し、さらに Windows PC に Cursor をインストールして、無料プランで実際にブロック崩しゲームを作らせてみました。料金プランの一覧、今の課金の仕組み、無料プランでどこまでできたか、モデル別の月額の目安を順にまとめます。

## Cursor の料金プラン一覧（2026年）

![Cursor の料金プラン一覧（2026年）: プラン, 月額, 向いている人（Cursor の説明を要約）](/cursor-ryoukin-cursor-2026-ja.jpg)

Cursor 公式料金ページの表示です（2026年10月11日確認）。

| プラン | 月額 | 向いている人（Cursor の説明を要約） |
|---|---:|---|
| Hobby | 無料 | まず試したい人。エージェントのリクエストに制限あり、カード登録不要 |
| Pro | $20 | 個人向け。エージェントの上限拡大、最新モデル、クラウドエージェント |
| Pro+ | $60 | 毎日エージェントを使う人に Cursor が推奨 |
| Ultra | $200 | エージェントを大量に使うパワーユーザーに Cursor が推奨 |
| Teams Standard | 1人 $40 | チーム向け。一括請求、SSO、利用状況の分析 |
| Teams Premium | 1人 $120 | Standard よりエージェントの上限が高い |
| Enterprise | 要問い合わせ | 全社で使用量を共有、請求書払い、SCIM、監査ログ |

**円での料金について:** Cursor の料金ページとドキュメントには円建ての価格はなく、すべてドル表示です。表示価格は税抜きです。円での実際の支払額は、その時点の為替レートとカード会社の海外利用手数料によって変わります。

- **年払いもあります。** 料金ページで月払いと年払いを切り替えられます。
- **Start（インド限定）** という月₹649（税込）のプランもあります。インド限定で、使えるのは Cursor 独自のモデル（Grok 4.7・4.6・4.5、Composer 2.5）だけです。

## 各プランでできること

Cursor の料金ページとドキュメントに書かれている内容を整理しました（2026年10月11日時点）。

- **Hobby（無料）:** カード登録不要。エージェントのリクエストは制限付きで、Composer を使えます。モデルは選べず、私の試用では特定のモデルを選ぶと Pro へのアップグレードを求められました。
- **Pro・Pro+・Ultra:** Hobby の内容に加えて、エージェントの上限拡大、Grok の多めの利用枠、Anthropic・OpenAI・Google の最新モデル、MCP サーバー、スキルとフック、クラウドエージェント、従量課金のコードレビュー「Bugbot」。ドキュメントによると Tab 補完は無制限です。**3つのプランの違いは機能ではなく、含まれる使用量の多さ**です。
- **Teams:** 個人プランの内容に加えて、一括請求と管理機能、社内ルールやスキルを共有するチーム用マーケットプレイス、チームの文脈を共有するクラウドエージェントと自動化、利用状況の分析、チーム全体のプライバシーモード、SAML/OIDC によるシングルサインオン。
- **Enterprise:** 全社での使用量の共有、請求書・発注書による支払い、SCIM によるシート管理、使えるリポジトリ・モデル・MCP サーバーの制御、監査ログ、優先サポート。

### Auto（自動選択）のしくみ

モデルを「Auto」にしておくと、Cursor がリクエストごとにモデルを選びます。ドキュメントでは Cost・Balance・Intelligence の3つのモードが説明されていて、どのモードでも、実際に送られたモデルの定価で使用量が差し引かれます。無料プランでは Auto しか選べず、私の試用では Grok 4.6 が選ばれました。

## Cursor の課金の仕組み：2つの使用量プール

有料プランの使用量は、毎月リセットされる2つのプール（枠）に分かれています。

- **Cursor Models プール:** Grok 4.7、Grok 4.6、Grok 4.5、Composer 2.5。Cursor は、こちらのプールのほうが含まれる使用量が「大幅に多い」と説明しています。
- **Other Models プール:** Claude、GPT、Gemini など他社のモデル。各モデルの API 価格で差し引かれます。
- **使い切ったら:** 同じ API 価格でオンデマンド利用（後払い）をオンにするか、上位プランにアップグレードします。Cursor は、使用量を超えてもリクエストの品質や速度を落とすことはないとしています。
- **Teams と Enterprise:** 他社モデルには、API 価格に加えて100万トークンあたり$0.25の「Cursor Token Rate」がかかります。Grok と Composer は対象外です。
- **公開されていないこと:** 各プランに含まれる使用量がドル換算でいくらなのかは書かれていません。そのため「Pro なら何回使える」と正確に計算することはできません。

目安として、Cursor のガイドはこう説明しています。Tab 補完を毎日使う人やエージェントをたまに使う人は、たいてい含まれる使用量の範囲に収まります。**エージェントを毎日使う人は合計で月$60〜$100**、複数のエージェントを動かすパワーユーザーは**月$200を超える**こともよくあるそうです。

## 「月500回」「Max モード」は昔の仕組み

日本語の解説記事には、今も「Pro は月500回の高速リクエスト、使い切ると低速に」「Max モードはトークン単位で別料金」と書かれているものがありますが、これは旧料金体系の説明です。現在の Cursor の公式ドキュメントでは、次のように変わっています。

- **今のプランはすべて、トークン単位の使用量で差し引かれます。** モデルごとの API 価格で、上の2つのプールから減っていきます。
- **リクエスト単位の料金は「レガシー」扱いです。** ドキュメントには、古いプラン向けの「legacy request-based pricing」の項目だけが残っています。
- **Max モードは、そのレガシープランにだけあります。** モデルのコンテキストを広げる機能で、API 価格に20%上乗せされます。
- **利用者にとっての意味:** 同じモデルでも、会話が長くなったりコードベースが大きくなったりするほど費用が増えます。コンテキストに含まれるトークンがすべて数えられるからです。

## Cursor で使えるモデルと価格

![Cursor の設定で使えるモデル一覧：Claude Opus 5.5、Sonnet 5.5、GPT-5.6 Sol、Gemini 3.8 Flash、Grok など](/cursor-ryoukin-ja-6.jpg)

他社モデルは API 価格で差し引かれるので、どのモデルを選ぶかで使用量の減り方が大きく変わります。Cursor のドキュメントに載っている100万トークンあたりの価格です。

| モデル | 入力 | 出力 | プール |
|---|---:|---:|---|
| Composer 2.5 | $0.50 | $2.50 | Cursor Models |
| Grok 4.6 / 4.7 | $2 | $6 | Cursor Models |
| Gemini 3.8 Flash | $0.75 | $3.50 | Other Models |
| Claude Sonnet 5.5 | $2 | $10 | Other Models |
| Claude Opus 5.5 | $4 | $20 | Other Models |
| GPT-5.6 Sol | $4 | $20 | Other Models |
| Claude Fable 5.1 | $10 | $50 | Other Models |

- **Claude Sonnet 5.5 と Opus 5.5 は、Anthropic の API と同じ価格です。** Cursor 経由だから高くなる、ということはありません（個人プランの場合）。
- **Grok 4.6 は入力価格が Sonnet 5.5 と同じで、出力は40%安くなっています。** いちばん安いのは Composer 2.5 です。

## 無料プラン（Hobby）を実際に試した結果

![Cursor 無料プランでブロック崩しを作らせた結果：Auto が Grok 4.6 を選択、1分31秒、398行、月の無料使用量の15%](/cursor-ryoukin-ja-5.jpg)

Windows PC に Cursor をインストールして無料プランに登録し、Claude Code の実測で使ったのとまったく同じプロンプトを入力しました。内容は、ブラウザで遊べるブロック崩しゲームを `index.html` 1ファイルで作るもので、レベル2つ、スコア、ライフ3つ、キーボードとマウス操作という条件です。

| 項目 | 結果 |
|---|---|
| モデル | Auto（実際には Grok 4.6・medium が選ばれた） |
| かかった時間 | 1分31秒（Cursor の画面表示） |
| ゲームのコード | 398行、エラーなく動作 |
| 使った無料枠 | 月の上限の15% |

- **無料プランではモデルを選べません。** Claude Sonnet 5.5 などを選ぼうとすると、Pro へのアップグレードを求められました。
- **1回で15%なので、この規模のゲームなら月に6回ほどで無料枠を使い切る計算です。** もっと大きな作業なら、さらに早く減ります。
- **ゲームはきれいでしたが、シンプルでした。** 角の丸いブロック、グラデーションの背景、レベル2ではパドルが狭くなってボールが速くなり、上の段ほど点数が高くなる作りでした。パーティクル、効果音、ハイスコアの保存はありませんでした。

同じプロンプトを Claude Code で実行したときは、Sonnet 5.5 の medium で37秒、high で58秒でした。詳しい結果は [Claude Sonnet 5.5 と Opus 5.5 の比較](/ja/blog/claude-sonnet-5-5-vs-opus-5-5)にまとめています。

無料プランは**試してみるには十分ですが、毎日の開発に使い続けるには足りません**。

## モデル別の月額の目安（試算）

Cursor は Claude を API 価格で差し引くので、Claude Code での実測コストがよい目安になります。同じゲームのプロンプトのコストは次のとおりでした（Claude Code、API 価格で換算）。

| モデル・effort | 1回あたり |
|---|---:|
| Sonnet 5.5・medium | $0.25 |
| Sonnet 5.5・high | $0.30 |
| Opus 5.5・medium | $0.56 |
| Opus 5.5・high | $0.75 |

effort（推論の深さ）の違いについては [Claude Opus 5.5 の effort 設定](/ja/blog/claude-opus-5-5-effort)で解説しています。

この規模の作業を1日10回、月22日（合計220回）行うとして単純に計算すると、次のようになります（当サイトの試算）。

- **Sonnet 5.5・high:** 月 約$66
- **Opus 5.5・high:** 月 約$165

Cursor の「エージェントを毎日使うと月$60〜$100」という目安とほぼ同じ範囲です。ただし、Cursor のエージェントは独自の指示とコンテキストを付けて送るので、Claude Code とまったく同じトークン数にはなりません。実際の作業の大きさもまちまちなので、おおよその目安としてご覧ください。

## Cursor・Claude Code・GitHub Copilot・Devin の料金比較

各社の公式料金ページに載っている税抜きの月額です（2026年10月11日確認）。

| ツール | 無料 | 入門プラン | 中間プラン | 個人向け最上位 |
|---|---|---:|---:|---:|
| Cursor | Hobby | Pro $20 | Pro+ $60 | Ultra $200 |
| Claude（Claude Code を含む） | 無料（Claude Code なし） | Pro $20 | Max 5x $100 | Max 20x $200 |
| GitHub Copilot | Free | Pro $10 | Pro+ $39 | Max $100 |
| Devin（windsurf.com/pricing はこちらに転送） | 無料 | Pro $20 | – | Max $200 |

- **Claude Code は Claude の Pro と Max に含まれます。** 無料の Claude プランでは使えません。Anthropic の料金ページによると、Max プランには Claude Platform で使える月$100〜$200の API クレジットも付きます。Claude Code の料金は [Claude Code の料金は月いくら？](/ja/blog/claude-code-ryoukin) をご覧ください。
- **GitHub Copilot は入門プランが$10といちばん安く、** 料金ページでは月のクレジットが Pro で$15、Pro+ で$70、Max で$200分と示されています。詳しくは [GitHub Copilot pricing](/blog/github-copilot-pricing)（英語）へ。
- **Devin の Pro と Max は、Cursor の Pro・Ultra と同じ価格です。** チームプランは月$80に、開発者1人あたり$40が加わります。
- **表の価格がすべてではありません。** Cursor と Devin は、上限を超えると API 価格で追加の使用量を買えるので、エージェントをたくさん使うとプランの月額を超えることがあります。

ChatGPT・Gemini も含めたサブスクの比較は [生成AIのサブスク料金比較](/ja/blog/ai-subscription-ryoukin-hikaku) に、Codex の上限は [Codex の使用量上限まとめ](/ja/blog/codex-shiyouryou-jougen) にあります。

## Cursor のメリット・デメリット（Claude Code と比べて）

Cursor のドキュメントと、自分で試した結果をもとにまとめました。

**メリット**

- **安い独自モデルがある。** Composer 2.5（$0.50/$2.50）と Grok 4.6（$2/$6）は Claude や GPT より安く、含まれる使用量が多い別のプールから差し引かれます。
- **1つのエディタで多くのモデルを使える。** Claude、GPT、Gemini、Grok、Muse Spark を設定で切り替えられます。
- **Claude の価格は同じ。** Claude Sonnet 5.5 と Opus 5.5 は、Anthropic の API と同じトークン単価です。
- **無料で試せる。** 私の試用では、1分31秒で動くゲームを無料で作れました。

**デメリット**

- **同じモデルでも結果は同じにならない。** ツールごとにモデルへ付ける指示やコンテキストが違うので、Cursor の Sonnet 5.5 と Claude Code の Sonnet 5.5 は同じようには動きません。
- **プランの月額を超えることがある。** 含まれる使用量を使い切ってオンデマンド利用をオンにすると、トークン単位の API 価格で請求されます。大きなコンテキストや高いモデルでは、すぐに金額が積み上がります。
- **事前に計算しにくい。** 各プランに含まれる使用量のドル換算額が公開されていません。
- **無料プランは制限が大きい。** モデルを選べず、小さなゲーム1つで月の15%を使いました。

## 想定外の請求を防ぐコツ

- **オンデマンド利用はオフにしておく。** 含まれる使用量がどのくらいの速さで減るかわかるまでは、オンにしないほうが安心です。
- **大きな作業は小さく分ける。** いちばん高いモデルに巨大なリクエストを1つ投げるのは避けましょう。
- **普段の修正は Composer や Grok で。** 難しい部分だけ Claude Opus や GPT-5.6 Sol を使います。
- **関係のない作業は新しいチャットで。** 長い会話を引きずると、毎回送るコンテキストが増えます。
- **使用量の画面を毎週確認する。** 2つのプールの残りは、エディタの設定と使用量ダッシュボードに表示されます。

## まとめ：まず無料で試し、毎日使うなら Pro+

- **無料プランは「お試し」です。** 小さなゲームを1分31秒で作れましたが、月の上限の15%を使い、モデルも選べませんでした。
- **Pro（$20）は軽い使い方向けです。** エージェントを毎日使うと月$60〜$100かかるため、Cursor 自身も Pro+ を勧めています。
- **プランよりモデル選びのほうが料金に効きます。** 私の実測では Opus 5.5・high の1回あたりのコストは Sonnet 5.5・high より150%高く（$0.75と$0.30）、Composer や Grok はさらに安くなります。
- **料金はドル建て・税抜き表示です。** 円での支払額は為替とカードの手数料で変わります。

## よくある質問

**Cursor は無料で使えますか？**
はい。Hobby プランはカード登録なしで無料ですが、エージェントのリクエストに制限があり、モデルは自動で選ばれます。私の試用では、小さなゲーム1つで月の上限の15%を使いました。

**Cursor Pro はいくらですか？円だといくら？**
月$20（税抜き）です。Pro+ は$60、Ultra は$200です。Cursor は円建ての価格を出していないので、円での支払額は決済時の為替レートで決まります。

**Cursor で Claude を使うと割高になりますか？**
個人プランではなりません。Cursor は Claude Sonnet 5.5 を100万トークンあたり$2/$10、Opus 5.5 を$4/$20で差し引いており、Anthropic の API と同じ価格です。Teams と Enterprise では、他社モデルに100万トークンあたり$0.25が加わります。

**「月500回」の制限や Max モードは今もありますか？**
いずれも旧料金体系のものです。公式ドキュメントでは、リクエスト単位の料金と Max モードはレガシープランだけのものです。今のプランはすべてトークン単位の使用量で差し引かれます。

**使用量を使い切ったらどうなりますか？**
同じ API 価格でオンデマンド利用をオンにするか、上位プランにアップグレードします。Cursor は、リクエストの品質や速度を落とすことはないとしています。

**学生割引はありますか？**
常設の割引はありません。Cursor の学生向けページには、誰でも無料で始められ、アップグレードは大学やオンラインのイベントでのプロモーションを通じて提供すると書かれています。「学生は1年無料」という古い記事は今と違う可能性があるので、学生向けページで確認してください。
