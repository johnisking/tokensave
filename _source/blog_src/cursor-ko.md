## 요금제별로 들어 있는 것

커서 공식 문서 기준입니다(2026년 10월 23일).

- **Free:** 에이전트와 채팅을 제한된 사용량 안에서 씁니다.
- **Plus ($8):** 커서 자체 모델(Grok 4.7·4.6·4.5, Composer 2.5)만 정해진 설정(medium effort, Fast 꺼짐)으로 씁니다. 자동(Auto), 클라우드 에이전트, Bugbot 코드 리뷰, 다른 회사 모델, 내 API 키 연결은 안 됩니다.
- **Premium ($30):** Plus의 400% 사용량에 클라우드 에이전트와 자동화, Origin 코드 호스팅, Bugbot 코드 리뷰, 다른 회사 모델(API 정가), Grok Bot이 붙습니다. 커서는 에이전트를 처음 쓰는 분께 추천합니다.
- **Super ($100):** Plus의 1,500% 사용량과 사용자가 몰리는 시간대의 모델 우선 접근입니다. 커서는 에이전트를 매일 쓰는 분께 추천합니다.
- **Ultra ($200):** Plus의 5,000% 사용량과 새 모델 가장 빠른 사용입니다. 커서는 에이전트나 자동화를 여러 개 돌리는 파워 유저께 추천합니다.
- **Teams:** 팀원마다 Premium, Super, Ultra 좌석을 개인 요금제와 같은 가격으로 받고, 좌석 종류를 섞을 수 있습니다. 팀 결제·관리, 규칙·스킬·플러그인을 나누는 팀 마켓플레이스, 사용량 분석, 팀 전체 프라이버시 모드, SAML/OIDC SSO가 붙습니다. Plus는 팀에서 쓸 수 없습니다.
- **Enterprise:** Grok과 커서 전체에서 사용량 공유, 청구서 결제, SCIM, 세부 지출 관리, 감사 로그를 제공합니다.

### 자동(Auto)은 모델을 어떻게 고르나

개인 요금제의 자동(Auto)은 Cost(예전 Auto) 모드 하나뿐입니다. 실제로 어떤 모델이 답하든 커서 모델 요청으로 계산되어 주간 주머니에서 차감됩니다. Teams와 Enterprise에서는 Balance, Intelligence 모드가 요청을 Claude나 GPT로 보낼 수 있고, 이때는 다른 회사 모델 사용으로 청구됩니다.

## 지금 커서 과금 방식

- **커서 모델용 주간 주머니 하나입니다.** 유료 요금제마다 Grok 4.7·4.6·4.5와 Composer 2.5용 사용량이 들어 있습니다. 편집기, CLI, 클라우드 에이전트, Grok Bot, Grok 앱이 이 주머니를 함께 쓰고, 매주 다시 채워집니다.
- **다른 회사 모델은 항상 따로 냅니다.** Claude, GPT, Gemini는 주머니에 포함되지 않습니다. Premium 이상에서 첫 요청부터 모델의 API 정가로, 선불 크레딧에서 빠져나갑니다. Plus와 Free에서는 쓸 수 없습니다.
- **선불 크레딧과 한도가 있습니다.** 크레딧을 충전하거나 자동 충전(Auto Top-up)을 켜 두고, 월 한도로 추가 사용 금액의 상한을 정합니다. 주간 주머니를 다 쓴 뒤 커서 모델을 계속 쓸 때도 이 크레딧이 쓰입니다.
- **Teams와 Enterprise:** 다른 회사 모델 요청에 100만 토큰당 $0.25의 Cursor Token Rate가 더 붙습니다. Claude Haiku 5.5, GPT-5.6 Luna 같은 작은 모델 목록은 예외입니다. 개인 요금제에는 붙지 않습니다.
- **공식 문서에 없는 것:** 요금제마다 주간 주머니가 달러로 얼마인지는 나와 있지 않습니다. 남은 사용량과 다음 초기화 시점은 편집기 설정과 Grok 대시보드에서 볼 수 있습니다.

## 모델별 한 달 비용 계산

이제 커서는 Claude를 전부 API 가격으로 청구하므로, Claude Code 실측 비용이 그대로 기준이 됩니다. 같은 게임 요청의 비용은 이랬습니다.

| 모델 · effort (Claude Code 2.1.295, API 가격 환산, 3회 평균) | 1회 비용 |
|---|---:|
| 소넷 5.5 · medium | $0.10 |
| 소넷 5.5 · high | $0.12 |
| 오퍼스 5.5 · medium | $0.26 |
| 오퍼스 5.5 · high | $0.35 |

이 크기의 작업을 하루 10번, 한 달 22일(220번) 한다고 단순 계산하면 이렇습니다.

- **커서에서 소넷 5.5 high:** 선불 크레딧 약 $26에 Premium 최소 $30을 더해 한 달 약 **$56 (약 7만 5천원)**
- **커서에서 오퍼스 5.5 high:** 크레딧 약 $77에 $30을 더해 한 달 약 **$107 (약 14만 4천원)**
- **Grok이나 Composer:** 주간 주머니를 다 쓰기 전까지는 포함되므로 요금제 가격만 낼 수도 있습니다.

다만 커서는 자체 지시문과 맥락을 붙여 보내서 Claude Code와 토큰 수가 똑같지 않고, 실제 작업 크기도 제각각이라 대략적인 값으로 보셔야 합니다.

## 커서 vs Claude Code vs GitHub Copilot vs Devin 요금 비교

각 회사 공식 가격 페이지의 월 가격입니다(커서는 2026년 10월 23일, 나머지는 10월 11일 확인, 세금 별도).

| 도구 | 무료 | 기본 요금제 | 중간 요금제 | 개인 최고 요금제 |
|---|---|---:|---:|---:|
| 커서 | Free | Plus $8 (Grok, Composer만) | Premium $30 / Super $100 | Ultra $200 |
| Claude (Claude Code 포함) | 무료, Claude Code 없음 | Pro $20 | Max 5x $100 | Max 20x $200 |
| GitHub Copilot | 무료 | Pro $10 | Pro+ $39 | Max $100 |
| Devin (windsurf.com 가격 페이지가 여기로 연결됨) | 무료 | Pro $20 | – | Max $200 |

- **Claude Code는 Claude Pro와 Max에 포함됩니다.** 무료 Claude에는 없고, 요금제 사용 한도 안에서 Claude 모델을 씁니다. 커서에서는 같은 Claude 사용량을 요금제 위에 따로 냅니다.
- **Claude와 GPT를 쓸 수 있는 가장 싼 요금제는 GitHub Copilot $10입니다.** 가격 페이지에는 월 크레딧이 Pro $15, Pro+ $70, Max $200으로 나와 있습니다.
- **가장 싼 유료 요금제는 커서 Plus $8입니다.** 다만 Grok과 Composer 전용입니다.
- **표에 적힌 가격이 전부는 아닙니다.** 커서와 Devin은 추가 사용을 API 가격으로 받아서, 에이전트를 많이 쓰면 요금제 가격보다 더 나올 수 있습니다.

## 커서 vs Claude Code 비용 비교

Claude를 쓰는 게 목적이라면, 커서에 돈을 내기 전에 Claude Code와 먼저 비교해 보세요.

- **토큰 가격은 같고, 포함 범위가 다릅니다.** 커서는 Claude를 Anthropic API 가격으로 청구하고, 10월부터는 그중 어느 것도 요금제에 포함되지 않습니다. Claude 요금제는 사용 한도 안에서 Claude Code 사용이 포함됩니다.
- **대략 비교하면:** 위 예시의 월 $26어치 소넷 사용은 커서에서 요금제 가격에 $26을 그대로 더해 냅니다. Claude 요금제에서는 사용 한도 안에 들어가는 한 월 $20~200 정액입니다. 요금제별 숫자는 [클로드 코드 요금 정리](/ko/blog/claude-code-yogeum)와 [클로드 코드 vs 코덱스 비교](/ko/blog/claude-code-vs-codex)에 정리돼 있습니다.
- **커서가 더해 주는 것:** 자동완성(Tab)이 있는 편집기, 포함 주머니로 쓰는 Grok과 Composer, 그리고 Claude·GPT·Gemini·Grok을 한곳에서 바꿔 쓸 수 있다는 점입니다.

## 커서 장단점 (Claude Code와 비교)

커서 공식 문서와 직접 테스트한 결과를 바탕으로 정리했습니다.

**장점**

- **자체 모델은 싸게 시작합니다.** Plus $8로 Grok과 Composer를 쓰고, 모든 유료 요금제에 이 모델용 주간 주머니가 있습니다.
- **여러 회사 모델을 한 편집기에서 씁니다.** 위 화면처럼 Claude, GPT, Gemini, Grok, Muse를 커서 안에서 쓸 수 있습니다.
- **Claude 가격이 API와 같습니다.** Claude 소넷 5.5와 오퍼스 5.5는 Anthropic API와 같은 토큰 가격입니다.
- **무료로 써 볼 수 있습니다.** 직접 테스트에서 1분 31초 만에 작동하는 게임을 돈 없이 만들었습니다.

**단점**

- **Claude와 GPT는 항상 추가 비용입니다.** 이제 어느 요금제에도 포함되지 않아서, Claude 위주 작업은 요금제 가격에 API 가격이 더해집니다.
- **같은 모델이어도 결과가 같지 않습니다.** 도구마다 모델에 붙이는 지시문과 맥락이 달라서, 커서의 소넷 5.5와 Claude Code의 소넷 5.5는 똑같이 움직이지 않습니다.
- **미리 계산하기 어렵습니다.** 요금제별 주간 주머니 크기가 달러로 공개돼 있지 않습니다.
- **X와 묶여 있습니다.** 원하든 원하지 않든 요금제가 Grok, X Premium과 한 구독으로 나옵니다.

**요금 폭탄 피하는 법**

- **자동 충전을 켜기 전에 추가 사용 월 한도부터 정합니다.**
- **큰 작업은 작게 나눠 시킵니다.** 가장 비싼 모델에 거대한 요청 하나를 맡기지 않습니다.
- **평소 수정은 Grok이나 Composer로 합니다.** 어려운 부분만 Claude 오퍼스나 GPT-5.6 Sol을 씁니다.
- **사용량 화면을 매주 확인합니다.** 이제 주머니가 매주 초기화됩니다.

## 결론: Grok엔 Plus, Claude엔 Claude Code

- **Grok과 Composer라면 커서가 이제 쌉니다.** Plus $8로 쓸 수 있고, 매일 에이전트를 쓴다면 커서는 Super $100을 추천합니다.
- **Claude라면 커서가 이제 비싼 길입니다.** Claude 토큰은 전부 요금제 위에 API 가격으로 붙지만, Claude Pro와 Max에는 Claude Code 사용이 포함됩니다.
- **요금제보다 모델 선택이 더 중요합니다.** 실측에서 오퍼스 5.5 high는 소넷 5.5 high보다 1회 비용이 약 200% 많았고($0.35 vs $0.12), Grok과 Composer는 포함 주머니에서 차감됩니다.

## 자주 묻는 질문

**커서는 무료인가요?**
네. Free 플랜은 무료지만 사용량이 제한되고 커서 자체 모델만 씁니다. 10월 11일 직접 테스트에서는 작은 게임 하나에 한 달 무료 한도의 15%를 썼습니다.

**커서 Pro는 얼마인가요?**
Pro($20, 약 2만 7천원)와 Pro+($60)는 이제 기존 가입자용 레거시 요금제입니다. 새로 가입하면 Plus($8), Premium($30), Super($100), Ultra($200) 중에서 고릅니다.

**커서에서 Claude를 쓸 수 있나요?**
Premium 이상에서 쓸 수 있고, 선불 크레딧에서 Anthropic API 정가로 차감됩니다. 100만 토큰당 소넷 5.5는 $2/$10, 오퍼스 5.5는 $4/$20입니다. Plus와 Free에서는 Claude를 쓸 수 없습니다. Teams와 Enterprise는 100만 토큰당 $0.25가 더 붙습니다.

**커서 팀 요금제는 얼마인가요?**
1인당 월 $30, $100, $200으로 Premium, Super, Ultra와 같습니다. 한 팀 안에서 좌석 종류를 섞을 수 있습니다.

**사용량을 다 쓰면 어떻게 되나요?**
주간 초기화를 기다리거나, 같은 모델별 가격으로 선불 크레딧을 써서 계속하거나, 요금제를 올립니다. 커서는 요청의 품질이나 속도를 낮추지 않는다고 안내합니다.

**맥스 모드는 아직 있나요?**
맥스 모드는 예전 요청 단위 레거시 요금제에만 남아 있고, API 가격에 20%를 더해 청구됩니다.
