> **30초 요약**
> - 커서(Cursor) 개인 요금제는 **Hobby 무료 · Pro $20 · Pro+ $60 · Ultra $200** (월), 팀은 **1인당 $40부터**입니다.
> - 원화로는 대략 **Pro 2만 7천원 · Pro+ 8만 1천원 · Ultra 26만 9천원**입니다 (1달러 1,345원 기준, 달러 결제).
> - 지금 커서는 "몇 번 요청"이 아니라 **쓴 만큼 API 가격으로 차감**됩니다. 그래서 **어떤 모델을 고르느냐**에 따라 같은 요금제도 빨리 닳거나 오래 갑니다.
> - 커서 공식 추천: **매일 에이전트를 쓰면 Pro+, 하루 종일 쓰는 파워 유저는 Ultra.**

커서 요금제를 검색하면 "Pro는 월 500회 요청" 같은 설명이 아직 많이 나옵니다. 하지만 그건 예전 방식입니다. 지금 커서는 요금제마다 정해진 **사용량을 API 가격으로 깎아 쓰는 구조**라서, 가격표만 봐서는 "한 달에 얼마나 쓸 수 있나"가 잘 안 보입니다. 요금제별 가격과, 실제로 얼마나 쓸 수 있는지 계산까지 정리했습니다.

## 사용량은 어떻게 차감되나: 주머니가 두 개

![커서 사용량 구조: Cursor 모델 주머니(Composer·Grok)와 다른 모델 주머니(Claude·GPT·Gemini)](/cursor-usage-pools-ko.jpg)

Pro·Pro+·Ultra에는 사용량 주머니가 두 개 있고, 둘 다 매달 결제일에 초기화됩니다.

1. **Cursor 모델 주머니:** 커서 자체 모델 Composer와 Grok을 쓰면 여기서 빠집니다.
2. **다른 모델 주머니:** Claude, GPT, Gemini 같은 외부 모델을 쓰면 **그 모델의 API 가격 그대로** 빠집니다.

자동(Auto) 모드도 공짜가 아닙니다. 커서가 고른 모델의 가격대로 차감됩니다. 사용량을 다 쓰면 에디터에 알림이 뜨고, **추가 사용(on-demand)을 켜서 같은 API 가격으로 계속 쓰거나 요금제를 올리면** 됩니다. 커서는 "한도를 넘어도 품질이나 속도를 낮추지 않는다"고 밝히고 있습니다.

참고로 Pro 요금제의 포함 사용량은 커서가 2025년 요금제 개편 때 "API 가격 기준으로 매달 최소 $20어치"라고 밝혔습니다. 지금 요금제별 정확한 포함량은 공식 문서에 금액으로 나와 있지 않고, 본인 계정의 사용량 대시보드에서 확인할 수 있습니다.

## 모델별 가격: 무엇을 고르느냐가 핵심

커서 공식 문서의 모델 가격입니다 (100만 토큰당, 달러).

| 모델 | 주머니 | 입력 | 출력 |
|---|---|---|---|
| Composer 2.5 | Cursor 모델 | $0.5 | $2.5 |
| Grok 4.7 | Cursor 모델 | $2 | $6 |
| GPT-5.6 Luna | 다른 모델 | $0.2 | $1.2 |
| Gemini 3.1 Pro | 다른 모델 | $2 | $12 |
| Claude Sonnet 5.5 | 다른 모델 | $2 | $10 |
| GPT-5.6 Sol | 다른 모델 | $4 | $20 |
| Claude Opus 5.5 | 다른 모델 | $4 | $20 |
| Claude Fable 5.1 | 다른 모델 | $10 | $50 |

입력 가격만 봐도 가장 싼 모델은 $0.2, 가장 비싼 모델은 $10입니다. 그래서 **간단한 수정은 싼 모델, 어려운 설계만 비싼 모델**로 나누는 것이 사용량을 아끼는 가장 큰 방법입니다.

| GPT-5.6 Luna | 약 $0.008 | 약 2,400번 |
| Composer 2.5 | 약 $0.02 | 약 1,000번 |
| Claude Sonnet 5.5 | 약 $0.08 | 약 250번 |

실제로는 같은 코드를 다시 읽을 때 캐시 가격(훨씬 저렴)이 적용돼서 이보다 더 많이 쓸 수 있습니다. 반대로 큰 프로젝트를 통째로 읽히면 입력이 수십만 토큰이 되어 훨씬 빨리 닳습니다. 내 프로젝트의 코드나 프롬프트가 몇 토큰인지는 [토큰 계산기](/ko/)에 붙여 넣으면 바로 나옵니다.

## 사용량 아끼는 팁 4가지

1. **모델을 상황별로 바꾸기:** 자잘한 수정은 Composer나 Luna, 어려운 설계만 Opus급.
2. **필요한 파일만 읽히기:** 프로젝트 전체 대신 관련 파일만 지정하면 입력 토큰이 크게 줄어듭니다.
3. **대화가 길어지면 새로 시작하기:** 대화가 길수록 매번 다시 읽는 맥락이 커집니다.
4. **추가 사용은 지켜보며 켜기:** on-demand는 쓴 만큼 나중에 청구됩니다. 켜 둘 때는 사용량 대시보드를 자주 확인하세요.

## 자주 묻는 질문

**커서 무료(Hobby)로 충분한가요?**
에이전트 요청이 제한돼 있어서 맛보기용입니다. 매일 쓰면 금방 한도에 닿습니다.

**Auto 모드는 무제한인가요?**
아닙니다. 지금은 Auto도 실제로 쓰인 모델의 가격대로 사용량에서 빠집니다.

**사용량을 다 쓰면 어떻게 되나요?**
에디터에 알림이 뜹니다. 추가 사용을 켜서 같은 API 가격으로 계속 쓰거나, 요금제를 올리면 됩니다.

**결제는 원화로 되나요?**
달러로 결제됩니다(인도만 루피 전용 Start 요금제가 있습니다). 원화 금액은 환율과 카드 수수료에 따라 달라집니다.
