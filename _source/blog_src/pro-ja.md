2026年9月29日、OpenAIはChatGPT Proを **Pro 100**、**Pro 200**、そして新設の **Pro 500** の3プランに分割しました。あわせて、Pro 200で使える量もひっそりと減らしています。どのプランにするか迷っている方、そもそもProが必要なのか気になっている方に向けて、ChatGPT Proの料金体系で実際に何が変わったのか、どう選べばよいのかを整理します。

## プラン比較表

![プラン比較表: プラン, 月額料金, 利用量（Plus比）, 「Plus 1つ分」の利用量あたりの料金, Ultrafast](/chatgpt-pro-ryokin-hikaku-ja-1.jpg)

| プラン | 月額料金 | 利用量（Plus比） | 「Plus 1つ分」の利用量あたりの料金 | Ultrafast |
|---|---:|---:|---:|:---:|
| Go | $8 | Plusより少ない | – | – |
| Plus | $20 | 1× | $20 | – |
| Pro 100 | $100 | 5× | $20 | – |
| Pro 200 | $200 | 10× | $20 | – |
| Pro 500 | $500 | 25× | $20 | ✓ |

料金は米国価格です。OpenAIのヘルプページには「Pro 200はPro 100より利用量が多く、Pro 500が最も多い」としか書かれていません。5×・10×・25×という倍率は、OpenAIの発表内容として報じられている数値です。

3つのProプランの機能はすべて共通で、Proモデル、Codex、ディープリサーチ、画像生成、メモリ、ファイルアップロードが使えます。唯一の違いは **Ultrafast**（GPT-6 Astraの高速モード）で、これはPro 500限定です。Pro 100やPro 200で追加クレジットを購入しても、Ultrafastは使えるようになりません。

## 見落としがちなポイント：「まとめ買い割引」はもうない

各プランの料金を利用量で割ると、どのプランも同じ数字になります。**Plus 1つ分の利用量あたり$20** です。つまりPro 500はPro 100よりお得なわけではなく、同じものを多く買えて、そこに速度が付いてくるだけです。

以前は事情が違いました。今回の変更までは、Pro 200でPlusの **20×** の利用量が使え、1単位あたり$10、つまり他のプランの半額でした。新たにPro 200を契約する人は **10×** になります。すでにPro 200を契約している人は **2026年10月29日** まで従来の20×が維持され、その後は同じ$200のまま10×に下がります。

ですから、選び方のルールはシンプルです。**上限に達しない範囲で、いちばん小さいプランを選ぶ。** 使わない余裕分にお金を払うことだけが、払いすぎの原因になります。

## Pro 500 の長所と短所

![ChatGPT Pro 500 の長所と短所：最大の利用量、Ultrafast、コンピューター操作エージェント vs 月 $500、まとめ買い割引なし](/chatgpt-pro-500-pros-cons-ja.jpg)

**長所**

- **利用量が最大：** Plus 25 プラン分の利用量です（OpenAI の発表として報じられた数値）。1日中 Codex やエージェントを動かしても上限にかかりにくいです。
- **Ultrafast は Pro 500 だけ：** GPT-6 Astra を毎秒最大 300 トークンで動かすモードで、ChatGPT Work と Codex で使えます（DevDay 発表）。
- **パソコンを操作するエージェント：** DevDay 発表では、Codex と ChatGPT Work でコンピューター操作エージェントを使える個人プランは Pro 500 です（ほかは Enterprise）。
- **大きく買っても損はない：** Plus 1 プラン分あたり $20 で、Pro 100・200 と単価は同じです。

**短所**

- **月 $500：** 個人プランで最も高額です。使い切れなければ無駄になります。
- **まとめ買い割引なし：** 単価が Pro 100・200 と同じなので、大きく買っても安くなりません。
- **Ultrafast は利用量を早く消費：** 速く生成するぶん、上限も早く減ります。
- **Ultrafast は今のところ Astra のみ：** GPT-6.1 Sol 向けは「近日提供」と発表されただけです。
- **正確な上限は非公開：** OpenAI のヘルプには「Pro 500 が最も多い」としか書かれていません。

**向いている人：** 毎週 Pro 200 の上限にかかる人、Codex やエージェントで1日中作業する人、待ち時間がそのままコストになる人。

## どのプランを選ぶべき？

![どのプランを選ぶべき？: Plusの上限にほとんど達しない： Plus（$20）のままで十分です。どのProプランも、日常のチャットでより賢い回答をくれるわけではなく、使える量が増えるだけです。; Plusの上限に週に数回達する： Pro 100](/chatgpt-pro-ryokin-hikaku-ja-2.jpg)

- **Plusの上限にほとんど達しない：** Plus（$20）のままで十分です。どのProプランも、日常のチャットでより賢い回答をくれるわけではなく、使える量が増えるだけです。
- **Plusの上限に週に数回達する：** Pro 100。料金5倍で利用量も5倍、$20から$100への移行はいちばん小さなステップアップです。
- **Pro 100でも頻繁に使い切る：** Pro 200。単価は同じで、使える量が2倍になります。
- **Codexやエージェントを1日の大半動かしている、または出力待ちの時間がそのままコストになる：** Pro 500。Ultrafastが使える唯一のプランです。ただし、生成が速い分、利用枠の消費も速くなる点に注意してください。
- **旧Pro 200を契約中：** 10月29日までは続けましょう。現時点でOpenAIが提供している中で最もお得なプランです。その後は、実際にどれだけ使っていたかを確認してください。旧利用枠の4分の1程度に収まっていたなら、Pro 100で同じことが$100安くできます。

## APIを直接使うのはどうか？

![APIを直接使うのはどうか？: 利用量, GPT-6 Sol API, GPT-6 Astra API](/chatgpt-pro-ryokin-hikaku-ja-3.jpg)

主に短め〜中程度のメッセージを送る使い方なら、トークン単位の従量課金のほうが、どのProプランよりも大幅に安く済むことがよくあります。以下は、1会話6メッセージ・英語テキストを前提に、1か月分のチャットをAPI経由で使った場合のおおよその料金です。

| 利用量 | GPT-6 Sol API | GPT-6 Astra API |
|---|---:|---:|
| 通常メッセージ 1日30件 | ≈ $8 | ≈ $39 |
| 通常メッセージ 1日80件 | ≈ $21 | ≈ $103 |
| 長文メッセージ 1日80件（ドキュメントを貼り付け） | ≈ $59 | ≈ $294 |
| 長文メッセージ 1日200件 | ≈ $147 | ≈ $735 |

「通常」＝1メッセージあたり入力約150トークン・出力約500トークン、「長文」＝入力約2,000トークン・出力約700トークン。APIの料金は、100万入力／出力トークンあたりSolが$2／$10、Astraが$10／$50です。

金額を一気に押し上げる要因が2つあります。1つ目は、新しいメッセージを送るたびに会話全体が再送信されるため、長いチャットは短いチャットよりはるかに高くつくことです。2つ目は、英語以外の言語では同じ内容でも多くのトークンが必要になることです。**日本語は英語の約1.8倍**、**韓国語は約1.4倍** のトークンを消費するため、APIの請求額もその分だけ増えます。日本語で使う場合は、上の表の金額を約1.8倍して考えてください。

結論として、日常用モデルのライト〜ミドルユーザーは、たいていPlusかAPIのほうが得です。Proが元を取れるのは、最上位モデルをヘビーに使う場合、長いドキュメントを扱う場合、あるいはCodexに張り付いている場合です。
