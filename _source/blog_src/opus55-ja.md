![Claude Opus 5 と 5.5 の違い：料金・性能・実測レビュー](/claude-opus-5-vs-5-5-ja.jpg)

Claude **Opus 5.5** は、2026年9月22日に登場した Anthropic の新しい上位モデルです。前のモデル **Opus 5** と比べて、トークン単価は20%安く、キャッシュ読み取りは60%安くなりました。Anthropic は「一般的な作業で運用コストが40%少ない」としていますが、コーディングエージェントの作業で私たちが計算すると約37%安くなりました。同じゲーム制作の依頼で実際に測ると、Opus 5.5 のトークン使用量は64%少なくなりました。料金・性能・実測結果を比べ、Max 20x プランで両モデルを使った感想とあわせて、乗り換える価値があるかをまとめました。

## Opus 5 と 5.5 の料金比較

![Opus 5 と 5.5 の料金比較: 項目, Opus 5, Opus 5.5, 差](/claude-opus-5-vs-5-5-opus-5-5-5-ja.jpg)

Anthropic の公式料金ページより、100万トークンあたりの価格です。

| 項目 | Opus 5 | Opus 5.5 | 差 |
|---|---:|---:|---:|
| 入力 | $5 | $4 | 20%安い |
| 出力 | $25 | $20 | 20%安い |
| キャッシュ書き込み（5分） | $6.25 | $5 | 20%安い |
| キャッシュ読み取り | $0.50 | $0.20 | **60%安い** |
| 高速モード | – | $8 / $40 | Opus 5.5 で追加 |

- **キャッシュ読み取りが最も大きく下がりました。** Opus 5 では入力価格の10%でしたが、Opus 5.5 では5%です。同じ文書や会話を繰り返し読む作業ほど差が大きくなります。
- **トークン数は同じです。** どちらも Claude 4.7 以降の新しいトークナイザーを使うため、同じ文章ならトークン数は同じです。単価の差がそのまま費用の差になります。
- **高速モード：** Opus 5.5 には入力 $8、出力 $40 の高速モードが加わりました。Claude Code と API で使え、Anthropic によると速度は最大150%速くなります。

## 使ってみた感想：Max 20x の週間上限が余るようになった

私（ジェヒョン）は Claude Max 20x プランでゲームを作りながら、Opus 5 と Opus 5.5 の両方を使いました。測定した数値ではなく、実際に使って感じたことです。

- **週間上限：** Opus 5 のときは、週間上限がリセットされる1日前に使い切るくらいでした。Opus 5.5 に変えてからは、1週間を使用量90%ほどで終えることが多くなりました。
- **外部作業：** トークンを多く使う外部作業を任せたときに差が一番大きく出ました。使ったモデルの中で、Opus 5.5 がいちばんトークンを使わない印象でした。
- **コーディング性能とコスパ：** コーディングでは Fable 5.1 並みの性能が出る感覚で、コスパはずっと良く感じました。参考までに、API 単価は Opus 5.5（入力 $4、出力 $20）が Fable 5.1（入力 $10、出力 $50）より60%安くなっています。

上の公式料金と下の計算結果も同じ方向です。同じ作業をより少ない費用（＝より少ない上限）でこなすので、同じプランでより長く使えます。

## 同じ依頼で実際に測ってみた

![同じ依頼で実測：Opus 5 と Opus 5.5 が作ったブロック崩しゲームの比較](/claude-opus-5-vs-5-5-ja-5.jpg)

感覚だけでは足りないので、2026年10月9日に Claude Code で両モデルに**同じ依頼**を1回ずつ出しました。ブラウザで動くブロック崩しゲーム（2レベル、スコアとライフ表示）を HTML ファイル1つで作るという依頼で、使用量は無料ツール ccusage で測りました。

| 項目 | Opus 5 | Opus 5.5 | 差 |
|---|---:|---:|---:|
| 出力トークン | 36,640 | 15,180 | 59%少ない |
| キャッシュ書き込みトークン | 74,533 | 63,917 | 14%少ない |
| キャッシュ読み取りトークン | 1,774,025 | 595,337 | 66%少ない |
| 合計トークン | 1,885,246 | 674,452 | **64%少ない** |
| 費用（API 料金換算） | $2.55 | $0.93 | **64%安い** |
| 作ったゲームのコード | 約684行 | 409行 | 40%短い |

![同じ依頼で使ったトークンのグラフ：Opus 5 は188万、Opus 5.5 は67万トークン](/claude-opus-5-vs-5-5-ja-6.jpg)

- **費用の差は単価の差（20%）よりずっと大きくなりました。** Opus 5.5 は同じ依頼を処理しながら、トークンそのものを64%少なく使いました。特に前の会話を読み直すキャッシュ読み取りが66%減りました。Max プランで週間上限が余るようになった理由と同じ方向です。
- **機能は Opus 5 のほうが多くありました。** Opus 5 のゲームには2回当てないと壊れないブロック、パーティクル効果、リスタート（R）キーがあり、Opus 5.5 は基本機能だけでした。ただ、画面は私の目には Opus 5.5 のほうがすっきりして見やすく感じました。トークンが少なかったのには、この機能の差も一部関係しています。
- **Opus 5.5 のファイルは末尾が欠けていました。** 最後の閉じタグ（`</script></body></html>`）がなく、最初は真っ白な画面でした。その3つを足すと正常に遊べました。Opus 5 のファイルはそのまま動きました。
- **注意：** 各モデル1回ずつの結果なので、やり直すと数字が変わる可能性があります。費用は ccusage が API 料金で換算した値で、プランの利用者はこの金額を払うのではなく上限から差し引かれます。

## 実際の作業費用の比較

![実際の作業費用の比較: 作業, Opus 5, Opus 5.5, 差](/claude-opus-5-vs-5-5-ja-3.jpg)

同じ作業を両モデルで実行した場合の費用を計算しました。トークン数は同じとして、価格だけを変えています。

| 作業 | Opus 5 | Opus 5.5 | 差 |
|---|---:|---:|---:|
| チャット1回（入力2,000 / 出力500） | $0.0225 | $0.018 | 20%安い |
| 文書への質問1回（入力5万のうち4万5,000がキャッシュ / 出力1,000） | $0.0725 | $0.049 | 32%安い |
| コーディングエージェントで機能1つ（入力160万、大半がキャッシュ / 出力1万7,500） | $1.79 | $1.14 | 37%安い |
| コーディングエージェント1か月（機能110個） | 約 $197 | 約 $125 | 37%安い |

計算例：Opus 5.5 の文書への質問 = 新しい入力5,000 × $4 + キャッシュ45,000 × $0.20 + 出力1,000 × $20（すべて100万トークンあたり）= $0.049。

**キャッシュを多く使うほど節約幅が大きくなります。** 単純なチャットは20%しか安くなりませんが、会話を読み直し続けるコーディングエージェントは37%近く安くなります。Anthropic の「40%削減」はこうした作業を基準にしたものと考えられます。

## Pro・Max プランの利用者には

- サブスクリプションでは、トークン単価ではなく**上限**が重要です。Anthropic は Opus 5.5 の公開に合わせて、Pro、Max、Team、シート制 Enterprise の5時間の使用上限を引き上げ、あとで使える上限リセットも提供するとしています。
- 同じ作業をより少ない費用でこなすモデルなので、同じ上限の中でより多く使える可能性が高いです。ただし、Anthropic はプランごとの正確な上限を公開していません。

## Opus 5 から乗り換えるべきか

- **API で Opus 5 を使っているなら：** 乗り換えをおすすめします。同じトークナイザーなのでプロンプトをほとんど変える必要がなく、費用は20〜37%下がり、性能は上がります。モデル名を `claude-opus-5-5` に変えて、結果を何回か比べてみてください。
- **Claude Code で大きな作業をよく回すなら：** キャッシュ割引の効果が最も大きいケースなので、得るものが大きいです。
- **Sonnet で足りる作業なら：** Opus 5.5 に上げる必要はありません。難しい設計やデバッグだけを Opus に任せるのが最も経済的です。

## よくある質問

**Opus 5.5 は Opus 5 よりどれくらい安いですか？**
トークン単価は20%、キャッシュ読み取りは60%安くなります。実際の作業費用では、チャットで20%、キャッシュを多く使うコーディングエージェント作業で約37%安くなります。

**トークン数も変わりますか？**
いいえ。両モデルとも同じ新しいトークナイザーを使うため、同じ文章ならトークン数は同じです。

**Opus 5.5 と Sonnet 5.5 のどちらを使うべきですか？**
ほとんどの作業は Sonnet 5.5 で十分で、トークンあたりの価格も半分です。難しいコーディング、長いエージェント作業、品質が重要な文章には Opus 5.5 を使いましょう。
