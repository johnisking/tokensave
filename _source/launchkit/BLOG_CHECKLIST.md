# 블로그 게시 전 체크리스트 (tokensave.app)

모든 블로그 글은 게시 전에 이 체크리스트를 통과해야 한다.
자동 항목은 `python3 check_post.py <md 이름...>` 으로 검사하고, 결과 표를 원고와 함께 재현에게 보여 준다.
FAIL이 하나라도 있으면 고친 뒤 다시 검사한다. "올려"를 받기 전에는 게시하지 않는다.

## 1. 검색 의도·키워드 (작성 전)
- [ ] 노릴 검색어와 검색 의도를 정했다 (자동완성·상위 글 확인)
- [ ] 상위 1~3위 글의 구조를 보고, 우리 글만의 차별점을 한 줄로 적었다
- [ ] 같은 주제의 기존 우리 글과 겹치지 않는다 (겹치면 기존 글 보강 또는 내부 링크)

## 2. SEO 최적화 (자동 검사 + 확인)
- [ ] 제목: 핵심 검색어를 앞쪽에, 한·일 40자 / 영어 65자 이내 (자동)
- [ ] 설명(meta description): 70~160자, 핵심 검색어·숫자 포함 (자동)
- [ ] 첫 문단에 핵심 검색어 포함 (자동)
- [ ] 소제목(H2) 4개 이상, 표 1개 이상 (자동)
- [ ] 내부 링크 2개 이상 + 계산기 링크: 이미지→/image, 영상→/video, 채팅·토큰→토큰 계산기 (자동)
- [ ] 출처 섹션과 공식 출처 링크 2개 이상 (자동)
- [ ] 자주 묻는 질문(FAQ) 섹션 (권장, 자동)
- [ ] 여러 언어판이면 hreflang으로 서로 연결 (빌드에서 자동)
- [ ] 배수 표현(×, 배, 倍, 20x) 없음 — 퍼센트로 (요금제 이름 Max 5x 등은 예외) (자동)

## 3. 이미지 생성
- [ ] 대표 이미지(1200×630) 1장 — 글 맨 위, 공유 이미지로도 사용 (자동)
- [ ] 설명 이미지 2장 이상 — 핵심 표·비교·장단점 등 읽기 쉽게 (자동: 전체 3장 이상)
- [ ] 이미지 속 숫자가 본문과 같다, 배수 표현 없다 (확인)
- [ ] 글자가 잘리거나 겹치지 않는다 (미리보기로 확인)

## 4. 이미지 SEO
- [ ] 파일 이름: 검색어가 들어간 영어 소문자-하이픈, 언어 코드 포함 (자동)
- [ ] 대체 텍스트(alt): 그 언어로 이미지 내용을 15자 이상 설명 (자동)
- [ ] 용량 200KB 이하 JPG (자동)
- [ ] 가로·세로 크기 지정, 첫 이미지 우선 로딩, og:image·og:image:alt (빌드에서 자동)

## 5. 글 깊이·전문성
- [ ] 분량 최소선: 한·일 2,500자 / 영어 700단어 이상 (자동)
- [ ] 분량 목표: 핵심 검색어 상위 글 분량의 중앙값의 90% 이상. 상위 글을 재서 launchkit/length_bench.json에 적는다 (자동, 2026-10-11부터)
- [ ] 가격·수치는 공식 자료로 확인한 날짜를 글에 적었다 (확인)
- [ ] 확인 못 한 사실은 빼거나 "보도 기준"처럼 출처를 밝혔다 (확인)
- [ ] 회사 주장(벤치마크 등)은 "○○에 따르면"으로 구분했다 (확인)

## 6. 독창성
- [ ] 우리만의 데이터·계산이 있다 (계산기 결과, 직접 측정, 실제 개발 경험) (확인)
- [ ] 다른 글을 옮긴 게 아니라 독자 상황별 추천·장단점 등 판단이 들어갔다 (확인)
- [ ] 경험담은 재현이 실제로 말한 내용만 쓴다 (확인)

## 7. 게시
- [ ] 원고 + 이미지 미리보기 + 체크 결과를 재현에게 보여 주고 "올려"를 받았다
- [ ] 빌드 통과, 게시 후 색인 요청 목록에 추가, 메모에 게시 기록
