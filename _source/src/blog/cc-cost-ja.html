Claude Code（クロードコード）は、Claude の Pro・Max プランに含まれているほか、使った分だけ払う API でも使えます。では、実際に月いくらかかるのでしょうか。使う量しだいで、同じ作業でも払い方によって900%以上の差が出ます。実際の数字でまとめました。

払い方は2つ

1. サブスクリプション（定額プラン）。Claude Code が含まれるプランです（米国価格、2026年10月確認）。

プラン 月額 利用量
Pro $20（年払いなら月$17） 基準
Max 5× $100 Pro の5倍
Max 20× $200 Pro の20倍

日本での支払額（税込）: 日本ではドル建てで、消費税10%込みの価格になります。Pro は$22（約3,480円、年払いなら月約2,900円相当）、Max 5× は$110（約17,380円）、Max 20× は$220（約34,760円）です（1ドル＝158円、2026年10月6日）。ChatGPT・Gemini との円での比較は生成AIのサブスク料金比較へ。

料金は定額で、利用上限があります。Claude Code と Claude アプリ（Web・デスクトップ・モバイル）は同じ上限を共有します。料金はドル建てなので、円での支払額は為替によって変わります。

2. API。Anthropic の API 価格で、トークン単位で支払います。

モデル 入力 100万トークン 出力 100万トークン
Claude Haiku 4.5 $1 $5
Claude Sonnet 5.5 $2 $10
Claude Opus 5.5 $4 $20

プロンプトキャッシュから読み込む入力は、Sonnet 5.5 と Opus 5.5 では通常の入力価格の5%（95%安い）、Haiku 4.5 では10%です。プランの上限はありませんが、使ったトークンはすべて課金されます。

Claude Code がトークンを多く使う理由

Claude Code はステップごとに作業します。ファイルを読み、編集し、テストを実行し、結果を見て、またやり直す。そしてステップのたびに作業コンテキスト全体（指示、ツール定義、読んだファイル、それまでの経緯）をモデルに送り直します。そのため、機能を1つ追加するだけでも入力トークンが約160万になることは珍しくありません。書くコードが短くても同じです。

これを現実的なコストに抑えているのがプロンプトキャッシュです。繰り返し送られる部分は Sonnet 5.5 と Opus 5.5 では入力価格の5%（Haiku 4.5 は10%）で計算され、Claude Code は自動で使っています。

API で1タスクあたりいくらか

TokenSave のコーディングエージェント費用計算機で、キャッシュありの場合です。

タスク ステップ Haiku 4.5 Sonnet 5.5 Opus 5.5
小さな修正 約8 $0.08 $0.14 $0.27
新機能 約25 $0.36 $0.57 $1.14
大規模リファクタ 約60 $1.33 $1.91 $3.82

キャッシュがなければ、Sonnet での新機能タスクは$0.57ではなく約$3.38になります。

1か月の費用

月の稼働日を22日とした場合です。

使い方 月のタスク数 API（Sonnet） API（Opus） たいてい合う最安プラン
ライト：1日に小さな修正3件 66 約$9 約$18 API または Pro（$20）
普通：1日に新機能5件 110 約$63 約$125 Pro または Max 5×
ヘビー：1日に新機能15件 330 約$188 約$375 Max 5× または Max 20×
一日中エージェント：大きなタスク1日8件 176 約$336 約$672 Max 20×

傾向ははっきりしています。

  • たまに使うなら、API がどのプランより安いこともあります。Pro が$20の月に、API なら$9ほどです。
  • 毎日使うなら、サブスクのほうがすぐに大幅に安くなります。Opus で普通に使うと API は約$125、Max 5× は$100です。
  • ヘビーに使うなら、上限が足りる限り Max は API よりはるかに安くなります。

プランの落とし穴は上限です。Anthropic はプランごとの正確なトークン数を公開しておらず、ヘビーユーザーは週の上限に当たります。Claude Code の使用量上限まとめをご覧ください。

トークンを料金に換算すると

Claude Sonnet 5.5 での簡単な目安です。

  • 入力100万トークン = $2（キャッシュからの読み込みなら$0.10）
  • 出力100万トークン = $10

Claude Code が送る内容の大半はキャッシュされたコンテキストなので、エージェント作業の実質単価は Sonnet で処理トークン100万あたり$1を大きく下回ることが多いです。Opus はそれより約100%高いと考えてください。

どう選ぶか

  1. 週に数回使う程度なら、まず Pro から。
  2. 上限にどれくらい当たるかを見ましょう。ほぼ毎週当たるなら、追加分を API で払うより Max 5× のほうが安い可能性が高いです。
  3. 自動化、CI パイプライン、使う量が不規則な場合は API が向いています。
  4. タスクごとにモデルを選ぶ。多くのコーディングは Sonnet で十分で、Opus はトークン単価が100%高いです。

自分の1か月を計算する

コーディングエージェント費用計算機で、タスクの大きさ、1日のタスク数、稼働日数を入れると、Claude・GPT・Gemini モデルの API 費用を Claude・ChatGPT の各プランと並べて比較できます。どちらの払い方でもトークンを減らしたいなら、Claude Code のトークン節約術をどうぞ。

料金と上限はよく変わります。決める前に claude.com/pricing を確認してください。
