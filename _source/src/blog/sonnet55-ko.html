클로드 소넷 5.5(Sonnet 5.5)는 오퍼스 5.5보다 토큰 단가가 50% 싼 모델입니다. 단가가 싼 만큼 결과물도 떨어질까요? 2026년 10월 9일, 오퍼스 5.5 effort 실측 때와 똑같은 벽돌깨기 게임 요청을 소넷 5.5에 medium과 high로 한 번씩 시켜, 오퍼스 5.5와 시간·토큰·비용·결과물을 1대1로 비교했습니다. 가장 싼 조합은 37초에 $0.25, 가장 비싼 조합은 1분 50초에 $0.75였습니다. 네 게임을 직접 플레이해 본 소감과 평소 두 모델을 써 본 경험도 함께 정리했습니다.

소넷 5.5 vs 오퍼스 5.5 가격

Anthropic 공식 가격 페이지 기준, 100만 토큰당 가격입니다.

항목 소넷 5.5 오퍼스 5.5 차이
입력 $2 $4 소넷 50% 저렴
출력 $10 $20 소넷 50% 저렴
캐시 쓰기(5분) $2.50 $5 소넷 50% 저렴
캐시 읽기 $0.10 $0.20 소넷 50% 저렴
  • 같은 양의 토큰이면 소넷이 정확히 50% 쌉니다. 다만 실제 비용은 모델이 작업하면서 쓰는 토큰 양에 따라 달라집니다. 그래서 같은 요청으로 직접 재 봤습니다.
  • 두 모델 모두 캐시 읽기가 입력 가격의 5%입니다. 같은 문서나 대화를 반복해서 읽는 작업이라면 둘 다 캐시 효과가 큽니다.

실측 방법

  • 환경: 오퍼스 5.5 effort 실측과 같은 Windows PC, 같은 클로드 코드
  • 요청(원문 그대로): "Make a brick-breaker game that runs in the browser as a single file named index.html in the current folder. It needs 2 levels, a score display and 3 lives, and it must be playable with the keyboard and the mouse. Write the file and finish." 브라우저용 벽돌깨기 게임을 HTML 파일 하나로, 레벨 2개, 점수, 목숨 3개, 키보드·마우스 조작으로 만들어 달라는 내용입니다.
  • 방법: 소넷 5.5를 --effort medium, --effort high로 한 번씩 실행하고, 같은 날 잰 오퍼스 5.5의 medium·high 결과와 비교했습니다. 단계마다 폴더를 따로 썼습니다.
  • 측정: 토큰과 비용은 무료 도구 ccusage로, 시간은 시작·종료 시각으로 쟀습니다. 비용은 API 가격으로 환산한 값입니다.

  • 단가만이 아니라 토큰도 덜 썼습니다. 출력 토큰이 두 단계 모두 오퍼스보다 35% 적었습니다. 단가 50% 차이에 토큰 차이가 더해져 절감 폭이 50%를 넘었습니다.

단계별 상세 리뷰

게임을 직접 플레이하고, 모델이 마지막에 남긴 요약과 코드를 함께 확인했습니다. 오퍼스 5.5의 medium·high 리뷰는 effort 비교 글에 있습니다.

소넷 5.5 medium: 37초, $0.25

  • 만든 것: 1레벨은 5줄 벽돌, 2레벨은 7줄 체크무늬 배치에 공이 빨라지고 맨 윗줄은 두 번 맞아야 깨집니다. 게임 오버와 승리 화면이 있습니다.
  • 좋은 점: 요청한 기능은 모두 정상 작동합니다. 네 게임 중 가장 빠르고 가장 쌉니다.
  • 아쉬운 점: 효과음·파티클 같은 게임 효과가 없고, 목숨도 하트 없이 글자로만 나옵니다. 코드도 198줄로 가장 짧습니다.
  • 이럴 때: 동작만 확인하면 되는 시제품, 단순한 수정 작업.

소넷 5.5 high: 58초, $0.30

  • 만든 것: 2레벨은 빈칸이 섞인 7줄 배치에 두 번 맞아야 깨지는 벽돌이 있고, 공이 빨라지고 패들이 좁아집니다.
  • 좋은 점: 벽돌이 깨질 때 파티클이 튀고, 최고 점수 저장, 레벨 클리어 보너스, 창을 벗어나면 자동 정지까지 넣었습니다. 목숨은 빨간 점으로 보여 줍니다.
  • 아쉬운 점: 두 번 맞아야 깨지는 벽돌은 코드상 얇은 흰 테두리와 한 번 맞은 뒤 흐려지는 효과로만 구분돼, 플레이 중에는 알아채기 어려웠습니다. 터치 조작은 없습니다.
  • 이럴 때: 평소 코딩, 보여 줄 만한 시제품을 싸게 만들 때.

직접 해 본 소감

두 게임을 직접 플레이해 본 느낌과, 평소 게임을 만들면서 소넷을 써 본 경험입니다. 측정값이 아니라 체감입니다.

소넷 medium: 밋밋하지만 기능은 정상

굉장히 심플하고 각종 게임 효과도 없고 하트도 없어서 밋밋하지만, 기능적으로는 정상 작동하는 느낌입니다.

화면을 보면 차이가 바로 보입니다. 벽돌은 깨져도 아무 효과 없이 사라지고, 목숨은 하트 대신 화면 위에 "Lives: 3"이라는 글자로만 나옵니다. 그래도 점수, 레벨 2개, 목숨 3개, 키보드·마우스 조작까지 요청한 것은 하나도 빠지지 않았습니다. 요청서를 체크리스트로 놓고 보면 합격이지만, 게임으로 놓고 보면 손이 덜 간 결과물입니다. "일단 돌아가는지 보자" 할 때는 이것으로 충분합니다.

소넷 high: 오퍼스 high 수준, 다만 한 군데가 아쉬움

오퍼스 5.5 high 수준의 작업물입니다. 게임 효과는 파티클을 잘 만들었습니다. 벽돌이 깨질 때마다 조각이 튀어서 medium과는 손맛이 확 다릅니다. 최고 점수 저장과 레벨 클리어 보너스까지 넣어서, 화면만 놓고 보면 오퍼스 high 옆에 둬도 크게 밀리지 않습니다.

다만 두 번 깨는 벽을 플레이어가 알아채지 못하게 만들었습니다. 코드를 열어 보면 이 벽돌은 얇은 흰 테두리로만 구분되고, 한 번 맞으면 조금 흐려지는 정도입니다. 플레이하는 입장에서는 똑같아 보이는 벽돌이 한 번 맞혀도 안 깨지니 버그처럼 느껴질 수 있습니다. 기능은 넣었는데, 그것을 플레이어에게 보여 주는 마무리가 빠진 셈입니다.

평소에 소넷을 써 보면

원하는 것을 세세하게 말해도 잘 구현이 안 되는 느낌이 있었습니다. 기능 구현은 가능하지만, 원하는 디테일까지 가려면 계속해서 추가로 요청해야 하는 느낌입니다. 그래서 만들고 고치고, 만들고 고치는 일을 오퍼스보다 더 자주 했던 것 같습니다.

이번 소넷 high의 두 번 깨는 벽돌도 같은 모습으로 볼 수 있습니다. "두 번 맞아야 깨지는 벽돌"이라는 기능은 만들었지만, "플레이어가 보고 바로 알 수 있게"라는 디테일은 한 번 더 요청해야 채워지는 식입니다.

그래서 비용을 볼 때

이번 실측은 요청 한 번으로 끝나는 작은 게임이라 이 차이가 숫자에 드러나지 않았습니다. 단순 계산으로 소넷 high($0.30)에 같은 크기의 요청을 두 번 더 하면 $0.90로, 오퍼스 high 한 번($0.75)보다 비싸집니다. 실제 수정 요청은 크기가 제각각이라 비용도 달라지지만, 고치는 횟수가 늘수록 소넷의 싼 단가가 주는 이점이 빠르게 줄어든다는 점은 함께 고려해야 합니다.

자주 묻는 질문

소넷 5.5는 오퍼스 5.5보다 얼마나 싼가요? 토큰 단가는 입력·출력 모두 50% 쌉니다. 이번 실측에서는 토큰도 35% 덜 써서, 같은 effort 기준 실제 비용은 55~60% 적었습니다.

소넷 5.5로도 게임을 만들 수 있나요? 네. 이번 실측에서 소넷 medium과 high 모두 요청한 기능을 다 갖춘 게임을 오류 없이 만들었습니다. high는 파티클 효과와 최고 점수 저장까지 넣었습니다.

그럼 오퍼스 5.5는 언제 쓰나요? 원하는 디테일이 많고 정확해야 할 때입니다. 소넷은 한 번에 끝나는 작업에서는 충분했지만, 세세한 요구는 여러 번 고쳐야 하는 경우가 많았습니다.
