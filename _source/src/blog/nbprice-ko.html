구글 이미지 모델 나노바나나는 이름이 계속 바뀌고, 가격표도 모델과 해상도마다 따로 있어서 "그래서 한 장에 얼마냐"는 질문에 바로 답하기가 어렵습니다. 10월 6일에는 나노바나나 2.1이 새로 나왔고, 원조 나노바나나(Gemini 2.5 Flash Image)는 10월 2일에 API 서비스가 끝났습니다. 그래서 구글 공식 가격 페이지(10월 13일 업데이트판)를 기준으로 모델별 API 가격, 무료로 쓸 수 있는 범위, 실제로 몇 장을 만들면 얼마가 나오는지를 정리했습니다. 구글 AI 스튜디오에서 나노바나나 2.1로 직접 이미지를 만들어 본 결과도 함께 넣었습니다.

원화 금액은 1달러=1,340원으로 계산한 대략적인 값이고, 부가세와 카드 해외결제 수수료는 빠져 있습니다.

2026년 10월 14일 기준으로 구글 Gemini API에서 나노바나나라는 이름으로 쓸 수 있는 이미지 모델은 4개입니다.

구글은 이미지 출력도 토큰으로 계산합니다. 예를 들어 나노바나나 2.1은 이미지 출력 100만 토큰당 $30이고, 1K(1024×1024) 이미지 한 장이 1,120토큰을 쓰니 한 장에 $0.0336이 됩니다. 이렇게 환산한 장당 가격은 아래와 같습니다(표준 요청 기준).

나노바나나 API는 무료로 쓸 수 있나요?

API로 무료로 쓰는 방법은 없습니다. 구글 가격표에서 나노바나나 2.1, 2, 2 Lite, 프로 모두 무료 등급(Free tier) 칸이 "사용 불가"로 되어 있습니다. 텍스트 모델처럼 API 키만 받아서 무료로 이미지를 뽑는 건 안 되고, 결제 정보를 등록한 유료 등급에서만 호출됩니다. 대신 유료 등급에서 보낸 내용은 구글 제품 개선에 쓰이지 않습니다.

무료로 써 볼 수 있는 길은 두 가지입니다.

  • 제미나이 앱(웹·모바일): 구글 공식 도움말 표를 보면 '나노바나나 2로 이미지 생성'은 요금제가 없는 무료 계정을 포함해 모든 요금제에서 쓸 수 있습니다.
  • 구글 AI 스튜디오: 개발자용 테스트 화면입니다. 아래에 직접 써 본 결과를 적었습니다.

구글은 지금 장수로 된 한도를 공개하지 않습니다. 공식 도움말에 나온 내용은 이렇습니다.

인터넷에서 보이는 "무료는 하루 몇 장" 같은 숫자는 대부분 예전 기사나 개인 측정치입니다. 지금 공식 문서에는 장수가 없으니, 무료 계정이라면 직접 써 보면서 한도 안내가 뜨는지 보는 게 가장 정확합니다. 10월 9일부터 무료 계정의 대화 모델이 Flash-Lite로 바뀐 내용은 제미나이 요금제 개편 정리에 따로 정리했습니다.

제미나이 무료 계정으로 직접 만들어 봤습니다

10월 14일에 구독이 없는 무료 구글 계정(화면 오른쪽 위에 '업그레이드' 버튼이 보이는 상태)으로 제미나이 앱에서 이미지를 만들어 봤습니다. 모델 선택은 기본값인 'Gemini 자동 모드' 그대로 두었습니다.

  • 프롬프트: 한국 카페 가을 메뉴판 포스터. 제목 '가을 신메뉴', 메뉴 3개와 가격 '고구마 라떼 5,500원', '단호박 케이크 6,800원', '밤 크림 스콘 4,200원'(영어로 지시, 한글은 그대로 입력)
  • 결과: 30초 안에 세로 이미지 1장(572×1024)이 나왔습니다. 제목·메뉴 이름·가격의 한글은 모두 정확했습니다.
  • 아쉬운 점: 시키지 않은 'AUTUMN SEASON' 문구를 맨 아래에 넣었는데, 연도를 2023년으로 적었습니다. 글자가 들어간 이미지는 받은 뒤 한 번 더 읽어 봐야 합니다.
  • 한도 안내: 한 장을 만드는 동안 한도 경고는 뜨지 않았습니다.
  • 프로로 다시 만들기: 이미지 아래 '다시 실행' 메뉴에는 길게·짧게·맞춤설정·다시 시도만 있었고, 나노바나나 프로로 다시 만드는 메뉴는 없었습니다. 구글 도움말에서 이 기능을 유료 요금제에만 표시한 것과 같습니다.

화면에는 어떤 이미지 모델이 쓰였는지 나오지 않습니다. 구글 도움말 기준으로 무료 계정의 이미지 생성은 나노바나나 2입니다.

AI 스튜디오에서 나노바나나 2.1을 써 봤습니다

API로 쓰는 나노바나나 2.1은 개발자용 테스트 화면인 구글 AI 스튜디오에서 써 볼 수 있습니다. 모델을 Nano Banana 2.1로 고르고, 해상도 1K, 생각 수준 중간(Medium)으로 이미지를 만들어 봤습니다. 이 테스트는 Google AI Pro를 구독 중인 계정에서 했고, API 키는 따로 연결하지 않았습니다.

  • 프롬프트: "작은 배낭을 멘 바나나 마스코트가 금화 더미 위에 서 있는 플랫 벡터 일러스트, 연보라 배경, 글자 없음"(영어로 입력)
  • 결과: 20초 안에 이미지 1장이 나왔습니다. 생각 과정(Thoughts)이 먼저 나오고 그 아래 이미지가 붙습니다.
  • 이어서 수정: "배경을 하늘색으로 바꿔 줘"라고 한 번 더 요청하니 캐릭터와 금화는 그대로 두고 배경만 바뀐 이미지가 나왔습니다.

두 번 모두 요금은 청구되지 않았습니다. 다만 입력창이 비어 있을 때 실행 버튼 위에 "이 모델은 유료 API 키가 필요합니다. API 키를 선택하세요"라는 안내가 떴습니다. AI 스튜디오의 무료 테스트 범위는 계정과 시점에 따라 달라질 수 있습니다. 앱이나 서비스에 넣으려면 결국 유료 API 키가 필요합니다.

무료 제미나이, 나노바나나 2.1, 프로의 품질 차이가 있나요?

위의 무료 제미나이와 같은 메뉴판 프롬프트를 AI 스튜디오에서 나노바나나 2.1과 프로(둘 다 1K)에도 넣어 봤습니다. 글자 표현이 어려운 한국어 메뉴판이라 차이가 드러나기 쉬운 주제입니다.

  • 한글: 세 결과 모두 제목·메뉴 이름·가격을 한 글자도 틀리지 않았습니다. 한글이 깨지던 예전 이미지 모델과는 확실히 다릅니다.
  • 제미나이 앱 무료(0원): 카페 안에 세워 둔 메뉴판처럼 배경까지 그렸고 다람쥐 같은 장식도 넣었습니다. 다만 시키지 않은 문구에 연도를 2023년으로 잘못 넣은 것은 세 결과 중 이것뿐이었습니다.
  • 나노바나나 2.1(장당 약 45원): 글자가 가장 크고 또렷해서 메뉴판으로 바로 쓰기 좋았습니다. 라떼 옆에 고구마, 스콘 위에 밤 크림을 올리는 등 메뉴 내용도 그림에 잘 반영했습니다.
  • 나노바나나 프로(장당 약 180원): 나무 벽에 붙인 포스터처럼 장면 전체를 연출했고 테두리 장식이 가장 풍성했습니다. 대신 글자가 작아져 작은 화면에서는 읽기가 조금 어렵습니다.

이번 비교로는 프로가 2.1보다 300% 더 비싼 값을 할 만큼 낫다고 느끼기 어려웠고, 무료 제미나이도 한글 품질은 충분했습니다. 메뉴판·썸네일처럼 단순한 이미지는 무료나 2.1로 충분하고, 프로는 복잡한 장면이나 여러 장에 걸친 브랜드 일관성이 필요할 때 따로 시험해 볼 만합니다. 다만 프롬프트 하나로 한 장씩만 비교한 결과라 다른 그림에서는 차이가 다르게 나올 수 있습니다.

API로 나노바나나를 쓰려면 무엇이 필요한가요?

코드를 직접 짜지 않더라도, 다른 앱이나 자동화 도구에 나노바나나를 연결하려면 API 키가 필요합니다. 순서는 간단합니다.

  1. 구글 AI 스튜디오에서 API 키 만들기: 왼쪽 아래 열쇠 아이콘(API 키) 메뉴에서 새 키를 만듭니다.
  2. 결제 등록: 이미지 모델은 무료 등급이 없어서, 키가 연결된 구글 클라우드 프로젝트에 결제 정보를 등록해야 호출됩니다.
  3. 모델 ID 넣기: 새로 시작한다면 gemini-nano-banana-2.1을 쓰면 됩니다. 해상도(1K·2K·4K)와 가로세로 비율은 요청할 때 고릅니다.

API 키는 비밀번호와 같아서 블로그나 깃허브에 그대로 올리면 다른 사람이 내 돈으로 이미지를 만들 수 있습니다. 결제 등록 후에는 구글 클라우드 콘솔에서 예산 알림을 걸어 두는 편이 안전합니다.

나노바나나 비용을 줄이는 방법

  • 처음엔 1K로 구도를 잡고, 마음에 드는 것만 크게: 4K는 1K보다 2.1 기준 약 236% 비쌉니다. 시안은 1K로 여러 장 뽑고, 쓸 것만 2K·4K로 다시 만듭니다.
  • 급하지 않으면 Batch: 같은 이미지를 절반 가격에 받습니다.
  • 수정은 처음부터 다시 만들지 말고 대화로: 2.1은 대화하며 고치는 데 강해서, 마음에 안 드는 부분만 말로 고치면 다시 뽑는 횟수가 줄어듭니다. 다만 대화가 길어지면 입력 토큰(100만 토큰당 $1.50)이 늘어나니 너무 길게 끌지 않는 편이 좋습니다.
  • 프로는 마지막 결과물에만: 글자가 정확해야 하는 포스터처럼 2.1로 해결이 안 되는 경우에만 씁니다.

어떤 나노바나나를 골라야 하나요?

  • 처음 써 보거나 대부분의 용도: 나노바나나 2.1. 구글이 새 프로젝트에 권장하고, 2보다 싸며 2K·4K까지 됩니다.
  • 1K 이미지를 아주 많이, 빠르게: 나노바나나 2 Lite. 장당 가격은 2.1과 같지만 입력이 싸고 더 빠릅니다. 대신 연속 수정이나 여러 장 참고에는 약합니다.
  • 글자가 많은 포스터, 브랜드 일관성, 복잡한 장면: 나노바나나 프로. 2.1보다 1K 기준 약 300% 비싸니, 2.1로 먼저 구도를 잡고 마지막 결과물만 프로로 만드는 방법이 있습니다.
  • 나노바나나 2를 쓰던 프로젝트: 공식 문서에 종료일은 아직 없지만 구글이 이전 세대로 분류했으니 2.1로 옮기는 편이 가격도 낮습니다. 모델 ID만 gemini-nano-banana-2.1로 바꾸면 되는지, 입력 비용이 늘지는 않는지 먼저 확인하세요.

자주 묻는 질문

나노바나나 2.1은 한 장에 얼마인가요? 표준 요청 기준 1K $0.0336(약 45원), 2K $0.0504(약 68원), 4K $0.113(약 151원)입니다. Batch로 보내면 절반입니다.

나노바나나 API 무료 한도는 얼마인가요? API에는 무료 등급이 없습니다. 모든 나노바나나 모델의 무료 등급 칸이 "사용 불가"입니다. 무료로 써 보려면 제미나이 앱이나 구글 AI 스튜디오를 이용해야 합니다.

제미나이 무료로 이미지 몇 장까지 만들 수 있나요? 구글이 장수를 공개하지 않습니다. 무료 계정은 '기본 한도'를 쓰고, 5시간마다 다시 채워지며 주간 한도가 있습니다. 이미지 생성은 대화보다 한도를 더 많이 씁니다.

원조 나노바나나(Gemini 2.5 Flash Image)는 이제 못 쓰나요? API에서는 2026년 10월 2일에 종료됐습니다. gemini-2.5-flash-image를 쓰던 코드는 오류가 나니, 바꿔야 합니다. 종료 안내에는 나노바나나 2나 2 Lite로 옮기라고 적혀 있고, 지금 새로 시작한다면 구글이 권장하는 2.1이 가격도 더 낮습니다. 장당 가격은 예전 $0.039보다 2.1·Lite(1K $0.0336)가 오히려 조금 쌉니다.

나노바나나 프로는 왜 1K와 2K 가격이 같나요? 구글 기준으로 1K부터 2K까지는 같은 1,120토큰으로 계산되기 때문입니다. 4K부터 2,000토큰으로 올라갑니다.

정리

나노바나나는 지금 2.1이 기본입니다. API로 쓰면 1K 한 장에 약 45원이고 Batch로는 약 23원이라, 블로그나 작은 프로젝트에는 비용 부담이 거의 없습니다. 고급 결과물이 필요할 때만 프로(1K·2K 약 180원)를 쓰면 됩니다. API에는 무료 등급이 없으니, 무료로는 제미나이 앱이나 AI 스튜디오에서 먼저 써 보고 많이 쓸 때 API로 넘어가는 순서가 무난합니다. 제미나이 앱의 무료 한도는 장수가 아니라 사용량 기준이고 5시간마다 다시 채워집니다.
