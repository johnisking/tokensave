ChatGPT Go は月1,400円、ChatGPT Plus は月3,000円です（税込）。2026年8月から、無料を含むすべてのプランで普段の会話が無制限になったので、「メッセージが足りないから上げる」という理由はなくなりました。今の違いは、どのモデルが答えるか、どれだけ深く考えるか、何がついてくるかです。1,600円の差で何が変わるのか、誰にどちらが向いているのかをまとめました。

本当の違い：Luna か Sol か

Go は OpenAI の小さくて速いモデル GPT-5.6 Luna で答えます。Plus は中くらいのモデル GPT-5.6 Sol で答え、考える時間を長くすることもできます。簡単な質問、文章の手直し、Web ページの要約くらいなら、違いはほとんど感じません。でも長い文書、込み入った推論、コーディングのように、間違えると困る作業では Sol がはっきり上です。

数字で見ると、API では Sol クラスのモデルは Luna クラスよりトークンあたり約20倍高いです。Plus の月額には、それだけ大きなモデルを動かしてもらう費用が入っているわけです。

Go が向いている人

  • ChatGPT を普段の質問、文章の手直し、簡単な要約に使う。
  • Codex や ChatGPT Work は使わない。
  • たまに広告が出ても気にならない。
  • 無料版より、メモリ・ファイルのアップロード・画像生成を少し多く使いたい。

Plus が向いている人

  • 長い文書を書いたり分析したりする。正確さが大事な質問をする。
  • 難しい問題では推論レベルを上げて使いたい。
  • コーディングや業務の自動化に Codex・ChatGPT Work を使う。ちゃんと使える一番安いプランが Plus です。
  • 広告なしで使いたい。

Plus の上限に毎週かかるなら、次は Pro（16,800円〜）です。ChatGPT Pro の料金比較を参考にしてください。

同じ価格帯のほかの選択肢

  • Google AI Plus（725円）: Go より安く400GB のストレージもつきますが、まもなく Pro モデルが使えなくなります（Gemini 無料版の変更まとめ）。
  • Google AI Pro（2,900円）、Claude Pro（月$22、約3,480円）: Plus と同じ価格帯です。全体の比較は生成AIのサブスク料金比較にあります。

どちらも使わず API で使う

会話がほとんどなら、使った分だけ払う API のほうが安いことがあります。GPT-6 Luna で1日60回の続く会話を1か月しても、日本語で API 料金は300円前後です。そのかわり画像、音声、メモリ、ディープリサーチといった ChatGPT アプリの機能はなくなり、別のチャットアプリが必要です。日本語は英語よりトークンが多く出るので、自分の使い方でサブスク vs API 計算機で比べてみてください。
