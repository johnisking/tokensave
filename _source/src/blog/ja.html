同じことを聞いても、日本語で書くと英語よりトークンが多くかかります。APIはトークン単位で課金されるので、そのぶん料金も高くなります。どのくらい差があるのかを実際に測り、その差をボタンひとつで縮める方法もまとめました。

結論から言うと、日本語は英語の1.79倍。41言語中で高いほうから11番目です。そしてプロンプトを英語にして送ると、トークンが約44%減ります。

測定方法

英語で34トークンになる、ごく普通のカスタマーサポート用プロンプトを使いました。

Please summarize the customer email below in three bullet points and suggest a polite reply. The customer says the order arrived two days late and one item was missing from the box.

日本語版はこちらです。

以下の顧客メールを3つの箇条書きで要約し、丁寧な返信を提案してください。顧客によると、注文品が2日遅れて届き、箱から商品が1つ欠けていたそうです。

これを41言語に翻訳し、GPT-4o以降のOpenAIモデルで使われているトークナイザー（o200k_base）で数えました。

import { getEncoding } from "js-tiktoken";

const enc = getEncoding("o200k_base");
const count = (text) => enc.encode(text).length;

count(english);  // 34
count(japanese); // 61

Pythonなら tiktoken で同じことができます。

import tiktoken
enc = tiktoken.get_encoding("o200k_base")
print(len(enc.encode(japanese)))  # 61

なぜ日本語は多くかかるのか

AIは文字や単語をそのまま読むわけではありません。まずトークナイザーが文章を決まった断片（トークン）に切り分けます。この断片の辞書は主に英語のテキストから作られているため、英語の単語はほとんどが1トークンですが、日本語は語や文字が複数の断片に分かれることが多くなります。

面白いのは、同じ漢字を使う中国語（簡体字）は1.03倍で英語とほぼ同じだという点です。日本語の割高さは漢字そのものより、ひらがな・カタカナと漢字が混ざる書き方や、学習データに含まれる量の差によるものと考えられます。

ボタンひとつで英語に：TokenSaveの翻訳機能

いちばん効く節約は、プロンプトを英語にして送ることです。最近のモデルは英語の指示を正確に理解し、「日本語で答えて」と一行添えれば回答は日本語で返してくれます。

TokenSaveのトークンカウンターなら、これが一度にできます。

  1. プロンプトを貼り付けると、トークン数とモデルごとの料金がすぐに表示されます。
  2. 減らせる余地があると 💸 トークン節約 ボタンが現れ、横に予想節約率（例：−44%）が出ます。
  3. 押すと 空白を整理 → 英語に翻訳 → 冗長表現を短縮 を順に行い、最後に "Reply in Japanese." を自動で付けます。プロンプトは英語でも、回答は日本語で受け取れます。何トークン（何%）減ったかもすぐに表示されます。
  4. 英語になったプロンプトを コピー して、ChatGPT・Claude・Geminiなどにそのまま使えます。気に入らなければ、ボタンが ↩ 原文 に変わっているので、もう一度押せば元に戻ります。

どう動いているの？

  • 翻訳にはブラウザに内蔵されたAI翻訳を使います。デスクトップ版Chrome 138以降またはEdge 148以降で動きます。
  • 最初の1回だけ翻訳モデルをダウンロードし（進捗が表示されます）、それ以降は 自分の端末の中で 翻訳します。入力した文章はどのサーバーにも送られません。
  • 翻訳するとかえってトークンが増える場合、翻訳は適用しません。
  • コードを貼り付けた場合は、コードはそのままで 日本語のコメントだけ を英語にします。
  • スマートフォンや対応していないブラウザでは翻訳を飛ばし、空白の整理だけ行って案内を表示します。

そのほかの節約のコツ

  • システムプロンプトや固定の指示文は英語で書く。毎回送る部分なので効果がいちばん大きいところです。ユーザーの入力と最終回答だけ日本語にします。
  • 中間処理（分類・抽出・ツール呼び出し）は英語かJSONで出力させる。ユーザーが直接見ない部分です。
  • 全角スペースや空行を消す。コピペした文章には意外と多く含まれています。
  • 敬語を盛りすぎない。「〜していただけますと幸いです」より「〜してください」で十分です。
  • 長い会話は新しいチャットで。メッセージを送るたびに、それまでの会話全体が再送されます。話題が変わったら5行の要約だけ持って新しいチャットを開きましょう。
  • プロンプトキャッシュを使う。固定部分をキャッシュすれば、その部分の入力単価は大幅に下がります（90%近く安くなるモデルもあります）。

翻訳しないほうがいい場合

指示や質問は英語にしても問題ありませんが、原文そのものが大事な文章はそのままにしてください。そのまま引用すべき契約書の文言、日本語の添削を頼む文章、詩やコピーのように表現そのものが中身の文章などです。

注意点

  • 測ったのは1つのプロンプトだけです。文によって倍率は0.1〜0.2倍ほど変わるので、おおまかな目安として見てください。
  • 翻訳は機械翻訳をベースに確認しました。日本語訳に違和感があれば教えてください。測り直します。
  • ClaudeとGeminiはトークナイザーが異なるため、この数字がそのまま当てはまるのはOpenAIのモデルです。ほかのモデルはトークンカウンターで推定値として表示します。

トークン数と日本語の文字数・原稿用紙の枚数をすぐ換算したいときは、トークン⇔文字数 変換ツールが便利です。
