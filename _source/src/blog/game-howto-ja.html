プログラミングが得意でなくても、いまはAIツールを組み合わせればスマホゲームを1人で作れます。この記事では、AIでゲームを作る手順と必要なツール、そして実際にかかる費用と期間をまとめます。

結論から言うと、小規模なスマホゲームなら2〜3週間、費用は約$50〜180です。費用の大半は画像ではなく、コーディングAIのサブスクにかかります。

数字はすべてAIゲーム制作費計算機で出したもので、料金は2026年10月5日時点です。計算機の規模の基準は、AIコーディングエージェントを使って実際に1人で作ったモバイルゲームです。

AIでゲームを作る6つの手順

1. 何を作るか1行で決める

最初に「どんなゲームか」を1行で書きます。たとえば「猫の家具を合体させてカフェを飾るゲーム」のように、ジャンルと遊び方がわかれば十分です。初めてなら、ジャンルは小さくまとまるものを選びましょう。ハイパーカジュアル、マージ、ノベルゲームは素材も少なく、完成させやすいジャンルです。

2. ゲームエンジンを選ぶ

エンジン 向いている人 言語
Unity スマホゲームの定番。情報が多い C#
Godot 無料・軽量。2Dに強い GDScript
Ren'Py ノベルゲーム専用。文章中心ならいちばん早い Python
Roblox Studio Roblox上で遊ぶゲーム。公開も無料 Luau
Phaser ブラウザで遊ぶゲーム TypeScript

AIにコードを書かせる場合、Unity と Godot はAIの知識量が多く、指示どおりに動くコードが出やすい傾向があります。

3. コードはAIエージェントに書いてもらう

Claude Code、Cursor、Gemini CLI などのコーディングエージェントに「こういうゲームを作りたい」と伝えると、フォルダ構成から実装まで少しずつ進めてくれます。コツは次の3つです。

  • 1回に1つの機能だけ頼む
  • 各ステップのあとにスマホで動かして確認する
  • 本番の絵ができるまでは四角や丸の仮素材で進める

計算機の「開発スタート」プロンプトは、この進め方をそのまま指示文にしたものです。コピーして貼り付ければ始められます。

4. キャラクター・背景・UIは画像AIで作る

Midjourney、Gemini（Nano Banana 2）、Leonardo などで作ります。ドット絵なら PixelLab がアニメーションまで作れるので便利です。

小規模なマージゲームで必要な画像は約86枚です。キャラクター、アニメーションのコマ、背景、アイテム、UIの合計です。3回生成して1枚使う前提でも、Midjourney の最安プラン（月$10）に収まります。

5. 音楽と効果音を用意する

BGMは Suno や AIVA、効果音は ElevenLabs で作れます。お金をかけたくない場合は、Pixabay、Kenney、Freesound の無料素材でも十分です。

お金はどこにかかるのか

小規模なマージゲームを標準の組み合わせで作った場合の内訳です。

項目 費用 割合
コード（Claude Max 5×、1か月） $100 約66%
ストア登録料（Google Play） $25 約17%
画像（Midjourney） $10 約7%
音楽（Suno） $10 約7%
効果音（ElevenLabs） $6 約4%

コーディングAIは一日中動かすので、使用量の上限に余裕のあるプランが必要になります。そのため、費用の3分の2がここに集中します。開発が1か月を超えるとサブスクがもう1か月分かかるので、期間を短く区切ることが一番の節約になります。

注意したいこと

  • 最初から大きく作らない：RPGやMMOは素材もコードも一気に増えます。まず小さく完成させてから広げましょう。
  • サーバー代：オンライン対戦を入れると、Photon や Firebase などのサーバー代が別にかかります。
  • 公開後の費用：広告やアップデートの運営費は、ここでの計算に入っていません。

自分のゲームで計算してみる

AIゲーム制作費計算機では、ジャンル（33種類）、規模、エンジン（21種類）、出し先を選ぶと、費用と期間に加えて開発スタート・画像・音楽・効果音・トレーラー用のプロンプトがまとめて出ます。気になったジャンルでそのまま試してみてください。
