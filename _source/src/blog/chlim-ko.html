"한도에 도달했습니다"는 한때 ChatGPT에서 가장 흔한 불만이었습니다. 2026년에는 규칙이 많이 바뀌었습니다. 일상적인 텍스트 대화는 이제 모든 요금제에서 한도가 없지만, 최신 모델, ChatGPT Work와 Codex, 파일 업로드, 이미지, 음성에는 여전히 한도가 있습니다. 요금제별로 무엇이 제한되는지, 한도가 어떻게 초기화되는지, 내 사용량은 어떻게 확인하는지 정리했습니다.

텍스트 대화: 2026년 8월부터 한도 없음

2026년 8월 6일, OpenAI는 Free, Go, Plus, Pro 요금제의 일상 텍스트 대화 한도를 없앴습니다. Free와 Go 사용자는 GPT-5.6 Luna와 대화하고, 어려운 질문에는 "Think" 버튼을 누를 수 있습니다. Plus와 Pro 사용자는 생각 수준 슬라이더가 있는 GPT-5.6 Sol을 씁니다. 다만 OpenAI는 남용 방지 장치를 계속 두고 있어서, 자동화된 사용이나 극단적인 사용은 속도가 제한될 수 있습니다.

그러니 평범한 텍스트 메시지만 보낸다면 이제 메시지 한도를 볼 일은 없습니다.

ChatGPT Work와 Codex (GPT-6 Astra 포함) 있음: 5시간 단위 한도와 주간 한도

요금제별 생각 수준. Plus는 GPT-5.6 Sol에서 Medium과 High 생각 수준을 쓸 수 있습니다. Pro는 여기에 Extra High와 Pro 모델이 추가됩니다. Pro 100과 Pro 200에서는 GPT-6 Pro와 GPT-5.6 Sol Pro가 주간 사용량을 함께 나눠 씁니다. 이를 다 쓰면 ChatGPT가 Medium 수준의 GPT-5.6 Thinking으로 전환합니다.

GPT-6 Astra 한도

OpenAI의 플래그십 모델인 GPT-6 Astra는 ChatGPT Work와 Codex에서 씁니다. OpenAI 고객센터는 5시간 단위당 예상 메시지 수를 다음과 같이 안내합니다.

요금제 5시간당 GPT-6 Astra 메시지
Plus 약 5–45
Pro (5× 등급) 약 25–225

범위가 넓은 이유는 길고 여러 단계를 거치는 작업 하나가 짧은 작업보다 사용량을 훨씬 많이 쓰기 때문입니다. 5시간 단위 한도 위에 주간 한도도 따로 적용됩니다. 상위 Pro 등급은 그만큼 더 받습니다. 2026년 9월 29일부터 신규 구독자 기준으로 Pro 200은 Plus의 10배, Pro 500은 Plus의 25배입니다. ChatGPT Pro 100 vs 200 vs 500을 참고하세요.

한도가 초기화되는 방식

  • 5시간 단위: 하루 중 정해진 시각이 아니라, 그 구간에서 첫 요청을 보낸 시점부터 계산되는 롤링 방식입니다. Plus는 2026년 8월 말부터 Work와 Codex에 5시간 단위 한도가 적용되고 있습니다. OpenAI는 8월에 Pro 100과 Pro 200에는 앞으로 몇 달간 5시간 단위 한도를 두지 않겠다고 밝혔습니다.
  • 주간 한도: Plus, Pro, Business에 적용되는 7일 롤링 사용량입니다.
  • 파일, 이미지, 음성: 각각 별도의 사용량이 있습니다.

사용량 확인하는 법

OpenAI 고객센터는 Settings → Usage를 안내합니다. 여기서 Work와 Codex의 남은 사용량과 초기화 시각을 볼 수 있습니다. 한도에 걸리면 ChatGPT가 언제 다시 이어 쓸 수 있는지도 알려 줍니다.

한도에 걸렸을 때

  1. 초기화를 기다립니다. 5시간 단위 한도라면 보통 길어야 몇 시간입니다.
  2. 리셋이나 크레딧을 씁니다. 자격이 되는 Plus와 Pro 계정은 적립된 리셋을 쓰거나 즉시 리셋을 구매할 수 있고, 일부 요금제는 크레딧으로 계속 쓸 수 있습니다.
  3. 모델을 바꿉니다. 일상적인 작업에는 GPT-6 Astra가 필요한 경우가 드뭅니다. GPT-5.6 Sol이나 Luna는 사용량을 훨씬 적게 씁니다.
  4. 업그레이드합니다. Pro 100은 Plus의 5배, Pro 200은 10배, Pro 500은 25배입니다.
  5. API를 씁니다. 특정 모델을 꾸준히 많이 쓴다면 토큰당 요금을 내는 편이 더 간단할 수 있습니다. GPT-6 Astra는 입력 100만 토큰당 $10, 출력 100만 토큰당 $50입니다. GPT-6 API 가격을 참고하세요.

대화마다 "토큰 한도"가 있나요?

모든 모델에는 컨텍스트 윈도가 있습니다. 한 번에 고려할 수 있는 텍스트의 최대량입니다. 아주 긴 대화나 문서는 결국 여기에 닿고, 그 전에도 품질이 떨어집니다. 모델이 메시지마다 대화 전체를 다시 읽기 때문입니다. 짧은 요약과 함께 새 대화를 시작하면 생각보다 효과가 큽니다. 컨텍스트 윈도 설명 (영어)을 참고하세요.

요금제냐 API냐

주로 대화만 한다면 8월 변경 덕분에 $20 요금제의 가성비가 예전보다 훨씬 좋아졌습니다. Codex나 GPT-6 Astra를 많이 쓴다면 구독 vs API 계산기와 코딩 에이전트 계산기로 요금제 가격과 같은 작업을 API로 했을 때의 비용을 비교해 보세요. 한국어로 쓰는 지시문을 영어로 바꾸면 토큰을 약 31% 아낄 수 있는데, 토큰 계산기의 💸 토큰 절약 버튼을 누르면 내 기기 안에서 바로 번역해 줍니다(PC용 Chrome 138 이상 또는 Edge 148 이상).

한도는 자주 바뀝니다. 최신 수치는 OpenAI의 GPT-6 Astra 사용량 도움말에서 확인하세요.
