作業の途中で Claude が「使用量の上限に達しました」と止まってしまうことがあります。いつまた使えるのか、なぜこんなに早く上限に来たのか、お金を払えばすぐ解除できるのか。調べてみると「最初のメッセージから5時間」「7日ごとにリセット」など記事によって説明が少しずつ違い、画面の見た目もその間に変わっているので、今の自分のアカウントに当てはまる答えを見つけるのは意外と大変です。

そこで、Anthropic のヘルプセンターにある使用量関連の記事を2026年10月16日に読み直し、実際に Max 5x を使っているアカウントの使用量画面と一つずつ照らし合わせました。この記事では、Claude のセッション上限と週の上限の仕組み、リセット時刻の確認方法、新しく加わった「無料でリセット」ボタン、日本語で使うと上限の減り方が変わるのか、そして上限を長持ちさせるコツまでを順番にまとめます。

Claude の使用量上限は2つが同時にかかる

Claude には性質の違う上限が2種類あります。

  1. 使用量の上限。 一定時間にどれだけ使えるかを決める上限です。有料プラン（Pro、Max、Team など）には、5時間ごとにリセットされるセッション上限と、週に1回リセットされる週の上限が同時にかかります。
  2. 長さの上限。 1つの会話がどこまで長くなれるかを決める上限で、モデルのコンテキストウィンドウの大きさで決まります。有料プランの最新モデルは最大100万トークン、ほかのモデルは50万または20万トークンです。

この記事で扱うのは1つ目、使用量の上限です。週の上限に余裕があっても5時間に集中して使えばセッション上限に当たりますし、セッションが新しくても週の上限を使い切っていれば止まります。そして claude.ai（Web）、デスクトップアプリ、モバイルアプリ、Claude Code はすべて同じ上限を分け合っています。 Claude Code で長くコーディングすると、チャットに残る分も減る仕組みです。

金額は Web 契約のドル建て価格（Pro $20、Max 5x $100、Max 20x $200）に、2026年4月から日本で加わった消費税10%を足し、1ドル＝158円で換算したおおよその値です。Anthropic は円の公式価格を出しておらず、実際の引き落とし額はカード会社のレートで変わります。表から読み取れないポイントもまとめておきます。

  • 決まったメッセージ数はありません。 Anthropic はどのプランにも「5時間で何通」という数字を出していません。メッセージの長さ、添付ファイルの大きさ、それまでの会話の長さ、選んだモデルと effort（考える深さ）、Web 検索やリサーチなどのツールによって、同じ上限で送れる量が変わるからです。
  • Max の倍率はセッション単位です。 ヘルプセンターによると、Max 5x は Pro のセッションあたり使用量の500%、Max 20x は2,000%です。週の上限の大きさは数字で公開されていません。
  • Max には Fable 専用の週の上限が別にあります。 使用量画面に「今週の Fable」という別のバーがあり、通常の週の上限と同じ時刻にリセットされます。
  • アプリ内課金は価格が違う場合があります。 プランごとの機能と日本での支払いの詳細は Claude の料金プラン比較 にまとめています。

Claude の使用量はいつリセットされる？

2つの上限はリセットの仕組みが違います。ネット上の説明が食い違うのは、ここが混ざっているせいです。

上限 リセットの仕組み 確認する場所
セッション上限 5時間ごと。「17:40にリセット」のように時刻が表示される 設定 > 使用量の「現在のセッション」
週の上限 アカウントごとに決まった曜日・時刻に毎週リセット 設定 > 使用量の「今週」
Fable の週の上限（Max） 週の上限と同じ曜日・時刻 設定 > 使用量の「今週の Fable」

セッション上限は、深夜0時のような決まった時刻にリセットされるわけではありません。使い始めると5時間のセッションが始まり、その終わりの時刻が使用量画面に表示されます。朝10時ごろに使い始めたなら、午後3時ごろにまた満タンに戻ると考えれば大丈夫です。

週の上限はよく「最初に使ってから7日後」と説明されますが、2026年10月時点のヘルプセンターの説明は違います。Pro も Max も、アカウントごとに決まった週のリセット曜日・時刻があり、いつ使い始めたかやいつ契約したかに関係なく変わらないと案内しています。確認したアカウントは毎週木曜日19時（日本時間も同じ）に固定されていました。自分のアカウントの曜日と時刻は、使用量画面ですぐ確認できます。

残りの使用量を確認する方法

Web かデスクトップアプリで 設定 > 使用量 を開きます（claude.ai/settings/usage を直接開いても同じです）。画面の表記は言語設定によって少し違うことがあります。いちばん上に「新しい週です。週の上限の9%を使いました」のような1行のまとめがあり、その下に3本のバーが並びます。

  • 現在のセッション： この5時間で使った割合と、次のリセット時刻
  • 今週： 週の上限を使った割合と、次のリセット曜日・時刻
  • 今週の Fable： Max だけにある Fable 専用の週の上限

さらに下には 今週の製品別使用量 があり、週の使用量を Claude Code、チャット、Cowork、その他に分けて見せてくれます。確認した Max 5x のアカウントでは、今週の使用量の93%が Cowork（ファイルやツールを使って何段階も作業するエージェント機能）で、Claude Code は3%、ふつうのチャットはわずか1%でした。何段階も自分で進める作業は、1回頼むだけでも裏で多くのやり取りが発生するので、チャット数十回分を使うこともあります。

Claude Code を使っているなら、ターミナルで /usage と入力すると同じ情報が見られます。上限の割合ではなく、使ったトークンを API 料金に換算するといくらか、日付やプロジェクト別にどこで多く使ったかを見たいときは、Claude Code 使用量アナライザーに記録フォルダを入れてみてください。計算はブラウザ内だけで行います。

新しく加わった「無料でリセット」

使用量画面に 上限のリセット という欄が加わりました。ヘルプセンターによると、Anthropic が対象のプランに「ときどき」配る特典で、使うと上限が満タンに戻ります。

  • 種類は2つです。 5時間のセッション上限を戻す「5時間リセット」と、週の上限を戻す「全体リセット」があります。確認したアカウントには 全体リセットが1回分（期限10月23日） 入っていて、5時間リセットは「今はありません」と表示されていました。
  • 上限に達する前でも使えます。 ただし一度使うと取り消せず、決まった週のリセット日程はそのままです。
  • ボタンは Web とデスクトップアプリだけです。 モバイルアプリと Claude Code にはありません。上限はアカウント全体で共通なので、Web でリセットすればモバイルと Claude Code も一緒に回復します。
  • 期限を過ぎると消えます。 プランを下げたり解約したりしても、使っていないリセットはなくなります。すでに請求された追加使用分が返金されることもありません。

使い方は、設定 > 使用量の上限のリセット欄で 無料でリセット を押し、確認画面でもう一度押すだけです。上限に達したときに出る案内メッセージにも同じボタンが表示されます。全体リセットを持っているなら、週の後半に週の上限がほぼいっぱいになったところで使うのがいちばん無駄がありません。

上限に達したときにできること

方法 費用 向いている場面
リセットを待つ なし セッション上限に当たり、数時間待てるとき
無料でリセット なし（持っている場合のみ） 週の上限がほぼいっぱいで、リセットの特典があるとき
使用量クレジットをオンにする API 料金で使った分だけ たまに上限を超え、すぐ作業を続けたいとき
プランを上げる 月 約13,900円〜31,300円（$88〜$198、税込）の追加 ほぼ毎週上限に当たるとき

使用量クレジットは 設定 > 使用量 でオンにできます。オンにしておくと、セッション上限や週の上限（Max は Fable の週の上限も）を使い切っても作業は止まらず、クレジットに切り替わって「Now using credits」と表示されます。料金は API の標準料金で、サブスクとは別に請求されます。オンにする前に 月の支出上限 を必ず決めておきましょう。無制限のままだと、エージェントの長い作業1回で思った以上の金額になることがあります。クレジットを使っても、セッションと週の上限のリセット時刻は変わりません。

なお、ヘルプセンターによると、日本で購入した使用量クレジットは 2026年9月10日以降、購入から6か月で失効 します。失効の7日前にメールが届き、期限は使用量画面に表示されます。多めにまとめ買いするより、必要な分だけチャージするほうが安全です。

プランを上げると新しい上限がすぐに適用され、残りの期間は日割りで計算されます。たまにしか上限に当たらないなら、毎月 約13,900円 多く払うより、クレジットを少し使うほうが安く済みます。どちらが合うかは Claude Max vs Pro 比較 で使い方別に整理しています。

日本語で使うと上限の減り方は変わる？

ヘルプセンターが使用量を左右する要因として最初に挙げているのは、メッセージの長さと会話の長さです。同じ内容でも、日本語は英語よりトークンが多くなります。2026年10月16日に Claude Opus 5.5 へ同じ文章と質問を日本語・英語で送って測った結果はこうでした。

  • 同じ意味の文章を書かせると、日本語の出力トークンは英語より65％多くなりました。
  • 同じ日常的な質問5つでは、日本語と英語の差は4％ で、ほとんどありませんでした。日本語の回答が短めにまとまったためです。

Anthropic は上限をトークン数で公開していないので、この差がそのまま上限の差だとは言い切れません。それでも、使用量がメッセージと回答の長さで決まる仕組みである以上、翻訳や長い文章づくりのように出力が多い作業では、日本語のほうが上限を早く使うと考えるのが自然です。測り方と数字は Claude 日本語トークン実測 に詳しく載せています。

長い指示文や毎回貼りつける前提説明を英語にすると、この差を減らせます。トークンカウンターにプロンプトを貼り付けて 💸 トークン節約 を押すと、英語にしたときにどれだけ減るかすぐ分かります。回答は「日本語で答えて」と1行添えれば大丈夫です。

Claude の上限を長持ちさせるコツ

  • 質問はまとめて1回で。 関連する質問を3回に分けて送ると、そのたびに前の会話が読み直されます。前提と質問を1つのメッセージに入れたほうが節約になります。
  • 長い会話は新しく始める。 会話が長くなるほど、1通あたりの使用量が増えます。話題が変わったら新しいチャットを開きましょう。文脈が必要なら、要点をまとめてもらって新しいチャットに貼り付ければ十分です。
  • よく使う資料はプロジェクトに。 ヘルプセンターによると、プロジェクトに入れた資料はキャッシュされ、繰り返し使うときに上限の消費が少なくなります。ただし長く間を空けると、最初のメッセージでまた全部計算されます。
  • 拡張思考と高い effort は必要なときだけ。 要約や翻訳なら低い effort で十分です。effort ごとの違いは Claude Opus 5.5 の effort 比較 で時間と費用を実測しています。
  • 使わないコネクタと Web 検索はオフに。 つないだアプリやツールはリクエストのたびに説明が一緒に送られ、Web 検索は結果を読む分だけ使用量を使います。
  • エージェントの作業は範囲を狭く。 Cowork や Claude Code のように何段階も自分で進める作業は、「どのファイルの何を変えるか」まで指定するほど手順が減ります。Claude Code 向けのコツは Claude Code のトークン節約術9選 にまとめています。

実際に使ってみて

私は無料から Pro、そして Max 5x へと上げてきて、今は Max 5x を使っています。コーディングや外部ツールをつなぐ作業が多くトークンをたくさん使うので Max が合っていて、それ以外の作業だけなら Pro で十分だと感じました。Opus 5 のころは上限を使い切ったことがありますが、Opus 5.5 になってからはまだ上限に当たっていません。

数字で見るとこうなります。Claude Code の記録を使用量アナライザーにかけたところ、17日間の使用量は API 料金に換算すると $145.90 でした。同じ期間の Max 5x の料金の257%にあたる量を、定額で使ったことになります。今週は木曜日に週の上限がリセットされてから9%を使い、そのうち93%が Cowork の作業でした。画面で見ると、上限を早く減らすのは会話の回数より エージェントに任せる長い作業 だということがよく分かります。

まとめ

Claude の使用量上限は、5時間ごとにリセットされるセッション上限と、アカウントごとに決まった曜日・時刻にリセットされる週の上限が同時にかかる仕組みです。Web・アプリ・Claude Code で上限を分け合い、決まったメッセージ数はなく、メッセージと会話の長さ、モデルやツールによって使う量が変わります。

上限に当たったら、まず 設定 > 使用量 でリセット時刻と「無料でリセット」の特典があるかを確認しましょう。すぐに作業を続けたいなら月の支出上限を決めてから使用量クレジットをオンにし、ほぼ毎週止まるようになったらプランを上げる、という順番がいちばんお金がかかりません。長い指示文を日本語で書くことが多いなら、その部分だけ英語にするのも上限を延ばす手軽な方法です。

よくある質問

Claude Pro で5時間に何通送れますか？ 決まった数はありません。Anthropic は、メッセージの長さ、添付ファイル、会話の長さ、モデルや機能によって変わるとだけ案内しています。短い質問が中心ならたくさん送れますが、長い文書やエージェントの作業ではずっと少なくなります。

週の上限は最初のメッセージから7日後にリセットされますか？ 2026年10月時点のヘルプセンターの説明では違います。アカウントごとに決まった曜日・時刻にリセットされ、初めて使った時期や契約日には左右されません。設定 > 使用量の「今週」の下に表示される曜日と時刻を見てください。

Claude Code とチャットは上限が別ですか？ いいえ。claude.ai、デスクトップアプリ、モバイルアプリ、Claude Code は同じ上限を使います。使用量画面の「今週の製品別使用量」で、どれがどれだけ使ったかを分けて確認できます。

使用量クレジットは高いですか？ API の標準料金で使った分だけ払います。軽いチャットなら負担は小さいですが、Opus で長いエージェント作業を回すとすぐに大きくなるので、オンにする前に月の支出上限を決めておきましょう。日本で購入したクレジットは6か月で失効する点にも注意してください。

「無料でリセット」は誰でももらえますか？ ヘルプセンターは「対象のプランにときどき配られる」と説明するだけで、誰が何回もらえるかは公開していません。もらっていれば、設定 > 使用量の上限のリセット欄に期限と一緒に表示されます。

自分の使い方で計算する

サブスクの上限内で使うのと、API で使った分だけ払うのとどちらが安いかは、使用量しだいです。サブスク vs API 計算機にメッセージ数と長さ、言語を入れれば、どちらが安いかすぐに計算できます。Claude Code 側の上限の仕組みは Claude Code の使用量上限まとめ にまとめています。

使用量上限と機能はよく変わります。この記事の内容は、2026年10月16日時点の Anthropic ヘルプセンターの記事と実際の使用量画面に基づいています。
