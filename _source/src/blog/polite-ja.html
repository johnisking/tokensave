AIに敬語を使うとコストは増えるのでしょうか。ChatGPT や Claude に「お疲れ様です。お忙しいところ恐縮ですが…」と書き始め、「よろしくお願いいたします」で締める人は少なくありません。2025年には OpenAI のサム・アルトマン氏が、ユーザーが「please」「thank you」と言うために数千万ドルの電気代がかかっていると冗談めかして答え、ニュースになりました。

日本語はさらに事情が複雑です。英語なら「please」を一語足せば済みますが、日本語は「考えて」が「考えてください」「ご提案いただけますでしょうか」と変わり、文末そのものが長くなります。あいさつとお礼まで付ければ、文はかなり長くなります。一方で AI の料金は文字数ではなくトークン数で決まります。敬語が実際にトークンと費用をどれだけ増やすのかは、測ってみないと分かりません。

そこで Claude Opus 5.5 と Haiku 5.5 に、同じ依頼10件を普通体から最も丁寧な言い方まで4段階で送り、プロンプトのトークン、回答のトークン、費用を比べました。測定日は2026年10月20日、料金は Anthropic の公式料金表（10月20日確認）を基準にしています。同じ方法で韓国語と英語も測りました。金額は1ドル＝158円で換算し、円を先に、ドルを括弧に書いています。

どうやって測ったか

日常で AI によく頼む依頼を10件選びました。メールの件名、Python の質問、デートコース、翻訳、議事録のテンプレート、Excel の VLOOKUP、ブログ記事のタイトル、自己紹介、文章の誤字修正、在宅勤務のコツです。それぞれを4段階の言い方で書きました。

段階 言い方 例
1 普通体 会議の日程変更を知らせるメールの件名を3つ考えて。
2 です・ます（丁寧語） 会議の日程変更を知らせるメールの件名を3つ考えてください。
3 敬語（尊敬語・謙譲語） 会議の日程変更をお知らせするメールの件名を3つご提案いただけますでしょうか。
4 敬語＋あいさつ・お礼 お疲れ様です。お忙しいところ恐縮ですが、会議の日程変更をお知らせするメールの件名を3つご提案いただけますでしょうか。よろしくお願いいたします。

測定には Claude Code 2.1.295 のヘッドレスモードを使いました。システムプロンプトを「You are a helpful assistant.」の一行に差し替え、ツールをすべてオフにして、普通のチャットのように質問1つに回答1つだけを受け取る形にしています。Opus 5.5 で2回、Haiku 5.5 で1回送り、プロンプトのトークンは1文字だけの基準プロンプトとの差で求めました。比較のため GPT のトークナイザー（o200k_base）でも数えています。

敬語にするとプロンプトのトークンはどれだけ増えるか

依頼10件のプロンプトのトークンを、言い方ごとに合計しました。Haiku 5.5 は Opus 5.5 と同じトークナイザーを使うので、トークン数はまったく同じでした。

言い方 Claude のトークン（10件合計） 普通体との差 GPT のトークン（10件合計） 普通体との差
普通体 236 基準 186 基準
です・ます 247 +5% 193 +4%
敬語 328 +39% 247 +33%
敬語＋あいさつ・お礼 619 +162% 414 +123%

「考えて」を「考えてください」にする程度なら、トークンは5％しか増えませんでした。1件目の依頼でいえば、普通体24トークン、です・ます25トークンで、差はちょうど1トークンです。尊敬語・謙譲語を使った敬語は「お知らせする」「ご提案いただけますでしょうか」のように表現そのものが長くなり、39％増えました。

大きく増えたのは、あいさつとお礼を付けたときです。「お疲れ様です。お忙しいところ恐縮ですが」と「よろしくお願いいたします」が付くことで、プロンプトは162％増えました。1件目の依頼は24トークンから67トークンになっています。同じ条件の韓国語（+115％）や英語（+114％）よりも増え方が大きく、日本語の丁寧な決まり文句が長いことが分かります。言語ごとのトークンの違いは Claude 日本語トークンの実測 にまとめています。

回答の長さは変わったか

費用でより大事なのは回答です。丁寧に聞けば、AI も丁寧で長めに答えるかもしれません。Opus 5.5 の回答のトークンと費用を言い方ごとに比べました。2回測った平均です。

言い方 回答のトークン（10件合計） 普通体との差 費用（10件合計） 普通体との差
普通体 5,672 基準 約18.0円（$0.114） 基準
です・ます 6,082 +7% 約19.4円（$0.123） +7%
敬語 6,796 +20% 約21.6円（$0.137） +20%
敬語＋あいさつ・お礼 5,800 +2% 約18.6円（$0.118） +4%

意外だったのは3段階目の敬語です。「ご提案いただけますでしょうか」のように聞いたときは、回答が20％長くなり、費用も20％増えました。ところが、そこにあいさつとお礼まで付けた最も丁寧な言い方では、回答は普通体とほとんど同じ長さに戻りました。

同じプロンプトを2回送ったときでも回答の長さは最大19％ほどぶれたので、この20％を「敬語にすると回答が長くなる」と言い切ることはできません。英語でも「Could you please…?」と聞いたときに回答が21％長くなっており、丁寧な依頼の形が回答を少し長くする可能性はある、という程度に受け取ってください。

Haiku 5.5 では、最も丁寧な言い方の総費用が普通体より15％多くなりました。回答のトークンが14％多く出たためで、Opus 5.5 とは結果が逆でした。回答の長さがその都度変わることが、費用を左右していることが分かります。

結局、費用はどれだけ増えたか

プロンプトが162％増えたのに費用が4％しか増えなかった理由は2つです。

  • 回答のほうがはるかに長い。 普通体の依頼10件のプロンプトは236トークンでしたが、回答は5,672トークンでした。増えた383トークンは、全体から見ればごく一部です。
  • 出力は入力より高い。 Opus 5.5 は入力が100万トークンあたり$4、出力が$20です。出力の単価が入力より400％高いため、費用のほとんどは回答から生まれます。

依頼1件あたりで考えると、あいさつとお礼で増えたプロンプトは平均約38トークン、Opus 5.5 の入力料金で約$0.00015、円にすると約0.02円です。Haiku 5.5 なら入力単価が$0.10なので、さらに約98％安くなります。

韓国語・英語との比較

同じ依頼を韓国語と英語でも4段階の言い方で送りました。最も丁寧な言い方を、最も短い言い方と比べた結果です。

言語 プロンプトのトークン（Claude） プロンプトのトークン（GPT） 総費用（Opus 5.5）
日本語 +162% +123% +4%
韓国語 +115% +78% +1%
英語 +114% +121% ±0%

プロンプトの増え方は日本語が最も大きく、総費用の増え方も日本語が最も大きくなりました。それでも4％です。韓国語は「안녕하세요! 바쁘신데 죄송하지만」、英語は「Hi! Sorry to bother you」と付けても、総費用はほぼ変わりませんでした。

敬語がコストを押し上げるとき

一度送って終わるチャットでは、敬語は費用にほとんど影響しませんでした。ただし、同じ文章が毎回くり返し送られる場所では話が変わります。

  • システムプロンプトとテンプレート: サービスに組み込むシステムプロンプトや、くり返し使うテンプレートは、リクエストのたびに送り直されます。「お疲れ様です」「よろしくお願いいたします」のような表現が入っていると、リクエストの数だけ費用が積み上がります。
  • CLAUDE.md のような指示ファイル: Claude Code は CLAUDE.md を毎回のリクエストと一緒に送ります。トークンセーブの実測では、CLAUDE.md 1KB がリクエストごとに約320トークンを占めました（CLAUDE.md のサイズの実測）。指示ファイルは丁寧な表現より、短い命令形で書くほうが向いています。
  • 長い会話: 会話が長くなると、前のメッセージも毎回一緒に送られます。ただし、キャッシュから読み込むトークンは Opus 5.5 で通常の入力より95％安いので、丁寧な表現が数行あっても大きな差にはなりません。

反対に、自分で直接やり取りする普段のチャットなら、言い方を変えて節約できる金額はほとんどありません。回答を短くしてもらうほうがずっと効果的です。「3行で」「表だけで」のように回答の長さを指定すれば、費用の大部分を占める出力トークンが直接減ります。

自分のプロンプトで測ってみる

よく使うプロンプトが何トークンになるか気になる場合は、トークンカウンターに普通体の版と敬語の版を順番に貼り付けてみてください。モデルごとのトークン数と費用がすぐ分かります。計算はブラウザの中だけで行い、何も送信しません。

今回の120件のプロンプトと、依頼ごとの結果はすべて AI の丁寧語コストの実測データ から CSV でダウンロードできます。CC BY 4.0 なので、出典を明記すれば自由に使えます。

よくある質問

AI に敬語を使うと料金は高くなりますか？ 少し高くなりますが、ほとんど差はありません。今回の測定では、あいさつとお礼まで付けた最も丁寧な言い方でプロンプトのトークンは162％増えましたが、回答を含めた総費用は Opus 5.5 で4％増えただけでした。

普通体で聞くと回答は短くなりますか？ 今回の測定では、普通体と最も丁寧な言い方で回答の長さはほぼ同じでした。尊敬語・謙譲語だけで聞いたときは回答が20％長くなりましたが、同じ質問を2回送ったときのぶれ（最大19％）と同じくらいの差です。

です・ます調と敬語では、どちらが安いですか？ です・ます調のほうが短く済みます。プロンプトのトークンは普通体に比べて、です・ます調が+5％、尊敬語・謙譲語の敬語が+39％でした。ただし金額にすると、依頼1件あたり1円にも届かない差です。

サブスク（Pro、Max）なら関係ないのでは？ サブスクはトークン単位で料金を払いませんが、使用量の上限は使ったぶんだけ減ります。それでも敬語が占める割合は数％なので、上限への影響もほとんどありません。

敬語を使うと回答の質は上がりますか？ 今回の測定ではトークンと費用だけを測り、回答の質は評価していません。

まとめ

Claude に同じ依頼10件を4段階の言い方で送ったところ、あいさつとお礼まで付けた最も丁寧な言い方では、プロンプトのトークンが162％増えました。しかし費用のほとんどは回答から生まれるため、総費用は Opus 5.5 で4％増えただけでした。韓国語（+1％）と英語（±0％）も同じ傾向です。

一人で使うチャットなら、話しやすい言い方で書けば十分です。システムプロンプトや CLAUDE.md のように毎回くり返し送る文章は短い命令形にして、費用を抑えたいなら言い方より回答の長さを指定するほうがはるかに効果があります。測定は Opus 5.5 で2回、Haiku 5.5 で1回なので、小さな差は回数を増やすと変わる可能性があります。
