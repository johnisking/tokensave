클로드 코드는 강력하지만 토큰을 많이 먹습니다. 작업 하나에 100만 토큰 넘게 모델로 보내는 경우도 흔해서, Pro·Max 한도가 금방 바닥나거나 API 청구서에 그대로 찍힙니다. 다행히 그중 상당 부분은 클로드 코드가 해 주는 일은 그대로 두고도 줄일 수 있는 낭비입니다. 효과가 큰 순서대로 정리했습니다.

토큰이 쌓이는 이유

클로드 코드는 단계별로 일하고, 단계마다 작업 맥락 전체를 다시 보냅니다. 지시문, 도구 정의, 읽은 파일, 이전 단계까지 전부입니다. 시작 맥락 22,000토큰에 단계마다 3,500토큰씩 늘어나는 25단계 기능 작업이면 입력 토큰이 모두 약 160만 개입니다. 그래서 맥락을 줄이거나 작업을 짧게 만드는 건 무엇이든 매 단계마다 효과가 납니다.

1. 작업을 작고 구체적으로

비용을 가장 크게 좌우하는 것은 단계 수입니다. 비교해 보세요.

  • "인증 모듈 정리해 줘" → 범위가 열려 있어 수십 단계.
  • "tests/auth_test.py에서 실패하는 테스트 고쳐 줘. 토큰 만료 확인이 하나 어긋나 있어" → 몇 단계.

큰 일을 명확한 작은 작업으로 나누면, 막연한 요청 하나보다 전체 토큰이 훨씬 적게 들고 결과도 좋아지는 경우가 많습니다.

2. 관련 없는 작업 사이에는 새로 시작

긴 세션은 새 단계마다 지금까지의 기록 전체를 끌고 갑니다. 다른 일로 넘어갈 때는 /clear를 치세요. 같은 작업을 이어가는데 세션이 너무 길어졌다면 /compact로 기록을 요약으로 바꾸세요.

3. 어디를 보면 되는지 알려 주기

찾는 데도 단계가 들고, 한 번 읽은 파일은 계속 맥락에 남습니다. 관련 파일을 알면 이름을 대 주세요. "src/billing/invoice.ts의 calculateTax 근처가 문제야"라고 하면 파일 열 개 대신 하나만 읽습니다.

4. CLAUDE.md는 짧게

프로젝트 지시문은 모든 작업의 모든 단계마다 같이 전송됩니다. 2,000토큰짜리 CLAUDE.md는 25단계 작업에서 입력 토큰 50,000개를 더합니다. 빌드·테스트 명령어, 클로드가 자주 틀리는 규칙처럼 꼭 필요한 것만 남기고, 긴 배경 설명은 필요할 때 읽을 수 있는 별도 파일로 빼세요.

5. 지시문은 영어로 쓰기

한국어로 프롬프트를 쓰신다면 가장 쉬운 절약입니다. GPT 토크나이저 기준으로 같은 내용이 한국어는 영어보다 토큰이 약 44% 더 들어서, 영어로 쓰면 약 31% 줄어듭니다. Claude의 토크나이저는 다르지만, 한국어가 영어보다 토큰을 더 쓰는 건 마찬가지입니다. CLAUDE.md와 긴 지시문은 영어로 쓰고 "Reply in Korean."으로 답만 한국어로 받으세요. 토큰세이브 토큰 계산기의 💸 토큰 절약 버튼을 누르면 내 기기 안에서 영어로 바꿔 주고 몇 % 줄었는지 보여줍니다.

6. 로그를 통째로 붙이지 않기

테스트 전체 실행 결과나 빌드 로그는 수천 줄일 수 있습니다. 첫 번째 에러와 스택 트레이스면 정보는 거의 다 들어 있습니다. 그 부분만 붙이거나, 실패하는 테스트 하나만 돌리라고 하세요.

7. 파일 전체 말고 바뀐 부분만

출력 토큰이 가장 비쌉니다. Sonnet 5.5 기준 출력은 100만 토큰당 $10, 입력은 $2입니다. 두 줄 고치고 파일 전체를 다시 쓰게 하면 바뀌지 않은 줄까지 출력 가격을 냅니다.

8. 작업에 맞는 모델 고르기

API에서 Claude Opus 5.5는 Sonnet 5.5보다 토큰당 100% 비싸고, 요금제에서는 한도를 더 빨리 씁니다. /model로 바꾸세요. 대부분의 코딩은 Sonnet, 어려운 설계나 까다로운 버그는 Opus, 단순 반복 수정은 Haiku면 됩니다.

9. 캐시가 일하게 두기

클로드 코드는 반복되는 맥락을 자동으로 캐시하고, 캐시된 입력은 보통 가격의 약 10%입니다. 세션 중간에 CLAUDE.md를 고치지 않고, 같은 작업을 잇는데 굳이 세션을 다시 시작하지 않는 것만으로도 도움이 됩니다.

얼마나 차이 날까

토큰세이브 코딩 에이전트 비용 계산 모델 기준으로, Sonnet 5.5에서 일반적인 기능 작업 하나는 캐싱을 켜고 약 $0.72입니다. 정확한 지시와 파일 위치를 줘서 25단계를 15단계로 줄이면 약 $0.40으로 내려갑니다. 작업마다 새 세션으로 시작하면 시작 맥락도 작게 유지됩니다. 한 달에 작업 100개라면 주간 한도에 걸리느냐 안 걸리느냐가 갈리는 차이입니다.
