Claude Code は強力ですが、トークンをたくさん使います。1つのタスクで100万トークン以上をモデルに送ることも珍しくなく、Pro・Max の上限がすぐに尽きたり、API の請求額にそのまま表れたりします。幸い、その多くは Claude Code にやってもらうことは変えずに減らせるムダです。効果の大きい順にまとめました。

トークンが積み上がる理由

Claude Code はステップごとに作業し、ステップのたびに作業コンテキスト全体を送り直します。指示、ツール定義、読んだファイル、それまでのステップのすべてです。開始時のコンテキストが22,000トークンで、1ステップごとに3,500トークン増える25ステップの機能タスクなら、入力トークンは合計で約160万になります。だから、コンテキストを小さくすること、タスクを短くすることは、どんなことでも毎ステップ効いてきます。

1. タスクは小さく具体的に

ステップ数がいちばん大きな倍率です。比べてみてください。

  • 「認証モジュールを整理して」→ 範囲があいまいで数十ステップ。
  • 「tests/auth_test.py の失敗しているテストを直して。トークンの有効期限チェックが1つずれている」→ 数ステップ。

大きな仕事を明確な小さいタスクに分けると、あいまいな依頼1つより合計トークンがずっと少なく済み、結果も良くなることが多いです。

2. 関係のないタスクの間は新しく始める

長いセッションは、新しいステップのたびにそれまでの履歴をすべて引きずります。別の作業に移るときは /clear を実行しましょう。同じ作業を続けたいけれどセッションが長くなりすぎたら、/compact で履歴を要約に置き換えましょう。

3. どこを見ればいいか伝える

探すのにもステップがかかり、一度読んだファイルはコンテキストに残り続けます。関係するファイルが分かっているなら名前を伝えましょう。「src/billing/invoice.ts の calculateTax あたりが原因」と言えば、10ファイルではなく1ファイルを読むだけで済みます。

4. CLAUDE.md は短く

プロジェクトの指示は、すべてのタスクのすべてのステップで一緒に送られます。2,000トークンの CLAUDE.md は、25ステップのタスクで入力トークンを50,000増やします。ビルド・テストのコマンドや、Claude がよく間違えるルールなど本当に必要なものだけ残し、長い背景説明は必要なときに読める別ファイルに移しましょう。

5. 指示は英語で書く

日本語でプロンプトを書いているなら、いちばん手軽な節約です。GPT のトークナイザーでは、同じ内容が日本語だと英語の約1.79倍のトークンになるため、英語で書けば約44%減ります。Claude のトークナイザーは別物ですが、日本語が英語よりトークンを多く使うのは同じです。CLAUDE.md や長い指示は英語で書き、「Reply in Japanese.」で回答だけ日本語にしましょう。TokenSave のトークンカウンターで 💸 トークン節約 ボタンを押すと、自分の端末の中で英語に変換し、何%減ったかを表示します。

6. ログを丸ごと貼らない

テスト全体の実行結果やビルドログは数千行になることがあります。最初のエラーとスタックトレースに、必要な情報はほぼ入っています。その部分だけ貼るか、失敗しているテスト1つだけを実行するよう頼みましょう。

7. ファイル全体ではなく変更点だけ

出力トークンがいちばん高価です。Sonnet 5.5 では出力が100万トークンあたり$10、入力は$2です。2行直したあとにファイル全体を書き直させると、変わっていない行にまで出力料金を払うことになります。

8. タスクに合ったモデルを選ぶ

API では Claude Opus 5.5 は Sonnet 5.5 の2倍のトークン単価で、プランでは上限を早く消費します。/model で切り替えましょう。ほとんどのコーディングは Sonnet、難しい設計や厄介なバグは Opus、単純な繰り返しの修正は Haiku で十分です。

9. キャッシュに働いてもらう

Claude Code は繰り返し送るコンテキストを自動でキャッシュし、キャッシュされた入力は通常価格の約10%です。セッションの途中で CLAUDE.md を書き換えない、同じ作業を続けるのにわざわざセッションを立ち上げ直さない、それだけでも効果があります。

どれくらい差が出るか

TokenSave のコーディングエージェント費用モデルでは、Sonnet 5.5 での一般的な機能タスクはキャッシュありで約$0.72です。正確な指示とファイルの場所を伝えて25ステップを15ステップに減らすと、約$0.40まで下がります。タスクごとに新しいセッションで始めれば、開始時のコンテキストも小さく保てます。月に100タスクなら、週の上限に当たるかどうかが分かれるほどの差です。

使用量を確認する

Claude Code で /status を実行すると、残りの使用量が表示されます。上限そのものの仕組みは Claude Code の使用量上限まとめ、プランと API の比較は Claude Code の月額料金をご覧ください。
