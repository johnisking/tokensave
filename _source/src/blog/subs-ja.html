ChatGPT、Claude、Gemini、Grok は、それぞれ有料プランを3〜5つ用意しています。名前もバラバラで、支払い通貨も違う（ChatGPT・Google は円、Claude・Grok はドル）ので、ひと目では比べにくくなっています。日本で実際に払う金額で一つの表にまとめ、どのプランが誰に向いているかまで整理しました。

日本の料金 早見表

2026年10月6日確認。円の料金は各社の日本向け表示価格、ドル払いは税込の金額を1ドル＝158円で換算しています。

  • ChatGPT: 円建て・税込です。Pro は使用量に応じて複数のティアがあり、上位ティアは新規受付を止めている時期があります。
  • Claude: 日本ではドル建てで、消費税10%込みの価格が表示されます。年払いなら Pro は月約2,900円相当です。カード会社によっては海外決済の手数料がかかります。
  • Google: 円建てです。18歳以上の大学生は AI Plus を1年間無料で使える特典があります。
  • Grok: ドル建てです。米国価格で SuperGrok Lite $10、SuperGrok $30、SuperGrok Plus $100、SuperGrok Heavy $300 です。

同じ3,000円でも中身は違う

3,000円前後の基本プランは、3社ともほぼ同じ値段です。ほとんどの人はこのクラスで十分です。違いは値段よりも何に使うかで出ます。

  • ChatGPT Plus: 画像生成、音声、ディープリサーチ、カスタム GPT まで、機能の幅が一番広いです。Codex と ChatGPT Work も含まれます。
  • Claude Pro: 長文やコーディングに強く、Claude Code が含まれます。ただし5時間と週の上限があり、たくさん使うとすぐ止まります。
  • Google AI Pro: 5TB のストレージ、Gmail・ドキュメント・スプレッドシートの中の Gemini がセットです。Google のサービスをよく使うなら一番お得です。

1,000円前後のプランは要注意

  • ChatGPT Go（1,400円）: 会話のモデルは小さい GPT-5.6 Luna で、広告が表示されることがあります。普段の会話は無料でも無制限なので、Go で増えるのはアップロード・画像・メモリの上限です。詳しくはChatGPT Go と Plus の違いへ。
  • Google AI Plus（725円）: まもなく Pro モデルが使えなくなります。400GB のストレージが必要な人には今も悪くありません。Gemini 無料版の変更まとめを参照してください。

サブスクは本当に必要？

4社とも、使った分だけ払う API も売っています。軽い使い方なら API のほうがずっと安く済みます。ただし日本語は同じ内容でも英語よりトークンが約79%多く出るので、日本語でたくさん使う人ほど、定額のサブスクが相対的に有利になります（日本語は英語よりトークンが多い？）。画像生成、音声、ディープリサーチなど API にない機能を使うなら、サブスクが向いています。

自分の使い方で月の API 料金と各プランを並べて見るなら、サブスク vs API 計算機を使ってみてください。Claude Code や Codex などのコーディングエージェントはエージェント費用計算機で計算できます。
