커서(Cursor)를 쓰려는데 "월 $20인데 요금 폭탄을 맞았다"는 이야기가 걸리시나요? 예전에 많이 알려진 노멀·맥스 모드 설명은 지금 요금 구조와 다릅니다. 2026년 10월 11일, 커서 공식 가격 페이지와 공식 문서를 다시 확인하고, Windows PC에 커서를 직접 설치해 무료 플랜으로 Claude Code 실측 때와 똑같은 벽돌깨기 게임 요청을 시켜 봤습니다. 요금제 가격, 지금 과금 방식, 무료 플랜이 실제로 해낸 것, 모델별 한 달 비용, 커서의 장단점까지 정리했습니다.

커서 공식 가격 페이지 기준입니다(2026년 10월 11일 확인). 가격은 세금 별도이고, 원화는 1달러 1,342원(10월 9일 환율)으로 계산한 참고값입니다.

노멀·맥스 모드는 이제 옛날 이야기

예전 설명은 "Pro는 월 500회 빠른 요청, 다 쓰면 느린 요청, 맥스 모드는 토큰만큼 따로 과금"이었습니다. 지금 커서 공식 문서 기준으로는 이렇게 바뀌었습니다.

  • 요청 횟수가 아니라 사용량(토큰)으로 차감합니다. 요금제마다 정해진 사용량이 있고, 쓴 토큰만큼 모델의 API 가격으로 깎입니다.
  • 사용량 주머니가 두 개입니다. 커서 자체 모델(Grok 4.7·4.6·4.5, Composer 2.5) 주머니와, Claude·GPT·Gemini 같은 다른 회사 모델 주머니입니다. 커서는 자체 모델 쪽 포함 사용량이 "훨씬 많다"고 안내합니다.
  • 맥스 모드는 예전 요청 단위 요금제에서만 남아 있습니다. 지금 요금제에서는 해당하지 않습니다.
  • 다 쓰면 두 가지 중 하나입니다. 같은 API 가격으로 추가 사용을 켜서 나중에 청구받거나, 더 높은 요금제로 올립니다.
  • 공식 문서에 없는 것: 요금제마다 포함된 사용량이 달러로 얼마인지는 나와 있지 않습니다. 그래서 "Pro면 정확히 몇 번 된다"는 계산은 할 수 없습니다.

커서 공식 안내의 대략적인 기준은 이렇습니다. 자동완성(Tab)만 매일 쓰거나 에이전트를 가끔 쓰면 보통 포함 사용량 안에서 끝나고, 에이전트를 매일 쓰면 한 달 총 $60~100, 에이전트 여러 개를 돌리는 파워 유저는 $200 이상이 흔하다고 합니다.

무료 플랜으로 직접 써 보니

Windows PC에 커서를 설치하고 무료 플랜으로 가입한 뒤, Claude Code 실측 때와 똑같은 요청을 넣었습니다. 브라우저용 벽돌깨기 게임을 HTML 파일 하나로, 레벨 2개, 점수, 목숨 3개, 키보드·마우스 조작으로 만들어 달라는 영어 요청입니다.

항목 결과
모델 자동(Auto) 선택, 실제로는 Grok 4.6 (medium)
걸린 시간 1분 31초 (커서 화면 표시)
게임 코드 398줄, 오류 없이 실행
쓴 무료 사용량 한 달 한도의 15%
  • 무료 플랜에서는 모델을 고를 수 없습니다. Claude 소넷 5.5 같은 모델을 고르려고 하면 Pro로 업그레이드하라고 나옵니다.
  • 한 번에 15%면, 이 정도 작은 게임을 한 달에 6번쯤 하면 끝납니다. 더 큰 작업은 더 빨리 닳습니다.
  • 게임은 깔끔하지만 밋밋했습니다. 둥근 벽돌, 그라데이션 배경, 2레벨에서 좁아지는 패들과 빨라지는 공, 윗줄일수록 높은 점수까지 있었지만, 파티클·효과음·최고 점수 저장은 없었습니다.

같은 요청을 Claude Code로 돌렸을 때는 소넷 5.5 medium이 37초, high가 58초였습니다. 자세한 결과는 클로드 소넷 5.5 vs 오퍼스 5.5 실측 비교에 있습니다.

모델별 한 달 비용 계산

커서는 Claude를 API 가격 그대로 차감하므로, Claude Code 실측 비용이 좋은 기준이 됩니다. 같은 게임 요청의 비용은 이랬습니다.

소넷 5.5 · high $0.30

이 크기의 작업을 하루 10번, 한 달 22일(220번) 한다고 단순 계산하면 이렇습니다.

  • 소넷 5.5 high: 한 달 약 $66 (약 8만 9천원)
  • 오퍼스 5.5 high: 한 달 약 $165 (약 22만 1천원)

커서 공식 안내의 "에이전트를 매일 쓰면 $60~100"과 비슷한 범위입니다. 다만 커서는 자체 지시문과 맥락을 붙여 보내서 Claude Code와 토큰 수가 똑같지 않고, 실제 작업 크기도 제각각이라 대략적인 값으로 보셔야 합니다.

커서 장단점 (Claude Code와 비교)

커서 공식 문서와 직접 테스트한 결과를 바탕으로 정리했습니다.

장점

  • 싼 자체 모델이 있습니다. Composer 2.5($0.50/$2.50)와 Grok 4.6($2/$6)은 Claude나 GPT보다 싸고, 포함 사용량이 더 많은 별도 주머니에서 차감됩니다.
  • 여러 회사 모델을 한 편집기에서 씁니다. Claude, GPT, Gemini, Grok, Muse Spark를 설정에서 켜고 끌 수 있습니다.
  • Claude 가격이 같습니다. Claude 소넷 5.5와 오퍼스 5.5는 Anthropic API와 같은 토큰 가격으로 차감됩니다.
  • 무료로 써 볼 수 있습니다. 직접 테스트에서 1분 31초 만에 작동하는 게임을 돈 없이 만들었습니다.

단점

  • 같은 모델이어도 결과가 같지 않습니다. 도구마다 모델에 붙이는 지시문과 맥락이 달라서, 커서의 소넷 5.5와 Claude Code의 소넷 5.5는 똑같이 움직이지 않습니다.
  • 요금제 가격을 넘어설 수 있습니다. 포함 사용량을 다 쓴 뒤 추가 사용을 켜면 모든 요청이 토큰 단위 API 가격으로 청구되므로, 큰 맥락이나 비싼 모델은 금방 쌓입니다.
  • 미리 계산하기 어렵습니다. 요금제별 포함 사용량이 달러로 공개돼 있지 않습니다.
  • 무료 플랜은 제약이 큽니다. 모델을 고를 수 없고, 작은 게임 하나에 한 달 한도의 15%를 썼습니다.

요금 폭탄 피하는 법

  • 추가 사용은 꺼 둡니다. 포함 사용량이 얼마나 빨리 닳는지 알기 전까지는 켜지 않습니다.
  • 큰 작업은 작게 나눠 시킵니다. 가장 비싼 모델에 거대한 요청 하나를 맡기지 않습니다.
  • 평소 수정은 Composer나 Grok으로 합니다. 어려운 부분만 Claude 오퍼스나 GPT-5.6 Sol을 씁니다.
  • 사용량 화면을 매주 확인합니다. 두 주머니가 설정과 사용량 화면에 모두 나옵니다.

커서 Hobby Pro $20 Pro+ $60 Ultra $200
Claude (Claude Code 포함) 무료, Claude Code 없음 Pro $20 Max 5x $100 Max 20x $200
GitHub Copilot 무료 Pro $10 Pro+ $39 Max $100

  • Claude Code는 Claude Pro와 Max에 포함됩니다. 무료 Claude에는 없습니다. Anthropic 가격 페이지에 따르면 Max 요금제에는 Claude Platform에서 쓸 수 있는 월 $100~200 API 크레딧도 들어 있습니다.
  • GitHub Copilot이 가장 싼 $10부터 시작합니다. 가격 페이지에는 월 크레딧이 Pro $15, Pro+ $70, Max $200으로 나와 있습니다.
  • Devin의 Pro와 Max는 커서 Pro·Ultra와 가격이 같습니다. 팀 요금제는 월 $80에 개발자 1인당 $40이 붙습니다.
  • 표에 적힌 가격이 전부는 아닙니다. 커서와 Devin은 한도를 넘기면 API 가격으로 추가 사용을 살 수 있어서, 에이전트를 많이 쓰면 요금제 가격보다 더 나올 수 있습니다.

결론: 무료로 써 보고, 매일 쓰면 Pro+

  • 무료 플랜은 체험판입니다. 작은 게임을 1분 31초 만에 만들었지만, 한 달 한도의 15%를 쓰고 모델도 고를 수 없었습니다.
  • Pro $20은 가볍게 쓸 때 맞습니다. 에이전트를 매일 쓰면 월 $60~100이 들어서 커서도 Pro+를 추천합니다.
  • 요금제보다 모델 선택이 더 중요합니다. 실측에서 오퍼스 5.5 high는 소넷 5.5 high보다 1회 비용이 150% 많았고($0.75 vs $0.30), Composer와 Grok은 그보다 더 쌉니다.
  • 요금 폭탄은 추가 사용 관리로 막습니다. 노멀·맥스 모드 시절과 달리 지금은 모든 사용이 토큰 기준이라, 추가 사용을 켜기 전에 사용량부터 확인하는 게 가장 확실합니다.

자주 묻는 질문

커서는 무료인가요? 네. Hobby 플랜은 카드 등록 없이 무료지만 에이전트 요청이 제한되고 모델은 자동으로 정해집니다. 직접 테스트에서는 작은 게임 하나에 한 달 한도의 15%를 썼습니다.

커서 Pro는 얼마인가요? 월 $20(약 2만 7천원)이고 세금 별도입니다. Pro+는 $60, Ultra는 $200입니다.

커서에서 Claude를 쓰면 더 비싼가요? 개인 요금제에서는 아닙니다. 커서는 Claude 소넷 5.5를 100만 토큰당 $2/$10, 오퍼스 5.5를 $4/$20으로 차감하는데, Anthropic API와 같은 가격입니다. Teams와 Enterprise는 다른 회사 모델에 100만 토큰당 $0.25가 더 붙습니다.

커서 학생 할인이 있나요? 상시 할인은 없습니다. 커서 학생 페이지에는 누구나 무료로 시작할 수 있고, 업그레이드는 대학·온라인 행사의 프로모션으로 제공된다고 나와 있습니다. "학생은 1년 무료"라는 예전 글은 지금과 다를 수 있으니 학생 페이지를 먼저 확인하세요.

맥스 모드는 아직 있나요? 공식 문서 기준으로 맥스 모드는 예전 요청 단위 요금제에서만 쓸 수 있습니다. 지금 요금제는 모든 사용량을 토큰 단위로 차감합니다.

내 작업으로 계산해 보기

코딩 에이전트 비용 계산기에서 작업 크기와 하루 작업 수를 넣으면 오퍼스 5.5, 소넷 5.5 등 모델별 한 달 비용을 비교할 수 있습니다. 프롬프트 하나의 비용은 토큰 계산기에서 확인하세요.

2026년 10월 11일 가격 확인. 무료 플랜 테스트는 1회 결과이며, 자동으로 고른 모델과 작업 크기에 따라 달라질 수 있습니다.
