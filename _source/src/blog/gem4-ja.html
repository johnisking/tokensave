Google は2026年9月30日、新しい最上位モデル Gemini 4 Argon を発表しました。コーディング、サイバーセキュリティ、長時間のエージェント作業に重点を置いたモデルで、Google は複数のベンチマークで GPT-6 Astra や Claude Fable・Opus を上回ると説明しています。API 料金、1リクエストあたりの実費、GPT・Claude との比較をまとめました。

Gemini 4 Argon の API 料金

100万トークンあたりの料金です。最初は導入価格で始まり、その後に通常価格へ切り替わります。

区分 入力 キャッシュ入力 出力
導入価格 $2 約 $0.10 $10
通常価格 $4 約 $0.20 $20

キャッシュ入力は通常の入力から95%割引なので、同じ指示や文書を繰り返し送る作業では大きな差になります。導入価格がいつまで続くかはまだ公表されていません。

1回の応答で最大 100万トークンを出力 できるのも特徴です。ただし出力が長いほど費用も増え、100万トークン出力すると通常価格で1回 $20 になります。

もう使える？

まだです。現在は Google のサイバー防御パートナー向けプログラム（Fairwind）参加組織だけに提供されており、Google AI Ultra 加入者と有料 API ユーザーには順次展開される予定です。API のモデル ID は gemini-4-argon と報じられていますが、公式ドキュメントにはまだ載っていません。

他のモデルは2026年10月に確認した公式 API 料金です。

ポイントは次のとおりです。

  • 通常価格は Claude Opus 5.5 とまったく同じです（入力 $4、出力 $20）。
  • 導入価格は GPT-6 Sol や Claude Sonnet 5.5 と同じです。最上位モデルを中位モデルの価格で使える期間です。
  • 通常価格でも GPT-6 Astra や Claude Fable 5.1 より2.5倍安いです。Google の発表どおりの性能なら、最上位モデルの中でいちばんコスパの良い選択肢になります。
  • Gemini 3.1 Pro よりは高いです。通常価格で1リクエストあたり約1.8倍。3.1 Pro で足りている作業なら、乗り換える理由はありません。

どんな作業に使う？

向いている作業： 大規模なコード修正や移行、セキュリティ診断、何段階も続く長いエージェント作業、長い動画やグラフの分析。ミスのコストが高い作業ほど価値があります。

使わなくてよい作業： 要約、翻訳、分類、短い回答。これらは Gemini 3.8 Flash が1リクエストあたり約5分の1の費用で十分こなします。

普段は Flash や 3.1 Pro で処理し、難しいリクエストだけ Argon に回すのが一般的な使い方です。

費用を抑えるコツ

  1. 導入価格のうちに試す。 通常価格の半額なので、自分の作業に合うか試すには最適な時期です。
  2. キャッシュを使う。 キャッシュ入力は95%割引です。固定の指示や文書はプロンプトの先頭に置きましょう。
  3. 出力の長さを絞る。 最大100万トークンまで出力できますが、出力は入力の5倍の価格です。必要な分だけ答えるよう指示しましょう。
  4. プロンプトを英語にする。 日本語のプロンプトは同じ内容でも英語よりトークンが多くかかります。トークンカウンターの 💸 トークン節約 ボタンで、端末内ですぐ英語に変えられます。
