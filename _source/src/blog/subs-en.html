What the limits actually limit

  • ChatGPT: since August 6, 2026, everyday text chat has no cap on any plan. Limits apply to the newest models, file uploads, images, voice, ChatGPT Work and Codex. See ChatGPT usage limits.
  • Claude: every plan has a rolling 5-hour limit and a weekly limit, shared between the Claude app and Claude Code. See Claude Code usage limits and how many tokens you get with Claude Pro and Max.
  • Google: the Ultra tiers are named by their usage multiple; Google's newest model, Gemini 4 Argon, is rolling out to AI Ultra subscribers first.
  • Grok: limits are a weekly usage pool that grows with each tier; xAI does not publish the sizes. SuperGrok Heavy, the top tier, also includes X Premium+.

Do you need a subscription at all?

Every one of these companies also sells its models through an API, where you pay only for what you use. For light and medium chat, the API is often much cheaper. On GPT-6 Sol, a typical message in an ongoing conversation costs about a cent, so $20 buys roughly 1,800 messages a month; below that, paying per token wins. On a small model like GPT-6 Luna, a month of daily chatting can cost under a dollar.

A subscription wins when:

  • you chat a lot, with long conversations or documents (every message re-sends the whole chat),
  • you use the extras — image generation, voice, deep research, file uploads — which a plain API does not include,
  • you use a coding agent such as Claude Code or Codex for hours a day, or
  • you write in a language that needs many more tokens than English (Korean about 44% more, Japanese about 79% more), which you pay for on the API but not on a plan.

Which one to choose

  • Just trying AI, or light use: a $20 plan is plenty, or the API with a small model if you are comfortable with a third-party chat app.
  • Heavy chat, images and voice: ChatGPT Plus or Google AI Pro.
  • Coding with an agent most of the day: Claude Max 20× is the best value per unit of usage; ChatGPT Pro if you live in Codex.
  • Hitting your plan's limit every week: go up one tier, not two. On ChatGPT you pay the same per unit at every Pro tier, so buy the smallest one you do not run out on.

Prices and limits change often. Grok prices are from third-party trackers that checked xAI's plans page; check each company's pricing page before you subscribe.
