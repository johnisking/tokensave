ChatGPT、Claude、Gemini、Grok 現在各自有 3 到 5 個付費方案，名稱不一樣，計價幣別也不一樣（Google 和 ChatGPT 的 App Store 用新台幣，Claude、Grok 用美元），很難一眼比較。我們把台灣實際要付的價格整理成一張表，也整理了各方案適合誰。

同樣 NT$650～690，內容不一樣

主力方案三家價格幾乎一樣，大部分人用這個等級就夠了。差別不在價格，而在你主要拿來做什麼。

  • ChatGPT Plus: 生成圖片、語音、深度研究、自訂 GPT，功能最廣，也包含 Codex 和 ChatGPT Work。
  • Claude Pro: 長篇寫作和寫程式很強，包含 Claude Code。但有 5 小時和每週上限，用得多很快就會被擋。
  • Google AI Pro: 雲端空間、Gmail・文件・試算表裡的 Gemini 都包在一起。常用 Google 服務的人最划算。

NT$300 以下的方案要注意

  • ChatGPT Go（NT$270）: 聊天模型是較小的 GPT-5.6 Luna，而且有廣告、不能關。一般聊天免費版也不限次數，所以 Go 多給的主要是上傳、圖片、記憶的額度。詳見ChatGPT Go 與 Plus 差在哪。
  • Google AI Plus（NT$260）: 即將不能用 Pro 模型，需要 200GB 雲端空間的人還是划算。詳見Gemini 免費版只剩 Flash-Lite。

付款小提醒

  • 美元計價的方案會有海外刷卡手續費，金額也會隨匯率變動。用海外消費回饋高的信用卡可以省一點。
  • 不要買共享帳號或代儲值。 可能違反服務條款而被停權，對話內容也可能被別人看到。
  • 香港用戶: ChatGPT 和 Claude 並未正式支援香港地區，Gemini 則可以直接使用。訂閱前請先確認各家的官方支援地區。

一定要訂閱嗎？

四家都有用多少付多少的 API。用得少的話，API 便宜很多。繁體中文表達同樣的內容，需要的 Token 比英文多約 35%（繁體中文在 GPT 要多少 Token？），用得越多，定額的訂閱就相對越划算。要用生成圖片、語音、深度研究這些 API 沒有的功能，就選訂閱。

想看自己的用法每月 API 要花多少、和各方案並排比較，可以用訂閱 vs API 計算機。Claude Code、Codex 這類寫程式代理，請用程式代理費用計算機。
