「usage limit reached（使用量の上限に達しました）」は、Claude Code を使っているといちばんよく見るメッセージのひとつで、いちばん分かりにくいメッセージでもあります。2種類の上限が同時に働いているからです。仕組み、2026年に変わったこと、上限に当たったときの対処法をまとめました。

上限は2種類

1. 5時間のセッション上限。最初のメッセージを送った時点から5時間単位で使用量を測ります。その5時間で使える分を使い切ると、リセットされるまで待つ必要があります。

2. 週の上限。セッション上限とは別に、1週間の合計使用量にも上限があります。一部のアカウントが Claude Code を24時間動かし続けるのを防ぐため、2025年8月に導入されました。これに当たると、5時間のセッションが新しく始まっていても、週のリセットまで待つことになります。

どちらの上限も Claude Code と Claude アプリ（Web・デスクトップ・モバイル）で共有です。アプリで長い会話をすると、コーディングに使える分も減ります。

プランごとの使用量

Anthropic は正確なトークン数ではなく、プラン同士の倍率で説明しています。

プラン 料金 使用量
Pro 月$20 基準
Max 5× 月$100 Pro の5倍
Max 20× 月$200 Pro の20倍

実際にどこまで持つかは作業内容で大きく変わります。大きなファイル、長いセッション、Opus は、Sonnet で短いタスクをするよりずっと早く上限を消費します。ステップごとに作業コンテキスト全体を送り直すからです。

2026年に変わったこと

  • 2026年5月6日：Anthropic が Pro・Max・Team・シート制 Enterprise プランで Claude Code の5時間上限を2倍にしました。Pro・Max のピーク時間帯の上限引き下げも廃止されました。
  • 2026年夏：週の上限に50%の一時的な引き上げが適用されていました。
  • 2026年9月14日：Pro・Max・Team・シート制 Enterprise の標準の週上限を恒久的に25%引き上げました。ただし50%の一時増量を置き換えたものなので、夏と比べると約17%少なくなっています。元の水準よりは25%多い状態です。

9月中旬以降、週の上限に早く当たるようになったと感じているなら、それは気のせいではありません。

残りの使用量を確認する

Claude Code で /status コマンドを実行すると、残りの使用量を確認できます。上限に近づくと Claude Code が警告も出してくれます。長いタスクは途中ではなく、始める前に確認しましょう。

上限に当たったら

  1. リセットを待つ。5時間上限なら、たいてい数時間で解除されます。
  2. 追加使用（usage credits）を有効にする。有料プランなら、止まらずに別課金のクレジットで続けられます。
  3. API クレジットに切り替える。Claude Code は従量課金の API でも動きます。切り替える前に必ず同意を求められます。
  4. プランを上げる。Pro → Max 5×、Max 5× → Max 20×。
  5. 1タスクあたりのトークンを減らす。実はいちばん安い解決策です。下をご覧ください。

思ったより早く上限に当たる理由

  • 長いセッション。ステップごとにそれまでの内容をすべて送り直します。2時間のセッションは、新しいステップのたびに巨大なコンテキストを引きずります。
  • Opus。Sonnet より上限を早く消費します。
  • 大きなファイルやログ。3,000行のファイルやテストログ全体を読むと、数万トークンが加わります。
  • あいまいな指示。「プロジェクトを整理して」は数十ステップ、「auth.py の失敗しているテストを直して」なら数ステップで終わります。
  • Claude アプリとの同時利用。同じ上限から引かれます。
  • 日本語の指示文。同じ内容でも、日本語は英語よりトークンが多くかかります（GPT のトークナイザーで約1.79倍）。

上限を長持ちさせるには

  • 関係のないタスクの間は /clear で新しく始め、長くなったセッションは /compact で要約しましょう。
  • Claude に探させず、どのファイルを見ればいいか伝えましょう。
  • CLAUDE.md の指示は短く。毎ステップ一緒に送られます。
  • 普段は Sonnet、難しい問題だけ Opus を使いましょう。

具体的な方法と数字は Claude Code のトークン節約術にまとめています。

プランか API か

週の上限によく当たるなら、その追加分を API で払った場合と、ひとつ上のプランを比べてみましょう。Claude Code の月額料金とコーディングエージェント費用計算機で計算できます。

上限は変わります。最新のルールは Anthropic の Claude Code プランのヘルプと料金ページで確認してください。
