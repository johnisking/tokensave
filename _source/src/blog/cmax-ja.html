Claude Pro は月$20、Claude Max は$100か$200です。どちらも Claude アプリと Claude Code が使えるので、問題はシンプルです。増える使用量は、5倍や10倍の料金に見合うのか。多くの人にとっては見合いません。ただし Claude Code をヘビーに使う人にとっては、Max 20× が Anthropic のプランの中でいちばんお得です。

プラン一覧

米国の料金（2026年10月確認）です。料金はドル建てなので、円での支払額は為替によって変わります。

プラン 料金 使用量 「Pro 1つ分」の使用量あたりの料金
Pro 月$20（年払いなら$17） 基準 $20
Max 5× 月$100 Pro の5倍 $20
Max 20× 月$200 Pro の20倍 $10

3つとも Claude Code を含み、Claude アプリと Claude Code は同じ使用枠を共有します。

日本での支払額（税込）: 日本ではドル建てで、消費税10%込みの価格になります。Pro は$22（約3,480円、年払いなら月約2,900円相当）、Max 5× は$110（約17,380円）、Max 20× は$220（約34,760円）です（1ドル＝158円、2026年10月6日）。ChatGPT・Gemini との円での比較は生成AIのサブスク料金比較へ。

ポイント：Max 5× は単価が安くならず、Max 20× は安くなる

Max 5× は、5倍の料金で Pro の5倍の使用量です。条件は同じで、量が増えるだけです。

Max 20× は、10倍の料金で Pro の20倍の使用量です。使用量あたりの単価は Pro の半分です。 Pro 10個分を超える使用量が必要なら、迷わずこちらです。Max 5× の枠では足りないことが多いなら、API クレジットを追加するよりお得です。

上限の仕組み

どのプランにも、2つの上限が同時にかかります。

  • 5時間のセッション上限。最初のメッセージから始まるローリング方式の枠です。Anthropic は2026年5月6日に Claude Code の5時間上限を2倍にしました。
  • 週の上限。すべての使用量の合計にかかります。2026年9月14日、Anthropic は Claude Code の標準の週上限を恒久的に25%引き上げ、一時的な50%増量を置き換えました。

Max では、この両方がプランの倍率分だけ増えます。今の状況は Claude Code で /status を実行すると確認できます。詳しくは Claude Code の使用量上限をご覧ください。

Pro のままでいい人

  • Claude を1日に数回、主にアプリで使う。
  • Claude Code は何時間も使うのではなく、ときどきのタスクで使う。
  • 上限のメッセージをほとんど、またはまったく見ない。

当てはまるなら、$20で十分です。たまに足りなくなっても、使用量クレジットか少し待つことで対応できます。

Max 5× が向いている人

  • ほぼ毎週、Pro の上限に当たる。
  • 1日に何度も、実際の仕事で Claude Code を使う。
  • Sonnet より枠を速く使う Opus を、もっと使いたい。

Max 20× が向いている人

  • Claude Code を1日に何時間も、または複数セッションを並行して動かす。
  • Max 5× の週上限に何度も当たる。
  • Opus を標準モデルにしている。

このレベルになると、API のほうがたいていずっと高くつきます。私たちの費用モデルでは、機能追加サイズのタスクを1日15件こなすヘビーユーザーの場合、API 費用は Sonnet で月約$236、Opus なら約$473です。Max 20× は$200です。Claude Code の月額費用をご覧ください。

どのプランでも枠を長持ちさせるコツ

  • 関係のないタスクの間では新しいセッションを始め（/clear）、長いタスクでは /compact を使いましょう。
  • CLAUDE.md は短く。毎ステップ送られます。
  • 日常的な作業には Sonnet、Opus は難しい問題にだけ使いましょう。
  • 普段ほかの言語で書いているなら、指示は英語で書きましょう。日本語の指示を英語にすれば、トークンは約44%減ります。トークンカウンターの 💸 トークン節約 ボタンを使うと、自分の端末の中で英語に変換できます（デスクトップ版 Chrome 138以降 / Edge 148以降）。

詳しくは Claude Code のトークン節約術をご覧ください。

Claude Max か ChatGPT Pro か

$200のプランで比べると、Claude Max 20× は基本プランの20倍、ChatGPT Pro 200 は新規加入者の場合で基本プランの10倍です。ただし両社の基本プランの大きさは同じではないので、実際に使う量で比べましょう。ChatGPT Pro vs Claude Max をご覧ください。
