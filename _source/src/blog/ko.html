같은 내용을 물어봐도, 한국어로 쓰면 영어보다 토큰이 더 듭니다. API는 토큰 단위로 돈을 받으니 그만큼 비용도 더 나갑니다. 얼마나 차이 나는지 직접 재봤고, 그 차이를 버튼 하나로 줄이는 방법도 정리했습니다.

결론부터 말하면 한국어는 영어의 1.44배입니다. 프롬프트를 영어로 바꿔서 보내면 토큰이 약 31% 줄어듭니다.

어떻게 쟀나

영어로 34토큰짜리 평범한 고객 응대 프롬프트를 썼습니다.

Please summarize the customer email below in three bullet points and suggest a polite reply. The customer says the order arrived two days late and one item was missing from the box.

한국어 버전은 이렇습니다.

아래 고객 이메일을 세 가지 요점으로 요약하고 정중한 답장을 제안해 주세요. 고객은 주문이 이틀 늦게 도착했고 상자에서 물건 하나가 빠져 있었다고 말합니다.

이걸 41개 언어로 옮긴 뒤, GPT-4o 이후 OpenAI 모델이 쓰는 토크나이저(o200k_base)로 토큰 수를 셌습니다.

import { getEncoding } from "js-tiktoken";

const enc = getEncoding("o200k_base");
const count = (text) => enc.encode(text).length;

count(english); // 34
count(korean);  // 49

파이썬이라면 tiktoken으로 똑같이 할 수 있습니다.

import tiktoken
enc = tiktoken.get_encoding("o200k_base")
print(len(enc.encode(korean)))  # 49

왜 한국어가 더 들까

AI는 글자나 단어를 그대로 읽지 않습니다. 먼저 토크나이저가 글을 정해진 조각(토큰)으로 자릅니다. 이 조각 사전은 주로 영어 텍스트로 만들어졌기 때문에, 영어 단어는 대부분 한 조각이지만 한국어는 음절이나 단어가 여러 조각으로 나뉘는 경우가 많습니다. 조사와 어미가 붙으면서 형태가 다양해지는 것도 이유입니다.

같은 이유로 일본어(1.79배)는 한국어보다 더 비싸고, 중국어 간체(1.03배)는 영어와 거의 같습니다.

돈으로 따지면

입력 100만 토큰당 2달러인 모델에 이 프롬프트를 100만 번 보낸다고 해보겠습니다.

언어 입력 토큰 입력 비용
영어 3,400만 $68
한국어 4,900만 $98
일본어 6,100만 $122

입력만 계산한 겁니다. 답변도 한국어로 받으면, 입력보다 보통 4~5배 비싼 출력 토큰에도 같은 배수가 붙습니다. 코딩 에이전트처럼 한 작업에 수십만~수백만 토큰을 쓰는 경우라면 이 30% 차이가 사용량 한도와 비용에 그대로 반영됩니다.

버튼 하나로 영어로 바꾸기: 토큰세이브 번역 기능

가장 큰 절약은 프롬프트를 영어로 보내는 것입니다. 요즘 모델은 영어로 받은 지시를 정확히 이해하고, "한국어로 답해 줘"라고 한 줄만 붙이면 답은 한국어로 줍니다.

토큰세이브 토큰 계산기에서는 이걸 한 번에 할 수 있습니다.

  1. 프롬프트를 붙여 넣으면 토큰 수와 모델별 비용이 바로 나옵니다.
  2. 줄일 여지가 있으면 💸 토큰 절약 버튼이 나타나고, 옆에 예상 절약률(예: −30%)이 표시됩니다.
  3. 누르면 공백 정리 → 영어 번역 → 군더더기 정리를 차례로 하고, 끝에 "Reply in Korean." 한 줄을 자동으로 붙입니다. 그래서 프롬프트는 영어로 보내도 답은 한국어로 받습니다. 몇 토큰(몇 %)을 아꼈는지도 바로 알려줍니다.
  4. 바뀐 영어 프롬프트를 복사해서 ChatGPT, Claude, Gemini 등에 그대로 쓰면 됩니다. 마음에 안 들면 버튼이 ↩ 원문으로 바뀌어 있으니 한 번 더 눌러 원래 글로 되돌리면 됩니다.

어떻게 동작하나요?

  • 번역은 브라우저에 들어 있는 AI 번역 기능을 씁니다. PC용 Chrome 138 이상 또는 Edge 148 이상에서 작동합니다.
  • 처음 한 번만 번역 모델을 내려받고(진행률이 표시됩니다), 그다음부터는 내 기기 안에서 번역합니다. 입력한 글은 어느 서버로도 전송되지 않습니다.
  • 번역 결과가 오히려 토큰을 늘리면 번역은 적용하지 않습니다.
  • 코드를 붙여 넣으면 코드는 그대로 두고 한국어 주석만 영어로 바꿉니다.
  • 모바일이나 지원하지 않는 브라우저에서는 번역 단계를 건너뛰고 공백 정리만 한 뒤 안내 문구를 보여줍니다.

그 밖에 토큰 아끼는 방법

  • 시스템 프롬프트와 고정 지시문은 영어로 쓰기. 매 요청마다 반복해서 보내는 부분이라 효과가 가장 큽니다. 사용자 입력과 최종 답변만 한국어로 두면 됩니다.
  • 중간 단계는 영어나 JSON으로 받기. 분류, 정보 추출, 도구 호출처럼 사용자가 직접 보지 않는 단계는 영어로 처리합니다.
  • 공백과 빈 줄 정리하기. 문서에서 복사한 텍스트에는 불필요한 공백이 생각보다 많습니다.
  • 과한 존댓말 줄이기. "~해 주시면 정말 감사하겠습니다" 대신 "~해 주세요"면 충분합니다.
  • 긴 대화는 새 채팅으로. 메시지를 보낼 때마다 앞의 대화 전체가 다시 전송됩니다. 주제가 바뀌면 5줄 요약만 들고 새 채팅을 여세요.
  • 프롬프트 캐시 활용하기. 고정된 앞부분을 캐시하면 그 부분의 입력 단가가 크게 떨어집니다. 90% 가까이 싸지는 모델도 있습니다.

번역하지 않는 게 나은 경우

지시문과 질문은 영어로 바꿔도 되지만, 원문 그대로가 중요한 글은 그대로 두세요. 그대로 인용해야 하는 계약서 문구, 맞춤법을 고쳐 달라는 글, 시나 카피처럼 표현 자체가 내용인 글이 그렇습니다.

한계

  • 프롬프트 하나로 잰 결과입니다. 문장에 따라 배수가 0.1~0.2 정도 달라질 수 있으니 대략적인 참고용으로 봐주세요.
  • 번역은 기계 번역을 바탕으로 확인했습니다.
  • Claude와 Gemini는 토크나이저가 달라서, 이 숫자가 그대로 맞는 건 OpenAI 모델입니다. 다른 모델은 토큰 계산기에서 추정치로 보여드립니다.
