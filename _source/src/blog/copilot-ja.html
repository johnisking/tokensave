GitHub Copilot の料金は、2026年6月1日に大きく変わりました。以前の「プレミアムリクエスト」の回数制はなくなり、個人向けの各プランには毎月「GitHub AI Credits（AIクレジット）」が付与されるようになっています。チャット、エージェント、CLI のタスクはどれも、使ったモデルのトークン単価でこのクレジットを消費します。この記事では、現在のプランと料金、日本での支払い（ドル建てと消費税）、AIクレジットの仕組み、Copilot 内のモデル別の価格、そして私たちが実測した4回のエージェント実行をもとに「各プランで実際のタスクを何回こなせるか」を試算します。プランの内容は、2026年10月11日に GitHub のプランページとドキュメントで確認しました。

日本での支払い：円価格はなくドル建て、消費税10%

GitHub のプランページとドキュメント（日本語版を含む）の価格は、すべて米ドル建てです。円建ての価格は確認できませんでした。日本語ドキュメントにも「1 AI credit = $0.01 USD」と書かれています。

さらに GitHub は、2024年10月1日から、日本でクレジットカードや PayPal で支払うセルフサービスの利用者に 日本の消費税（10%） を請求しています。請求書には税額がドルと円の両方で記載されます。これに当てはめると、税込みの月額は次のとおりです（当サイトの計算）。

Max $100 $110

円での実際の支払額は、決済時の為替レートとカード会社の手数料によって変わります。請求書払いの企業契約など、支払い方法によって扱いが異なる場合があるので、自社の請求画面で確認してください。

各プランでできること

GitHub のプランページによる内容です。

  • Free: 月2,000回のコード補完、少量のチャットとエージェントの利用枠、自動モデル選択を通じた軽量モデル（Claude Haiku 4.5 や GPT-5 mini など）、Copilot CLI。本人確認された学生は、代わりにコード補完が無制限の Copilot Student を使えます。
  • Pro（$10）: Free の内容に加えて、無制限のコード補完と次の編集候補、Copilot cloud agent とコードレビュー、モデルの選択。
  • Pro+（$39）: Pro の内容に加えて、Anthropic の Claude や OpenAI Codex などのサードパーティ製コーディングエージェントへのタスクの委任（プレビュー）。含まれるクレジットは Pro より367%多くなります。
  • Max（$100）: Pro+ の内容に加えて、新しいモデルや機能への優先アクセス。含まれるクレジットは Pro+ より186%多くなります。

有料プランはどれも、含まれるクレジットを使い切ったあと追加のクレジットを購入できます。

GitHub AI Credits（AIクレジット）の仕組み

Copilot とのやりとりは、すべてトークンを使います。モデルに送る入力トークン、モデルが書く出力トークン、そして再利用されるキャッシュのトークンです。GitHub は各トークンをモデルの単価で計算し、合計をクレジットに換算します。つまり、タスクの費用を決めるのは モデル と そのタスクが使うトークン数 の2つです。

  • クレジットを使うもの: Copilot Chat、Copilot CLI、Copilot cloud agent、Copilot Spaces、Spark、サードパーティ製コーディングエージェント。
  • 使わないもの: 有料プランでのコード補完と次の編集候補。
  • コードレビューは二重に課金されます。 トークン分がクレジットで請求され、レビューを実行するエージェントは GitHub Actions の実行時間（分）も使います。コードレビューのモデルは自動で選ばれ表示されないので、1回あたりの費用は一定ではありません。
  • 基本クレジットから先に使い、次にフレックス割り当てを使います。 使用状況のダッシュボードで両方を確認できます。
  • クレジットは毎月1日の00:00（UTC）にリセットされます。 契約した日に関係なく固定で、日本時間では1日の午前9時です。使い残したクレジットは翌月に繰り越せません。
  • 自動モデル選択は10%安くなります。 有料プランでは、Chat、CLI、Copilot アプリ、cloud agent でモデルを Copilot に選ばせると、モデルの費用が10%割引されます。

クレジットを使い切ったら

GitHub は3つの選択肢を示しています。

  1. アップグレードする。 その月の残りはプランの差額だけを払えばよく、増えた枠はすぐに使えます。
  2. 追加利用の予算を設定する。 追加分も同じトークン単価で請求され、$10の予算で1,000クレジット分です。
  3. 毎月1日のリセットを待つ。

なお、2026年6月1日以降も旧方式のまま残った Pro・Pro+ の年払い契約者は、当面これまでのプレミアムリクエスト制での請求が続きます。該当する方は請求ページを確認してください。

Copilot 内のモデル別の価格

GitHub はすべてのモデルのトークン単価を公開しています。コーディングでよく使われるモデルについては、Copilot 内の単価は各社の API 定価と同じです。

モデル 入力 キャッシュ入力 キャッシュ書き込み 出力
Claude Haiku 5.5 $0.10 $0.01 $0.125 $0.50
Claude Sonnet 5.5 $2 $0.10 $2.50 $10
Claude Opus 5.5 $4 $0.20 $5 $20
Claude Fable 5.1 $10 $0.25 $12.50 $50
GPT-6 Luna $0.10 $0.01 $0.125 $0.50
GPT-6.1 Sol $2 $0.10 $2.50 $10
GPT-6 Astra $10 $1 $12.50 $50
Gemini 3.8 Flash $0.75 $0.075 – $3.75
Grok 4.7 $2 $0.50 – $6

価格は100万トークンあたりで、各モデルの長文コンテキストのしきい値より短いプロンプトの場合です。しきい値を超えると高くなるモデルもあり、たとえば GPT-6 Astra は入力が272Kトークンを超えると入力$20・出力$75になります。Gemini 3.8 Flash は2026年12月31日までのキャンペーン価格です。

  • Copilot の単価は API と同じです。 Claude Sonnet 5.5 は Copilot でも Anthropic の API でも100万トークンあたり$2と$10、GPT-6 Astra はどちらでも$10と$50です。自動選択の10%割引を除けば、Copilot による上乗せも値引きもありません。
  • 実質的には「API の前払い＋おまけのクレジット」です。 Pro は$10で$15分、Max は$100で$200分のモデル利用ができます。
  • プランよりモデル選びのほうが月の費用に効きます。 Claude Opus 5.5 のトークンは Sonnet 5.5 より100%高く、GPT-6 Astra は GPT-6.1 Sol より400%高くなります。

各プランで何回タスクをこなせるか（試算）

Copilot は API 定価で課金されるので、実際のタスクの費用からプランの容量を見積もれます。私たちは2026年10月9日に、小さなブラウザゲームを作るという同じタスクを、Claude Sonnet 5.5 と Opus 5.5 の medium・high の4通りで Claude Code に実行させ、ccusage で API 価格に換算しました。テストの全容は Claude Sonnet 5.5 と Opus 5.5 の比較にあります。

このくらいのタスク1回 1回の費用 Pro（$15分） Pro+（$70分） Max（$200分）
Sonnet 5.5・medium $0.25 約60回 約280回 約800回
Sonnet 5.5・high $0.30 約50回 約233回 約667回
Opus 5.5・medium $0.56 約27回 約125回 約357回
Opus 5.5・high $0.75 約20回 約93回 約267回

更新（2026年10月23日）： Claude Code 2.1.295 で3回ずつ測り直すと、同じタスクは平均 $0.10、$0.12、$0.26、$0.35 で、上の10月9日の値より53〜61%安くなりました。各プランでこなせるタスク数は、この表よりおよそ110〜160%多くなる計算です。effort データセットを参照。

これは当サイトの試算で、次のような注意点があります。

  • 実行したのは Claude Code で、Copilot ではありません。 Copilot のエージェントは独自の指示とコンテキストを送るので、同じタスクでもトークン数は同じになりません。
  • 費用の大半はキャッシュ書き込みでした。 この実行では費用の63%〜81%が、Anthropic の1時間キャッシュの料金でコンテキストをキャッシュに書き込む分でした。Copilot の Sonnet 5.5 のキャッシュ書き込み単価は$2.50で、Anthropic の5分キャッシュの料金と同じです。Copilot がこの料金でキャッシュするなら同じタスクはもっと安くなり、各プランでこなせる回数も増えますが、まだ測定していません。
  • ゲームは小さなものでした。 実際のコードベースでの機能追加は、読むファイルもステップも多くなります。大きなタスクはもっと高く、場合によってはずっと高くなると考えてください。

effort（推論の深さ）による費用の違いは Claude Opus 5.5 の effort 設定で解説しています。

それでも、桁の感覚はつかめます。Pro では Sonnet での小さなエージェントタスクが月に数十回、Opus ならそれよりかなり少なくなります。私たちの試算では、エージェントを毎日使うなら、小さなタスクでひと月をまかなえる最初のプランが Pro+ です。

Copilot Pro+ は誰向けか

Pro から Pro+ に上げるか迷ったら、次の3つを判断のポイントにしてください。

  • クレジットの量: Pro+ は月$39で$70分（7,000クレジット）。Pro の1,500クレジットより367%多く、上の試算では Sonnet 5.5・high の小さなタスクを約233回こなせます。
  • サードパーティ製エージェント: Claude や OpenAI Codex にタスクを任せる機能（プレビュー）は Pro+ 以上で使えます。
  • 費用対効果: 月額に対するクレジットの上乗せは Pro が50%、Pro+ が79%なので、たくさん使う人ほど Pro+ のほうが割安です。さらに使う人には、上乗せが100%の Max（$100で$200分）があります。

エージェントをほとんど使わず補完が中心なら、Pro のままで十分です。

Free・Pro・Pro+・Max の選び方

こんな人は おすすめ 理由
補完が中心で、チャットは少しだけ Free → Pro Free は補完が月2,000回、Pro は$10で無制限
Sonnet クラスのモデルで週に数回チャットやエージェントを使う Pro（$10） $15分のクレジットで小さなタスクを数十回
エージェントを毎日使う Pro+（$39） $70分のクレジットに加え、サードパーティ製エージェント（プレビュー）
長いエージェントセッションや cloud agent を多用する Max（$100） $200分のクレジットで、月額に対する比率がいちばん高い

プランと同じくらい請求額を左右する習慣が2つあります。

  • 安いモデルを基本にする。 10%割引のある自動選択や、Sonnet 5.5・GPT-6.1 Sol をふだん使いにし、Opus や GPT-6 Astra は必要なときだけ使いましょう。
  • エージェントのセッションを短くする。 セッションが長いほど、ステップごとに送り直すコンテキストが増えます。別のタスクは新しいセッションで始めましょう。

Copilot Business と Enterprise

企業向けの Copilot Business は1ユーザー月$19、Enterprise は月$39で、1ユーザーあたり1,900・3,900クレジットが付きます。個人プランとの違いは、クレジットの分け方です。

  • クレジットは共有されます。 GitHub の例では、Business ユーザーが100人の会社は、100人分の別々の枠ではなく、190,000クレジットの共有プールを1つ持ちます。たくさん使う人がいても、あまり使わない人の分で相殺されます。
  • シートを追加するとプールはすぐ増えます。 月の途中でシートを減らしても、プールが減るのは次のサイクルからです。
  • フレックス割り当てはありません。 含まれるクレジットはシートの価格と同じ金額です。
  • 使い切ったときの扱いが違います。 会社のポリシーによって、超過分を有料で使い続けるか、利用が止まるかのどちらかです。ユーザーが自分でクレジットを買うことはできません。
  • 会社のシートは個人プランを置き換えます。 Pro・Pro+・Max を契約している人に会社が Business や Enterprise のシートを割り当てると、個人プランは自動的に解約され、日割りで返金されます。

まとめ

  • Copilot Pro（$10）は、ここで比べた4つのツールでいちばん安い有料プランです。 コード補完は無制限で、$15分のモデルクレジットが付きます。日本のカード払いでは消費税10%が加わり$11です。
  • どのプランも実質的には API の前払いです。 Copilot は各モデルの定価で課金するので、月の費用はどのモデルを使い、エージェントのセッションをどれだけ長く回すかで決まります。
  • フレックス割り当ての恩恵がいちばん大きいのは Max です。 $100で$200分になりますが、GitHub はこの量が変わる可能性があるとしています。
  • 私たちの試算では、エージェントを毎日使うなら Pro+ が基準です。 Pro のクレジットでは小さな Sonnet タスクが月に数十回、Pro+ なら数百回です。

よくある質問

GitHub Copilot の料金はいくらですか？ Copilot Free は$0、Pro は月$10、Pro+ は$39、Max は$100です。チーム向けは Business が1ユーザー月$19、Enterprise が$39です。いずれもドル建てで、日本のカード・PayPal 払いでは消費税10%が加わります。

GitHub Copilot は無料で使えますか？ はい。Free プランでは月2,000回のコード補完と、自動モデル選択による少量のチャット・エージェント利用ができます。本人確認された学生は、補完が無制限の Copilot Student を使えます。

GitHub AI Credits とは何ですか？ 2026年6月1日から使われている Copilot の利用単位です。1クレジットは$0.01で、各操作はモデルのトークン単価に応じてクレジットを消費します。月に Pro は1,500、Pro+ は7,000、Max は20,000クレジットが含まれます。

コード補完でもクレジットは減りますか？ いいえ。コード補完と次の編集候補はクレジットで課金されず、有料プランでは無制限です。

クレジットを使い切ったらどうなりますか？ 差額だけを払ってその月のうちにアップグレードするか、予算を設定して同じトークン単価で追加購入するか、毎月1日00:00（UTC）のリセットを待ちます。

Copilot は Claude Code や Cursor より安いですか？ 入門プランでは安く、$10と$20です。エージェントを多く使う場合はモデルと使用量しだいです。Copilot は各モデルの API 定価で課金しますが、Claude のプランは API 価格に連動しない利用枠の方式です。
