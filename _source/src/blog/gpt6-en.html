GPT-6 Sol vs GPT-6.1 Sol: which to call

GPT-6.1 Sol arrived one week after GPT-6 Sol at the same list price, $2 input and $10 output. The only price change is cached input, which fell from $0.20 to $0.10 per million. According to OpenAI, 6.1 Sol is also better at coding, agent work and factual accuracy: 6.4 points higher on the DeepSWE coding benchmark and about 32% fewer factual errors at low reasoning effort.

Request GPT-6 Sol GPT-6.1 Sol Saving
Chat: 2,000 in / 500 out, nothing cached $0.0090 $0.0090 0%
Chatbot: 10,000 cached + 1,000 new in / 500 out $0.0090 $0.0080 11%
Agent step: 45,000 cached + 5,000 new in / 1,000 out $0.0290 $0.0245 16%

Call GPT-6.1 Sol. A one-off request costs the same, and anything that resends instructions, documents or history costs 11% to 16% less. What a request really costs

Three common requests at standard rates. These are calculations from the list prices, not measurements:

  • Chat reply: 2,000 input tokens (instructions, history and the question) and 500 output tokens, nothing cached.
  • RAG question: 20,000 input tokens of retrieved passages plus the question, and 500 output tokens. The passages change with every question, so nothing is cached.
  • Coding-agent step: 50,000 input tokens, 45,000 of them cached (instructions, files and earlier steps), and 1,000 output tokens. A task here is 30 such steps.

GPT-6 Sol $0.0090 $0.045 $0.0290 $0.87
GPT-6.1 Sol $0.0090 $0.045 $0.0245 $0.74
GPT-6 Astra $0.045 $0.225 $0.145 $4.35
GPT-6.1 Sol Ultrafast $0.054 $0.27 $0.147 $4.41

The agent step on GPT-6.1 Sol: 5,000 new input tokens at $2 per million ($0.010), 45,000 cached at $0.10 ($0.0045) and 1,000 output at $10 ($0.010), for $0.0245.

  • Input can outweigh output. In the RAG question, input is 89% of the cost on Sol, even though each output token costs 400% more.
  • Caching changes agent costs. Without the cache, the agent step would cost $0.11 on GPT-6.1 Sol; caching takes 78% off.

How to cut your GPT-6 API bill

  1. Route by difficulty. Start on Luna, escalate hard or failed requests to 6.1 Sol and only the hardest to Astra. At 100,000 chat requests, 80% on Luna and 20% on 6.1 Sol costs $216 against $900 all on Sol: 76% less.
  2. Move to GPT-6.1 Sol. Same list price as GPT-6 Sol, with a 50% lower cache price. If you are still on GPT-5.6 Sol ($4 / $20), switching cuts the per-token price by 50%; moving from GPT-5.6 Luna ($0.20 / $1.20) to GPT-6 Luna cuts input by 50% and output by 58%. See GPT-5.6 vs GPT-6 Sol.
  3. Cache everything that repeats. Fixed instructions, tools and documents first, the changing part last; cached reads are 90% to 95% off. See Prompt caching explained.
  4. Batch work that can wait. Batch and Flex are 50% off, per LiteLLM's list.
  5. Keep output and reasoning short. Reasoning tokens are billed as output. Use the lowest reasoning effort that works. See Reasoning models and cost.
  6. Stay under 272K tokens per prompt.
  7. Skip Priority and Ultrafast unless someone is waiting.
  8. Prompt in English if you can. On the GPT tokenizer, Korean uses about 44% more tokens and Japanese 79% more. See token cost by language.

FAQ

How much does the GPT-6 API cost? Per million tokens: GPT-6 Luna $0.10 input and $0.50 output, GPT-6 Sol and GPT-6.1 Sol $2 and $10, GPT-6 Astra $10 and $50, and GPT-6.1 Sol Ultrafast $12 and $60. Cached input is $0.01, $0.20, $0.10, $1 and $0.60 respectively.

What is the cheapest GPT-6 API? GPT-6 Luna, at $0.10 input and $0.50 output per million tokens: about $0.00045 for a 2,000-token prompt with a 500-token answer. Per LiteLLM's price list, Batch and Flex bring that down to $0.05 and $0.25.

Is GPT-6.1 Sol more expensive than GPT-6 Sol? No. Both cost $2 input and $10 output per million tokens. GPT-6.1 Sol's cached input is cheaper, $0.10 against $0.20, so it costs the same or less on every request.

How much does GPT-6 Astra cost? $10 per million input tokens, $1 cached and $50 output, 400% more than Sol: about $0.045 for a typical chat request. Per LiteLLM, prompts over 272,000 tokens cost $20 / $75 and Batch $5 / $25.

Does GPT-6 cost more for long prompts? Yes. Per LiteLLM's price list, once a prompt passes 272,000 input tokens the whole request is billed 100% more for input and 50% more for output, on every GPT-6 model.

Is GPT-6 cheaper than Claude? At list price they tie: Luna matches Haiku 5.5, 6.1 Sol matches Sonnet 5.5 and Astra matches Fable 5.1. Per request GPT-6 usually costs less, because Claude turns the same English text into about 30% more tokens.
