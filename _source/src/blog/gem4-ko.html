구글이 2026년 9월 30일 새 최상위 모델 Gemini 4 Argon(제미나이 4 아르곤)을 발표했습니다. 코딩, 사이버보안, 오래 걸리는 에이전트 작업에 초점을 맞춘 모델로, 구글은 GPT-6 Astra와 Claude Fable·Opus보다 여러 벤치마크에서 앞선다고 밝혔습니다. API 가격, 실제 요청당 비용, GPT·Claude와의 비교를 정리했습니다.

Gemini 4 Argon API 가격

100만 토큰당 가격입니다. 처음에는 출시 기념가로 시작하고, 이후 정가로 바뀝니다.

구분 입력 캐시된 입력 출력
출시 기념가 $2 약 $0.10 $10
정가 $4 약 $0.20 $20

캐시된 입력은 일반 입력의 95% 할인이라, 같은 지시문이나 문서를 반복해서 보내는 작업에서 차이가 큽니다. 출시 기념가가 언제까지인지는 아직 공개되지 않았습니다.

한 번에 최대 100만 토큰을 출력할 수 있다는 점도 특징입니다. 다만 출력이 길어질수록 비용도 그만큼 커집니다. 출력 100만 토큰이면 정가 기준 응답 한 번에 $20입니다.

지금 바로 쓸 수 있나

아직은 아닙니다. 현재는 구글의 보안 파트너 프로그램(Fairwind) 참여 기관에만 열려 있고, Google AI Ultra 구독자와 유료 API 고객에게는 순차적으로 배포될 예정입니다. 공개 API 모델 ID는 gemini-4-argon으로 알려져 있지만 공식 문서에는 아직 올라오지 않았습니다.

다른 모델 가격은 2026년 10월 확인한 공식 API 가격입니다.

정리하면 이렇습니다.

  • 정가는 Claude Opus 5.5와 똑같습니다. 입력 $4, 출력 $20입니다.
  • 출시 기념가는 GPT-6 Sol, Claude Sonnet 5.5와 같은 가격입니다. 최상위 모델을 중간 모델 가격에 쓸 수 있는 기간입니다.
  • GPT-6 Astra, Claude Fable 5.1보다는 정가로도 2.5배 쌉니다. 구글 발표대로 성능이 이들보다 높다면, 최상위 모델 중에서는 가장 가성비가 좋은 선택이 됩니다.
  • Gemini 3.1 Pro보다는 비쌉니다. 정가 기준 요청당 약 1.8배입니다. 지금 3.1 Pro로 충분한 작업이라면 굳이 바꿀 이유는 없습니다.

어떤 작업에 쓸까

Gemini 4 Argon이 어울리는 작업: 대규모 코드 수정이나 마이그레이션, 보안 취약점 분석, 여러 단계를 거치는 긴 에이전트 작업, 긴 영상이나 차트 분석. 실수 한 번이 비싼 작업일수록 값을 합니다.

굳이 안 써도 되는 작업: 요약, 번역, 분류, 짧은 답변. 이런 작업은 Gemini 3.8 Flash가 요청당 5분의 1 수준 비용으로 충분히 처리합니다.

흔한 방식은 평소엔 Flash나 3.1 Pro로 처리하고, 어려운 요청만 Argon으로 넘기는 것입니다.

비용 줄이는 방법

  1. 출시 기념가 기간에 테스트하기. 정가의 절반이라, 내 작업에 맞는지 시험해 보기 가장 좋은 시기입니다.
  2. 캐싱 적극 활용. 캐시된 입력이 95% 할인이라 고정 지시문과 문서는 항상 프롬프트 앞부분에 두세요.
  3. 출력 길이 제한. 최대 100만 토큰까지 출력할 수 있지만, 출력은 입력의 5배 가격입니다. 필요한 만큼만 답하도록 지시하세요.
  4. 프롬프트를 영어로. 한국어 프롬프트는 같은 내용이라도 영어보다 토큰이 더 듭니다. 토큰 계산기의 💸 토큰 절약 버튼으로 내 기기 안에서 바로 영어로 바꿀 수 있습니다.
