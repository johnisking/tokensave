Google の画像生成モデル「Nano Banana」は名前がよく変わり、料金表もモデルと解像度ごとに分かれているので、「結局1枚いくら？」にすぐ答えにくいモデルです。10月6日には Nano Banana 2.1 が正式公開され、初代 Nano Banana（Gemini 2.5 Flash Image）は10月2日に API の提供が終わりました。そこで Google の公式料金ページ（10月13日更新版）をもとに、モデル別の API 料金、無料で使える範囲、実際に何枚作るといくらかかるかをまとめました。Gemini アプリの無料版と Google AI Studio で、日本語のプロンプトを使って実際に画像を作った結果も載せています。

円の金額は1ドル＝158円で計算したおおよその値で、消費税とカードの海外事務手数料は含みません。

Nano Banana のモデルはいくつある？

2026年10月14日時点で、Gemini API で「Nano Banana」の名前で使える画像モデルは4つです。

名前 モデルID 特徴
Nano Banana 2.1 gemini-nano-banana-2.1 10月6日に正式公開。Google が新規プロジェクトにすすめる標準モデル
Nano Banana 2 gemini-3.1-flash-image 1つ前の標準モデル。0.5K の解像度も選べる
Nano Banana 2 Lite gemini-3.1-flash-lite-image いちばん速くて安い。1K のみで、複数枚の参照や連続編集は苦手

初代 Nano Banana（gemini-2.5-flash-image）は公式ドキュメントに「2026年10月2日に終了」と書かれていて、いまは API で使えません。古い記事にある「1枚 $0.039」はこのモデルの料金なので、今の料金とは違います。どのモデルで作った画像にも、Google の SynthID 透かし（目に見えない識別情報）が入ります。

Nano Banana API の料金は1枚いくら？

Google は画像の出力もトークンで計算します。たとえば Nano Banana 2.1 は画像出力100万トークンあたり $30 で、1K（1024×1024）の画像1枚が1,120トークンなので、1枚 $0.0336 になります。こうして換算した1枚あたりの料金は次のとおりです（標準リクエスト）。

Nano Banana 2 $0.045（約7.1円） $0.067（約10.6円） $0.101（約16円） $0.151（約24円）
Nano Banana 2 Lite なし $0.0336（約5.3円） なし なし

注目したい点がいくつかあります。

  • 2.1 のほうが 2 より安い。 新しいモデルなのに、1K で $0.067 から $0.0336 に下がりました。そのかわり入力料金は100万トークンあたり $0.50 から $1.50 に上がっています。参考画像を何枚も入れて長い指示を書く編集作業なら、入力の費用も合わせて見ておく必要があります。
  • 2.1 と Lite は 1K の料金が同じ。 どちらも $0.0336 です。Lite は入力が100万トークンあたり $0.25 と安くて速いものの、1K しか作れず、複数枚の参照や対話しながらの修正には向かないと Google が書いています。
  • Pro は 1K と 2K が同じ料金。 Pro を使うなら 2K で受け取るほうが得です。
  • 4K は 2.1 でも1枚約18円。 Web や SNS 用なら 1K〜2K で足りることが多いです。

Nano Banana の API は無料で使える？

API で無料で使う方法はありません。Google の料金表では、Nano Banana 2.1、2、2 Lite、Pro のすべてで無料枠（Free tier）の欄が「利用不可」になっています。テキストモデルのように API キーをもらうだけで無料で画像を作ることはできず、お支払い情報を登録した有料枠でだけ呼び出せます。そのかわり、有料枠で送った内容は Google のサービス改善には使われません。

無料で試せる方法は2つです。

  • Gemini アプリ（Web・スマホ）： Google 公式ヘルプの表では、「Nano Banana 2 で画像を生成」は、プランなしの無料アカウントを含むすべてのプランで使えることになっています。
  • Google AI Studio： 開発者向けのテスト画面です。下に実際に使った結果を書きました。

Gemini アプリの無料版は1日何枚まで？

Google はいま、枚数での上限を公開していません。公式ヘルプに書かれている内容は次のとおりです。

プラン 月額（日本） 使用上限
無料 0円 標準の上限
AI Plus 725円 標準の利用量の2倍
AI Pro 2,900円 標準の利用量の4倍
AI Ultra 14,500円 / 32,000円 AI Pro の利用量の5倍または20倍
  • 上限はメッセージ数ではなく使用量で決まり、5時間ごとに回復し、週の上限に達すると止まります。
  • Google は「メディアの生成や Deep Research などの一部の機能は、使用量を多く消費する」と書いています。画像ばかり作っていると、会話だけのときより早く上限に近づきます。
  • 画像を作り直す「Nano Banana Pro で再生成」は、AI Plus 以上の有料プランにだけチェックが付いています。

ネットで見かける「無料は1日○枚」という数字は、ほとんどが昔の記事や個人の計測です。いまの公式ドキュメントには枚数がないので、無料アカウントなら実際に使ってみて上限の案内が出るかを見るのがいちばん確実です。10月9日から無料版の会話モデルが Flash-Lite になった件は、Gemini 無料版の変更まとめに別にまとめています。

Gemini の無料アカウントで実際に作ってみた

10月14日に、プランに加入していない無料の Google アカウント（画面右上に「アップグレード」ボタンが出ている状態）で、Gemini アプリから画像を作ってみました。モデルの選択は初期設定の「Gemini 自動モード」のままです。

  • プロンプト（日本語で入力）： 日本のカフェの秋のメニューボードのポスター。タイトルは「秋の新メニュー」、メニューは「さつまいもラテ 580円」「かぼちゃケーキ 650円」「栗クリームスコーン 420円」の3つ。温かみのある秋のイラスト風で、文字は読みやすく。
  • 結果： 30秒ほどで縦長の画像が1枚（572×1024）できました。タイトル、かぼちゃケーキ、栗クリームスコーンと3つの値段は正しく描かれました。
  • まちがい： 「さつまいもラテ」が「さつまいも」になり、「ラテ」が抜けました。文字の入った画像は、受け取ったあと必ず読み直したほうがいいです。
  • 上限の案内： 1枚作るあいだに上限の警告は出ませんでした。
  • Pro で再生成： 画像の下の「再実行」メニューにあるのは長く・短く・カスタマイズ・再試行だけで、Nano Banana Pro で作り直すメニューはありませんでした。Google のヘルプでこの機能が有料プランだけに付いているのと一致します。

画面には、どの画像モデルが使われたかは表示されません。Google のヘルプでは、無料アカウントの画像生成は Nano Banana 2 です。

AI Studio で Nano Banana 2.1 を使ってみた

API で使う Nano Banana 2.1 は、開発者向けのテスト画面 Google AI Studio で試せます。モデルを Nano Banana 2.1 にして、解像度 1K、思考レベル Medium で画像を作りました。このテストは Google AI Pro に加入しているアカウントで行い、API キーはつないでいません。

  • プロンプト： 小さなリュックを背負ったバナナのマスコットが金貨の山の上に立っているフラットなベクターイラスト、薄紫の背景、文字なし（英語で入力）
  • 結果： 20秒以内に1枚できました。先に思考過程（Thoughts）が表示され、その下に画像が付きます。
  • 続けて修正： 「背景を水色にして」ともう一度頼むと、キャラクターと金貨はそのままで、背景だけが変わった画像が出ました。

2回とも料金はかかっていません。ただし入力欄が空のとき、実行ボタンの上に「このモデルには有料の API キーが必要です。API キーを選択してください」という案内が出ました。AI Studio の無料テストの範囲はアカウントや時期によって変わる可能性があります。アプリやサービスに組み込むなら、結局は有料の API キーが必要です。

無料の Gemini、2.1、Pro で画質に差はある？

上の無料版と同じメニューのプロンプトを、AI Studio で Nano Banana 2.1 と Pro（どちらも 1K、縦横比は自動）にも入れてみました。漢字・ひらがな・カタカナと値段が混ざる日本語のメニューは、差が出やすい題材です。

  • Gemini アプリ無料版（0円）： お店の中に置いた黒板のように背景まで描き込み、雰囲気はいちばんありました。ただ「さつまいもラテ」の「ラテ」が抜け、3つの中で文字のまちがいがあったのはこれだけでした。
  • Nano Banana 2.1（1枚約5.3円）： 文字はすべて正確で、大きく読みやすいです。ただ頼んでいない英語の「AUTUMN NEW MENU」を付け足しました。
  • Nano Banana Pro（1枚約21円）： 文字はすべて正確で、余計な文字もありませんでした。横長のレイアウトを選び、3つのメニューを横に並べたので、店頭のボードとしてそのまま使えるまとまりでした。

同じ比較を韓国語のメニューで行ったときは3つともほぼ正確だったので、日本語のほうが差がはっきり出ました。

プロ級の広告プロンプトでもう一度比べた

メニューは比較的やさしい題材なので、実際の広告撮影の指示書のように条件をたくさん入れたプロンプトでもう一度比べました。Pro は複雑な指示に強いと言われているので、差が出やすいテストです。

  • 指定したこと（日本語で入力）： 縦4:5の商品広告、マットブラックのタンブラーに小さく刻印された「TOKEN」ロゴ、濡れた黒いスレートの台、左上45度のソフトボックスと右後ろの温かいリムライト、開いたふたから立ちのぼる湯気、100mm マクロレンズ f/8、表面の水滴、深い緑のボケ背景、上部に日本語の見出し「一日の温度を守る」をすっきりしたゴシック体で、その下に英語「Keeps hot 12h · cold 24h」、右下に価格バッジ「¥3,980」、それ以外の文字は入れない

ゲームの絵は、気に入った1枚を得るために平均3回くらい作り直す前提で計算しています。同じ作業を Batch で送れば、どれも半額です。

ブログのアイキャッチくらいなら月に缶コーヒー1本分ほどです。逆に、Gemini アプリで画像をたくさん作るために AI Pro（月2,900円）に入るなら、同じ金額で API の Nano Banana 2.1 なら 1K の画像を約550枚作れます。ただし API は自分でコードを書くか、ほかのアプリにキーを入れる必要があり、Gemini アプリはそういった準備なしにすぐ使えるという違いがあります。

ほかの画像 AI と比べると高い？

1K 1枚で比べると、Nano Banana 2.1（約5.3円）は安いほうです。OpenAI の GPT Image は品質設定によって1枚約1セントから30セント近くまで差が大きく、同じ Google でも Pro は 2.1 より約300%高くなります。モデルごとの1枚の料金を解像度まで入れて比べたいときは、AI 画像生成コスト計算ツールを使ってみてください。指示文のトークン数はトークン計算ツールで数えられます。日本語がほかの言語よりトークンを多く使う理由は日本語のトークン数の計測にまとめています。

API で Nano Banana を使うには何が必要？

自分でコードを書かなくても、ほかのアプリや自動化ツールに Nano Banana をつなぐには API キーが必要です。手順はシンプルです。

  1. Google AI Studio で API キーを作る： 左下の鍵のアイコン（API キー）のメニューから新しいキーを作ります。
  2. お支払い情報を登録する： 画像モデルには無料枠がないので、キーをつないだ Google Cloud のプロジェクトにお支払い情報を登録して初めて呼び出せます。日本の利用者には消費税10%が加算される場合があります。
  3. モデル ID を入れる： これから始めるなら gemini-nano-banana-2.1 で大丈夫です。解像度（1K・2K・4K）と縦横比はリクエストのときに選びます。

API キーはパスワードと同じなので、ブログや GitHub にそのまま載せると、他人が自分のお金で画像を作れてしまいます。お支払い情報を登録したら、Google Cloud コンソールで予算アラートを設定しておくと安心です。

Nano Banana の費用を抑えるコツ

  • 最初は 1K で構図を決め、気に入ったものだけ大きく： 4K は 2.1 でも 1K より約236%高くなります。ラフは 1K で何枚か作り、使うものだけ 2K・4K で作り直します。
  • 急がないなら Batch： 同じ画像を半額で受け取れます。
  • 修正は作り直しではなく会話で： 2.1 は対話しながらの修正が得意なので、気に入らない部分だけ言葉で直すと作り直す回数が減ります。ただし会話が長くなると入力トークン（100万トークンあたり $1.50）が増えるので、長引かせすぎないほうがいいです。
  • 文字やレイアウトを厳密に守らせたい最終版だけ Pro： 日本語の書体指定のように、2.1 で守れなかった部分があるときに使います。

どの Nano Banana を選べばいい？

  • はじめて使う・ほとんどの用途： Nano Banana 2.1。Google が新規プロジェクトにすすめていて、2 より安く、2K・4K まで作れます。
  • 1K の画像を大量に、速く： Nano Banana 2 Lite。1枚の料金は 2.1 と同じですが、入力が安くて速いです。そのかわり連続の修正や複数枚の参照は苦手です。
  • 日本語の書体指定、文字の多いポスター、ブランドの一貫性： Nano Banana Pro。1K で 2.1 より約300%高いので、2.1 で構図を決めて最後の1枚だけ Pro で作る方法もあります。
  • Nano Banana 2 を使っていたプロジェクト： 公式ドキュメントに終了日はまだありませんが、Google が1つ前の世代に分類しているので、料金も安い 2.1 へ移るのがおすすめです。モデル ID を gemini-nano-banana-2.1 に変えるだけで済むか、入力の費用が増えないかは先に確かめてください。

よくある質問

Nano Banana 2.1 は1枚いくら？ 標準リクエストで 1K $0.0336（約5.3円）、2K $0.0504（約8円）、4K $0.113（約18円）です。Batch なら半額です。

Nano Banana の API に無料枠はある？ ありません。すべての Nano Banana モデルで無料枠の欄が「利用不可」です。無料で試すなら Gemini アプリか Google AI Studio を使います。

Gemini の無料版で画像は何枚まで作れる？ Google は枚数を公開していません。無料アカウントは「標準の上限」で、5時間ごとに回復し、週の上限があります。画像生成は会話より多く使用量を消費します。

初代 Nano Banana（Gemini 2.5 Flash Image）はもう使えない？ API では2026年10月2日に終了しました。gemini-2.5-flash-image を使っていたコードはエラーになるので変更が必要です。終了の案内には Nano Banana 2 か 2 Lite へ移るよう書かれていて、これから始めるなら Google がすすめる 2.1 のほうが料金も安いです。

日本語の文字はちゃんと描ける？ 今回の比較では、3つとも大部分の日本語を正しく描きました。ただ無料版は「さつまいもラテ」の「ラテ」が抜け、書体の指定（ゴシック体）を守れたのは Pro だけでした。文字の入った画像は必ず読み直してください。

まとめ

Nano Banana はいま 2.1 が標準です。API なら 1K 1枚約5.3円、Batch なら約2.7円で、ブログや小さなプロジェクトならほとんど負担になりません。日本語での比較では、文字のまちがいや書体の指定で Pro がいちばん正確だったので、仕上がりにこだわる最終版だけ Pro（1K・2K 約21円）にする使い分けがおすすめです。API には無料枠がないので、無料ではまず Gemini アプリか AI Studio で試し、たくさん使うようになったら API に移るのが無難な順番です。Gemini アプリの無料版の上限は枚数ではなく使用量で決まり、5時間ごとに回復します。
