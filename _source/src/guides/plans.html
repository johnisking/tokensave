How to use the Subscription vs API calculator

  1. Enter roughly how many messages you send per month.
  2. Pick a typical message size and how many turns a chat usually runs.
  3. Choose the language you write in.
  4. Each card shows what that usage would cost on the API next to every ChatGPT, Claude and Gemini plan, and which is cheaper.

How it is calculated

A chat model re-reads the whole conversation on every message, so later messages in a chat send more input tokens than earlier ones. The calculator adds up those growing inputs, the replies, and your language's measured token ratio versus English, then applies each model's API price per million tokens. Plan prices are official US monthly prices.

What the comparison leaves out

Plans include features a plain API does not, such as image generation, voice, memory and deep research, and they have usage limits that vary over time. The API has no app of its own. Use the result as a guide to which side is cheaper for your usage, then decide on features.
