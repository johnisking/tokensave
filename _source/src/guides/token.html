How to use the token counter

  1. Paste or type your prompt. The count updates as you type.
  2. Compare what that text costs on each model, from small, cheap models to the largest ones.
  3. Press Save tokens to clean up spaces, trim filler and, for non-English text, translate it to English on your device. The counter shows how many tokens and how much money you saved.

How the count is calculated

For OpenAI models the counter runs the real o200k tokenizer in your browser, so the number matches what the API bills. Claude, Gemini and other model families use their own tokenizers, which are not public in the same form, so their counts are estimates calibrated against measured text. Cost is tokens ÷ 1,000,000 × the price per million tokens, using each provider's list price and the date it was checked.

Why the same text costs different amounts

  • Language. The same meaning takes 1.03× (Chinese) to 2.44× (Punjabi) the tokens of English. Korean is 1.44×, Japanese 1.79×.
  • Input vs output. What the model writes costs 2–6 times more per token than what you send.
  • Model. Prices per million tokens range from $0.05 to $10 for input across the models listed here.
