사용 방법

  1. 클립당 길이(초)와 클립 수를 넣습니다.
  2. 해상도(480p·720p·1080p·4K)와 오디오 포함/없음을 고릅니다.
  3. 그 조건을 지원하는 모델이 합계가 싼 순서로 정렬되고, 가장 싼 모델에 “최저가” 표시가 붙습니다.

어떻게 계산하나요?

  • 대부분의 영상 API는 초 단위로 과금합니다. 합계 = 클립 길이 × 클립 수 × 초당 가격.
  • Luma는 5초/10초 클립 단위로 과금해서, 긴 영상은 여러 클립으로 나눠 계산합니다.
  • Veo처럼 오디오가 항상 포함된 모델도 있고, Kling처럼 오디오를 켜면 더 비싸지는 모델도 있습니다.
  • 제작사가 초당 API 가격을 공개하지 않은 모델은 Runway API 가격으로 보여주고 “Runway API 경유”로 표시합니다.

예산 잡을 때 팁

계산기는 한 번 생성한 비용입니다. 실제로는 쓸 만한 장면 하나에 2~4번 다시 만드는 경우가 많으니 한 번 생성 비용보다 약 200% 더 잡으세요. 프롬프트는 720p·저가 모델로 먼저 시험하고, 마지막 장면만 고급 모델로 뽑으면 비용을 크게 줄일 수 있습니다.
