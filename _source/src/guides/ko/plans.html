사용 방법

  1. 하루 메시지 수를 정합니다.
  2. 메시지 길이(짧은 질문 · 일반 대화 · 긴 문서)와 대화당 메시지 수를 고릅니다.
  3. 작성 언어를 고릅니다. 한국어는 영어보다 토큰이 약 1.44배 들어 API 비용에 그대로 반영됩니다.
  4. ChatGPT · Claude · Gemini 카드마다 같은 사용량을 API로 쓰면 월 얼마인지, 각 요금제와 비교해 어느 쪽이 싼지 보여줍니다.

어떻게 계산하나요?

채팅 모델은 메시지를 보낼 때마다 앞의 대화 전체를 다시 읽습니다. 그래서 대화가 길어질수록 뒤쪽 메시지의 입력 토큰이 커집니다. 계산기는 이렇게 늘어나는 입력, 답변(출력), 언어별 토큰 배수를 모두 더한 뒤 모델별 100만 토큰당 API 가격을 곱합니다. 요금제 가격은 공식 미국 월 가격입니다.

계산에 들어가지 않는 것

구독에는 앱, 이미지 생성, 음성, 메모리, 딥 리서치 같은 기능이 포함되고 사용량 제한이 있습니다. API에는 자체 앱이 없습니다. 결과는 “내 사용량이면 어느 쪽이 싼가”의 기준으로 보시고, 필요한 기능을 함께 따져 고르세요.
