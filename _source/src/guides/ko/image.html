사용 방법

  1. 출력 해상도를 고릅니다: 0.5K(512px) · 1K(1024px) · 2K(2048px) · 4K.
  2. 만들 이미지 수를 넣습니다.
  3. 그 해상도를 지원하는 모델이 장당 가격과 합계 순으로 정렬됩니다.

어떻게 계산하나요?

  • 대부분의 이미지 API는 해상도별로 장당 고정 가격을 받습니다.
  • FLUX.2는 메가픽셀 단위로 과금합니다. 첫 1MP와 추가 MP 가격이 달라서 2K(4MP)는 그만큼 더 비쌉니다.
  • 같은 모델도 품질 설정에 따라 가격이 크게 다릅니다. GPT Image 2.5는 high가 low보다 1,500% 더 비쌉니다.
  • 공식 API 가격이 없는 모델은 Runway API 가격으로 보여주고 표시합니다.

팁

  • 구도는 저가·저품질 설정으로 먼저 찾고, 고른 것만 고품질로 다시 뽑으세요.
  • 웹이나 SNS용이면 1K로 충분한 경우가 많습니다.
  • 손, 글자, 같은 캐릭터 반복처럼 어려운 이미지는 2~4번 시도를 예산에 넣으세요.
