사용 방법

  1. 일반적인 작업 크기를 고릅니다: 작은 수정(~8단계) · 새 기능(~25단계) · 대규모 리팩터링(~60단계).
  2. 하루 작업 수와 한 달 작업일을 정합니다.
  3. 프롬프트 캐싱은 대부분의 도구가 쓰므로 켜 두세요.
  4. 모델별 월 API 비용을, 에이전트가 포함된 Claude · ChatGPT 요금제와 나란히 비교합니다.

어떻게 계산하나요?

코딩 에이전트는 단계마다 작업 맥락 전체(시스템 프롬프트, 도구 정의, 읽은 파일, 이전 단계)를 모델에 다시 보냅니다. 계산기는 작업을 “시작 맥락 + 단계마다 늘어나는 맥락 + 단계마다 쓰는 출력”으로 봅니다. 예를 들어 새 기능 작업은 25단계, 시작 맥락 22,000토큰, 단계마다 3,500토큰 증가, 단계마다 출력 700토큰입니다. 캐싱이 켜져 있으면 반복되는 맥락은 입력 가격의 약 10%로 계산하고, 맥락은 180,000토큰에서 압축된다고 봅니다.

비용 줄이는 팁

  • 작업을 작고 구체적으로 주면 단계 수가 크게 줄어듭니다.
  • 관련 없는 작업 사이에는 새 세션을 열어 이전 기록이 다시 전송되지 않게 하세요.
  • 간단한 수정은 작은 모델로 처리하세요.
  • 지시문(시스템 프롬프트)을 영어로 쓰면 한국어보다 토큰이 약 30% 줄어듭니다.
