How to use the agent cost calculator

  1. Choose a typical task size: a small fix, a feature, or a big change.
  2. Set how many tasks you run per day and how many days a month.
  3. Leave prompt caching on unless your tool does not use it.
  4. Compare the monthly API cost of each model with the Claude and ChatGPT plans that include an agent.

How it is calculated

An agent works in steps, and every step sends its whole working context back to the model. The calculator models a task as a number of steps with a starting context, a fixed amount of new context per step and a fixed output per step: a feature task is 25 steps starting at 22,000 tokens, adding 3,500 per step and writing 700 per step. With caching on, the repeated part of the context is billed at 10% of the input price. Contexts are capped at 180,000 tokens, as agents compact long sessions.

Tips

  • Small, specific tasks need far fewer steps than open-ended ones.
  • Start a fresh session between unrelated tasks so old history is not re-sent.
  • Use a smaller model for routine edits.
