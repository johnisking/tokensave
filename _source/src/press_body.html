Press kit

TokenSave measures what AI models and coding agents really cost in tokens and publishes the raw data. Everything on this page, including the charts and the photo, is free to quote and reuse under CC BY 4.0. Please credit TokenSave (tokensave.app) and link to the dataset or its DOI.

Key findings

Each line links to the dataset page with the method, tool versions, dates, limits and a downloadable CSV.

  1. The same text costs more tokens on Claude. Across 40 languages, the median extra tokens compared with English is +88% on Claude 5.5, +52% on GPT and +41% on Gemini. Language Tax Index
  2. Claude writes about 60% more output tokens for the same code. Opus 5.5 used about 60% more output tokens per character of code than Gemini 4 Argon or GPT, in two different coding tools and five prompt languages (80 runs). Output tokens per character
  3. A coffee break can cost 507% more. In Claude Code, the next message after a pause of up to 55 minutes cost the same; after 65 minutes the prompt cache had expired and it cost 507% more. Coffee-break tax
  4. The agent itself is most of the bill. Claude Code's own instructions and tools made up 90% of the input tokens on a coding task, and a subagent made the same task cost 128% more. Claude Code harness cost
  5. A big CLAUDE.md is paid on every request. A 50 KB CLAUDE.md adds about 16,000 input tokens to each Claude Code request, and Codex silently ignores AGENTS.md text past 32 KiB. CLAUDE.md and AGENTS.md size
  6. One web page can fill the context. One accessibility snapshot of a long Wikipedia article was over 200,000 Claude tokens in both Playwright MCP and Chrome DevTools MCP. Our open-source proxy turned it into a table of contents of about 1,100 tokens. Browser MCP token cost
  7. The cheapest Claude model built the same games. Haiku, Sonnet and Opus 5.5 each built 15 browser games; all 45 passed play tests, and Haiku 5.5 cost about 95% less than Opus. Vibe coding by Claude model
  8. CSV beats JSON for prompts. The same table needs about two thirds fewer tokens as CSV than as indented JSON; TOON comes close but does not beat CSV. Token cost by format
  9. Image cost varies widely between providers. Gemini charges a flat ~1,100 tokens per image, while a 12 MP photo costs 14,364 tokens on GPT-6 Astra by default. Image token cost
  10. AI agents search in English. Asked about AI topics in Korean, Japanese, Spanish or Ukrainian, Claude Code and Codex still searched in English; only local questions (Seoul, Tokyo, Madrid, Kyiv) brought local-language searches. Web search by language

All 24 datasets: tokensave.app/data. Each has a DOI on Zenodo and mirrors on Hugging Face, Kaggle and GitHub.

About the founder

Jaehyun Cho, founder of TokenSave, is an independent developer in Seosan, South Korea, and the only person behind the site and its measurements.

He had no coding background and started by building Android games with AI, describing what he wanted to Claude in plain language. Repeatedly running into the usage limits of his AI plans led him to measure tokens himself; TokenSave started as a token counter he built for that.

How the measurements are made

  • Every number comes from tests run on real accounts and the real tools (Claude Code, Codex, Antigravity CLI, Cursor, the providers' token counters), not from numbers copied from other sites.
  • Each dataset page states the tool versions, dates, prompts, number of runs and the limits of the test. Raw logs are published with the CSV.
  • Prices come from each provider's official pricing page, with the date checked.
  • No funding, credits or commercial relationship with Anthropic, OpenAI, Google or any other AI company. Tests run on the founder's own accounts and subscriptions.
