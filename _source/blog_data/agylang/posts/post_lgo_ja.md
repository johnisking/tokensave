# 同じコードでClaudeだけ出力トークンが約60%多い：Claude Code・Codex・Antigravityを5言語で80回実測

昨日、Googleの新しいAntigravity CLIをClaude Code、Codexと比べたとき、ひとつ気になる数字がありました。Claude Opus 5.5はGeminiより短いゲームを作ったのに、出力トークンはその分減っていなかったのです。そこで、出力トークンを各実行が書いたファイルの大きさで割ってみました。ツールとモデルの組み合わせ4つ、プロンプトの言語5つです。

## 測り方

- 同じブロック崩しのタスク（「index.html 1ファイル、レベル2つ、スコア、ライフ3つ、キーボードとマウス」）を英語、韓国語、日本語、スペイン語、ウクライナ語で依頼
- Claude Code 2.1.295 + Opus 5.5、Codex CLI 0.162 + gpt-6-luna：各言語5回（以前のプロンプト言語の実測、同じバージョン）
- Antigravity CLI 1.4.5 + Gemini 4 Argon、+ Claude Opus 5.5：各言語3回（今日の新規24回と昨日の英語）
- すべてeffort medium、Windows 11、実行ごとに空のフォルダ
- できたゲームはすべてスクリプトがブラウザで実際に遊び、スコア、ステージ2、ライフ3→0を確認

## 結果：コード1,000文字あたりの出力トークン

| ツール + モデル | 英語 | 韓国語 | 日本語 | スペイン語 | ウクライナ語 | 平均 |
|---|---:|---:|---:|---:|---:|---:|
| Claude Code + Opus 5.5 | 554 | 624 | 581 | 614 | 584 | 591 |
| Antigravity + Opus 5.5 | 574 | 590 | 606 | 612 | 597 | 596 |
| Antigravity + Gemini 4 Argon | 367 | 380 | 370 | 364 | 378 | 372 |
| Codex + gpt-6-luna | 367 | 386 | 385 | 366 | 376 | 376 |

同じ量のコードを書くのに、OpusはGeminiより約60%、GPTより約57%多い出力トークンを使いました。面白いのは、Opusがまったく違う2つのツールでほぼ同じ値（591と596）になったことです。ツールではなく、モデルが文字をトークンに区切る方法（トークナイザー）の違いだということです。プロンプトの言語はほとんど関係ありませんでした。

出力トークンは高い方です。APIではOpus 5.5の出力は入力の5倍の価格なので、この差がそのまま費用に乗ります。モデルごとにどれだけ長いコードを書くかとは別にです。

以前、同じプログラムを10のプログラミング言語で数えたときも、ClaudeはGPTより43〜59%多くのトークンが必要で、同じ方向の結果です。

## プロンプトの言語は入力トークンをほとんど変えない

| 入力トークン | 英語 | 韓国語 | 日本語 | スペイン語 | ウクライナ語 |
|---|---:|---:|---:|---:|---:|
| Claude Code + Opus 5.5 | 96,462* | 78,638 | 79,266 | 79,030 | 79,787 |
| Codex + gpt-6-luna | 51,674 | 48,538 | 48,660 | 48,201 | 48,816 |
| Antigravity + Gemini 4 Argon | 13,041 | 13,289 | 12,408 | 12,629 | 13,447 |
| Antigravity + Opus 5.5 | 9,822 | 11,316 | 9,983 | 9,945 | 10,958 |

*英語のClaude Code 5回のうち2回は、やり取りが1回多かったため高くなっています。

プロンプト自体は数十トークンで、残りはツールが入れる指示文です。入力の大きさは何語で書くかではなく、どのツールを使うかで決まります。

もうひとつ：AntigravityのOpusは、韓国語とウクライナ語で頼むとゲームを長めに作りました（英語より文字数が約31%、20%多い）。そのため出力の合計は増えましたが、1,000文字あたりでは同じでした。

## ゲームはちゃんと動いたか

80本中79本が正常で、すべてのゲームがプロンプトの言語で画面の文字を表示しました。動かなかった1本は、以前の実測のウクライナ語のCodexのゲームです。

## 今回の限界

- タスクは1つ（HTML、CSS、JavaScriptのブラウザゲーム）。ほかの種類のコードは違う区切られ方をするかもしれません
- 出力トークンにはコードだけでなく、短い最後の返答とファイルを書くツール呼び出しの部分も含まれます
- 各セル3〜5回、2026-10-18〜23に同じツールのバージョンで測定
