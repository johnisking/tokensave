# 같은 코드인데 Claude만 출력 토큰 60% 더: Claude Code·Codex·Antigravity, 5개 언어로 80번 실측

어제 구글의 새 Antigravity CLI를 Claude Code, Codex와 비교했는데 숫자 하나가 계속 걸렸습니다. Claude 오퍼스 5.5가 Gemini보다 짧은 게임을 만들었는데, 출력 토큰은 그만큼 줄지 않았습니다. 그래서 출력 토큰을 각 실행이 만든 파일 크기로 나눠 봤습니다. 도구와 모델 조합 4가지, 프롬프트 언어 5가지입니다.

## 어떻게 쟀나

- 같은 벽돌깨기 과제("index.html 한 파일, 레벨 2개, 점수, 목숨 3개, 키보드와 마우스")를 영어, 한국어, 일본어, 스페인어, 우크라이나어로 시켰습니다
- Claude Code 2.1.295 + 오퍼스 5.5, Codex CLI 0.162 + gpt-6-luna: 언어마다 5회 (앞서 한 프롬프트 언어 실측, 같은 버전)
- Antigravity CLI 1.4.5 + Gemini 4 Argon, + Claude 오퍼스 5.5: 언어마다 3회 (오늘 새로 24회, 영어는 어제 실측)
- 모두 effort medium, Windows 11, 실행마다 빈 폴더
- 만들어진 게임은 전부 스크립트가 브라우저에서 직접 플레이해 점수, 2단계, 목숨 3→0을 확인했습니다

## 결과: 코드 1,000자당 출력 토큰

| 도구 + 모델 | 영어 | 한국어 | 일본어 | 스페인어 | 우크라이나어 | 평균 |
|---|---:|---:|---:|---:|---:|---:|
| Claude Code + 오퍼스 5.5 | 554 | 624 | 581 | 614 | 584 | 591 |
| Antigravity + 오퍼스 5.5 | 574 | 590 | 606 | 612 | 597 | 596 |
| Antigravity + Gemini 4 Argon | 367 | 380 | 370 | 364 | 378 | 372 |
| Codex + gpt-6-luna | 367 | 386 | 385 | 366 | 376 | 376 |

같은 분량의 코드를 쓰는 데 오퍼스는 Gemini보다 출력 토큰이 약 60%, GPT보다 약 57% 더 들었습니다. 재미있는 건 오퍼스가 전혀 다른 두 도구에서 거의 같은 값(591, 596)이 나왔다는 점입니다. 도구가 아니라 모델이 글자를 토큰으로 쪼개는 방식(토크나이저) 때문이라는 뜻입니다. 프롬프트를 어떤 언어로 쓰든 거의 차이가 없었습니다.

출력 토큰은 비싼 쪽입니다. API 가격으로 오퍼스 5.5는 출력이 입력보다 5배 비싸서, 이 차이가 그대로 비용에 붙습니다. 모델마다 코드를 얼마나 길게 쓰느냐와는 별개로요.

전에 10개 프로그래밍 언어로 같은 코드를 세어 봤을 때도 Claude가 GPT보다 토큰이 43~59% 많았는데, 같은 방향입니다.

## 프롬프트 언어는 입력 토큰을 거의 안 바꾼다

| 입력 토큰 | 영어 | 한국어 | 일본어 | 스페인어 | 우크라이나어 |
|---|---:|---:|---:|---:|---:|
| Claude Code + 오퍼스 5.5 | 96,462* | 78,638 | 79,266 | 79,030 | 79,787 |
| Codex + gpt-6-luna | 51,674 | 48,538 | 48,660 | 48,201 | 48,816 |
| Antigravity + Gemini 4 Argon | 13,041 | 13,289 | 12,408 | 12,629 | 13,447 |
| Antigravity + 오퍼스 5.5 | 9,822 | 11,316 | 9,983 | 9,945 | 10,958 |

*영어 Claude Code 5회 중 2회가 한 번 더 주고받아서 높게 나왔습니다.

프롬프트 자체는 수십 토큰이고, 요청의 나머지는 도구가 넣는 지시문입니다. 입력 크기는 어떤 언어로 쓰느냐가 아니라 어떤 도구를 쓰느냐로 정해집니다.

하나 더: Antigravity의 오퍼스는 한국어와 우크라이나어로 시키면 게임을 더 길게 만들었습니다(영어보다 글자 수가 약 31%, 20% 많음). 그래서 출력 총량은 늘었지만, 1,000자당으로는 같았습니다.

## 게임은 제대로 돌아갔나

80개 중 79개가 정상이었고, 모든 게임이 프롬프트 언어로 화면 글자를 표시했습니다. 안 된 1개는 앞선 실측의 우크라이나어 Codex 게임입니다.
