Make a Sudoku game that runs in the browser as a single file named index.html in the current folder. Use a 9x9 grid of HTML input elements, one per cell. A "New Puzzle" button generates a new random puzzle that has exactly one solution; the given numbers are shown in their inputs and are read-only. The player types digits 1-9 into the empty cells. A "Check" button highlights wrong cells, and a "Solve" button fills every cell with the solution. Start with a puzzle already on the screen. Write the file and finish.
